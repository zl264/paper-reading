01VAE 是什么

一句话：VAE（变分自编码器，Variational Autoencoder）是一种「生成模型」——它学习的不是把输入分类成什么，而是数据本身的分布长什么样，学完后可以从这个分布里采样新样本。它由一个概率化的 Encoder、一个隐变量空间和一个 Decoder 组成，用「变分推断」来训练。

1.1 生成模型 vs 判别模型

先用一个最粗的对比建立位置感。常见的神经网络大多属于判别模型：给定输入 x，预测标签 y（猫还是狗？下一个词是什么？）。而生成模型反过来，它要建模数据本身的分布 p(x)，然后从分布里「无中生有」地采样出新样本。

视角判别模型生成模型
学什么p(y | x)：条件分布p(x)（可能带隐变量 z）
能干什么分类、回归、打标签采样新数据、算似然、补全、去噪
典型代表ResNet、BERT、GPT（判别式用法）VAE、GAN、Diffusion、PixelRNN
难度「照葫芦画瓢」相对容易「造一个新葫芦」难得多

VAE 就是生成模型家族的一员，而且是其中数学结构最优雅、训练最稳定的一支——这也是它至今仍被大量使用的原因。

1.2 历史与出处

  • 2013 年，Diederik Kingma 与 Max Welling 发表《Auto-Encoding Variational Bayes》（arXiv:1312.6114），首次提出 VAE 并给出可扩展到神经网络规模的训练方法；同期 Danilo Rezende 等人也独立提出了几乎相同的思路（"Stochastic Backpropagation and Approximate Inference in Deep Generative Models"）。两篇论文共同开启了深度生成模型的「变分」时代。
  • 名字拆解：Autoencoder 指它的结构形态——一个 Encoder 压缩、一个 Decoder 还原，长得像经典自编码器；Variational 指它的训练方法——用变分推断（用简单分布近似复杂后验分布）来解决不可解的积分。
  • 后续影响：GAN（2014）、Diffusion（2020）相继出现后，三大生成范式并立；而 Stable Diffusion（2022）这个名字里的 "Latent"，指的正是把扩散搬进 VAE 的潜空间——VAE 至今仍是主流文生图模型不可或缺的组件（第 8 章详述）。

1.3 三大生成范式一眼对比

范式核心思想训练稳定性样本质量典型短板
VAE最大化似然下界（ELBO）非常稳定，损失单调可监控偏模糊生成图像平均化、偏糊
GAN生成器与判别器对抗博弈不稳定，易模式坍缩锐利逼真训练难调、多样性差

有趣的联系

从数学上看，Diffusion 可以被写成一种特殊的、隐变量逐步加噪的 VAE（这是论文《Understanding Diffusion Models: A Unified Perspective》的观点）。理解 VAE 的 ELBO，也是理解扩散模型损失的敲门砖。

1.4 VAE 都用在哪

  • 图像生成与隐空间可视化：在 MNIST / 人脸数据集上训练后，可以采样生成新图像，还能把 2 维隐空间画成一张「连续地图」（第 7 章实战）；
  • 潜空间压缩器：Stable Diffusion 用 VAE 把 512×512×3 的图像压到 64×64×4，让扩散模型的计算量降到约 1/48——这是 VAE 在今天最重要、最广泛的应用；
  • 表示学习：隐变量 z 是数据的低维语义压缩，可直接用于分类、检索、聚类；
  • 异常检测：用正常数据训练后，异常样本的重构误差会显著偏高；
  • 科学领域：药物分子生成（图 VAE）、蛋白质结构、语音合成（如早期 Tacotron 系的变分组件）等。

02从自编码器说起：AE 为什么不能生成

VAE 的「A」是 Autoencoder。要理解 VAE 每一处设计，最好的路径是先看普通自编码器（AE）卡在了哪一步——VAE 的所有「怪异」设计（编码分布、KL 正则、重参数化），都是在给 AE 的死穴打补丁。

2.1 自编码器：把压缩学进网络里

自编码器由三段组成：Encoder 把输入 x 压缩成一个低维向量 z（也叫 latent code），Decoder 再从 z 尽量还原出 x̂。训练目标只有一个：让 x̂ 尽量等于 x。

图像 x [784] → Encoder → 隐码 z [20] → Decoder → 重构 x̂ [784] 损失：MSE(x̂, x)，784 维压到 20 维，压掉 97%

因为没有标签，重构目标就是输入本身，所以它属于自监督学习。学到的 z 是数据的一种有损压缩表示，广泛用于降维、去噪、预训练。

看起来一切正常。那如果想让 AE「生成」一张新图像呢？直觉上似乎可行：随便挑一个 20 维向量 z 喂给 Decoder 不就行了？

2.2 悲剧发生：在隐空间里随便挑一个 z

把 MNIST 的 6 万张数字图喂给 AE 训练，encoder 会把每张图映射到 z 空间里的一个点。6 万个训练样本，在 z 空间里留下 6 万个点。问题来了——z 空间是 20 维的连续空间，里面的点有无穷多个，而我们只在 6 万个点的极小邻域训练过 Decoder：

  • 训练时从未见过的 z（哪怕离训练点只有一点点距离），Decoder 的输出完全不可控——多数情况下是一团噪点状的「乱码」；
  • z 空间没有「密度」概念：encoder 只负责把图映射到点，没有任何机制约束这些点在空间里如何分布。哪里是「训练过的区域」、哪里是「空白地带」，模型自己都不知道；
  • 不同类别的编码点在空间里的排布是随机且不规则的，甚至互相纠缠——第 8 类数字的点和第 3 类的点可能交错分布，中间没有任何平滑过渡。

结论：AE 学会了压缩，但没有学会「分布」。它是一个合格的压缩器，却是一个不能用的生成器。

图 2-1 AE 与 VAE 的本质区别。左：AE 把每张图压成一个孤立点，z 空间大片区域从未被训练覆盖，在这些区域解码等于赌博；右：VAE 把每张图编码成一个分布（图中绿色椭圆），并把所有分布都往标准正态 N(0, I) 上拉，整个空间被「填满」，任意采样都是有效输入。

2.3 修法的直觉：从「点」到「分布」

VAE 的解法分两步，直觉非常朴素：

  1. 把「点」升级成「分布」。让 encoder 不再输出一个确定的 z，而是输出一个分布 q(z|x) = N(μ, σ²)——一组均值和方差。这样每个训练样本不再只照亮 z 空间的一个点，而是照亮一小片区域（越「典型」的样本 σ 越大，照亮的范围越大）；
  2. 把所有分布都往同一个「标准形状」上拉。给它们加一条正则：让 q(z|x) 尽量接近标准正态 N(0, I)。于是所有样本的「照明区」互相重叠、铺满整个 z 空间，而且整体呈现出规整的、可采样的高斯形状。

这一改，生成问题就解决了：想生成新图，只要从 N(0, I) 里随机采一个 z，交给 Decoder，出来的就是一张「没见过但合理」的图。

天下没有免费的午餐

「编码一个分布」让训练目标变得完全陌生：重构损失怎么对「一个分布」计算？「拉近两个分布」的距离怎么衡量、怎么可微？这些都必须用概率的语言严格回答，而且里面藏着一个不可解的积分。这就是第 3 章要推的数学——也是 VAE 精髓所在。

03数学原理：变分推断与 ELBO

这一章是 VAE 的核心。我们会从「生成模型想优化什么」出发，遇到那个不可解的积分，然后请出变分推断，一步步推导出 ELBO（证据下界）——VAE 训练损失的真正来源。两种推导都给出，每一步都不跳。

3.1 生成模型想优化什么：对数似然

我们手头有一批数据 x（比如 6 万张手写数字）。生成模型的目标是：找一个带参数 θ 的分布 pθ(x)，让它尽量贴合这批数据的真实分布。衡量「贴合」的标准方法叫最大似然——找一组参数 θ，让已观测到的这批数据出现的概率最大：

θ* = argmaxθ  log pθ(x) log 把连乘变成连加，数值更稳定，也让后面的推导成为可能

接下来的问题是：pθ(x) 这个分布具体怎么设计？直接用神经网络「一步到位」输出 p(x) 很难——图像是上万维的向量，直接对这么高维的空间建模分布，写不出合适的归一化形式。VAE 采用的是隐变量模型的两段式结构：

  • 先取一个简单、已知、好采样的先验：z ~ N(0, I)，z 是低维向量（比如 20 维）；
  • 再用神经网络（这就是未来的 Decoder）建模似然 pθ(x|z)：给定一个 z，输出一个「以 z 为条件」的 x 的分布。

于是整个数据分布由两者复合而成（边缘似然）：

pθ(x) = ∫ pθ(x|z) · p(z) dz 对所有可能的 z 求积分；「从模型生成一张图」= 先采 z，再按 p(x|z) 采样 x

这个形式很漂亮，但正是它埋下了本章最大的麻烦——

3.2 死结：积分不可解，后验也不可解

想把 log pθ(x) 优化起来，必须先把它算出来。但上面这个积分是灾难性的：

  • 没有闭式解：pθ(x|z) 是个神经网络，积分 ∫p(x|z)p(z)dz 对任意非平凡的神经网络都算不出解析形式；
  • 数值积分不可行：20 维的 z，每维哪怕只取 10 个格点，也要算 10²⁰ 次网络前向——宇宙尺度。

再看那条看似「绕开积分」的路——贝叶斯公式算后验：

pθ(z|x) = pθ(x|z) · p(z) / pθ(x) 分母正是那个算不出来的边缘似然——后验同样不可解
这不是 VAE 独有的困境

「边缘似然算不出、后验算不出」是概率建模的经典死结，统计学里已经研究了几十年。传统变分推断的做法是：既然真实后验算不出，那就用一个简单的、可参数化的分布去近似它，再把这个「近似」本身优化到尽量贴近。VAE 的天才之处在于：让「近似分布」由一个神经网络（Encoder）来输出，使这套方法第一次能扩展到深度网络与大数据。

3.3 请出主角：用 Encoder 近似后验

引入一个由参数 φ 参数化的分布 qφ(z|x)——给定输入 x，输出一个关于 z 的分布。用一个神经网络来实现它，这个网络就是 Encoder：

qφ(z|x) = N( μφ(x),  diag(σφ(x)²) ) encoder 对每张图输出一对 (μ, σ)，即第 2 章说的「把点变成分布」的严格版本

现在的局面是：θ（Decoder）想最大化 log pθ(x)，φ（Encoder）想逼近 pθ(z|x)。这两个目标纠缠在一起——而连接它们的桥梁，就是 ELBO。

3.4 ELBO 推导一：从 KL 分解开刀（最推荐掌握的推导）

技巧只有一个：在 log pθ(x) 里硬塞一个 q，再除掉它。从「对联合分布取期望」开始：

log pθ(x) = Ez~qφ(z|x)[ log pθ(x) ] p 与 z 无关，取期望后不变——这一步只是换个视角

用联合分布 pθ(x, z) = pθ(x|z)·p(z) 与贝叶斯公式 pθ(x) = pθ(x, z) / pθ(z|x) 改写 log 内部：

log pθ(x) = Eq[ log pθ(x, z) − log pθ(z|x) ]

再插入 −log q + log q（等于加零），并把式子劈成两项：

log pθ(x) = Eq[ log pθ(x, z) − log qφ(z|x) ]  +  Eq[ log qφ(z|x) − log pθ(z|x) ]

第二项正是 KL 散度的定义式！于是：

log pθ(x) = ELBO(x; θ, φ)  +  DKL( qφ(z|x) ‖ pθ(z|x) ) 第一项取名 Evidence Lower BOund（证据下界）；第二项是 encoder 近似与真后验的差距
这一行是整个 VAE 的心脏，值得反复品味

KL 散度恒非负，所以 ELBO ≤ log pθ(x)——它名副其实地是似然的下界。而 KL 项恰是「encoder 的近似误差」。于是最大化 ELBO 一石二鸟：既直接抬高了似然本身，又压小了 encoder 与真后验的差距（因为 log p 是被近似误差「垫」在下方的，抬下界必然压 gap）。

3.5 ELBO 推导二：Jensen 不等式路线

第二条路从边缘似然出发，把积分改写成对 q 的期望（重要性采样技巧：对任意 q，只要 q 的支撑覆盖 p 即可）：

pθ(x) = ∫ pθ(x|z) p(z) dz = Ez~qφ(z|x)[ pθ(x|z) · p(z) / qφ(z|x) ]

两边取 log，再用 Jensen 不等式（log 是凹函数，期望的 log ≥ log 的期望——注意方向，取负后变成 ≤）：

log pθ(x) = log Eq[ pθ(x|z) p(z) / qφ(z|x) ]  ≥  Eq[ log pθ(x|z) + log p(z) − log qφ(z|x) ] = ELBO

两条路殊途同归。展开后得到 ELBO 最常用的两项式：

ELBO(x; θ, φ) = Ez~qφ(z|x)[ log pθ(x|z) ]  −  DKL( qφ(z|x) ‖ p(z) ) 第一项：重构项；第二项：先验正则项。训练损失 = 负 ELBO

图 3-1 log p 与 ELBO 的关系。KL 项把两者隔开；训练时无法直接触碰紫线（真似然），但抬升绿线（ELBO）时，紫线被 gap「顶」着一起上升。这正是「下界」策略的精妙之处。

3.6 两项式 ELBO 的直观读法

项公式大白话负责的网络
重构项Ez~q[ log p(x|z) ]从 q 里采个 z，解码出来要像原图——保真压力Encoder + Decoder
正则项−DKL(q(z|x) ‖ N(0, I))编码出的分布要靠近标准正态——规整压力Encoder

两股力量天然互相制衡：正则项相当于给 z 通道限流——KL 越小，q 携带的「关于 x 的信息量」越少（极端情形 q 完全无视 x、恒等于 N(0, I)，KL 为 0，但什么都重构不出来）；重构项则逼着 q 往 z 里塞信息以还原 x。最终平衡点决定了隐空间「多有用、多规整」的折中。这个制衡关系是理解第 8 章「后验坍缩」「β-VAE」全部现象的钥匙。

为什么叫「证据」下界？

贝叶斯统计里，观测到的数据 x 被称为 evidence（证据）。ELBO 是这份数据对数似然的 lower bound（下界），因此得名 Evidence Lower BOund。

04重参数化技巧：让梯度穿过随机性

第 3 章推出了漂亮的损失：−ELBO = −Ez~q[log p(x|z)] + KL。但注意那个期望——训练时需要对 z 从 qφ(z|x) 里采样，而「采样」这个操作本身不可导，梯度传不回 φ。重参数化（reparameterization）就是为此而生的工程魔法，也是 VAE 论文标题里 "Stochastic Backpropagation" 的含义。

4.1 问题：采样节点会掐断梯度

把重构项的计算画成数据流图：

x → [fc_mu / fc_logvar] → μ, σ   → 采样 z ~ N(μ, σ²) →  z → [Decoder] → x̂ → loss 采样是一个「随机节点」：ε 从分布里凭空抽出，与 φ 没有可导关系

自动微分依赖「每个中间变量都是输入的确定函数」。而 z ~ N(μ, σ²) 这个操作：同样输入 (μ, σ)，每次输出的 z 却不同——它不是确定函数，反向传播在「采样」这一步就断了。损失对 μ、σ 的梯度全部丢失。

朴素的补救是用蒙特卡洛梯度估计（REINFORCE / score function estimator）：∇E[f(z)] = E[f(z)·∇log q(z)]。它能算，但方差极大，训练慢且不稳。VAE 论文给出了一个又简单又漂亮的替代方案。

4.2 解法：把随机性挪到旁边去

关键观察：高斯分布的采样总能写成「确定性变换 + 独立噪声」的形式。先从一个与参数完全无关的标准正态里采 ε，再用 μ、σ 做一次普通的可导运算：

z = μ + σ ⊙ ε,    ε ~ N(0, I) ⊙ 表示逐元素相乘；μ = μ(x)，σ = σ(x) 由 encoder 输出

分布完全不变（ε 平移缩放后仍是高斯）：若 ε ~ N(0, I)，则 μ + σ⊙ε ~ N(μ, diag(σ²))，与直接采 z 同分布。但计算图上发生了质变：

  • 随机性被「旁路」进了 ε——一个与网络参数无关的外部输入，就像数据噪声一样，不需要求导；
  • z 成为 (μ, σ, ε) 的确定函数：∂z/∂μ = 1，∂z/∂σ = ε，梯度畅通无阻地穿过 z 流回 encoder 的所有参数。

图 4-1 重参数化前后的计算图对比。上：直接在分布上采样，随机节点掐断反向传播；下：噪声 ε 改由旁路注入，z 变成确定函数，梯度（绿线方向）可以一路流回 encoder 参数。

4.3 期望的蒙特卡洛估计

有了可导的 z，重构项的期望用采样近似（蒙特卡洛估计）即可：

Ez~qφ(z|x)[ log pθ(x|z) ]  ≈  (1/L) Σl=1…L log pθ(x | μ + σ ⊙ εl),   εl ~ N(0, I) 实践中几乎总取 L = 1：每个 minibatch 的每个样本各采一次噪声，噪声之间的平均已经提供了积分的方差缩减
一个帮助记忆的类比

把 encoder 想成「工厂」：以前的做法是工厂内部摇骰子直接出货，货出了厂就查不到骰子的影响；重参数化相当于让骰子在厂外由第三方摇好，作为「原材料」送进工厂——工厂内的每道工序（加 μ、乘 σ）都可追溯、可审计（可求导）。分布没变，可导性变了。

05网络结构详解：Encoder、隐空间与 Decoder

数学铺垫完毕，现在把它翻译成具体的网络。VAE 的结构出奇地简单：一个 Encoder、两个线性头（fc_mu 与 fc_logvar）、一次重参数化、一个 Decoder。本章逐层拆解每一件「为什么」，最后给出 CNN 版结构。

5.1 全景图：一次前向的完整数据流

图 5-1 MLP 版 VAE 完整数据流（MNIST，B 为 batch size）。紫线为前向计算，橙线为噪声注入，红虚线为损失来源：重构项对比 x̂ 与 x，KL 项由 (μ, logvar) 与先验 N(0, I) 的闭式距离构成。

5.2 Encoder：一个主干，两个头

Encoder 要输出的是一个分布 q(z|x) = N(μ, diag(σ²))，所以它必须吐出两组数：均值 μ 和（对数）方差。工程上不搞两个独立网络，而是共享主干、只在最后一层分叉：

encoder 部分（PyTorch）Python
# Encoder：共享主干 + 两个投影头
self.enc_fc = nn.Sequential(
    nn.Linear(784, 400),   # 把 784 维图像压到 400 维特征
    nn.ReLU(),
)
self.fc_mu     = nn.Linear(400, z_dim)  # 均值头：输出 μ
self.fc_logvar = nn.Linear(400, z_dim)  # 对数方差头：输出 log σ²

def encode(self, x):
    h = self.enc_fc(x)
    return self.fc_mu(h), self.fc_logvar(h)   # 一图 → 一个分布 (μ, σ)
  • 为什么共享主干：提取「图像有什么内容」的特征对 μ 和 σ 是同一件事，没有必要训练两遍；分叉只发生在最后的线性投影——主干只需对一个 400 维特征做两种不同的「读出」。
  • 两个头只是普通线性层：没有任何激活约束（μ 可以是任意实数，logvar 同样），约束靠损失里的 KL 项「软」地拉出来。
  • 协方差为什么取对角：完整协方差矩阵有 d(d+1)/2 个参数且要求正定，对 20 维的 z 也不小；对角假设（各维独立）让每个样本只需输出 2d 个数，实践中完全够用。

5.3 Decoder：从 z 还原图像

Decoder 是普通的生成网络：输入 20 维的 z，输出 784 维的图像。它的输出被解释为「分布的参数」而不是图像本身——这是初学者最容易忽略的一点：

  • 若用伯努利似然（配合 BCE 损失）：输出层的每个值是像素为 1（前景）的概率，所以最后接 Sigmoid 压到 (0, 1)；
  • 若用高斯似然（配合 MSE 损失）：输出是高斯分布的均值，即「最可能的图像」，Sigmoid 可加可不加。
decoder 部分（PyTorch）Python
# Decoder：从 z 还原 x
self.dec_fc = nn.Sequential(
    nn.Linear(z_dim, 400),
    nn.ReLU(),
    nn.Linear(400, 784),
    nn.Sigmoid(),   # 伯努利似然：输出像素为 1 的概率，配合 BCE 使用
)

def decode(self, z):
    return self.dec_fc(z)   # 生成阶段直接调用这一段即可

5.4 重参数化节点

第 4 章的公式落在代码里只有三行，但每一行都有讲究：

reparameterize（PyTorch）Python
def reparameterize(self, mu, logvar):
    std = torch.exp(0.5 * logvar)   # logvar = log σ²，先还原 σ = exp(½ · logvar)
    eps = torch.randn_like(std)     # 与 std 同形状的标准正态噪声（外部随机性）
    return mu + eps * std           # z 是 (μ, σ, ε) 的确定函数，梯度可穿过

5.5 为什么预测 logvar 而不是直接预测 σ

细心的读者会发现：网络输出的叫 logvar（log σ²）而不是 σ 本身。这不是随意命名，而是数值稳定性的成熟做法：

方案做法问题
直接输出 σσ = fc(x)，必须再 clamp 到正数σ 必须大于 0；若用 clamp 硬截断，边界处梯度为零，网络容易被「卡死」在边界上
输出 logvar（推荐）logvar = fc(x) 无约束，σ = exp(½ logvar)exp 天然保证 σ 为正；网络可在整个实数轴上自由调整方差，logvar = 0 对应 σ = 1，移动一格就翻倍/减半，尺度跨度友好

另一个好处：KL 闭式解里恰好出现 log σ² 项（第 6 章推导），直接用 logvar 代入，一行搞定，无需再取对数。

最常见的实现 bug

把 logvar 直接当 σ 用（漏掉 exp(0.5 * ...)）。症状是训练几乎不收敛或输出全糊。记住输出的名字叫 logvar——它是方差的对数。

5.6 隐空间维度怎么选

  • z_dim = 2：专为可视化——可以直接画在平面直角坐标系上，观察类簇分布与插值（第 7 章实战）；
  • z_dim = 20：MNIST 的经典配置（原论文同款），重构与规整的平衡点；
  • 更大（64~512）：真实图像、更复杂的语义。维度越大重构越清晰，但 KL 要正则的参数也越多，隐空间越难保持规整——通常靠加大 β 或更深的结构（如 NVAE）来平衡。

5.7 升级：CNN 版结构（真实图像用）

MLP 对 28×28 的 MNIST 够用；处理 64×64 以上的自然图像时，Encoder/Decoder 换成卷积网络，其余思想一字不改：

层配置输出形状（64×64 输入）说明
Conv13→32, 4×4, stride 232 × 32 × 32分辨率减半
Conv232→64, 4×4, stride 264 × 16 × 16分辨率再减半
Conv364→128, 4×4, stride 2128 × 8 × 8通道翻倍
Conv4128→256, 4×4, stride 2256 × 4 × 4到达隐层特征
双头两个 1×1 卷积（或分离卷积）μ / logvar 各 256×4×4逐位置输出分布参数
DecoderConvTranspose 逐级上采样… → 3 × 64 × 64镜像还原

注意 CNN 版的 z 不再是一个 20 维向量，而是一张 空间化的特征图（比如 256 通道、4×4 分辨率）——每个空间位置一个分布。这个设计一路进化，最终成为 Stable Diffusion 里 64×64×4 潜空间的雏形（第 8 章）。

06损失函数：重构项与 KL 项完整推导

训练损失 = 负 ELBO。这一章把它的两个组成部分分别推到底：KL 项为什么有闭式解（四步推导）、重构项为什么长得像 BCE 或 MSE（从似然函数推出来），以及工程上最容易踩的 reduction 配比大坑。

6.1 总损失一览

综合第 3~5 章，单个样本的损失为（训练时对 batch 取平均）：

L(x; θ, φ) = −ELBO = 重构项 + KL 项 = −log pθ(x|z)  +  DKL( qφ(z|x) ‖ N(0, I) ) z = μ + σ ⊙ ε 由重参数化采样得到；重构项展开见 6.3，KL 项闭式解见 6.2
L(x; θ, φ) ≈ BCE(x̂, x)  +  ½ Σj=1…d( μj² + σj² − log σj² − 1 ) BCE 版（MNIST 系）；若用高斯似然，第一项换成 ‖x − x̂‖²（MSE 版）

6.2 KL 项闭式解：四步推导

两个分布都很简单：q(z|x) = N(μ, σ²I)（对角），先验 p(z) = N(0, I)。KL 定义为 E_q[log q − log p]，逐步展开：

第①步：写出两个对数密度

log q(z|x) = −(d/2)·log 2π − Σj log σj − ½ Σj (zj − μj)² / σj²
log p(z) = −(d/2)·log 2π − ½ Σj zj² d 为 z 的维度；高斯密度的标准形式取对数

第②步：相减（log 2π 项直接抵消）

log q − log p = Σj [ −log σj − ½ (zj − μj)²/σj² + ½ zj² ]

第③步：在 q 下取期望（用两个基本事实）

Eq[(zj − μj)²] = σj²（方差的定义），    Eq[zj²] = μj² + σj²（二阶矩 = 均值² + 方差）

代入第②步，每一维得到：

Eq[·] = −log σj − ½ + ½ μj² + ½ σj²

第④步：整理成标准形式

DKL( q(z|x) ‖ N(0, I) ) = ½ Σj=1…d( μj² + σj² − log σj² − 1 ) 自检：当 q 恰好等于 N(0, I)（μ=0, σ=1）时，每项 = ½(0+1−0−1) = 0，KL 为零 ✓

用网络输出的 logvar 表示（log σ² = logvar，σ² = exp(logvar)），就是代码里那行著名的公式：

KL = −½ Σj( 1 + logvarj − μj² − exp(logvarj) )
这个公式的「物理读法」

μ² 项惩罚「均值离 0 太远」——把编码中心拉回原点；σ² − log σ² − 1 项惩罚「方差偏离 1」（在 σ=1 处取最小值 0，过小或过大都吃亏）——把编码范围拉成标准宽度。两项合起来正是第 2 章「把所有分布拉向 N(0, I)」的数学实现。

6.3 重构项：BCE 和 MSE 都是「选了个分布」的结果

重构项 −log pθ(x|z) 的形状取决于我们为 decoder 的输出指定哪种分布族。两种主流选择：

选择一：伯努利似然 → BCE 损失

把每个像素看作一次独立的抛硬币（取值为 1 的概率是 x̂i）：

p(x|z) = Πi=1…D x̂ixi (1 − x̂i)1−xi D 是像素总数（MNIST 为 784）；decoder 输出经 Sigmoid，恰是合法的概率

取负对数：

−log p(x|z) = −Σi[ xi log x̂i + (1 − xi) log(1 − x̂i) ] = BCE(x̂, x)

这正是 PyTorch 的 binary_cross_entropy。黑底白字、前景背景近乎二值的 MNIST 是它的主场。

选择二：固定方差的高斯似然 → MSE 损失

把 decoder 输出解释为高斯分布的均值，方差固定为常数 σ²（常取 1 或 1/2）：

log p(x|z) = −‖x − x̂‖² / (2σ²) − D·log σ − (D/2)·log 2π 后两项与 θ 无关是常数，优化时可以扔掉

于是最大化对数似然等价于最小化 ‖x − x̂‖²（MSE），只差一个随 σ 变化的系数——这个系数在实践中常被吸收进重构/KL 的权重配比。自然图像（连续色彩）用这路更合适。

似然选择损失形式Decoder 末端适用数据
伯努利BCE（逐像素求和）SigmoidMNIST、二值图、笔画类
高斯（固定 σ）MSE（差一个系数）恒等或 Sigmoid自然图像、连续灰度/彩色

6.4 工程大坑：reduction 的配比

两个数值口径必须对齐，这是新手 VAE「训出来一团糊」的头号原因：

loss_function（正确示范）Python
def loss_function(x_hat, x, mu, logvar):
    # ① 重构项：BCE 逐像素求和（batch 内稍后统一除以 batch size）
    recon = F.binary_cross_entropy(x_hat, x, reduction="sum")
    # ② KL 闭式解：−½ Σ (1 + logvar − μ² − exp(logvar))，同样是全量求和
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    # 两项同口径后按 batch 平均，保证学习率稳定
    return recon / x.size(0), kl / x.size(0)
错误示范：口径不一致Python
# 错误：重构项用 mean（被像素总数 784 摊薄），KL 却是全量求和
recon = F.binary_cross_entropy(x_hat, x, reduction="mean")
kl    = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
total = recon + kl
# 后果：KL 的相对权重凭空放大约 784 倍 —— 正则压倒保真，
# encoder 输出被强行拉平，所有图像的编码挤成一团，输出糊成灰雾
配比方式重构项KL 项效果
sum / sum（推荐）sum（像素）÷ batchsum（维度）÷ batch两项天然同量级，无需调权
mean / sum（错误）mean（像素）÷ batchsum（维度）÷ batchKL 相对过强，过度正则，输出模糊
mean + β（可选）mean（像素）mean（维度）× β两项都被归一到 O(1)，用 β 手动控制权衡（β-VAE 的做法）
调参直觉

训练日志里同时打印两项。健康的状态是：重构项稳步下降，KL 从 0 先升后回落到某个不为 0 的平衡值（通常几到几十 nats）。若 KL 一路掉到接近 0：发生了「后验坍缩」（第 8 章）；若重构项始终不动：正则太强，检查 reduction 配比或降低 β。

7.1 完整的 VAE 模型类

model.py —— VAE 模型定义Python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VAE(nn.Module):
    def __init__(self, x_dim=784, h_dim=400, z_dim=20):
        super().__init__()
        # ---------- Encoder：共享主干 + 双头（第 5.2 节） ----------
        self.enc_fc = nn.Sequential(
            nn.Linear(x_dim, h_dim),
            nn.ReLU(),
        )
        self.fc_mu     = nn.Linear(h_dim, z_dim)   # 均值头：输出 μ
        self.fc_logvar = nn.Linear(h_dim, z_dim)   # 对数方差头：输出 log σ²

        # ---------- Decoder（第 5.3 节） ----------
        self.dec_fc = nn.Sequential(
            nn.Linear(z_dim, h_dim),
            nn.ReLU(),
            nn.Linear(h_dim, x_dim),
            nn.Sigmoid(),   # 伯努利似然：输出 [0,1]，配合 BCE
        )

    def encode(self, x):
        h = self.enc_fc(x)
        return self.fc_mu(h), self.fc_logvar(h)

    @staticmethod
    def reparameterize(mu, logvar):
        std = torch.exp(0.5 * logvar)   # logvar 是 log σ²，先还原 σ（第 5.5 节）
        eps = torch.randn_like(std)     # 外部噪声，与参数无关（第 4 章）
        return mu + eps * std           # 可导的采样

    def decode(self, z):
        return self.dec_fc(z)

    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        x_hat = self.decode(z)
        return x_hat, mu, logvar   # 损失需要的三元组


def loss_function(x_hat, x, mu, logvar):
    # ① 重构项：BCE 逐像素求和（第 6.3 节）
    recon = F.binary_cross_entropy(x_hat, x, reduction="sum")
    # ② KL 闭式解：−½ Σ (1 + logvar − μ² − exp(logvar))（第 6.2 节）
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    # 同口径后按 batch 平均
    return recon / x.size(0), kl / x.size(0)

结构对照第 5 章图 5-1 逐行可查：enc_fc 是 Encoder 主干，fc_mu / fc_logvar 是分叉的双头，reparameterize 是噪声旁路，dec_fc 是 Decoder。整个模型的参数量约 52 万，CPU 也能在几分钟内训完 MNIST。

train.py —— 完整训练循环Python

from torchvision import datasets, transforms
from torch.utils.data import DataLoader
from model import VAE, loss_function

model = VAE().to(device)

for epoch in range(1, 21):
    model.train()
    tot_rec = tot_kl = tot_n = 0
    for x, _ in loader:
        x = x.view(x.size(0), -1).to(device)   # [B,1,28,28] → [B,784]
        optimizer.zero_grad()
        x_hat, mu, logvar = model(x)
        recon, kl = loss_function(x_hat, x, mu, logvar)
        (recon + kl).backward()
        optimizer.step()
        bs = x.size(0)
        tot_rec += recon.item() * bs
        tot_kl  += kl.item() * bs
        tot_n   += bs
    print(f"epoch {epoch:2d}  recon {tot_rec/tot_n:8.2f}  kl {tot_kl/tot_n:6.2f}")

08进阶话题：模糊、坍缩与 Stable Diffusion

前七章搭建的是「标准 VAE」。它在 MNIST 上已经能跑通，但一旦换成更真实、更多样的图像，两个著名问题就会浮出水面：生成模糊与后验坍缩。本章解释它们的成因与主流对策（β-VAE、VQ-VAE），最后看清 VAE 在 Stable Diffusion 这类现代系统里真正的位置——它不再是生成模型本身，而是压缩引擎。

8.1 为什么 VAE 生成的图像总是模糊的？

一句话答案：MSE / BCE 这类逐像素损失的最优解是条件均值，而均值在多模态分布上必然模糊。推导只需一步：固定 z，decoder 的输出 x̂ 是确定值，而真实数据 x 在这个 z 下可能有多种形态。对二次损失求最优：

x̂*(z) = Ex~p(x|z)[x] = ∫ x · p(x|z) dx 逐像素 MSE 的最优解是条件均值；第 6 章讲过 BCE（伯努利 NLL）的最优解同样是条件均值——两种「标准损失」殊途同归

问题就出在「条件均值」四个字上。设想 z 编码了「一张数字 1」，但训练集里的 1 有的笔画偏左、有的偏右——真实的 p(x|z) 是双峰分布。decoder 只能输出一个答案，于是它输出两峰的平均：一条又粗又淡、不左不右的笔画。每个像素都经历同样的平均，整张图自然糊掉。而 GAN 清晰的原因也在这里：判别器判断的是「这张图像像不像真的」，均值图像恰好落在两个峰之间的低密度区，会被判假——生成器被迫把概率质量坍缩到某个具体模态上，输出锐利样本。

缓解手段思路代表
感知损失（LPIPS）用深度特征距离代替逐像素距离——均值图像在特征空间同样被惩罚SD 的 VAE
对抗损失引入判别器直接惩罚「看起来假」的模糊输出VQ-VAE-2、SD 的 VAE
离散化隐空间decoder 输入是确定性码字，不存在「均值化」VQ-VAE（8.4 节）
事后超分生成后再接一个超分网络修细节早期工业方案

8.2 后验坍缩：隐变量「罢工」

第二个问题的表现是：训练到一半，KL 项悄悄掉到 ≈ 0。

KL( qφ(z|x) ‖ p(z) ) → 0  ⟹   q(z|x) ≈ N(0, I) 对所有 x 成立 每个样本的编码分布都退化成先验本身——z 不再携带任何关于 x 的信息

此时隐变量通道彻底「断供」：encoder 传不出信息，decoder 全靠自己「记住」训练集。训练损失看起来完全正常（重构很好、KL 为 0），但采样生成时 decoder 面对的是一个它从未见过的、不含任何信息的 z——输出全是糊图。这就是后验坍缩（posterior collapse）。

为什么优化器偏爱这条路？两个梯度方向的比赛不公平：让 KL 下降只需把 (μ, σ) 拉向 (0, 1)，这是一条平坦好走的下坡路；让重构变好则要求 decoder 学出复杂映射，下降缓慢。只要 decoder 容量足够——尤其是自回归 decoder（逐像素条件生成，看前几个像素就能猜出下一个，根本不需要 z）——「不用 z 也能重构」就是可行解，优化器自然会砍掉这条信息通道。文本 VAE 用 LSTM decoder 时坍缩尤其严重，原因相同。

诊断方法

同时打印两项损失曲线。健康的训练：KL 先快速上升（信息涌入 z）再缓慢回落，稳定在一个正数。坍缩的典型曲线：KL 早早触零且不再回升，重构损失反而漂亮——一旦出现，先检查 KL 是否被 reduction 口径错误放大（6.4 节），再考虑下面的缓解手段。

8.3 β-VAE：一个旋钮换解耦

β-VAE 只改一个字符——给 KL 项乘上系数 β：

Lβ = Eq[ log pθ(x|z) ] − β · KL( qφ(z|x) ‖ p(z) )，β ≥ 1 β=1 退化为标准 VAE；经典设置 β=4

β 调大后发生了一件有趣的事：隐空间各维度开始解耦（disentanglement）——每个维度趋向于独立控制一个语义因子。在 MNIST 上滑动 β=4 模型的某个维度，数字的「倾斜角度」连续变化而笔画粗细不变；滑动另一个维度则专门控制粗细。直觉解释：加重的 KL 相当于收紧「信息预算」，encoder 被迫用最经济的方式编码——把天然独立变化的语义因子分摊到不同维度，恰是最省 KL 的编码方案。

代价同样是信息被过度丢弃：重构更差、更模糊。β 实质是重构保真 ↔ 隐空间解耦之间的旋钮，没有免费午餐。代码上只有一行差异：

β-VAE 损失（对照 6.4 节的标准版）Python
def loss_function_beta(recon, x, mu, logvar, beta=4.0):
    # 与 6.4 节完全一致，仅 KL 项多乘一个 beta
    recon = F.binary_cross_entropy(recon, x.view(-1, 784), reduction="sum")
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return (recon + beta * kl) / x.size(0)

8.4 VQ-VAE：把「分布」换成「码本」

模糊与后验坍缩这两个顽疾，都源自 VAE「连续 + 概率化」的隐空间设计。VQ-VAE（Vector-Quantized VAE）的解法干脆利落：隐空间不要连续分布，改成 K 个可学习的离散码字（codebook）。流程三步：

x → Encoder → 连续特征 ze(x) → 最近邻查码本（K 个码字）→ 离散码 zq(x) → Decoder → 重构 x̂ 量化：每个空间位置独立地在 K 个码字里挑 L2 距离最近的一个
zq(x) = ek，  k = argminj ‖ ze(x) − ej ‖₂

argmin 不可导，训练靠两件「外科手术」式的技巧：

  • 损失三件套（把 argmin 拆到损失里去优化）：
    L = log p(x|zq) + ‖ sg[ze(x)] − e ‖² + β‖ ze(x) − sg[e] ‖² 第一项重构；第二项把被选中的码字 e 拉向 encoder 输出；第三项（commitment）反过来把 encoder 输出拴在码字附近，防止它漂移；sg = stop-gradient，β 通常取 0.25
  • 直通估计（straight-through estimator）：前向正常用量化值 zq，反向时把 decoder 对 zq 的梯度原封不动抄给 ze——量化节点对梯度「透明」。
向量量化层（PyTorch，可插入任意 CNN 的 encoder/decoder 之间）Python
class VectorQuantizer(nn.Module):
    def __init__(self, num_codes=512, code_dim=64, beta=0.25):
        super().__init__()
        self.codes = nn.Embedding(num_codes, code_dim)  # 码本：K 个 D 维码字
        self.beta = beta
        nn.init.uniform_(self.codes.weight, -1/num_codes, 1/num_codes)

    def forward(self, z_e):
        # z_e: [B, D, H, W]，把每个空间位置当成一个待量化向量
        flat = z_e.permute(0, 2, 3, 1).reshape(-1, z_e.size(1))   # [N, D]
        dist = torch.cdist(flat, self.codes.weight)               # [N, K] L2 距离
        idx = dist.argmin(1)                                      # 每行挑最近码字
        z_q = self.codes(idx).view(z_e.shape).permute(0, 3, 1, 2) # 查表替换
        # codebook 项 + commitment 项（sg 用 detach 实现）
        loss = F.mse_loss(z_q, z_e.detach()) + self.beta * F.mse_loss(z_e, z_q.detach())
        # 直通估计：前向用 z_q，反向梯度绕过量化直达 z_e
        z_q = z_e + (z_q - z_e).detach()
        return z_q, loss

这套设计同时治好了两个老毛病：无后验坍缩——先验是「码字使用分布」，不存在每个维度对齐 N(0, I) 的要求，信息通过离散选择照常流动；重构锐利——decoder 输入是确定性码字，条件均值化无从谈起。代价是新问题：不能直接从 N(0, I) 采样生成，必须再训一个自回归先验（如 PixelCNN）来逐格生成码字序列，两阶段才完成生成。影响深远：DALL·E 的 dVAE、以及现代「视觉 tokenizer」路线（把图像变成 token 序列交给 Transformer）都发源于此。

8.5 Stable Diffusion 中的 VAE：从生成模型到压缩引擎

直接在像素空间做扩散太贵：512×512×3 的图约 78 万维，UNet 每一步去噪都要在这个维度上做卷积与注意力。Stable Diffusion 的第一性原理选择：先训一个 VAE 把图像压缩到 latent，扩散模型只在 latent 上运行，生成完再解码回像素。

512×512×3  →  64×64×4    空间 8× 下采样，体积压缩 48× latent 再乘缩放因子 0.18215 归一到单位方差附近，方便扩散模型建模

这个 VAE（diffusers 里叫 AutoencoderKL）的训练目标与传统 VAE 截然不同——重构不再是 BCE/MSE 独挑大梁，而是四种损失的组合：

Lautoenc = Lrecon(L1) + λlpips·LLPIPS + λadv·L对抗 + λkd·KL，  λkd ≈ 4×10−6 L1 管像素对齐，LPIPS 管感知相似，对抗损失管「看起来真」——正是 8.1 节开出的模糊处方

注意 KL 的权重小到 10−6 量级。原因：SD 里 VAE 的职责不是生成，而是规整地压缩。采样路径上的 latent 完全由扩散模型给出，VAE 只负责 decode；KL 只需轻轻拢住 latent 分布（别漂到无限远、别留太多「空洞」让扩散模型难建模），不需要为「能采样」付重构的代价。这也解释了 8.1 表格里的选择：模糊靠 LPIPS + 对抗解决，而不是靠加重 KL。

整个扩散训练期间 VAE 参数完全冻结——扩散模型学的是 p(latent)，与 VAE 解耦。两条路径各取一半：

9.1 故事线回顾：五步看懂 VAE

AE 压缩但不生成 → 点改成分布 N(μ, σ²) → 似然不可解，改 maximize ELBO → 重参数化让梯度穿过采样 → 两项损失，一百行代码
  1. 病灶诊断（第 2 章）：AE 的隐空间只有零散的训练点，任意采样的 z 解码出垃圾——生成需要的是填满且连续的隐空间。
  2. 对症下药（第 2~3 章）：把「每个 x 编码成一个点」改成「编码成一个分布 q(z|x)=N(μ, σ²)」，并用 KL 把所有分布向统一的先验 N(0, I) 拢——隐空间被摊平成连续地图。
  3. 数学落地（第 3 章）：直接最大化似然 p(x) 积不出、后验算不动，转而最大化它的下界 ELBO = 重构项 − KL 项，一步把「学得好」和「空间规整」写进同一个目标。
  4. 梯度手术（第 4~6 章）：KL 有闭式解；重构用单样本蒙特卡洛估计；采样节点用重参数化 z = μ + σ⊙ε 绕开不可导——三条路铺平反向传播。
  5. 工程实现（第 5~7 章）：双头 encoder、直通采样、两项相加 backward；reduction 口径统一是新手最大的坑。

9.3 训练 Checklist

动手训一个新 VAE（或排查旧代码）之前，从上到下过一遍：

  1. 数据归一到 [0,1]（ToTensor()）；用 BCE 则 decoder 末尾必须有 Sigmoid；数据标准化到 (−1,1) 时改用 MSE。
  2. logvar 头预测的是 log σ²；还原 σ 一律 torch.exp(0.5 * logvar)。
  3. 重构项与 KL 项都取 reduction="sum"，再各自除以 batch size——口径必须一致（6.4 节）。
  4. 两项相加前先分别 print 数值量级，确认谁强谁弱，再谈调参。
  5. KL 健康曲线：先升后稳在正数；早早触零即后验坍缩（8.2 节），先查 reduction 再试退火。
  6. KL 过强压死重构时：KL 退火（β 从 0 缓升至 1）或 free bits。
  7. 可视化选 z_dim=2 画网格；实用选 20 起步；CNN 版按 5.5 节表格配通道。
  8. eval 模式可固定用 μ 代替采样，让重构结果可复现。
  9. 优化器 Adam、lr=1e-3 起步；判断质量看 sample() 的输出而非只看 loss。
  10. 输出糊且各项都「正常」：这不是 bug，是 MSE/BCE 的均值化本质——上 LPIPS / 对抗（8.1 节）。
