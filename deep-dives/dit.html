DiT：把扩散去噪器改写为潜空间 Transformer

从 VAE 潜变量分块、adaLN-Zero、噪声与方差双头，到官方 PyTorch 采样调用链。

1. 问题定义：替换的是去噪器，不是扩散概率模型

DiT 要回答的不是“Transformer 能否做图像分类”，而是：在已有的潜空间扩散框架中，能否移除惯用的卷积 U-Net，同时保留稳定的训练和良好的规模扩展性。输入包括带噪潜变量 zt、离散扩散时间步 t 和 ImageNet 类别 y；输出是与输入空间尺寸相同的噪声预测和反向方差参数。生成图像时再从高斯噪声出发反复调用去噪器，最后交给冻结的 VAE 解码器。

因此，它是两个已有组件与一个替换主干的组合：Stable Diffusion 的现成 VAE 负责像素和潜空间之间的映射；ADM 风格的离散高斯扩散负责加噪、训练目标与反向转移；DiT 只负责学习条件去噪函数。与 U-Net 的局部卷积、多尺度跳跃连接不同，DiT 把二维潜特征统一转成 token，在所有块里做全局自注意力。它没有逐级升降采样，也没有 U-Net 式 encoder-decoder 跳连。

术语边界：“DiT-XL/2”中的 2 是潜空间 patch 边长，不是 RGB 图像的 2 像素 patch。256×256 图像先被下采样八倍为 32×32×4，再切成 2×2 的潜变量块，得到 256 个 token。

2. 扩散目标：一条前向公式对应两种训练损失

令 z0 = s·E(x) 为 VAE 编码并缩放后的潜变量，官方训练代码取 s = 0.18215。预定义 βt，令 αt = 1 − βt，ᾱt = ∏i=1…tαi。前向过程不必逐层模拟，一次采样即可得到任意时刻的带噪输入：

zt = √ᾱt z0 + √(1 − ᾱt) ε，   ε ~ 𝒩(0, I)(1)

这里 ε 是与 z0 同形状的标准高斯噪声。网络以 EPSILON 为目标，均方误差是 Lsimple = E‖ε − εθ(zt,t,y)‖²。若需要学习反向协方差，仅最小化这个误差并不足够；官方配置使用 LEARNED_RANGE，把额外通道解释为方差插值系数，再加入变分界项。

log σ²θ = (1 − v) log β̃t + v log βt，   v = (vraw + 1) / 2(2)

β̃t 是由 z0 和 zt 得到的后验方差。训练方差时，代码把噪声输出 detach() 后拼回方差输出，避免 VLB 的梯度改变均值预测。训练总项因此是 L = Lsimple + Lvlb，而不是把八通道输出统一做一次 MSE。由噪声可恢复干净潜变量：

ẑ0 = (zt − √(1 − ᾱt) εθ) / √ᾱt(3)

推理分布 pθ(zt−1|zt,y) 的均值由这个 ẑ0 和真实后验系数构成，协方差来自式（2）。注意论文正文有时把数据变量写作 x，而开源实现的 DiT 输入变量写作 x、实际装载的是 VAE latent；本文统一用 z 强调这一区别。

3. Patchify：卷积投影等价于不重叠线性嵌入

models.py 用 timm 的 PatchEmbed。对于 N×4×I×I 输入，卷积核与步长均为 p，将每个 p×p×4 小块展平并线性投影到 D 维，再变为 N×T×D，其中 T = (I/p)²。随后直接加上固定的二维正弦余弦位置编码；该参数 requires_grad=False，不是训练得到的类别 token，也不会向序列附加 CLS token。

例如 512×512 图像对应 64×64×4 潜变量，XL/2 得到 1024 个 1152 维 token；同一模型改为 p=4 时仅 256 个 token。unpatchify 是严格的重排逆过程：每个 token 被线性映射为 p²×Cout，先恢复 N×h×w×p×p×Cout，再转为 N×Cout×hp×wp。

官方源码节选 · models.py：主前向与 unpatchify
# 省略构造函数；c_out = 2 * in_channels（learn_sigma=True）
def forward(self, x, t, y):
    x = self.x_embedder(x) + self.pos_embed  # (N, T, D)
    t = self.t_embedder(t)                   # (N, D)
    y = self.y_embedder(y, self.training)    # (N, D)
    c = t + y                                # (N, D)
    for block in self.blocks:
        x = block(x, c)                      # (N, T, D)
    x = self.final_layer(x, c)               # (N, T, p*p*c_out)
    return self.unpatchify(x)                # (N, c_out, H, W)

def unpatchify(self, x):
    c, p = self.out_channels, self.x_embedder.patch_size[0]
    h = w = int(x.shape[1] ** 0.5)
    x = x.reshape(x.shape[0], h, w, p, p, c)
    x = torch.einsum('nhwpqc->nchpwq', x)
    return x.reshape(x.shape[0], c, h * p, h * p)

位置编码按 h、w 两个坐标分别产生 D/2 维频率特征再拼接。默认实现用 int(sqrt(T)) 恢复方格，所以直接改成非方形潜图需要同时调整网格形状和 unpatchify，不能仅更换输入尺寸。

4. adaLN-Zero：条件不是序列 token，而是每个残差分支的调制器

时间步先通过 256 维正弦频率编码和两层 SiLU MLP；类别通过嵌入表，训练时以默认 0.1 概率替换为编号 1000 的可学习空类别。二者相加得到 c = et + ey ∈ RN×D。每个 DiT block 先用 SiLU+Linear(c) 产生六组 D 维向量，分别控制注意力和 MLP 两个分支：

mod(u, b, g) = LN(u) ⊙ (1 + g) + b；   x ← x + amsa ⊙ MSA(mod(x,bmsa,gmsa))(4)

式中的 b 是 shift、g 是 scale、a 是 residual gate，广播到全部 T 个 token。第二个分支同理，将 MSA 换成 MLP。LayerNorm(elementwise_affine=False) 本身没有可学习仿射参数，尺度和偏移完全来自条件。MLP 隐藏层为 4D，激活采用 tanh 近似的 GELU，注意力投影带 QKV bias。

官方源码节选 · models.py：完整 DiTBlock 数据流
def modulate(x, shift, scale):
    return x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)

class DiTBlock(nn.Module):
    def __init__(self, hidden_size, num_heads, mlp_ratio=4.0):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_size, elementwise_affine=False, eps=1e-6)
        self.attn = Attention(hidden_size, num_heads=num_heads, qkv_bias=True)
        self.norm2 = nn.LayerNorm(hidden_size, elementwise_affine=False, eps=1e-6)
        self.mlp = Mlp(hidden_size, hidden_features=int(hidden_size * mlp_ratio),
                       act_layer=lambda: nn.GELU(approximate="tanh"), drop=0)
        self.adaLN_modulation = nn.Sequential(
            nn.SiLU(), nn.Linear(hidden_size, 6 * hidden_size, bias=True))

    def forward(self, x, c):
        b1, g1, a1, b2, g2, a2 = self.adaLN_modulation(c).chunk(6, dim=1)
        x = x + a1.unsqueeze(1) * self.attn(modulate(self.norm1(x), b1, g1))
        x = x + a2.unsqueeze(1) * self.mlp(modulate(self.norm2(x), b2, g2))
        return x

“Zero” 是初始化事实而非推理时把条件清零：所有 block 的调制线性层权重与偏置均置零，所以 shift、scale、gate 初始都是零，两个残差增量均为零，整块初始为恒等映射。最终层的调制层和输出线性层也全零初始化，使初始噪声与方差原始输出为零；后者仍要经过式（2）的插值和指数变换，并不表示实际反向方差为零。相较把条件拼进序列或另加 cross-attention，adaLN 只施加 token 共享的逐通道变换，计算开销较小；论文的消融也表明，这种零初始化不只是可有可无的工程细节。

5. epsilon / sigma 不是两个网络：是同一解码层的八通道输出

输入潜变量为 4 通道。默认 learn_sigma=True，因此 out_channels = 2 * in_channels = 8，最终 FinalLayer 仍由条件 shift/scale 调制，再把每个 token 映射到 p²×8。扩散器在通道维切成前四通道 epsilon 与后四通道方差原始值，而非分别实例化一个噪声 Transformer 和一个方差 Transformer。关闭 learn_sigma 才会得到四通道，并选择固定方差。

官方源码节选 · diffusion/__init__.py 与 gaussian_diffusion.py
# create_diffusion 默认 predict_xstart=False, learn_sigma=True
model_mean_type = gd.ModelMeanType.EPSILON
model_var_type = gd.ModelVarType.LEARNED_RANGE

# p_mean_variance 中把同一输出的两个半区分别解释
model_output, model_var_values = th.split(model_output, C, dim=1)
min_log = _extract_into_tensor(self.posterior_log_variance_clipped, t, x.shape)
max_log = _extract_into_tensor(np.log(self.betas), t, x.shape)
frac = (model_var_values + 1) / 2

由于代码没有 sigmoid 限制 v_raw，插值系数 v 并非严格保证处于 [0,1]；它通过学习逼近合适范围。最后一步反向采样通过 nonzero_mask=(t != 0) 禁止额外高斯扰动，避免在最终潜变量上再加噪声。采样 API 的 clip_denoised 在官方 sample.py 中显式设为 False，原因正是扩散空间是缩放 latent，不应以 RGB 的 [-1,1] 范围截断。

6. 规模扩展：参数量、token 数和单次前向 FLOPs 必须分开

论文固定扩散过程，系统改变深度 N、隐藏维 D、注意力头数与 patch 大小。扩大宽深增加参数和计算；减小 p 只增长序列，主干权重规模基本不变，却让自注意力的 pairwise 计算按 T² 增长。论文最重要的观察是 Gflops 与生成质量的关联，而不是“只要参数更多就更好”。

DiT-S12 / 384 / 61.416.0668.40

DiT-XL28 / 1152 / 1629.05118.6419.47

表中 FLOPs 是 256×256、I=32 的 DiT 单次前向估计，不含 VAE；FID-50K 为无 classifier-free guidance 的结果，不能和最终使用 CFG 的 2.27 混列。XL/2 训练到 7M 步、cfg=1.5 时报告 FID-50K 2.27；无引导时为 9.62。512×512 的 XL/2 因 token 从 256 增至 1024，报告 524.6 Gflops。

论文还发现，小模型简单增加采样步数并不能补齐与大模型的质量差距。内存方面，注意力显式矩阵的 N×heads×T×T 是复现时的直接压力；训练还需保存每层激活。官方最小训练脚本没有自动混合精度、梯度累积、梯度检查点或断点恢复，因此不能把“源码能启动”误解为低显存可复现。

7. 训练调用链：VAE 采样、随机时间步、VLB 与 EMA

论文实验采用 ImageNet 类别条件，256 和 512 两种分辨率；所有尺寸共享 AdamW、恒定学习率 10−4、无 weight decay、全局 batch 256、水平翻转、EMA 衰减 0.9999，不需要 warmup。默认 beta 是 1000 步、10−4 到 0.02 的线性表。官方 JAX/TPU 实验与公开 PyTorch 实现应分开理解：论文模型最初在 JAX 训练，仓库权重由 JAX 移植。

官方源码节选 · train.py：单个优化步骤
diffusion = create_diffusion(timestep_respacing="")  # 1000 步
opt = torch.optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0)
# x 已经过 center crop、随机水平翻转并归一化到 [-1, 1]

    x = vae.encode(x).latent_dist.sample().mul_(0.18215)

编码使用 latent_dist.sample() 而非后验均值，VAE 不参与反向传播。DiT 模型需保持 train()，否则 10% 的类别 dropout 不生效；EMA 副本则保持 eval()。DDP 每卡 batch 是全局 batch / world size，数据经 DistributedSampler 划分，初始化 EMA 前先从各 rank 同步模型参数。论文结果使用 EMA 权重，而 sample.py 对自行训练的检查点依赖 find_model 选择相应 ema 字典。

8. 采样与 CFG：双倍 batch 的前半、后半不能颠倒

官方默认从 N(0,I) 潜噪声开始，执行 250 步 DDPM。create_diffusion(str(num_sampling_steps)) 通过 SpacedDiffusion 重排原 1000 步时间索引；它仍使用模型学习到的方差。反向单步为 zt−1 = μθ + 1[t≠0]·exp(½logσ²θ)·ε。仓库也实现了 DDIM，但默认 sample.py 走的是 p_sample_loop，不要把 250 步默认脚本称为 DDIM。

分类器自由引导在训练时学习空类别，在推理时组合 ε̂ = εu + s(εc − εu)。官方 forward_with_cfg 接收 batch 前半为条件、后半为空条件的副本；只取同一张图的输入，计算一次包含两份的前向，再把引导后的 epsilon 复制回两半。一个极易遗漏的历史细节是它默认只引导前三个通道，第四个噪声通道和全部方差通道均不做 CFG 外推。

官方源码节选 · models.py：真实的三通道 CFG
def forward_with_cfg(self, x, t, y, cfg_scale):
    half = x[:len(x) // 2]
    combined = torch.cat([half, half], dim=0)
    model_out = self.forward(combined, t, y)
    # 官方复现默认仅前 3 个 epsilon 通道使用 CFG
    eps, rest = model_out[:, :3], model_out[:, 3:]
    cond_eps, uncond_eps = torch.split(eps, len(eps) // 2, dim=0)
    half_eps = uncond_eps + cfg_scale * (cond_eps - uncond_eps)
    eps = torch.cat([half_eps, half_eps], dim=0)
    return torch.cat([eps, rest], dim=1)
官方源码节选 · sample.py：初始噪声到 RGB 的边界
latent_size = args.image_size // 8

cfg_scale=1 恢复条件预测，并不等于关闭两份前向；小于 1 会向无条件方向外推，更大值通常提高类别一致性而牺牲多样性。修改随机种子会改变初始噪声；修改类别列表则同时决定 batch 大小。最后必须除以训练时的 0.18215 再调用 VAE decode，否则会形成明显尺度失配。

9. 仓库结构、依赖和论文—代码边界

最小阅读顺序是 models.py → train.py / sample.py → diffusion/__init__.py → respace.py → gaussian_diffusion.py。模型层只负责 DiT(x,t,y)；扩散层负责 q_sample、training_losses、p_mean_variance 和 p_sample_loop；download.py 负责预训练权重，sample_ddp.py 批量导出 FID 样本。核心依赖包括 PyTorch、torchvision、timm、diffusers、NumPy，以及训练时的 NCCL/DDP 环境。

复现边界：官方自动下载只支持 DiT-XL/2、256×256 或 512×512、1000 类；其他命名配置是模型结构，不表示仓库提供对应预训练权重。论文的 TPU-v3 速度也不能直接外推到消费级 GPU。该固定版本代码与权重采用 CC-BY-NC 许可，部署前应另行核对许可。

VAE 是外部 stabilityai/sd-vae-ft-ema 或 sd-vae-ft-mse，并不包含在 DiT 参数或 FLOPs 统计中。编码器相同意味着可以替换相应 decoder 而不重训 DiT，但不能随意换成不同缩放系数、不同 latent 通道数的 autoencoder。论文主要在 ImageNet 类别条件上验证方法，并没有在这份官方实现中提供文本编码器或通用图生视频能力。

与 U-Net 相比，DiT 的优势是标准、可扩展且各 token 全局通信；代价是位置、分辨率与 patch 配置紧密耦合，二次注意力成本明显，且缺少天然的多尺度卷积偏置。与像素空间 DDPM 相比，它借 VAE 降低空间尺寸，却继承压缩与解码误差。与 SVD 这类视频模型相比，它是单张潜图去噪器，不包含时间注意力或帧序列解码。

10. 实现检查清单与可执行的小单元测试

  1. 形状与重排：用 N=2、I=8、p=2、C=4 的纯 PyTorch 小张量检查 T=16；对 unpatchify 和显式 patch 重排做往返测试。测试非方形输入时应先修改固定位置网格，而不是期待原断言之外的形状自动成立。
  2. 初始化：实例化后不运行模型，断言每个 block 的调制末端 weight/bias 全零、最终 linear 全零、pos_embed.requires_grad=False。给定任意 x,c，零初始化 block 应输出与 x 精确相等的张量。
  3. 条件 dropout：构造标签并以 force_drop_ids 控制空类，检查被丢弃位置恰好等于 num_classes；训练态与 eval 态分别验证，避免“推理还随机丢标签”的 bug。
  4. 双头语义：对 4 通道 latent 断言模型输出 8 通道；按通道拆分后，噪声分支的 MSE target 必须是生成 zt 的同一个 ε。另写测试确认 VLB 分支中的 epsilon 已 detach，而方差仍可反传。
  5. 数值恒等式：固定 z₀、ε、t，先 q_sample，再由精确 ε 用式（3）恢复 z₀，浮点容差内应一致。验证 LEARNED_RANGE 的对数方差公式与代码广播维度，而非仅检查没有异常。
  6. CFG 顺序：用可区分的条件/无条件 mock 输出测试 cond 是前半、uncond 是后半；默认只改前三通道，方差不被外推。确认采样结束后仅条件半区进入 VAE，且除以 0.18215。
  7. 训练状态：检查 VAE 无梯度、DDP 每个 rank 的 batch 分配与 sampler 的 epoch、EMA 的 decay 和 eval 状态。论文级复现还需固定样本导出、ADM TensorFlow FID 评测和 250 步采样协议，不能以训练 loss 单独宣称达到论文指标。

这些建议可使用合成的确定张量和 mock 网络完成，不需要下载模型或执行图像生成。本文没有运行上述模型代码；列出测试是为了明确复现时的验收标准，而非报告已通过的测试结果。
