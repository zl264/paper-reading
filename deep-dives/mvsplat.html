1. 问题定义：一次前向传播把稀疏视图变成场景表示

MVSplat 解决的不是“对同一个场景采集大量照片后逐场景优化”，而是跨场景学习一个通用映射：输入 K 张图像及其内参、外参，通常只需两张，就直接输出可用于任意目标相机渲染的 3D Gaussian 集合。图像尺寸为 H×W 时，默认每个输入像素对应一个高斯，因此总计 KHW 个图元。每张上下文图像都保留自己的深度、协方差、透明度和球谐颜色，最后在世界坐标系中合并。

形式化地，输入为 Ii∈ℝH×W×3 与投影 Pi=Ki[Ri|ti]，输出为 {(μj, αj, Σj, cj)}。μ 是三维中心，α 是不透明度，Σ 是协方差，c 来自球谐系数。它与原始 3DGS 的本质差别是：没有为每个场景做梯度优化、稠密化和剪枝；与传统 MVS 的差别是：不先输出再融合一个点云，而是把逐视图反投影点的并集直接当作高斯中心，联合学习外观和形状参数。

fθ : {(Ii, Pi)}i=1…K ↦ {(μj, αj, Σj, cj)}j=1…KHW(1)

pixelSplat 也预测像素对齐高斯，但从跨视图特征直接估计概率深度并采样；MVSplat 则显式问“若这个像素位于某个深度，另一视图对应位置的特征是否相似”。因此它把学习难题部分转化为几何匹配，而不是要求网络记忆绝对图像特征到深度的映射。这也解释了论文所强调的跨数据集泛化：相对相关性通常比绝对特征尺度更稳定。

输入边界不能省略：MVSplat 不是无位姿重建器。相机内外参、深度近远界与一致的图像归一化都是前馈过程的一部分；遮挡区域、反光表面与超出深度范围的几何仍会带来歧义。

2. 多视图特征提取：浅层 CNN 加 Swin 式自/交叉注意力

主干先把形状为 [B,V,3,H,W] 的输入按 ImageNet 均值和标准差归一化，再把 batch 与 view 维合并，进入由六个残差块组成的浅层 ResNet 式 CNN。论文附录说明后四个块每两个块 stride 2 一次，净下采样为四倍，得到 Fi∈ℝH/4×W/4×C；默认配置 C=128。CNN 原始特征与 Transformer 输出都被保留：前者用于高分辨率上采样，后者用于构造代价体。

随后是六层多视图 Transformer。每层先做当前视图内的 self-attention，再以当前视图为 query、其余所有视图为 key/value 做 cross-attention，最后经过 FFN 与残差连接。代码用 batch_features 将 K 个视图组织成 K 组查询，每组查询携带另外 K−1 个视图，因而参数不随视图数改变。位置编码是正弦位置特征；窗口划分为 2×2，奇数层使用移位窗口，使信息能跨窗口流动。

实际文件：multiview_transformer.py：batch_features 与 MultiViewFeatureTransformer；初始化见 backbone_multiview.py。

这里不应把它描述成“用一个全局注意力混合所有 token”。官方实现的核心是局部窗口：同一窗口内完成跨视图交互，移位窗口弥补边界；多视图情况下 key/value 的 token 维包含其他视图，而输出仍回到每张图自己的特征网格。这种复用同一套投影参数的设计，是从两视图扩展到多视图的关键。

3. 平面扫描代价体：用相机几何显式衡量每个深度假设

对参考视图 i 的每个四分之一分辨率像素，先设 D 个深度候选。论文及 config/experiment/re10k.yaml 的正式实验配置均使用 D=128；基础 encoder YAML 中的 32 只是通用默认值，不能拿它替代实验设置。候选在逆深度而非线性深度上均匀采样，即 qm=(1−λm)/far+λm/near，dm=1/qm。近处候选因此更密，匹配透视投影的视差分布。

xi ∼ dm Ki−1 x̃i；　xj ∼ Kj(Rj←i xi + tj←i)；　Fj→idm = Sample(Fj, π(xj))(2)

实现时先由 coords_grid 生成齐次像素网格，用内参逆矩阵反投影，乘候选深度，再经相对位姿变换到另一相机。归一化投影坐标后，grid_sample 做双线性采样，得到 [VB,C,D,H/4,W/4]。注意此实现的 pose 是相对相机变换，不要把 world-to-camera 与 camera-to-world 混用。源视图在有效图像之外的采样填零，这既节约遮挡掩码计算，也意味着无匹配区域需要后续网络补足。

官方 warping、候选逆深度与相对位姿实现（固定提交）。

对每个候选，参考特征与 warp 后特征做逐通道乘积再求和，除以 √C，得到单通道匹配分数。K>2 时，每个其他视图都贡献一个 [D,H/4,W/4] 相关性体，代码将它们在源视图维求平均。这样每个参考视图最终都有 [D+C,H/4,W/4] 的“代价体＋自身特征”输入，而不是引入昂贵的 3D 卷积。

Cidm(u) = (1/(K−1)) Σj≠i [〈Fi(u), Fj→idm(u)〉 / √C](3)

4. 代价体细化与深度：2D U-Net、期望视差与残差修正

原始相关性在无纹理、重复纹理和遮挡处不唯一。MVSplat 将 D 通道相关性与 C 通道图像特征拼接，经卷积和 2D U-Net 产生 D 通道细化结果，再用 1×1 卷积提供从原输入到输出的残差支路。实验配置 costvolume_unet_channel_mult=[1,1,1]、costvolume_unet_attn_res=[4]，网络启用 use_cross_view_self_attn=True，在最低分辨率处展平不同视图以交换信息。它仍是二维卷积网络，D 被当作通道，不存在 [D,H,W] 上的 3D CNN。

softmax 沿 D 维归一化，深度不是 argmax，而是候选视差的概率加权平均，再取倒数。期望允许亚候选精度，也能在多峰分布中形成连续梯度，但若两个峰对应两个不同表面，期望可能落在两者之间。上采样后的期望视差、最大匹配置信度、投影特征与原图进入第二个轻量 U-Net，输出残差视差和 density logits。最终视差会被 clamp 到 [1/far,1/near]，所以几何范围明确受输入 near/far 限制。

pi,u,m = softmaxm(Ĉi)，　q̂i,u = Σm pi,u,m qm，　d̂i,u = 1 / clip(q̂i,u + Δqi,u)(4)
论文—代码差异：论文说由匹配置信度经两层卷积预测 opacity；启用深度细化的官方实现还让 to_disparity 输出一个 density logit，并经 sigmoid 得到 densities。渲染前另有 map_pdf_to_opacity，默认 initial=final=0 时简化为 0.5[(1−(1−p))+p]=p，不应把它误写成 softmax 最大值必然就是最终 alpha。

5. Gaussian head：从像素射线和网络原始通道构造合法图元

to_gaussians 的输入由深度细化特征、原 RGB 与上采样图像特征组成，两层 3×3 卷积预测像素偏移、尺度、四元数和球谐系数。GaussianAdapter 将每个高斯的原始向量拆成 3 个 scale、4 个 rotation 与 3·(L+1)² 个 SH 通道；默认 L=4，因此仅外观就有 75 个系数通道。另有两个原始通道经 sigmoid 产生 [0,1] 像素内偏移，并减 0.5 后以像素大小为单位加到射线坐标上。这就是“像素对齐”而不是“中心必须钉在像素格点”。

GaussianAdapter 完整参数变换；像素偏移及最终视图维合并见 EncoderCostVolume.forward。

μ = o + d r；　s = d·m·[smin + (smax−smin)σ(ŝ)]；　Σ = Rc→w Q(q) diag(s²) Q(q)T Rc→wT(5)

协方差实现为 Q diag(s) diag(s)T QT，等价于 Q diag(s²) QT，四元数先归一化，尺度经 sigmoid 限制在配置区间并乘深度与像素反投影因子。球谐被旋到世界坐标，非零阶系数使用随阶数减小的 mask，初始化时更偏向 DC 常量颜色。各视图点云不做学习式融合，直接 flatten 成一个 [B,V·H·W,…] 集合；所以默认模型一像素一高斯，与 pixelSplat 一像素三个高斯形成明显的图元数量差异。

6. 可微渲染与光度监督：目标 RGB 是唯一必需的真值信号

预测高斯传给官方修改版 diff_gaussian_rasterization。渲染器使用目标相机的内外参、近远界和背景色，把三维协方差投影成屏幕空间椭圆，按深度排序，并以 alpha 合成颜色。概念上像素颜色可写为按前后顺序累加的透射率公式；球谐根据观察方向提供视角相关颜色。与 NeRF 沿射线多次查询 MLP 不同，一套高斯可供多个目标视角共享，光栅化不用为每条射线重新跑场景网络。

Ĉ(u) = Σn Tn α̃n(u) cn(v)，　Tn=Πℓ<n(1−α̃ℓ(u))，　α̃n(u)=αn exp(−½ δuTΣ2D,n−1δu)(6)

decoder_splatting_cuda.py 调用 cuda_splatting.py：render_cuda。

训练目标是所有目标视图上的 RGB 均方误差与 VGG-LPIPS 的加权和。默认 mse 权重 1，lpips 权重 0.05 且从第 0 步启用；LPIPS 调用 normalize=True，把 [0,1] 图像转换到网络需要的范围。论文明确指出无真实深度监督，几何约束来自“相机 warp 的结构先验＋目标视图光度误差”，而非额外 depth loss。

L = (1/(B·N·3HW)) Σ ||Ĉ−C||²₂ + 0.05·mean(LPIPSVGG(Ĉ,C))(7)
不要把可选模块当成论文默认：仓库还有 loss_depth.py，它对渲染深度的相邻像素差做 RGB 边缘感知平滑，不是深度真值监督；默认 experiment/re10k.yaml 仅组合 [mse, lpips]。引用官方配置：re10k.yaml。

7. 训练设置与优化：数据采样和主干初始化也属于方法的一部分

论文在 RealEstate10K 的 67,477 个训练场景和 ACID 的 11,075 个训练场景上分别训练，输入输出统一为 256×256。每个 batch 元素是一条场景样本：两个上下文视图和四个目标视图，batch size 14，单张 A100 训练 300,000 次迭代，Adam 优化。当前配置给出初始/峰值学习率 2×10−4、余弦 OneCycle 调度、梯度裁剪 0.5；主干加载 UniMatch/GMDepth 预训练参数，而其余高斯预测部分照常学习。

RealEstate10K 的视角间隔在前 150,000 步从 25–45 帧逐渐扩大到 45–192 帧，让模型先学较容易的近基线对应，再适应大基线。代码还保留一个注释说明的兼容性细节：非环形相机采样时实际将 min_gap 用于上限，以复现 pixelSplat 的配置行为。因此复现实验不宜只照抄论文的“逐渐增加视角间隔”，而应固定相同配置和代码提交。

一次训练迭代在 ModelWrapper.training_step 中依次执行 data shim、encoder(context)、decoder(target camera)、loss 累加。论文消融显示，去掉代价体导致最严重退化；去掉跨视图注意力不仅降低质量，还出现过拟合；去掉 U-Net 主要伤害只在一个输入视图可见的区域；深度细化进一步提升最终质量。由此不能把全部收益简单归因于“用了 Transformer”或“用了 3DGS”。

主要可调项是输入视图数、D、near/far、图像尺寸、每像素高斯数及是否启用深度细化。增加视图不增加参数，但会增加 warp 和注意力计算；增加 D 提升深度分辨率，却线性扩大代价体通道和相关计算。论文附录报告每像素三个高斯可小幅改善指标，但渲染更慢，默认仍是一。评估使用官方场景索引，不能把任意两张照片直接当成与 RE10K 同分布的输入。

环境上，README 固定 PyTorch 2.1.2/torchvision 0.16.2 与 CUDA 11.8 安装源；requirements.txt 还依赖 Hydra、Lightning、einops、jaxtyping、beartype、LPIPS，以及 dcharatan 的修改版 CUDA rasterizer。路径、相机约定、数据 chunk 格式和 checkpoint 键名都需匹配；纯 Python 复刻 splatting 可以作为单元测试，但不能据此宣称复现官方速度。

9. 效率、真实对比与局限：快来自整条管线，而非单个算子

方法/设计几何与生成方式关键成本或边界
逐场景 NeRF / 3DGS一个场景单独优化；NeRF 体渲染采样，3DGS 光栅化测试新场景仍需优化；MVSplat 则一次前向
pixelSplat极线 Transformer 特征直接产生概率深度，再采样高斯默认每像素三个高斯；论文报告更多参数及较慢编码
传统 MVSNet 类代价体估计深度，再做点云融合常依赖深度监督与 3D 卷积；MVSplat 用 2D 网络直接输出高斯
MVSplat平面扫描相关性＋2D U-Net＋反投影高斯并集仍受位姿、深度范围、遮挡和反射限制

论文在作者实验条件下报告 0.044 秒（含 encoder 和 renderer）、12.0M 参数，输入两视图并渲染三个目标视图；encoder 为 0.043 秒，renderer 约 0.0015 秒。它不是“22 fps 的视频自回归生成”，而是稀疏图像到三维表示再到新视图的测量结果，硬件和计时协议必须一起引用。论文用 3DGS 光栅化避免逐射线网络查询，同时用一像素一高斯进一步减少图元数量。

代价体也有明确代价：粗略内存尺度为 O(K·D·(H/4)·(W/4)·C) 的 warp 特征和 O(K·D·H/4·W/4) 的相关性，注意力、上采样和中间 U-Net 特征另计；实际实现为了减少持有量会在各阶段重排和聚合，不能把某一个张量大小当作总显存。论文的限制包括玻璃、窗户等非朗伯反射面，以及 RE10K 场景多样性不足。只有单视图可见的区域不能靠相关性恢复真实几何，只能靠学习先验补全。

对相机控制任务而言，MVSplat 是“重建一次、目标相机可重复渲染”的显式场景先验；它不提供文本到视频运动生成，也不保证离输入相机很远的视角有可靠内容。把其输出用于轨迹渲染时，应同时检查深度、浮游高斯和视野外空洞，而不能只看目标 PSNR。

10. 复现检查清单与可执行单元测试设计

  • 相机约定：构造已知平移/旋转的合成双目场景，验证 warp 在正确深度处采样同一三维点；再交换视图顺序，检查相对位姿与内参像素缩放是否同步变化。
  • 候选深度：断言 q1=1/far、qD=1/near，所有 d 单调且位于 [near,far]；深度细化后 clamp 和取倒数不能颠倒顺序。
  • 张量布局：用 B=2、V=3 的小张量覆盖 (v b) 历史布局；确认每个 query 只看到其余 V−1 视图，代价体按源视图平均而非按 batch 平均。
  • softmax 与期望：在手工相关性体上检查深度维概率和为 1，期望视差在候选范围内；用双峰分布测试说明 argmax、期望与细化残差的不同。
  • 高斯合法性：测试四元数非零归一化、协方差对称半正定、scale 限幅、opacity 范围；单位深度和相机旋转下验证 μ=o+dr 与 Σ 的世界旋转一致。
  • 渲染梯度：用单个或少量高斯的合成图测试 RGB loss 对 means、scales、rotation、SH、opacity 的梯度是否有限，并与 CPU 简化 alpha 合成器对小案例做数值对照。
  • 训练配置：确认正式实验覆盖 D=128、四个目标视图、LPIPS=0.05、300k 步与间隔调度，避免把通用默认 D=32 当作论文模型。
  • 评估复现：固定官方 index、checkpoint、输入分辨率与相机近远界；分别记录 encoder 和每个目标的 renderer 时间，预热策略和硬件必须注明。
