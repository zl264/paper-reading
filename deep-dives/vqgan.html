VQGAN：先学会“视觉词汇”，再让 Transformer 组织画面

从 VQ-VAE 到感知压缩、对抗训练、自适应损失权重、Transformer 先验与滑动窗口高分辨率生成；逐文件读懂官方 taming-transformers。

本文逐节阅读 Esser、Rombach、Ommer 的 Taming Transformers for High-Resolution Image Synthesis，并静态核对官方 CompVis/taming-transformers 的模型、量化器与损失实现。原论文与当前仓库的具体配置需分开理解；本文没有运行训练或生成。

1. 先看全局：CNN 负责局部词汇，Transformer 负责全局组织

直接在像素上使用 Transformer，序列长度会随图像面积增加，注意力计算又随序列长度平方增长。VQGAN 的思路是先训练一个压缩模型，把图片变成较短的离散视觉符号序列，再让自回归 Transformer 学习这些符号怎样组成合理画面。

论文的核心不是“用了 VQ + Transformer”这句话，而是第一阶段必须学到上下文丰富、感知质量高的码本：否则第二阶段只能在信息损失严重的符号上补结构。为此，VQGAN 在 VQ-VAE 的量化与重建之外加入感知损失和 patch-based 对抗训练。

与 VQ-VAE 的关系：VQ-VAE 已经包含离散码本与先验生成。VQGAN 的新增重点是更强调感知与对抗监督的压缩器、Transformer 的全局组合，以及高分辨率/条件生成策略。不能把第一阶段只写成普通 MSE 自编码器。

2. 两阶段结构：从像素到码本，再到索引序列

第一阶段由卷积 encoder E、码本 Z、decoder G 组成。图片 x 先被编码成 h×w 个 n_z 维向量，再对每个空间位置找最近码本项；解码器从这些量化向量重建图像。

ẑ=E(x) ∈ Rh×w×n_z，   zq=q(ẑ)，   x̂=G(zq)(1)

第二阶段不再直接处理 embedding，而把每个码本项换成整数索引。图像变成 h·w 个离散 token，自回归 Transformer 学习下一索引的条件分布，再由第一阶段 decoder 还原为图片。

阶段输入输出训练信号
VQGAN 压缩器RGB 图像量化 embedding、重建图像与索引重建/感知 + 对抗 + 码本/承诺
索引化量化后空间编码h·w 个整数 token无参数，只记录码本位置
Transformer历史索引与可选条件下一 token 的 K 类 logits自回归交叉熵
生成采样得到的索引序列码本 embedding → 图片第一阶段 decoder 固定使用

3. VQ 与重建：量化如何进入训练

每个空间位置选择距离最近的码本向量：

zq,ij=zk，   k=argminz∈Z||ẑij−z||(2)

量化不可微，仍使用 VQ-VAE 的 straight-through：前向用量化的 z_q，反向把 decoder 侧梯度复制给 encoder。论文的 VQ 损失包含重建、码本和承诺项：

LVQ=||x−x̂||²+||sg[E(x)]−z_q||²+||sg[z_q]−E(x)||²(3)

重建项让编码和解码保留图像信息；码本项移动码本靠近编码；承诺项让 encoder 靠近码本。三项不是同一个对象上的重复 MSE，stop-gradient 的方向决定各自训练谁。

官方 taming/modules/vqvae/quantize.py 中 VectorQuantizer2 将 [B,C,H,W] 变为 [B,H,W,C]，用 ||z||²+||e||²−2ze 求距离，argmin 后查询 embedding，再用 z + (z_q-z).detach() 保留梯度。

官方源码节选 · VectorQuantizer2.forward
z = rearrange(z, 'b c h w -> b h w c').contiguous()
z_flattened = z.view(-1, self.e_dim)
d = torch.sum(z_flattened ** 2, dim=1, keepdim=True) + \
    torch.sum(self.embedding.weight**2, dim=1) - 2 * \
    torch.einsum('bd,dn->bn', z_flattened,
                 rearrange(self.embedding.weight, 'n d -> d n'))
indices = torch.argmin(d, dim=1)
z_q = self.embedding(indices).view(z.shape)
# 梯度直通；损失的 legacy/non-legacy 分支需按版本核对。
z_q = z + (z_q - z).detach()
版本细节：固定源码注释指出旧版 beta 项有历史兼容行为，新版可修正。阅读损失公式时要区分论文写法、旧版 legacy 实现和修正版，而不是把任意一个分支当成所有版本的事实。

4. 为什么还需要感知损失和 PatchGAN

只用像素 MSE 往往倾向平均化细节，导致模糊。VQGAN 将重建监督换为/加强为感知损失，并训练 patch-based discriminator 分辨真实与重建图片。其目标是让码本在高压缩率下仍保留纹理、边缘和局部真实感。

LGAN=log D(x)+log(1−D(x̂))(4)

这不是让 Transformer 做 GAN 训练，而是在第一阶段训练 encoder/decoder/码本时使用感知与对抗信号。第二阶段的 Transformer 仍然学习离散索引交叉熵。

官方 VQLPIPSWithDiscriminator 将 L1 与 LPIPS 合成重建项，使用 hinge discriminator loss，并分别处理 generator 和 discriminator 两个 optimizer。

官方源码节选 · 感知重建与对抗目标
rec_loss = torch.abs(inputs.contiguous()-reconstructions.contiguous())
if self.perceptual_weight > 0:
    p_loss = self.perceptual_loss(inputs.contiguous(),reconstructions.contiguous())
    rec_loss = rec_loss + self.perceptual_weight*p_loss
nll_loss = torch.mean(rec_loss)

# generator 分支
logits_fake = self.discriminator(reconstructions.contiguous())
g_loss = -torch.mean(logits_fake)
loss = nll_loss + d_weight*disc_factor*g_loss \
     + self.codebook_weight*codebook_loss.mean()

5. 自适应 λ：防止对抗项淹没重建

感知/对抗项与重建项量级可能差别很大。论文使用 decoder 最后一层 G_L 的梯度范数比构造 λ：

λ = ||∇G_LLrec|| / (||∇G_LLGAN||+δ)(5)

它根据当前训练中两类目标对 decoder 最后层的相对强度调整权重，而不是固定一个人工常数。δ 用于数值稳定。

官方实现分别计算两项对最后一层的梯度、取范数比并 clamp 后 detach，防止这个“权重计算”本身成为额外训练目标：

官方源码节选 · calculate_adaptive_weight
nll_grads = torch.autograd.grad(nll_loss,last_layer,retain_graph=True)[0]
g_grads = torch.autograd.grad(g_loss,last_layer,retain_graph=True)[0]
d_weight = torch.norm(nll_grads)/(torch.norm(g_grads)+1e-4)
d_weight = torch.clamp(d_weight,0.0,1e4).detach()
d_weight = d_weight*self.discriminator_weight

此外，disc_start 可让对抗项在若干 step 后才启用。论文公式是设计原则，实际训练还要记录启用时刻、clamp 和 optimizer 调度。

6. 官方模型结构：VQModel 里每个组件的位置

官方 taming/models/vqgan.py 的 VQModel 将 Encoder、Decoder、VectorQuantizer2 和损失组合起来。Encoder 输出先经 quant_conv 对齐 embedding 维度，量化后再经 post_quant_conv 回到 decoder 的 z_channels。

官方源码节选 · VQModel 编码与解码
def encode(self,x):
    h = self.encoder(x)
    h = self.quant_conv(h)
    quant,emb_loss,info = self.quantize(h)
    return quant,emb_loss,info

def decode(self,quant):
    quant = self.post_quant_conv(quant)
    return self.decoder(quant)

def forward(self,input):
    quant,diff,_ = self.encode(input)
    return self.decode(quant),diff

最低分辨率处还使用单个 attention 聚合全局上下文。这里的 attention 属于第一阶段压缩器，与第二阶段自回归 Transformer 不是同一个模块。

官方配置中 optimizer 分别管理 encoder、decoder、quantize、两个卷积以及 discriminator。训练时 optimizer_idx=0 计算 autoencoder/generator 损失，optimizer_idx=1 计算 discriminator 损失；两者不能简单放进一次 backward 就假设语义相同。

7. 第二阶段 Transformer：下一索引预测

将离散索引按某种顺序排列为 s，Transformer 学习：

p(s)=∏ip(si|s<i)，   L=−E log p(s)(6)

训练时通过 causal mask 防止当前位置看见未来索引；损失只在目标索引位置计算。推理时从已生成前缀出发，逐位置采样，再映射回码本并解码。

教学实现 · 非官方源码：离散 Transformer 训练/采样骨架
# 训练：第一阶段已固定，输入是真实图片编码出的索引。
indices = vqgan.encode_to_indices(images)
logits = transformer(indices[:,:-1],causal=True)
loss = F.cross_entropy(logits.transpose(1,2),indices[:,1:])

# 推理：从起始 token 逐位置采样，最后再查码本/解码。
sequence = start_token
for _ in range(H_latent*W_latent):
    logits = transformer(sequence,causal=True)
    next_index = sample(logits[:,-1]/temperature)
    sequence = torch.cat([sequence,next_index],dim=1)
image = vqgan.decode_indices(sequence)
# 省略位置编码、条件、KV cache、索引 remap 与批量高效实现。

若有类别、布局或另一张条件图片 c，任务变为 p(s|c)=∏p(s_i|s_<i,c)。论文可将另一模态先编码为索引前缀 r，再让 Transformer 在这些条件下生成目标索引。

8. 高分辨率与滑动窗口：不是无限加长注意力

即使 VQGAN 已压缩空间分辨率，注意力仍受 token 长度限制。论文常用码本大小约 1024，Transformer 训练序列常为 16×16；原文说明在约 12GB GPU 上对应 GPT2-medium 级配置，具体应结合表格和硬件理解。

更高分辨率时可在局部 patch 上生成，并用滑动窗口注意力/上下文处理；这依赖数据集空间统计或条件信息。如果整张图片需要严格全局布局，单纯滑窗可能产生拼接不一致，论文建议可附加坐标条件。

9. 完整训练与推理流程

  1. 训练 VQGAN：图像→encoder→quant_conv→码本→post_quant_conv→decoder；重建/感知、码本/承诺、对抗目标按两个 optimizer 交替更新。
  2. 固定第一阶段，将训练集图像转为索引序列；按任务准备类别、语义布局或其他条件。
  3. 训练自回归 Transformer，对下一索引做交叉熵；确认 causal mask 与条件 loss 范围。
  4. 推理时从提示/前缀采样索引，查询码本、post_quant_conv、decoder 得到图像；高分辨率时按窗口组织。
  5. 分别评估重建、码本利用、Transformer 采样质量与推理成本，不把某一个指标当作全部能力。

论文实验包含多种条件任务和与 PixelSNAIL 的对比；这些结果有特定训练时间、步数、参数量和数据设置。本文只读原文与源码，未运行其训练或生成，不声称复现论文指标。

10. 局限、失败模式与易混淆点

  • 第一阶段是信息瓶颈：压缩器没保留的纹理、文字或身份细节，Transformer 无法保证恢复。
  • 码本可能闲置：应监测 perplexity、使用频率和量化误差。
  • 对抗训练可能不稳定：需监控 LPIPS、重建、对抗项、λ 与 disc_start。
  • Transformer 串行采样有成本：token 数、窗口、KV cache 和采样温度都影响实际体验。
  • 条件不是自动精确控制：类别/语义/参考条件需要对应训练数据与正确接口。

不要把 VQGAN 与 VQ-VAE 的原始论文公式、当前仓库的 legacy 参数行为或后续 LDM 的连续 latent 混为一个方法。

11. 复现与单元测试清单

  • 固定论文版本、官方源码提交、模型 YAML、码本和 checkpoint。
  • 检查 encoder→quant_conv→quantize→post_quant_conv→decoder 的通道和空间形状。
  • 验证量化前向等于码本值，straight-through 梯度能进入 encoder。
  • 分别记录 L1/LPIPS、码本/承诺、GAN、λ 与两个 optimizer 的更新。
  • Transformer 的 causal mask、索引范围、loss 位置和采样温度需单独测试。
  • 条件生成时检查条件前缀不混入不该计算的 loss。
  • 高分辨率窗口测试边界、重叠、坐标条件和全局一致性。

附录 A：用一张图把两个阶段连起来

设想一张 256×256 的训练图片，经过 m=4 次空间下采样后，第一阶段 latent 网格为 16×16。每个位置先得到一个 n_z 维向量，再从 K 个码本项中选最近项。这样图片不再由 256×256×3 个像素值直接输入 Transformer，而变成 256 个离散索引。若 K=1024，Transformer 的每个位置是在 1024 个视觉词条中预测下一个。

训练第一阶段时，重建图会同时接受像素/感知监督与判别器反馈，码本/承诺项调整量化表示。此时并不训练 Transformer。等压缩器训练完成，才把这些索引作为第二阶段的离散数据。生成时，Transformer 逐位置采样 256 个索引，再查询码本并通过 decoder 输出 256×256 图片。若输出尺寸更大，则可能要在多个窗口中重复这一过程。

这个例子也解释两个常见错误：量化向量与索引不是同一种数据，前者用于 decoder，后者用于自回归先验；第一阶段重建图片与第二阶段生成新图片不是同一任务，前者输入真实图，后者从索引先验采样。

附录 B：小白最容易混淆的四件事

  1. 感知损失不是另一个码本损失。LPIPS 比较深度特征，更关心感知相似；码本项/承诺项管理 encoder 与离散 embedding 的距离。
  2. PatchGAN 不在第二阶段判别生成图。它在第一阶段指导压缩器，让离散重建保留纹理；第二阶段 Transformer 仍以交叉熵学习索引分布。
  3. 码本大并不总是更好。更大的 K 提高表示容量，却增加检索和下一索引分类难度；还需考虑码本闲置与数据覆盖。
  4. 低分辨率注意力与 Transformer 注意力作用不同。前者帮助 encoder/decoder 聚合图像上下文，后者负责离散 token 的历史条件建模。

阅读官方代码时，可以按这个顺序追踪：VQModel.forward → encode/decode → VectorQuantizer2.forward → VQLPIPSWithDiscriminator.forward → 两个 optimizer；随后再读 Transformer 的数据构造和训练脚本。这样不会把第一阶段的 GAN 损失误接到第二阶段。
