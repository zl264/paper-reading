VQ-VAE：让神经网络学会“从码本里选一个符号”

从连续自编码器到离散潜变量：最近邻量化、straight-through 梯度、码本/承诺损失，以及训练完编码器后怎样再学生成先验。

本文逐节阅读 van den Oord、Vinyals、Kavukcuoglu 的 Neural Discrete Representation Learning（arXiv v2，2018-05-30），包括附录 A.1 的 EMA 字典更新。论文没有附带本文所核验的原始完整训练仓库；下文 PyTorch 代码均为明确标注的教学实现。相关后续实现的差异会单独标注，不冒充原论文源码。

1. 先用一个比喻：把连续描述改成有限词汇表

普通自编码器会把一张图片变成一个连续向量。你可以把这个向量想成“用很多小数描述图片”。VQ-VAE 则增加一本有 K 个词条的字典：编码器先给出一个连续向量，系统在其中找最接近的词条，解码器只能根据这个词条重建图片。

这样做有两个直接收益：

  • 信息必须压缩到有限符号里。不能让每个像素噪声都藏进任意精细的小数编码。
  • 后续可以在离散符号上学习语言式先验。图片、语音或视频帧序列不必在原始高维像素空间中直接做自回归。

论文的两个核心不同点是：编码输出离散，而不是连续高斯潜变量；先验 p(z) 可以学习，而不是永远固定为标准正态。这也解释了为什么 VQ-VAE 常作为后续 Transformer、VQGAN、视频生成模型的 tokenizer。

不要把 VQ-VAE 等同于“把 VAE 的 z 四舍五入”。它使用的是共享 embedding 码本、确定性最近邻后验、特殊梯度近似和可学习离散先验，训练目标也与连续高斯 VAE 不同。

2. 整体结构：编码器、码本、解码器与第二阶段先验

输入 x 经 encoder 得到连续表示 ze(x)。码本 e 中有 K 个 D 维向量；每个空间/时间位置选择最近的 ek，得到量化向量 zq(x)，再交给 decoder 重建输入。

e ∈ RK×D，   k = argminj ||ze(x)−ej||2，   zq(x)=ek(1)

K 是词条数量，D 是每个词条的维度。图像不是只有一个全局离散变量，而通常是二维 latent 网格；语音是一维、视频是三维时空网格。每个网格位置都做一次最近邻查表。

阶段输入输出训练目的
编码器原始图像/音频/视频连续 z_e，形状 [B,D,…]提供可量化的内容表示
向量量化z_e 与码本 e离散索引 + 对应 embedding z_q形成离散 latent 网格
解码器z_q重建观测或输出分布参数让离散码保留可重建信息
第二阶段先验离散索引序列p(z) 或条件分布学会生成合理 latent，再由 decoder 出图

图 1：VQ-VAE 的训练与生成链路。第一阶段学习离散表示；第二阶段在固定编码器/码本上学习先验，再经解码器生成观测。

3. 概率视角：为什么 KL 变成常数

论文把后验写成确定性的 categorical 分布：对选中的最近码本项概率为 1，其余为 0。它不是从高斯后验采样，而是 argmin 最近邻查找。

q(z=k|x)=1 当 k=argminj||ze(x)−ej||，否则为 0(2)

如果在第一阶段把 latent 先验设为 K 类均匀分布，那么 posterior 与 uniform prior 的 KL 为常数 log K，不随 encoder 参数变化，因此训练时可以忽略。这与连续 VAE 里通过 KL 调整 μ、σ 的行为不同。

但“第一阶段使用均匀先验”不代表最终生成只能随机选码。论文在表示学习结束后，再用 PixelCNN/WaveNet 等模型学习离散 latent 的真实分布；真正的生成质量来自第二阶段先验与第一阶段 decoder 的组合。

4. 最难点：argmin 没有普通梯度，训练为何仍能进行

最近邻查找包含 argmin。输入稍微变化时，被选索引通常不变，变化到边界时又突然切换，所以普通梯度要么为零、要么不定义。不能直接把 argmin 放进网络就期待自动微分学会编码器。

VQ-VAE 使用 straight-through 估计：前向用真正量化值，反向把 decoder 输入处的梯度原样复制给 encoder 输出。PyTorch 教学代码中可写成：

教学实现 · 非官方源码：straight-through 量化
# z_e 与 z_q 同形，最后一维是 D。
distances = ((z_e.unsqueeze(-2) - codebook)**2).sum(-1)
indices = distances.argmin(dim=-1)
z_q = codebook[indices]
z_st = z_e + (z_q - z_e).detach()

# 前向：z_st 的数值严格等于 z_q。
# 反向：dL/dz_e 接收 z_q 处的梯度，而不是 detach 后的零梯度。

z_e + (z_q-z_e).detach() 的数值确实是 z_q；反向时 z_e 项保留梯度，detach 项不保留。因此它让 encoder 学到“把连续输出移动到哪个码附近会降低重建损失”，下一次前向时索引就可能改变。

这是一种有偏但低方差的实用估计，不是 argmin 的真实导数，也不是说量化操作变得连续可微。Gumbel/Concrete 等连续松弛是另一条路线，不应与这里的 straight-through 混为一谈。

5. 三项损失分别训练谁

论文的总目标可概括为：

L = log p(x|zq(x)) + ||sg[ze(x)]−e||² + β||ze(x)−sg[e]||²(3)

这里 sg 是 stop-gradient。以最小化实现时，第一项常写为负对数似然或重建误差；关键是三条梯度路径：

项训练对象作用
重建项encoder + decoder保留观测信息；经 straight-through 回传到 encoder
码本项 ||sg[z_e]−e||²码本 e把码本向量拉近 encoder 输出
承诺项 β||z_e−sg[e]||²encoder防止输出任意漂移/膨胀，鼓励靠近所选码

原论文使用 β=0.25，并报告 0.1–2.0 范围内较稳健；但 loss 尺度变化时不能机械照搬。若把 detach 放错位置，码本和 encoder 的训练对象就会反过来。

教学实现 · 非官方源码：三项损失与梯度归属
reconstruction = decoder(z_st)
recon_loss = F.mse_loss(reconstruction, target)
codebook_loss = F.mse_loss(z_q, z_e.detach())
commitment_loss = F.mse_loss(z_q.detach(), z_e)
loss = recon_loss + codebook_loss + beta * commitment_loss

# recon_loss：更新 decoder，并经 z_st 更新 encoder。
# codebook_loss：只更新码本 e。
# commitment_loss：只更新 encoder。

6. 网络结构与张量：把公式落到图像上

论文的连续/离散对比实验使用卷积 encoder、残差块和转置卷积 decoder。以输入 [B,3,32,32] 为例，若两次 stride=2 下采样，空间尺寸变成 8×8；再经残差块得到 [B,D,8,8]。量化时将它展平成 [B·8·8,D]，对每行查一次码本，再恢复网格。

在 ImageNet 128×128 实验中，论文使用 32×32 个离散 latent、K=512；CIFAR 的对比模型采用卷积/残差结构，Adam lr=2e−4、batch 128、250K steps。音频实验则用类似 WaveNet 的膨胀卷积，并可附加 speaker embedding。

这些配置属于不同任务，不应混为“VQ-VAE 唯一标准结构”。真正实现时，D 是码本通道，不是图片 RGB 通道；latent 的 H/W 取决于下采样倍率，码本 K 决定离散词表大小。

教学实现 · 非官方源码：一个图像 VQ-VAE 模块
class ImageVQVAE(nn.Module):
    def __init__(self, K=512, D=64, beta=.25):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Conv2d(3,64,4,2,1), nn.ReLU(),
            nn.Conv2d(64,D,4,2,1), nn.ReLU())
        self.codebook = nn.Parameter(torch.randn(K,D)*.02)
        self.beta = beta
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(D,64,4,2,1), nn.ReLU(),
            nn.ConvTranspose2d(64,3,4,2,1), nn.Sigmoid())

    def forward(self,x):
        z = self.encoder(x)                     # [B,D,H',W']
        z = z.permute(0,2,3,1)                  # [B,H',W',D]
        d = ((z[...,None,:]-self.codebook)**2).sum(-1)
        indices = d.argmin(-1)
        zq = self.codebook[indices]
        zst = z+(zq-z).detach()
        reconstruction = self.decoder(zst.permute(0,3,1,2))
        loss = F.mse_loss(reconstruction,x) \
             + F.mse_loss(zq,z.detach()) \
             + self.beta*F.mse_loss(zq.detach(),z)
        return reconstruction,indices,loss
# 教学网络未复现论文训练规模、残差细节与评估。'''

上述全量 pairwise 张量适合讲解，但高分辨率时 [B,H,W,K,D] 可能很大；工程实现应使用 cdist 或展开内积降低临时内存，而不是先构造巨大差值张量。

7. 附录 EMA：码本也可以不靠梯度下降更新

论文附录提出另一种字典更新：若第 i 个码在当前 batch 被 nᵢ 个 encoder 输出选择，理想均值是这些 z_e 的平均。mini-batch 下用指数滑动平均近似：

Nᵢᵗ = γNᵢᵗ⁻¹+(1−γ)nᵢᵗ，   mᵢᵗ=γmᵢᵗ⁻¹+(1−γ)Σze，   eᵢᵗ=mᵢᵗ/Nᵢᵗ(4)

γ 可取 0.99。Nᵢ 是平滑使用次数，mᵢ 是平滑向量总和。这样码本通过统计量更新，而不是通过码本 MSE 的 optimizer 梯度；但 encoder 仍需重建与承诺损失。

教学实现 · 非官方源码：EMA 字典更新
# 对当前 batch 的每个码聚合使用次数和 z_e 总和。
counts = torch.bincount(indices.flatten(),minlength=K).float()
sums = torch.zeros(K,D).to(z_e)
sums.index_add_(0,indices.flatten(),z_e.detach().reshape(-1,D))
ema_count = gamma*ema_count+(1-gamma)*counts
ema_sum = gamma*ema_sum+(1-gamma)*sums
codebook.data = ema_sum/ema_count.clamp_min(1e-6)[:,None]
# 真实实现要处理未使用码、分布式同步、初始化与数值稳定。'''

EMA 更新是论文附录的可选方案，论文正文说明其实验未使用该路径。不要把它与 VAE 权重 EMA 或扩散模型评估时的 EMA 混为一谈。

8. 第二阶段：怎样从“能重建”变成“能生成新内容”

第一阶段结束后，固定 encoder、码本与 decoder，把训练样本映射成离散索引网格，再用 PixelCNN/WaveNet 等自回归模型学习 p(z)。生成时先采样索引，再取对应码本向量并解码。

p(z1:N)=∏ip(zi|z<i)，   zi∈{1,…,K}(5)

对图像，PixelCNN 使用 mask 保证当前位置只依赖已生成位置；对语音，WaveNet 处理离散时间序列。第二阶段损失通常是索引交叉熵，而不是像素 MSE。

教学伪代码 · 非官方源码：训练离散先验与生成
# 阶段 1 已完成并冻结。
with torch.no_grad():
    indices = encode_to_indices(images)       # [B,H',W']
logits = pixelcnn(indices)                    # [B,K,H',W']
loss = F.cross_entropy(logits,indices)

# 生成：逐位置采样，再查询固定码本。
generated = torch.zeros(B,H',W',dtype=torch.long)
for position in raster_order(H',W'):
    logits = pixelcnn(generated)
    generated.view(-1)[position] = sample_categorical(logits_at(position))
z = codebook[generated]
images = decoder(z)
# 教学伪代码省略了 mask、缓存与高效并行实现。'''

因此“VQ-VAE 直接从噪声解码”是不完整的：噪声/索引要先经过学习到的先验。只用均匀随机索引通常不会得到有意义图像。

本文没有核验到原论文的完整官方训练仓库。为了理解后续工程实现，我另外读取了 CompVis 的 VQGAN/taming-transformers 中 quantize.py。它是后续相关项目的实现，不是本论文的原始官方代码。

该实现把 [B,C,H,W] 展平为 [BHW,C]，通过 ||z||²+||e||²−2ze 计算距离，使用 argmin 选码，并以 z + (z_q-z).detach() 保留 straight-through 梯度。其码本/承诺损失与 perplexity 计算可用于工程对照，但还包括后续 remap、Gumbel、EMA 变体等，不应混入原论文结构。

原论文任务也不只是图片：VCTK 语音、DeepMind Lab 视频、动作条件潜空间预测都在实验范围内。本文只分析共同算法骨架，不把其中一个任务的网络配置推广到所有任务。

10. 局限、常见误解与计算成本

  • 码本坍缩：少数码长期被使用，其余闲置。应监测码本利用率、perplexity、每个码的计数，而不是只看重建 loss。
  • 量化信息瓶颈：码本过小或 latent 网格过粗会丢失细节；增加 K 又提高检索和先验学习难度。
  • 两阶段误差：表示学习不好时，后续先验无法恢复未编码的信息；先验采样错误也会被 decoder 放大。
  • 训练/生成不相同：第一阶段均匀 latent 先验只服务于表示学习；第二阶段才真正学习生成先验。
  • 离散不等于免费加速：距离检索、PixelCNN 串行采样、码本存储与训练吞吐量都需要计入。

论文报告了与连续 VAE 接近的 CIFAR bits/dim 等结果，但本文没有运行任何模型训练或性能测试，不把这些论文数字写成本地实测。

11. 从零实现时的检查清单

  • 固定码本 K、embedding D、输入尺寸与 latent 空间分辨率。
  • 确认最近邻距离、索引形状与码本查询顺序一致。
  • 验证 straight-through 前向等于 z_q、反向能进入 encoder。
  • 分别打印重建、码本与承诺损失，检查 detach 的对象。
  • 记录每个码使用频率，检查码本坍缩。
  • EMA 路径检查未使用码、零除、分布式聚合与设备一致性。
  • 第二阶段固定第一阶段模块，训练索引交叉熵；生成必须经过先验与 decoder。
  • 分别报告重建质量、采样质量、码本利用率和采样成本。

附录 A：一个具体输入怎样走完训练与生成

设 batch 中有 128 张 32×32 图像，编码器输出 D=64、latent 网格 8×8，码本有 K=512 项。一次前向产生 128×8×8=8192 个连续编码向量，每个向量都与 512 个码比较距离，选出一个索引；8192 个索引组成离散 latent 网格，再恢复为 embedding 输入解码器。训练时，像素重建误差和承诺项更新编码器，码本项或 EMA 统计更新码本，解码器接收真正的量化向量。

第二阶段把每张训练图变成 8×8 的整数索引，PixelCNN 逐位置预测下一索引的 512 类概率。生成新图时，不输入真实图片：先由先验采样 64 个索引，再查询码本、解码为 32×32 图像。原论文的 ImageNet 任务使用更大的 128×128 图像与 32×32 latent，这里缩小尺寸只是为了帮助读者手算张量。

码本使用情况可用 perplexity 辅助观察：若每个位置使用码的概率为 pₖ，熵 H=−Σpₖlogpₖ，perplexity=exp(H)。全部质量集中在一个码时接近 1；均匀使用 K 个码时接近 K。它不能证明表示语义正确，但比单看 loss 更容易发现码本闲置。
