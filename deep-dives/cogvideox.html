1. 任务与整体数据流：生成的是压缩视频潜变量，不是逐帧独立图片

CogVideoX 的输入是文本提示，文生视频输出是一段在空间和时间上共同建模的视频；图生视频变体额外输入一张条件图像。它不是让图像扩散模型逐帧采样再插帧，而是先用 3D 因果 VAE 将视频压缩成时空 latent，再在该空间运行扩散 Transformer。训练时把文本与视频潜变量分别编码为 token 序列，沿序列维拼接后送入同一组 expert Transformer blocks，最终只保留视频部分并 unpatchify，由 VAE decoder 还原像素视频。

这一路径同时处理三个瓶颈。第一，像素视频数据量大，时空压缩缩短去噪序列；第二，文本与视觉的数值分布不同，简单共享 LayerNorm 可能掩盖模态差异；第三，分离的空间注意力和时间注意力只能通过中间 token 间接传递大运动信息。对应的工程解法分别是 3D 因果 VAE、按模态调制的 Expert AdaLN、覆盖全部文本和时空视频 token 的联合注意力。

图 1：CogVideoX 将文本语义与压缩视频 token 放入同一扩散 Transformer。依据论文机制与公开代码重新绘制；模块形状用于说明数据流，而非照搬论文插图。

论文描述的最终系统可在 768×1360、16 fps 下生成最长 10 秒的视频，但官方开源初代 2B/5B 与后续 1.5 的默认规格并不相同。初代 5B 的配置为 49 帧、480×720，通常按 8 fps 输出；1.5 默认 81 帧、768×1360，按 16 fps 输出。因此“CogVideoX 默认都生成 10 秒”是错误概括，必须同时写明模型代际与采样配置。

代码阅读约定：网络本体采用 [B,T,C,H,W] 表示视频 latent，VAE 接口常用 [B,C,F,H,W]；T/F 都表示时间长度，但在不同文件中的轴顺序不同。本文写形状时保留该顺序，避免把通道维误当时间维。

2. 3D 因果 VAE：时空压缩、后验采样与首帧特殊处理

对视频 x∈[−1,1]B×3×F×H×W，编码器由 3D ResNet 阶段组成，前两个下采样阶段同时压缩时间和空间，后续只做空间下采样，总压缩为 8×8×4。官方 5B 配置的 ch_mult=[1,2,2,4]、每级三个残差块、attn_resolutions=[]、z_channels=16；编码器最后输出 32 通道，经对角高斯 regularizer 拆成均值和 log-variance。decoder 对称上采样回到 3 通道 RGB。

qφ(z|x)=N(μφ(x), diag(σ²φ(x)))；　z=μφ+σφ⊙ε， ε∼N(0,I)；　Fz=(F−1)/4+1(1)

“4 倍时间压缩”不是简单写成 F/4。代码把首帧单独保留，对余下帧做 stride-2 平均池化两次，所以 F=49 对应 13 个 latent 时间位置，F=81 对应 21 个。这也解释 README 中初代要求 8N+1、1.5 要求 16N+1：后者还在 Transformer 中使用时间 patch q=2。VAE 本身无注意力，论文报告其分辨率泛化较好，但更多帧需要专门做长视频微调。

VAE 训练先在 256×256、17 帧视频上开始，随机 8 或 16 fps；之后借助时间上下文并行在 161 帧上微调。损失是 L1 重建、LPIPS 和 KL 的加权组合，数千步后引入 3D discriminator 的 GAN loss。论文没有给出这些项的完整数值权重，不应自行补齐。编码 latent 还需乘模型的 scaling_factor：SAT 5B 配置是 0.7，diffusers 微调代码从 vae.config.scaling_factor 读取，因此缩放不能在不同模型间硬编码复用。

3. 因果卷积与时间上下文并行：当前块只看历史，不看未来

普通对称 padding 的时间卷积会让第 t 帧依赖未来帧；CogVideoX 的时间核大小为 k 时，将 k−1 个 padding 全部放在序列开头，空间方向仍使用左右对称 padding。这样第 t 个输出只读取不超过 t 的输入，首块用复制首帧补历史。这个“因果”是 VAE 的感受野约束，不意味着 DiT 内部使用自回归 causal mask；相反，DiT 使用双向联合注意力。

yt = Στ=0…k−1 Wτ xt−k+1+τ；　xs<0 := x0　⇒　yt 不依赖 x>t(2)

上下文并行按时间切片后，每个 rank 不能只拿自己的局部片段做卷积，否则边界会缺失历史。实现中的 _pass_from_previous_rank 用非阻塞 isend/irecv 从前一个 rank 接收 k−1 帧，并在卷积后参与计算；反向传播通过自定义 autograd function 把相应历史梯度送回。论文因此将通信描述为每段只传 k−1 长度的 halo，而不是复制全部视频。

halo 传递；ContextParallelCausalConv3d.forward。

仓库还支持“fake CP”：单进程分时间块解码，同时把边界 cache 暂存到 CPU，用来模拟跨块历史而不建立分布式组。它是显存优化，不应误解为自动改变了视频总帧数或丢弃了首帧。真正的分布式 CP 和分块 cache 都必须在边界测试中比较，否则最隐蔽的错误往往表现为每段接缝处闪变。

4. T5 文本编码与 video patchify：把两个模态排成一条序列

官方 5B 配置使用冻结的 T5-v1.1-XXL encoder，初代文本长度 226（1.5 为 224），输出维度 4096。tokenizer 截断或 padding 到固定长度，T5 只保留 last_hidden_state，不使用 decoder。DiT 的 text_proj 将每个 4096 维 token 线性投影到 3072 维；视频 latent 则按时间 q、高宽 p 的三维 patch 展平，再线性投影到同一个 hidden size。论文的一般 token 数为 (T/q)(H/p)(W/p)，官方初代 5B 的 q=1、p=2。

ztext = Wt T5(xtext) ∈ ℝ226×d；　zvision = Wv Patchq,p,p(z) ∈ ℝ(T/q)(H/p)(W/p)×d(3)

ImagePatchEmbeddingMixin；FrozenT5Embedder；5B 网络及文本配置。

这里的 patchify 没有 3D 卷积下采样：它只是重排每个 patch 内的 C·q·p·p 个数再做 Linear。最终输出端对称地 unpatchify 为视频 latent，并抛弃文本 token。论文还规定 q>1 时在序列开始重复首帧以兼容图像和视频；diffusers 微调器实现为前置 F % patch_size_t 个首帧副本。实现者必须选用与实际 checkpoint 一致的规则，不能只凭 latent 形状猜测 pad 数。

为了让 classifier-free guidance 可学习，SAT conditioner 配置 ucg_rate=0.1，将部分训练文本 embedding 置零。推理时空文本也走同一个冻结 T5，而不是简单使用全零 token id；这点与最终无条件特征的实际分布有关。

5. 3D-RoPE 与联合全注意力：坐标相对性直接作用于 Q/K

每个视频 token 用三元坐标 (t,h,w) 标记。论文将每个 attention head 的通道按时间 2/8、空间高 3/8、空间宽 3/8 分配给三组一维 RoPE；5B 有 48 个头、hidden size 3072，因此每头 64 维，对应 16/24/24 维。对每个坐标轴分别生成频率，通过广播构造 [T,H,W,dhead] 的 sin/cos，最后展平成视频 token 顺序。

RoPE(qt,h,w) = [R(t)qt ; R(h)qh ; R(w)qw]；　R(θ)(a,b)=(a cosθ−b sinθ, a sinθ+b cosθ)(4)

源码只旋转视频部分的 Q 和 K，文本 Q/K 原样保留，V 默认不旋转。注意力随后将文本与视频放在同一矩阵中，所有 token 都能读取其他 token。论文的“3D full attention”不是把 T,H,W 三轴拆成三次注意力，而是对展平后的 T·H·W 个视觉位置直接进行全连接注意力，并同时纳入文本。大运动对象不必借助背景 token 中转信息。

3D-RoPE 频率、旋转及 attention hook。

多分辨率训练时，代码取预计算坐标表的前缀 [:rope_T,:rope_H,:rope_W]，而非把固定坐标缩放至目标分辨率。论文把这一选择称为 extrapolation：保留像素间相对步长和局部细节。它也意味着位置表必须覆盖目标形状；超出范围不会自动获得有效的视频位置编码。初代 2B 是例外：官方配置采用 3D sincos 而非 RoPE。

6. Expert Adaptive LayerNorm：共享联合计算，分开调制两种模态

时间步经过 sinusoidal embedding 与两层 MLP，得到 e(t)。每层的 adaLN_modulation 将其映射为 12d 个量：视频与文本各有一组 attention 的 shift/scale/gate 和 MLP 的 shift/scale/gate。注意力前，两个模态分别做 LayerNorm 和各自的调制，再拼回一个序列；输出后切开，用各自的 gate 控制残差。MLP 前重复同样过程。这样既避免两套完整 MMDiT 的参数开销，又不强迫文本和图像共享同一组统计校正。

h̃mattn = LN(hm) ⊙ (1+smattn(t)) + bmattn(t)， m∈{text,video}
hm ← hm + gmattn(t) ⊙ Splitm(Attn([h̃text; h̃video]))(5)

官方 5B 有 42 层，hidden=3072，时间 embedding MLP 输出 512，再由每层投影到 12×3072。Q/K 在 attention 前还各有一层 head-dim LayerNorm。最终层只取视频 token，经 shift/scale 和 Linear 输出 patch 内的 16·q·p·p 个数。初始化时 adaLN 最后一个 Linear 的权重和 bias 置零，使调制与 gate 从稳定起点学习。

7. 扩散训练目标：v-prediction、zero-SNR 与显式均匀时间步采样

设干净、缩放后的 latent 为 x0，从训练噪声日程取 at=√ᾱt，bt=√(1−ᾱt)，加噪 xt=atx0+btε。模型采用 v-prediction，目标 vt=atε−btx0。SAT 的 VideoScaling 返回 c_skip=a、c_out=−b，因此 denoiser 输出 x̂0=a xt−b vθ；代码损失表面比较 x̂0 和 x0，同时乘权重 1/b²，恰好对应未加权的 v 均方误差。

x̂0=atxt−btvθ；　(1/bt²)||x̂0−x0||² = ||vθ−(atε−btx0)||²(6)

VideoDiffusionLoss；VideoScaling；ZeroSNRDDPMDiscretization。

zero-SNR 实现从线性 β 日程计算 ᾱ，再将首尾缩放，使终端信噪比趋于零。显式均匀采样把 1000 个 timestep 区间分给数据并行 rank，各自只在自己的子区间均匀取样，减少一个全局 batch 内噪声水平的随机聚集。实际 DiscreteSampling 还有 group_num，且 world_size≤8 时关闭该策略；因此小规模 LoRA 示例中的逐样本 randint 不能冒充完整预训练算法。

完整的训练步骤是：编码并冻结 VAE latent 与 T5 特征；按 rank 采样 t 和 ε；构造 xt；联合 DiT 输出 v；转成 x̂0 后加权计算 MSE；只更新可训练参数。SAT 的 not_trainable_prefixes=["first_stage_model","conditioner"] 以及参数冻结逻辑确保 VAE 与文本编码器不参与去噪训练。

8. 数据与渐进训练：Frame Pack 解决变长，分辨率课程控制成本

论文的训练数据经过镜头切分和质量过滤后约有 3500 万个单镜头片段，平均约 6 秒，另用 LAION-5B 与 COYO-700M 中筛选的 20 亿图像辅助训练。过滤不仅看清晰度，还排除剪辑、运动不连贯、讲座、大段文字、录屏和相机抖动；光流和美学分数阈值会动态调整。短 caption 则通过 CogVLM 逐帧描述、GPT-4 汇总，再蒸馏到 LLaMA2 与端到端 CogVLM2-Caption，以覆盖动作、镜头和时序变化。

Multi-Resolution Frame Pack 将不同帧数、不同分辨率的样本 pack 到固定 token 总量的 batch 中，而不是一律截长弃短或大量 zero-padding。每个样本有自己的三维 RoPE 坐标，打包后需要样本级注意力隔离；不能把拼接边界当作同一场景中的相邻视频。图像作为单帧视频加入，重复首帧规则使其与视频 patch 对齐。

9. 采样与推理：从噪声 latent 到视频的完整反向过程

推理首先把提示词扩展成详细英文描述，再用冻结 T5 得到条件与空提示的无条件 embedding。采样器创建与目标视频 latent 相同形状的高斯噪声，从高噪声向低噪声迭代。SAT 5B 默认 VPSDEDPMPP2MSampler、50 步、DynamicCFG，配置 scale=6、exp=5。每一步 DiT 根据 xt、t 与文本联合注意力预测 v，再得到 denoised latent，求解器更新 x；最后除以 scaling factor 并调用 VAE decoder。

x̂0cfg = x̂0,u + s(k) (x̂0,c−x̂0,u)；　s(k)=1+s[1−cos(π(k/S)e)]/2(7)

动态 guidance 不是恒定 6：按上式从接近 1 增至 7。它把有条件与无条件输入拼成双 batch 一次前向，因而会显著增加 DiT 计算。DPM 求解器还使用上一次 denoised 估计构造二阶多步更新，不能用单个 Euler 公式替代官方采样细节。

主要参数包括 num_frames、height/width、步数、guidance scale、seed、dtype 和 fps。帧数、时长与 fps 必须共同说明，改变导出 fps 不等于 DiT 学到了不同运动速度。CPU offload、VAE slicing/tiling 降峰值显存但增加传输或边界处理成本；官方注释也提示 DDIM 通常推荐用于 2B，DPM 用于 5B。固定 seed 只在相同软硬件、调度器和配置下才有可比性。

10. 仓库结构与微调调用链：论文预训练不等同于开源 LoRA 脚本

固定提交中，sat/dit_video_concat.py 是核心 DiT，sat/vae_modules/ 是因果 VAE，sat/diffusion_video.py 负责第一阶段编码、冻结和训练/采样连接，sat/sgm/modules/ 包含 conditioner、loss、discretizer 与 sampler。inference/cli_demo.py 是 diffusers 推理入口，finetune/ 则提供 Accelerate/DeepSpeed 的 LoRA 与 SFT。它们共享模型概念，但不是一份从头复现全部预训练数据和 Frame Pack 基础设施的单一脚本。

官方源码节选 · finetune/models/cogvideox_t2v/lora_trainer.py
latent_dist = vae.encode(video).latent_dist
latent = latent_dist.sample() * vae.config.scaling_factor
# latent 从 [B,C,F,H,W] 转成 [B,F,C,H,W]
latent = latent.permute(0, 2, 1, 3, 4)
latent_added_noise = scheduler.add_noise(latent, noise, timesteps)
predicted = transformer(
    hidden_states=latent_added_noise,
    encoder_hidden_states=prompt_embedding,
    timestep=timesteps, image_rotary_emb=rotary_emb,
    return_dict=False,
)[0]
latent_pred = scheduler.get_velocity(predicted, latent_added_noise, timesteps)
loss = torch.mean((weights * (latent_pred - latent) ** 2).reshape(batch_size, -1), dim=1)

T2V trainer 的组件加载、T5/VAE 编码、RoPE 与 loss；冻结策略见 finetune/trainer.py。

微调脚本先离线预计算 latent 和 prompt embedding，再卸载 VAE/T5。LoRA 模式冻结所有原参数，只对默认 target modules to_q,to_k,to_v,to_out.0 注入 adapter；SFT 模式训练整个 transformer。可训练参数被转回 FP32，其余推理组件采用指定混合精度，支持 gradient checkpointing 和 ZeRO。默认 rank=128、lora_alpha=64，学习率默认 2×10−5，这些是仓库微调设置，不是论文数十亿参数预训练的复现配方。

依赖方面，pyproject 要求 Python≥3.8、torch≥2.5.1、diffusers≥0.32.2、transformers≥4.46.3，训练还需 decord、deepspeed、peft 等；当前 requirements.txt 有更高的下限。SAT 还依赖 SwissArmyTransformer，位置表构造含 .cuda()，并非开箱即用的纯 CPU 模型。本文只阅读这些文件，没有安装或运行。

11. 计算成本、版本差异与局限

联合全注意力的序列长度 L=Ltext+(T/q)(H/p)(W/p)，标准注意力的成对分数规模为 O(L²d)。FlashAttention 降低显式注意力矩阵的内存和 IO，却没有把理论 pairwise 计算变成线性。初代 5B 在 49 帧、480×720 下，VAE latent 为 13×60×90，p=2、q=1 后有 13×30×30=11,700 个视觉 token，再加 226 个文本 token；长视频高分辨率课程的序列长度会继续迅速增长。

项目论文/官方依据解读边界
VAE 压缩8×8×4，16 latent channels，首帧独立减少 DiT token，但重建误差限制最终保真度
Expert AdaLN同序列注意力，两个模态各 6 个调制参数组比双塔 MMDiT 更省参数，不是两个完全独立网络
3D full attention所有时空视觉 token 与文本共同注意力支持直接跨帧交互，但长序列昂贵
显式均匀采样各数据并行组使用不重叠 timestep 区间减少 batch 噪声水平偏斜，不等于推理步数均匀

论文附录在 H800、BF16、50 步下报告：5B 的 480×720、6 秒为 113 秒和 26GB，768×1360、5 秒为 500 秒和 76GB；2B 对应为 49 秒/18GB 与 220 秒/53GB。它们不是本机测试，也不代表开启 diffusers sequential offload 后的消费级显卡速度。仓库 README 的另一组优化推理数据使用不同实现与优化，不能直接混表比较。

局限首先是训练数据偏差与 caption 幻觉会进入文本条件；其次是冻结 T5 并不天然理解精确数量、复杂物理或任意语言，官方说明提示词主要为英文。VAE 时间压缩会损失高速细节，联合注意力不能凭空保证真实物理。长时一致性还受训练最长时长、位置坐标范围和视频分块边界影响。高质量微调甚至可能牺牲部分语义能力，评估应分别报告指令跟随、动态程度与视觉质量。

版本陷阱：论文表 6 同时列出 2B 的 sinusoidal 与 5B 的 RoPE；固定仓库默认 CLI 指向 1.5，SAT README 说明当前分支重点支持 1.5，初代模型应参考 v1.0 release。复现时必须固定模型权重、代码提交和 scheduler，而不是只写“CogVideoX-5B”。

12. 实现检查清单与单元测试建议

  • VAE 形状：测试 F=1、17、49、81，验证 Fz=(F−1)/4+1，空间每轴除以 8，后验输出均值与 logvar 通道各为 16；检查 scaling 在 encode/decode 两端互逆。
  • 因果性：固定前 t 帧，只扰动未来帧，断言第 t 帧及之前的 encoder 输出不变；对单进程、fake CP 和多 rank halo 做同输入数值比较，重点看块边界。
  • patch/unpatch：用每通道不同编号的 latent 验证 [B,T,C,H,W] 重排及逆变换完全还原；q=2 时分别测试首帧补齐数和 RoPE 时间网格的一致性。
  • T5 接口：检查 padding/truncation 长度、attention mask、4096→d 投影以及无条件特征生成路径；不要把 T5 decoder 输出误当 last_hidden_state。
  • 3D-RoPE：验证时间/高/宽通道为 1/4、3/8、3/8，文本 Q/K 不变；相同相对位移的 token 对应具有预期旋转关系，超出预计算坐标表应显式报错。
  • Expert AdaLN：分别把文本和视频调制置零，检查对应残差和尺度变化；验证 attention 与 MLP 之后按原 text_length 精确切分，没有把文本输出送入 unpatchify。
  • 扩散恒等式：随机生成 a,b,x,ε，检查 v=aε−bx、x̂₀=a xt−bv 和加权 MSE 等价；zero-SNR 首尾及 scheduler timestep 顺序要单独断言。
  • 采样与微调：固定 toy scheduler 检查首步一阶、后续二阶与末步无噪声分支；LoRA 测试只允许 adapter 参数产生梯度，SFT 则确认 VAE/T5 仍冻结。
  • 系统验证：分别记录文本编码、50 步 DiT、VAE 解码的时间与峰值显存；报告 offload/tiling、精度、GPU 和批量，不能把其中某一步冒充总推理时间。
