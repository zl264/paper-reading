一、问题不是“压缩后还原”，而是对不可归一化的后验做可扩展推断

设独立同分布数据为 X={x(i)}i=1N，每个观测都对应一个未观测的连续潜变量 z。生成模型先取 z∼pθ(z)，再取 x∼pθ(x|z)。训练时我们希望同时学习生成参数 θ 和变分参数 φ；后者控制的识别模型 qφ(z|x) 对不可处理的真后验 pθ(z|x) 给出摊销近似。这里“摊销”意味着所有输入共享同一个编码器，不必为每张图重新运行一轮 MCMC。

困难来自归一化常数：pθ(x)=∫pθ(z)pθ(x|z)dz 往往没有闭式解，因而 pθ(z|x)=pθ(x,z)/pθ(x) 也无法直接求。若解码器含非线性神经网络，即使先验是很简单的标准高斯，这个积分通常仍不可处理。VAE 的关键不是宣布真后验为高斯，而是选择一个易于采样、可以联合训练的近似分布族。

输入输出要按用途区分。推断输入一张观测 x，输出整个后验的参数而非单一编码；重建输入 x，经 qφ(z|x) 取 z，再由解码器给出 pθ(x|z) 的参数；生成则从固定先验取 z，不需要真实输入。普通确定性自编码器只学 x→z→x̂，没有 q(z|x)、p(z) 以及 log p(x) 的下界，不能把“隐藏层向量”自动解释为连续可采样的生成先验。

原文提出的范围比“VAE 网络”更广：SGVB 是可微的变分下界估计器，AEVB 是使用识别模型的算法，VAE 是以神经网络实现概率编码器和解码器的例子。论文实验采用 MNIST 与 Frey Face；本节之后的 PyTorch 超参数只属于示例。

二、ELBO：对数似然与后验 KL 的精确分解

固定某个 x，对任意归一化的 qφ(z|x)，在期望中乘除联合密度即可得到下面的恒等式。这不是丢弃 KL 后“约等于”，而是先写出一个恒等式，再利用 KL≥0 得到下界。

log pθ(x) = Eqφ(z|x)[log pθ(x,z) − log qφ(z|x)] + DKL(qφ(z|x) ‖ pθ(z|x))(1)

把第一项记为 L(θ,φ;x)，就是证据下界（Evidence Lower BOund，ELBO）。由于第二项非负，log pθ(x)≥L；只有当近似后验与真后验几乎处处相等时取等号。因此增大下界可能来自更好的生成模型，也可能来自更准确的后验近似，二者不能仅凭一个总损失数区分。

L(θ,φ;x) = Eqφ(z|x)[log pθ(x|z)] − DKL(qφ(z|x) ‖ pθ(z))(2)

式 (2) 的第一项要求潜码能够解释观测，第二项使输入相关的后验不要任意远离先验。KL 不是让每一张图的编码都成为同一个点：如果所有 q(z|x) 都与 N(0,I) 完全相同，z 通常不再携带关于 x 的信息，重建项会变差。它也不是“让单个 z 的样本均值接近零”；约束的是整个条件分布。

训练最大化下界，等价于最小化负下界。后续源码的 loss = BCE + KLD 正是 −L 的采样估计。原文的小批量估计乘以 N/M，使 M 个样本的和估计全数据集的目标；常见实现则直接优化小批量平均，这两种写法只在梯度的全局尺度上不同。

三、重参数化：把有参数的随机节点变成确定变换

如果直接对 z∼qφ(z|x) 采样，再使用 REINFORCE 型估计器，就需要 f(z)∇φlog qφ(z|x)，原文指出其方差很高。路径导数的思路是选择独立于 φ 的 ε∼p(ε)，并找到可微函数 gφ(x,ε)，使 z=gφ(x,ε) 的分布正好等于 qφ(z|x)。

Eqφ(z|x)[f(z)] = Eε∼p(ε)[f(gφ(x,ε))] ≈ (1/L) Σl=1L f(gφ(x,ε(l)))(3)

对 q=N(μ,diag(σ²))，取 ε∼N(0,I)，z=μ+σ⊙ε。现在随机性来自 ε，而 μ 与 log σ² 都由编码器计算，自动微分可以把重建损失对 z 的导数继续传到 μ、log σ² 和 φ。换言术，“重参数化”不是删掉噪声，也不是把 randn 变成可微函数；可微的是给定 ε 后的确定变换。

z = μ + exp(log σ² / 2) ⊙ ε,　∂z/∂μ = I,　∂z/∂log σ² = (1/2) diag(exp(log σ² / 2) ⊙ ε)(4)

网络输出 log σ² 而不是 σ²，避免对输出加非负约束；指数半次方才得到标准差。一般地，位置—尺度族可用“标准样本×尺度+位置”，有可求逆 CDF 的分布也可用均匀随机数与逆 CDF。原文实验在小批量足够大时每点用 L=1；一次抽样使重建期望带噪，但不是对期望本身取 log 后再抽样。

四、高斯先验、高斯编码器与两类解码器

原论文例子令 p(z)=N(0,I)，qφ(z|x)=N(μ(x),diag(σ²(x)))。这里“对角”是一个简化选择，不是 AEVB 的理论限制。逐维高斯与标准正态的 KL 有闭式，利用 E[zj²]=μj²+σj² 及高斯熵，可直接从 log p−log q 的期望消去 2π 常数：

DKL(q ‖ N(0,I)) = −(1/2) Σj=1J[1 + log σj² − μj² − σj²](5)

若把 sj=log σj²，KL 对 μj 的梯度为 μj，对 sj 的梯度为 (exp(sj)−1)/2。这解释了源码为何正好写 1 + logvar - mu.pow(2) - logvar.exp()；前面的 −0.5 将它转为要加入损失的正 KLD。

解码器的选择必须与观测匹配。二值或视作独立的 [0,1] 像素可用 yd∈(0,1) 参数化独立 Bernoulli：

log pθ(x|z) = Σd=1D[xd log yd + (1−xd) log(1−yd)](6)

其负值恰是二值交叉熵之和。实值观测则可选 p(x|z)=N(m(z),diag(v(z)))，若 v 固定，逐像素负对数似然等于 MSE/(2v) 加常数；若同时学 m 和 log v，就必须保留方差项。不能因为“高斯解码器对应 MSE”就任意把 MSE 与示例中的 Bernoulli BCE 混用。

对象原论文例子概率含义
先验 p(z)N(0,I)，无可学参数生成时潜码的起点
近似后验 q(z|x)编码 MLP 输出 μ、log σ²条件于每张输入，协方差对角
真后验 p(z|x)通常不可处理ELBO 中被逼近的对象，不等于 q
解码 p(x|z)二值数据用 Bernoulli；实值数据用高斯网络输出的是分布参数

五、网络、张量与一次参数更新

原论文附录 C 的概率编码器有一个 tanh 隐层，随后分别线性映射到 μ 和 log σ²；Bernoulli 解码器也是单隐层 MLP，输出经 sigmoid。论文 MNIST 比较下界时使用 500 隐单元，Frey Face 为 200，另有低维边际似然实验使用 100 隐单元和 3 个潜变量。这些数字不应套到下方的 PyTorch 教学网络。

在固定提交的 PyTorch 示例中，输入张量 [B,1,28,28] 被展平为 [B,784]。fc1:784→400 后接 ReLU，两个并行线性层 fc21/fc22:400→20 分别产生 μ 与 logvar，所以二者各为 [B,20]。重参数化的 z 为 [B,20]；解码器 fc3:20→400、ReLU、fc4:400→784、sigmoid，得到 [B,784] 的 Bernoulli 概率。它没有卷积、注意力、空间多尺度结构或离散码本。

  1. 从训练集打乱取一个 batch，MNIST 标签被丢弃；ToTensor 将像素转换到浮点 [0,1]。
  2. 前向得到重建概率、μ、logvar，每个样本从其后验取一次 z。
  3. BCE 和 KL 都对 batch 与所有元素求和；反向传播后由 Adam 同时更新编码器和解码器。
  4. 测试使用同一随机前向，但在 no_grad 下运行。展示的重建图使用解码均值/概率，没有再 Bernoulli 抽样。

示例默认 batch=128、10 epochs、Adam lr=10−3、seed=1，可用 --no-accel 禁用加速设备。与原论文的 Adagrad、M=100、L=1 不同，示例 README 明确说采用 ReLU 与 Adam 而非原实验的 sigmoid/tanh 与 Adagrad，以更快收敛。

官方源码 · pytorch/examples · vae/main.py · L46–77
class VAE(nn.Module):
    def __init__(self):
        super(VAE, self).__init__()

        self.fc1 = nn.Linear(784, 400)
        self.fc21 = nn.Linear(400, 20)
        self.fc22 = nn.Linear(400, 20)
        self.fc3 = nn.Linear(20, 400)
        self.fc4 = nn.Linear(400, 784)

    def encode(self, x):
        h1 = F.relu(self.fc1(x))
        return self.fc21(h1), self.fc22(h1)

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5*logvar)
        eps = torch.randn_like(std)
        return mu + eps*std

    def decode(self, z):
        h3 = F.relu(self.fc3(z))
        return torch.sigmoid(self.fc4(h3))

    def forward(self, x):
        mu, logvar = self.encode(x.view(-1, 784))
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

model = VAE().to(device)
optimizer = optim.Adam(model.parameters(), lr=1e-3)

forward 同时返回重建和分布参数，损失才能同时取到重建路径与解析 KL。注意 model.eval() 不会消除 randn_like；评估结果仍有采样随机性，除非另外固定 RNG 或明确使用 μ 作为确定性编码。

官方源码 · pytorch/examples · vae/main.py · L79–89
# Reconstruction + KL divergence losses summed over all elements and batch
def loss_function(recon_x, x, mu, logvar):
    BCE = F.binary_cross_entropy(recon_x, x.view(-1, 784), reduction='sum')

    # see Appendix B from VAE paper:
    # Kingma and Welling. Auto-Encoding Variational Bayes. ICLR, 2014
    # https://arxiv.org/abs/1312.6114
    # 0.5 * sum(1 + log(sigma^2) - mu^2 - sigma^2)
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())

    return BCE + KLD

这里取 reduction='sum'，所以返回的是整个 batch 的 −ELBO 估计，而非每样本或每像素平均。训练日志另行除以 len(data) 仅用于显示；传给 backward 的仍是和。改变 batch size 会同时改变梯度尺度和重建项相对于 KL 的聚合方式，复现实验时不能只看打印值。

官方源码 · pytorch/examples · vae/main.py · L92–129
def train(epoch):
    model.train()
    train_loss = 0
    for batch_idx, (data, _) in enumerate(train_loader):
        data = data.to(device)
        optimizer.zero_grad()
        recon_batch, mu, logvar = model(data)
        loss = loss_function(recon_batch, data, mu, logvar)
        loss.backward()
        train_loss += loss.item()
        optimizer.step()
        if batch_idx % args.log_interval == 0:
            print('Train Epoch: {} [{}/{} ({:.0f}%)]\tLoss: {:.6f}'.format(
                epoch, batch_idx * len(data), len(train_loader.dataset),
                100. * batch_idx / len(train_loader),
                loss.item() / len(data)))

    print('====> Epoch: {} Average loss: {:.4f}'.format(
          epoch, train_loss / len(train_loader.dataset)))

def test(epoch):
    model.eval()
    test_loss = 0
    with torch.no_grad():
        for i, (data, _) in enumerate(test_loader):
            data = data.to(device)
            recon_batch, mu, logvar = model(data)
            test_loss += loss_function(recon_batch, data, mu, logvar).item()
            if i == 0:
                n = min(data.size(0), 8)
                comparison = torch.cat([data[:n],
                                      recon_batch.view(args.batch_size, 1, 28, 28)[:n]])
                save_image(comparison.cpu(),
                         'results/reconstruction_' + str(epoch) + '.png', nrow=n)

    test_loss /= len(test_loader.dataset)
    print('====> Test set loss: {:.4f}'.format(test_loss))

八、推断、调参与论文复现边界

后验编码：输入满足预处理约定的 x，取 μ 可作为确定性表示，取 μ+σε 则是后验样本。二者不是同一种“编码结果”。重建：训练和源码使用随机 z，输出像素概率；可用 μ 降低重建方差，但那已是另一种评估协议。无条件生成：从 N(0,I) 取 z 并解码。若训练后的聚合后验与先验差距很大，先验采样的覆盖会受影响；标准高斯先验本身并不保证语义解耦或每个方向都有独立含义。

潜空间插值需区分线性插值、先验上归一化插值及后验采样；源码只实现重建和独立先验采样，没有分类、条件生成、图像补全或二维流形遍历。想实现原文图 4 的二维流形，应令 J=2，在单位正方形取网格，经标准高斯逆 CDF 映射到 z，再逐点解码；不能只在线性 [−2,2] 网格上移动就称作严格复刻。

它复现了什么，又没有复现什么。PyTorch 示例复现了论文的标准高斯先验、对角高斯识别模型、重参数化、解析 KL、Bernoulli 重建以及联合优化这一核心算法；它没有复现论文的网络宽度、原始激活与 Adagrad、参数初始化及 weight decay、Frey Face 高斯解码器、与 wake-sleep/MCMC EM 的比较、边际似然估计器和论文表格。示例也没有 β-VAE、自由信息量、KL warmup、层级后验、卷积编码器或离散量化。因而不应把一次 MNIST 示例运行称为“完整复现 2014 论文”。

基础 MLP 的计算和显存主要随 batch、784 维输入、400 隐单元与 20 潜维线性增长；重参数化只需一份与 μ 同形的噪声，却还需保存前向激活供反向传播。真正的限制不是“采样一次就必然模糊”，而是所选输出分布、对角后验、容量和目标的共同作用。把灰度像素当独立 Bernoulli 是示例建模选择；对真实连续图像，通常应重新明确似然和离散化协议。

  • 断言 [B,1,28,28]→[B,784]，μ/logvar/z 都是 [B,20]，解码输出与展平输入相同，并在 [0,1] 内。
  • 用 NumPy 独立计算 μ²+exp(logvar)−1−logvar 的半和，与 KLD 比较；μ=0、logvar=0 时严格为 0，非标准参数时为正。
  • 固定 μ=1.25、logvar=−0.7，把 torch.randn_like 替换为已知 ε，检查 z=μ+ε·exp(logvar/2)；同时检查对 μ 与 logvar 的梯度。
  • 对固定的 2 样本、2 像素输入手算 BCE 与 KL，确认 sum 语义；再分别记录 batch sum、样本均值和像素均值，避免不可比较的 loss 曲线。
  • 用相同 μ、logvar 的两次前向验证 z 会变化；仅切换到 eval 模式不应让噪声消失。使用固定 RNG 时，比较结果必须包含测试随机性。
  • 检查 train_loss / len(train_loader.dataset) 与测试损失的归一化一致，并留意最后一个不完整 batch 对和式损失的影响。
  • 断言先验生成路径只调用 decode，不调用 encode；检查保存形状 [64,1,28,28]。若实现二维流形，验证逆 CDF 映射及输出顺序。

若要验证“训练有效”而非仅“能运行”，需预先约定随机种子的多次运行、每样本 ELBO、重建与 KL 分开报告，并区分随机后验重建和 μ 重建。源码没有提供模型断言、指标报告或训练结果文件，所以这些是实现者需要补充的验证，不是已执行测试。

合并教程：从自编码器、两条 ELBO 路线到进阶变体

合并了原 VAE 入门教程中对学习路线和常见误区的说明：自编码器的隐向量只是一个确定点，VAE 的输出是输入相关的分布；重构项与 KL 项不是互相独立的两条训练目标，而来自同一个 ELBO。对于初读者，可以先沿“确定 AE → 后验分布 → 重参数化 → ELBO → 先验生成”阅读，再进入源码。

两条等价理解 ELBO 的路线：一条从 log p(x) 减去并加回 log q(z|x)，显式留下后验 KL；另一条用 Jensen 不等式，由 log E_q[p(x,z)/q(z|x)] ≥ E_q log[p(x,z)/q(z|x)] 得到下界。前者更容易看出误差来自后验近似，后者更容易看出它为何是“下界”。二者并非不同损失。

已有教程中的进阶讨论也被纳入：后验坍缩表现为 q(z|x) 接近先验、重构几乎忽略 z；β-VAE 将 KL 乘 β，增强正则却可能牺牲重构；VQ-VAE 把连续后验换成离散码本，因此不能直接沿用本文的高斯 KL。Stable Diffusion 的 AutoencoderKL 虽沿用 VAE 结构，却主要充当感知压缩器，其 KL 正则权重与训练目标并不等同于本页的 MNIST 示例。

class ConvVAE(nn.Module):
    def __init__(self, latent_dim=32):
        super().__init__()
        self.encoder=nn.Sequential(
            nn.Conv2d(1,32,4,2,1),nn.ReLU(),   # 28 -> 14
            nn.Conv2d(32,64,4,2,1),nn.ReLU(), # 14 -> 7
            nn.Flatten())
        self.mu=nn.Linear(64*7*7,latent_dim)
        self.logvar=nn.Linear(64*7*7,latent_dim)
        self.to_image=nn.Linear(latent_dim,64*7*7)
        self.decoder=nn.Sequential(
            nn.ConvTranspose2d(64,32,4,2,1),nn.ReLU(),
            nn.ConvTranspose2d(32,1,4,2,1),nn.Sigmoid())
    def forward(self,x):
        h=self.encoder(x)
        mu,logvar=self.mu(h),self.logvar(h)
        z=mu+torch.randn_like(mu)*torch.exp(.5*logvar)
        return self.decoder(self.to_image(z).reshape(-1,64,7,7)),mu,logvar
