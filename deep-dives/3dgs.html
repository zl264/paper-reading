1. 问题边界：不是神经网络渲染器，而是显式场景的逐场景优化

3DGS 接收静态场景的多张照片、对应的相机内外参，通常还有 SfM 标定时产生的稀疏点云；输出是一组可在任意目标相机下渲染的三维高斯。它不是“输入两张图、一次前向生成新场景”的泛化模型，也没有一个用于重建的编码器。训练针对每个场景单独进行，推理时直接使用优化好的高斯集合。

原始 NeRF 在每条相机射线上采样大量位置，反复查询密度与颜色网络，再沿射线积分。体素或哈希网格能减少网络成本，却仍然需要处理空间采样和空区域。3DGS 将基本单元改为有空间范围的显式椭球：每个高斯有位置、三维协方差、不透明度和方向相关颜色。渲染时将这些椭球投影成屏幕上的二维椭圆，按深度进行 α 混合，不沿每条射线查询 MLP。

图 1：3DGS 将显式场景表示与逐场景优化结合。依据论文机制与公开代码重新绘制；模块形状用于说明数据流，而非照搬论文插图。

“Splatting”不是把高斯直接当作一张带透明通道的精灵图片贴到屏幕，而是对三维概率形状的投影、可见性排序和连续权重求和。图中所示闭环体现三个相互依赖的设计：高斯提供可微的体积表示；tile 光栅器使训练和渲染足够快；密度控制则改变基元的数量，弥补稀疏初始化覆盖不足与 oversized 高斯的表示误差。

2. 高斯表示：用旋转与缩放保证协方差合法

第 k 个高斯可以记为 gk = (μk, Σk, ok, Sk)。μ ∈ R3 是世界坐标均值；Σ 是 3×3 对称半正定协方差；o 是学习的不透明度参数，经 sigmoid 得到 α；S 是三个颜色通道的球谐系数。以 μ 为中心的非归一化高斯形状为：

Gk(x) = exp(−½ (x−μk)T Σk−1 (x−μk))(1)

这里没有把概率密度前面的归一化常数用于像素着色，因为真正参与混合的是学习的不透明度与空间响应的乘积。直接对 Σ 的九个元素做无约束梯度下降会破坏半正定性，Σ−1 也可能失去意义。论文把协方差分解为旋转 R 和对角缩放 S：

L = R diag(sx, sy, sz),　Σ = L LT = R S ST RT(2)

实际存储的是三维 log-scale 和四元数 q，而不是矩阵 Σ。读取时执行 exp(scale) 得到正轴长，并归一化 q 构造旋转。L 的三列是椭球旋转后的主轴，L LT 自动对称半正定；正缩放让奇异情况也尽量受控。各向异性不是装饰：贴近表面的扁平椭球、细杆状结构和大面积低频区域，需要不同的轴长与朝向。若仅使用各向同性球体，在相同基元数下往往更难贴合几何。

3. SfM 初始化与球谐：位置来自点云，视角颜色渐进开放

官方 Scene 在输入目录存在 sparse 时走 COLMAP 读取器，存在 transforms_train.json 时走 Blender 合成数据读取器。COLMAP 分支读取 images.bin/txt、cameras.bin/txt 和 points3D，并支持针孔及简单针孔模型；它不是直接从畸变鱼眼照片运行高斯训练，输入需先完成合适的相机标定与去畸变。评估模式下按排序后的图像名每八张留出一张测试，前提是开启 eval。

初始化将每个 SfM 点的 RGB 转成零阶 SH，非零阶系数置零；不透明度设为 0.1 的 logit，旋转设为单位四元数。源码用 distCUDA2 计算最近三个邻点的平均平方距离，开方后取对数作为三个相同的初始 scale。这样无需从极稀疏点云估计易噪声的法线，也让初始半径适应局部点间距。合成数据若无点云，可在 [−1.3, 1.3]3 中生成 100,000 个随机点。

球谐函数用低频方向基表达每个高斯随观察方向变化的 RGB。设 d 为从相机指向高斯或其反向的约定方向（实现必须一致），颜色为：

ck(d) = Σℓ=0…L Σm=−ℓ…ℓ Sk,ℓm Yℓm(d),　通道数 = 3，系数数/通道 = (L+1)2(3)

零阶近似漫反射本色，高阶用于表达反光等方向效应，但不是完整的物理 BRDF、阴影或多次光照模型。默认最大 L=3，每通道 16 个系数。每 1000 次迭代调用 oneupSHdegree，从 0 阶逐渐增加一个 band，防止早期视角信息不足时高阶颜色干扰基本几何。若 convert_SHs_python 开启，Python 中先按高斯位置与相机中心构造方向、eval_sh，再以 clamp_min(SH+0.5, 0) 得到预计算颜色；否则把 SH 交给 CUDA 光栅器。

4. 投影与 tile 光栅化：三维协方差如何成为屏幕椭圆

透视投影在局部用仿射近似。W 是世界到观察坐标的变换，J 是透视投影在高斯中心处的仿射近似雅可比，则相机/屏幕相关协方差为：

Σ′ = J W Σ WT JT,　Σ2D = Σ′前两行、前两列(4)

J 包含焦距和深度倒数带来的局部尺度变化，因此同一个高斯靠近相机时 footprint 通常增大。去掉第三行与第三列后得到二维椭圆协方差，可在像素偏移 Δu 上计算 exp(−½ ΔuT Σ2D−1 Δu)。这只是局部投影近似；靠近近裁剪面、远离视锥或透视变化剧烈时可能不稳定，论文因此描述 guard band 等剔除策略。

论文的快速光栅器把屏幕分为 16×16 像素 tile。先剔除视锥外基元，用 99% 置信范围检测与视锥/tile 的相交；一个高斯若覆盖多个 tile，就产生多个实例。实例的排序键组合 tile ID 和观察空间深度，使用 GPU radix sort 一次排序。每个 tile 确定有序列表的首尾范围，一个线程块协同把一批高斯装入 shared memory，像素线程再按前到后顺序合成。

这是一种全局预排序加 tile 内顺序遍历，而非逐像素精确排序。大高斯、复杂遮挡或深度交叉时，混合顺序可能是近似的。饱和像素可提前停止；整个 tile 内所有像素都饱和后停止遍历。反向传播复用前向的排序数组和 tile 范围，从后向前重走列表，而不是为每个像素保存任意长的动态数组。这样避免固定“只给前 N 个 splat 回传梯度”的限制，尽管计算量仍随实际深度复杂度增长。

5. α 混合与梯度：与体渲染同构，但没有射线采样网络

对覆盖某像素且按前到后排列的 N 个高斯，定义学习不透明度与二维高斯响应的乘积 αi，Ti 为到达第 i 个基元前仍未被遮挡的透过率：

αi(u) = oi Gi,2D(u),　Ti = Πj=1…i−1 (1−αj),　C(u) = Σi=1…N Ti αi(u) ci(d)(5)

迭代实现为 C ← C + T αi ci、T ← T(1−αi)，再加入背景项 TN+1Cbg。NeRF 离散体渲染中 αi=1−exp(−σiδi)，两者合成形式相同；区别在于 3DGS 的有序项来自已投影的显式基元，而非沿射线采样的密度查询。一个高斯的位置、轴长、旋转和 SH 都能通过像素误差获得梯度。

screenspace_points 的零值占位张量被 retain_grad 标记，CUDA 将屏幕空间位置梯度写入其中。add_densification_stats 只累计可见高斯的二维梯度范数，并同步增加 denom。也就是说，密度控制的“位置梯度”不是三维世界坐标的梯度，而是 viewspace 张量前两维的梯度。这个细节直接影响复现时统计量的尺度。

前向的 T 随混合逐步衰减，反向从最终累积量恢复所需系数，避免长列表存储。对图像 L1/SSIM 的梯度先流经合成公式，再经二维协方差、透视雅可比和三维参数回到每个高斯。深度排序本身离散不可微，算法通过固定本次遍历顺序、对局部颜色和覆盖权重求导来优化；它并不把交换遮挡顺序的过程变成光滑函数。

6. 自适应密度：克隆、分裂、修剪与 Adam 状态同步

只优化固定点集无法可靠地从稀疏 SfM 覆盖所有细节。论文在预热后每 100 次迭代进行一次密度控制，默认从第 500 次持续至第 15,000 次；阈值是平均 view-space 位置梯度 0.0002。高梯度的小高斯倾向对应欠重建，保留原件并复制一个，后续优化让二者移动、分化。高梯度且尺度较大的高斯倾向对应一个基元覆盖过多变化区域，则删除原高斯并生成 N=2 个新样本。

分裂时，以原高斯为概率分布，在局部按缩放采样标准正态、旋转到世界方向并加原均值；新缩放除以 0.8N，即 N=2 时除以 1.6。颜色和旋转继承，opacity 的原始 logit 也复制。分裂大致保持覆盖体积但提高空间分辨率；克隆增加基元总量与覆盖。源码中的 clone 并未在同一语句显式沿梯度位移，而是靠之后优化分开，这是实现上值得说明的边界。

训练每 3000 次把 opacity 激活后上限压到 0.01，再转回 logit。后续确有需要的区域可重新增大 α，无用或浮空的低 α 高斯则被修剪。max_radii2D 记录各高斯在历史可见视图中的最大屏幕半径；超过屏幕阈值，或世界空间最大轴长超过场景尺度 0.1 倍，都可能被移除。场景尺度来自训练相机中心到其均值的距离最大值乘 1.1，不是点云的坐标包围盒。

基元数变化不能只执行张量拼接或布尔索引：官方 replace/prune/cat 工具还同步更新 Adam 的 exp_avg 和 exp_avg_sq、param_groups，以及 xyz_gradient_accum、denom、max_radii2D。分裂后的统计数组重置。漏掉优化器状态会导致参数引用错位、形状不匹配或学习动态异常，这是手写复现最常见的工程陷阱之一。

7. 训练目标与官方调用链：一视图一步、渲染反传、周期性增删

基础图像目标是 L1 与 D-SSIM 的加权和：

Lphoto = (1−λ) ||Ĉ−C||1 + λ (1−SSIM(Ĉ,C)),　λ = 0.2(6)

train.py 每步从当前相机栈随机取一张训练视图，栈空后重新复制。渲染、取对应 GT、计算损失并 backward，再在 no_grad 区域更新密度统计、保存、增删高斯，最后执行优化器 step/zero_grad。默认总迭代 30,000；位置学习率从 0.00016×spatial_lr_scale 指数衰减到 0.0000016×spatial_lr_scale。其余默认学习率分别为 SH DC 0.0025、SH 高阶 0.000125、opacity 0.025、scale 0.005、rotation 0.001。

论文与固定提交的差异必须保留。当前 train.py 还可加入可靠单目逆深度监督，深度损失权重默认从 1 指数降至 0.01；也可学习每相机 3×4 曝光变换、使用 fused SSIM 或 SparseGaussianAdam。这些属于 2024 更新后的代码能力，不是论文公式 (7) 的必要组成。复现原论文对比实验时，应核对数据预处理与开关，不能仅看当前 README 的默认硬件建议。

8. 推理、输出与参数：从 PLY 到目标视图

推理时不再需要 SfM 优化或图像损失。加载点云 PLY 后恢复 xyz、log-scale、rotation、opacity logit、SH 系数，将 active_sh_degree 设为最大值。对每个目标相机，构造 world-to-camera 和投影矩阵，准备背景色与相机中心，调用光栅器即得 RGB。若要连续导航，可复用同一场景表示，只更新相机，不逐帧训练。GaussianModel.capture/restore 保存的是恢复训练所需的优化器状态与统计，不同于仅渲染所需参数。

sh_degree方向相关颜色的最高阶数官方训练默认最大 3；高阶增加存储和计算，不自动改善观察不足区域
scaling_modifier统一缩放高斯轴长可视化/调试有用，改变实际 footprint，不是无成本缩放图像
resolution / data_device控制训练图像分辨率、原图放 GPU 或 CPU影响画质、显存和数据传输，不能与论文分辨率混为一谈
white_background / random_background设置合成背景或随机训练背景应与数据透明通道、评价协议一致
densify_* / opacity_reset控制数量增长与低透明度清理场景尺度和坐标约定变化会改变阈值意义
train_test_exp启用训练/测试曝光处理是较新源码特性，评价时应与基准协议匹配

官方渲染脚本可按模型目录保存训练与测试视图，再由 metrics.py 计算指标。真正复现应使用留出视图而非训练图像来报告泛化质量，且确保训练/渲染分辨率、背景、曝光裁剪和相机拆分一致。若换用自定义 PLY，应保留官方字段顺序及原始参数化，尤其不要提前对 scale 取 exp 后又按 log-scale 加载。

9. 局限与成本：显式并不等同于小而完美

论文测试场景通常形成一百万到五百万个高斯。每个基元不仅有 3 个位置，还包括 48 个最大三阶 RGB SH 数、3 个 scale、4 个四元数、1 个 opacity；训练时还需梯度、Adam 一阶/二阶状态、密度统计及光栅化中间数组。因此“无 MLP”不代表低显存。论文指出大型场景未优化原型的训练峰值可超过 20 GB，渲染除模型外还需随分辨率和场景变化的额外光栅器内存。

成本还来自覆盖面积和重叠深度：一个高斯与越多 tile 相交，实例和排序负载越大；同像素串行混合越长，前向与反向越昂贵。32-bit 基元属性和未压缩 PLY 会扩大磁盘与显存占用，但不应把网络权重大小与场景参数大小直接比较而忽略批量与激活。

在观察不足的区域，3DGS 可能产生漂浮物、斑片状或过度拉长的高斯；大高斯经过 guard band 或遮挡次序改变时可能出现 popping。近似 tile 排序并非严格逐像素可见性，视角相关颜色与错误几何也可能互相解释。它主要针对静态、已标定场景，不原生处理动态物体、未知曝光、镜面物理传输或相机姿态优化。论文还指出极大场景可能需要降低位置学习率。

与 NeRF 相比，3DGS 的优势是显式编辑和快速光栅化，而非“所有指标都更好”；与点云相比，可优化的连续 footprint 和 α 混合减少硬点洞与离散性，但带来排序和参数冗余。pixelSplat 等前馈方法则解决另一个问题：它们用网络从稀疏输入预测高斯，将逐场景重建成本转移到跨场景训练。

10. 复现检查清单与单元测试

  • 相机约定：用单个已知点验证 world-to-camera、投影矩阵转置、像素中心、图像宽高与 FoV；构造同一点在 CUDA 与独立 NumPy 参考投影中的一致性测试。
  • 协方差合法性：随机 scale/quaternion 测试 Σ 的对称性、特征值非负，以及 q 与 −q 产生相同旋转；比较 LLT 与 R diag(s²) RT。
  • 二维椭圆：轴对齐高斯应产生与轴长对应的椭圆；旋转 90° 应交换屏幕轴。检查 Σ2D 求逆的数值稳定性与近裁剪面剔除。
  • SH 与初始化：零阶常数输入应输出恒定 RGB；检查 (L+1)² 个系数和颜色通道布局。用一个手工点云验证最近邻尺度、0.1 opacity logit 及 PLY 保存/加载往返。
  • 混合参考：对两个具有固定前后顺序的半透明高斯手算 T 和 RGB，加入背景验证总贡献；交换深度顺序应得到预期的不同结果。测试 T 足够小时的提前退出。
  • 梯度：在小型合成图上对 position、scale、rotation、opacity 做有限差分抽查，特别是 Python 预计算协方差与 CUDA 内部协方差两条路径。
  • 密度控制：构造恰好跨阈值的二维梯度与小/大高斯，分别断言 clone/split 数量、分裂轴长除以 1.6、原始高斯删除及 opacity 修剪；检查 denom 为零时无 NaN。
  • 优化器引用：每次增删后遍历 param_groups，验证参数对象、exp_avg/exp_avg_sq、统计数组长度一致；执行一次额外 step 以确保没有悬空引用。
  • 训练协议：固定随机种子、相机留出、背景和输入分辨率，逐步记录高斯总数、可见数、最大半径与损失；区分原始光度目标和新增深度/曝光选项。

建议先用少量高斯和几十像素图像做参考光栅器，再验证 CUDA 优化；先固定基元数量验证可微参数，再接入密度控制。直接把大规模训练 loss 下降作为唯一测试，会掩盖坐标、排序和参数化错误。
