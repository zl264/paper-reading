# 基础与代表论文深度精读

本系列每篇均包含原理推导、详细结构、训练/推理流程、代码、局限与来源；源码与教学实现明确区分。

- [VAE：变分自编码器](deep-dives/vae.html)：ELBO、重参数化、编码器/解码器与 PyTorch 实现。
- [DDPM：去噪扩散概率模型](deep-dives/ddpm.html)：前向加噪、后验推导、U-Net 与反向采样源码。
- [DiT：扩散 Transformer](deep-dives/dit.html)：latent patch、adaLN-Zero、噪声/协方差预测与采样。
- [Stable Video Diffusion](deep-dives/svd.html)：图像条件、时空 U-Net、EDM 与视频生成源码。
- [CogVideoX](deep-dives/cogvideox.html)：3D 因果 VAE、T5 与文本视频联合 DiT。
- [3D Gaussian Splatting](deep-dives/3dgs.html)：显式高斯、可微光栅化、自适应密度控制与源码。
- [pixelSplat](deep-dives/pixelsplat.html)：多视图 Transformer、概率深度与前馈高斯预测。
- [MVSplat](deep-dives/mvsplat.html)：平面扫描代价体、多视图融合与高效高斯重建。
- [World Models](deep-dives/world-models.html)：VAE、MDN-RNN、控制器与梦境 rollout。
- [Genie](deep-dives/genie.html)：视频 tokenizer、潜在动作与动态环境预测。
