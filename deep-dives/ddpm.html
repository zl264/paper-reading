一、问题设定：把生成拆成一千个可学习的高斯反向转移

DDPM 处理的是无条件图像密度建模：x0∼q(x0) 是一张真实图像，x1,…,xT 与它同维，而不是一个较小的语义向量。模型从 p(xT)=N(0,I) 出发，经马尔可夫链逐步得到 x0。与只训练一个 x→z 编码器的 VAE 不同，这里前向近似后验 q(x1:T|x0) 被固定为逐渐加噪的链，学习集中在反向去噪器。

pθ(x0:T) = p(xT) Πt=1T pθ(xt−1|xt),　pθ(xt−1|xt) = N(μθ(xt,t), Σθ(xt,t))(1)

输入是带噪图像 xt 和整数时间 t，网络输出与图像同形的预测噪声 εθ；实际生成输出是完整图像，而不是低维特征。T 次转移共享一套参数，时间嵌入告诉网络当前噪声水平。相比自回归模型按像素顺序展开，它按噪声尺度展开；相比 GAN 的生成器—判别器博弈，它只需回归加噪时已知的目标。代价是原始采样需要顺序执行 T 次网络。

论文使用 CIFAR10 32×32、CelebA-HQ 与 LSUN 256×256，图像整数 {0,…,255} 线性缩放到 [−1,1]。缩放的目的是让网络输入与标准高斯先验尺度相容。代码张量顺序为 NHWC；论文的 t∈{1,…,T} 在 Python/NumPy 数组索引中对应 tcode=t−1∈{0,…,T−1}，以下推导用论文索引，源码段落另作说明。

二、前向过程、任意步加噪与可解高斯后验

令 βt∈(0,1) 为预先给定的方差计划，αt=1−βt，ᾱt=Πs=1tαs。每个前向节点把上一幅图略微缩小并添加独立高斯：

q(xt|xt−1) = N(√αt xt−1, βtI),　q(x1:T|x0) = Πt=1Tq(xt|xt−1)(2)

把 εs 相互独立地代入递推，均值的系数连乘，方差相加，得到任意一步的闭式边缘。这个性质省去训练时逐节点模拟整条链：

q(xt|x0) = N(√ᾱtx0, (1−ᾱt)I),　xt = √ᾱtx0 + √(1−ᾱt)ε,　ε∼N(0,I)(3)

只条件于 xt 时，逆向前向后验通常不可解；再条件于真实 x0，两个高斯密度的指数都是 xt−1 的二次式，乘积仍为高斯。比较二次项和一次项可得：

q(xt−1|xt,x0) = N(μ̃t(xt,x0), β̃tI)(4)
μ̃t = [βt√ᾱt−1/(1−ᾱt)]x0 + [√αt(1−ᾱt−1)/(1−ᾱt)]xt,　β̃t = βt(1−ᾱt−1)/(1−ᾱt)(5)

这两个系数分别乘真实干净图像和当前带噪图像。β̃1=0 是因为已知 x0 后，q(x0|x1,x0) 退化为确定分布；对 KL 取对数时不能直接把 0 送入 log，源码对此使用了替换或截断。若训练损失目标直接取 ε，则必须把加噪时同一份 ε 保留下来，不能再抽一份。

三、ELBO 如何逐项化为噪声回归

从 log pθ(x0)≥Eq[log pθ(x0:T)−log q(x1:T|x0)] 出发，对负下界展开，并用 q(xt|xt−1,x0)=q(xt−1|xt,x0)q(xt|x0)/q(xt−1|x0) 重新组合相邻项，可得到：

L = Eq[LT + Σt>1Lt−1 + L0](6)
LT=DKL(q(xT|x0)‖p(xT));　Lt−1=DKL(q(xt−1|xt,x0)‖pθ(xt−1|xt));　L0=−log pθ(x0|x1)(7)

β 固定时 LT 不依赖 θ，可从训练目标删除；t>1 的项都是高斯间 KL。若模型方差固定为 σt²I，则除与 θ 无关的常数 C 外，KL 变成均值平方误差。代入式 (5)，再以 x0=(xt−√(1−ᾱt)ε)/√ᾱt 消去 x0，得到：

Lt−1−C = E[ (1/(2σt²)) ‖(1/√αt)(xt−βtε/√(1−ᾱt))−μθ(xt,t)‖² ](8)

因此一个自然参数化是 μθ=(xt−βtεθ/√(1−ᾱt))/√αt。代入后，均值误差就转化为噪声误差：

Lt−1−C = E[ βt² / (2σt²αt(1−ᾱt)) · ‖ε−εθ(xt,t)‖² ](9)

DDPM 的实际简化目标 Lsimple=Et,x0,ε[‖ε−εθ(√ᾱtx0+√(1−ᾱt)ε,t)‖²] 去掉式 (9) 前面的时间相关系数，并均匀抽 t。它是重加权后的变分目标，不是逐项等价于原始 ELBO；论文报告它改善样本质量，而真正 VLB 训练的码长更好。t=1 的 L0 在简化目标中近似为密度乘 bin 宽度，完整离散似然则需要在 1/255 宽度的区间积分高斯。

不要把“MSE 训练”与“精确最大化数据似然”画等号。源码同时提供 loss_type='kl' 与 'mse' 路径；CIFAR 默认选未加权 MSE。评估 bits/dim 还单独计算 KL、离散解码 NLL 和先验项，而不是把 MSE 直接解释成 log-likelihood。

四、方差不是噪声幅度：固定 β、β̃ 与可学习分支

前向 βt 控制 q(xt|xt−1) 的新增方差；β̃t 是已知 x0 后逆推 xt−1 的后验方差；σt² 是模型实际反向转移 pθ(xt−1|xt) 使用的方差。三者相关但不是同一个量。论文实验固定 σt²=βt 或 β̃t，结果相近；前者对应数据坐标为独立标准高斯的极端情形，后者对应数据确定于一点的极端情形。

xt−1 = μθ(xt,t) + σtz = (1/√αt)[xt−(βt/√(1−ᾱt))εθ(xt,t)] + σtz(10)

t>1 时 z∼N(0,I)，最后一步不添噪声。预测 ε 后，另一种完全一致的均值计算是先求 x̂0=(xt−√(1−ᾱt)εθ)/√ᾱt，再把 x̂0 代入 μ̃t(xt,x̂0)。官方 CIFAR 路径采用后者，并将 x̂0 裁剪到 [−1,1]；这个裁剪影响实际采样均值，不能省略后仍声称逐操作一致。

在 diffusion_utils_2.py 中，model_var_type='fixedlarge' 把反向方差设为 βt，'fixedsmall' 设为 β̃t；'learned' 要求网络输出通道翻倍，一半作均值参数、一半作 log variance。CIFAR 入口默认 eps/fixedlarge/mse，即预测噪声、固定 β、未加权 MSE；这与论文实验的选择一致。旧版 diffusion_utils.py 被 LSUN/CelebA-HQ 入口调用，则只实现噪声预测并用 β̃ 采样，阅读时不能混为同一条配置。

五、时间嵌入、残差块、自注意力与 U-Net 形状

官方 nn.py 生成 sinusoidal 时间嵌入：对维度一半计算频率，指数步长含 log(10000)，把 t 乘频率后拼接 sin 和 cos，得到 [B,ch]。U-Net 再将 ch 维映射到 4ch，经 Swish 和第二层 dense，最终时间向量 temb 为 [B,4ch]。它不是学习到的 t 查表，也不是额外图像 token。

每个 残差块 的顺序为 GroupNorm→Swish→3×3 conv→加入时间投影→GroupNorm→Swish→dropout→3×3 conv，再加残差。时间向量经 dense 后 reshape/广播为 [B,1,1,Cout]；通道变化时 shortcut 用 3×3 conv 或 1×1 NIN。第二个卷积、attention 输出投影和最终输出卷积采用 init_scale=0 的近零初始化，让初始残差分支较小。

自注意力仅在空间边长属于 attn_resolutions 时启用。q,k,v 都是 1×1 投影；对 NHWC，q/k 的点积缩放到 [B,H,W,H,W]，每个位置关注同一张特征图的所有 HW 位置，softmax 后聚合 v 并残差相加。它不是跨 batch 或跨时间注意力，复杂度随 HW 的平方增长。

CIFAR 使用 ch=128, ch_mult=(1,2,2,2), num_res_blocks=2，空间尺度为 32→16→8→4，通道为 128→256→256→256；仅 16×16 处加注意力。中间是残差—注意力—残差；上采样每级有 num_res_blocks+1 个块，用 tf.concat([h, hs.pop()], axis=-1) 拼回对应下采样特征，最后 GroupNorm、Swish、卷积输出 3 通道（可学习方差时为 6）。256×256 配置为六尺度、ch_mult=(1,1,2,2,4,4)，对应通道最高 512；论文分别给出 35.7M 与 114M 参数。

def training_losses(self, denoise_fn, x_start, t, noise=None):
  assert t.shape == [x_start.shape[0]]
  if noise is None:
    noise = tf.random_normal(shape=x_start.shape, dtype=x_start.dtype)
  x_t = self.q_sample(x_start=x_start, t=t, noise=noise)

  if self.loss_type == 'kl':
    losses = self._vb_terms_bpd(
      denoise_fn=denoise_fn, x_start=x_start, x_t=x_t, t=t,
      clip_denoised=False, return_pred_xstart=False)
  elif self.loss_type == 'mse':
    assert self.model_var_type != 'learned'
    target = {
      'xprev': self.q_posterior_mean_variance(x_start=x_start, x_t=x_t, t=t)[0],
      'xstart': x_start,
      'eps': noise
    }[self.model_mean_type]
    model_output = denoise_fn(x_t, t)
    losses = nn.meanflat(tf.squared_difference(target, model_output))
  else:
    raise NotImplementedError(self.loss_type)
  return losses

七、官方反向采样：从 x̂₀ 到高斯转移

CIFAR 的 p_mean_variance 首先执行 εθ(x,t)，通过 _predict_xstart_from_eps 得到 x̂0，再裁剪；随后调用 q_posterior_mean_variance 计算 μ̃。固定大方差时实际用于采样的 log variance 是 log βt，但为 t=0 的对数 KL 计算另行替换首项。最后的 nonzero_mask 确保代码索引 0 不再加噪。

官方源码 · diffusion_tf/diffusion_utils_2.py · L186–219
def p_sample(self, denoise_fn, *, x, t, noise_fn, clip_denoised=True, return_pred_xstart: bool):
  model_mean, _, model_log_variance, pred_xstart = self.p_mean_variance(
    denoise_fn, x=x, t=t, clip_denoised=clip_denoised, return_pred_xstart=True)
  noise = noise_fn(shape=x.shape, dtype=x.dtype)
  # no noise when t == 0
  nonzero_mask = tf.reshape(1 - tf.cast(tf.equal(t, 0), tf.float32),
                            [x.shape[0]] + [1] * (len(x.shape) - 1))
  sample = model_mean + nonzero_mask * tf.exp(0.5 * model_log_variance) * noise
  return (sample, pred_xstart) if return_pred_xstart else sample

def p_sample_loop(self, denoise_fn, *, shape, noise_fn=tf.random_normal):
  i_0 = tf.constant(self.num_timesteps - 1, dtype=tf.int32)
  img_0 = noise_fn(shape=shape, dtype=tf.float32)
  _, img_final = tf.while_loop(
    cond=lambda i_, _: tf.greater_equal(i_, 0),
    body=lambda i_, img_: [
      i_ - 1,
      self.p_sample(
        denoise_fn=denoise_fn, x=img_, t=tf.fill([shape[0]], i_),
        noise_fn=noise_fn, return_pred_xstart=False)
    ],
    loop_vars=[i_0, img_0], shape_invariants=[i_0.shape, img_0.shape],
    back_prop=False
  )
  return img_final

上段省略少量输入/输出形状断言；完整版本见 L186–219。注意变量名 img_0 实际是初始噪声，并非最后图像。tf.while_loop 从 T−1 到 0，back_prop=False，每次调用同一个去噪器但填入不同 t；不能并行跳过中间状态。仓库也提供 progressive 版本记录 x̂0，旧版还提供轨迹和插值接口。

calc_bpd_loop 是另一条评估调用链：对每个 t 加噪，t=0 用离散高斯 NLL，其余用真实后验与模型转移间 KL，再加 prior KL。discretized_gaussian_log_likelihood 用近似标准正态 CDF 计算 ±1/255 区间概率，对 ±1 两端使用单侧尾部。评估默认使用 EMA 权重，这与训练时更新 θ 的路径不同。

八、DDIM：同一噪声模型，不同反向随机性

DDIM 来自 Song、Meng、Ermon 的后续论文，不属于 2020 年 DDPM 原文，也不存在于所核验的 hojonathanho 仓库。它构造一族条件于 x0 的非马尔可夫推断分布，但保持每个 q(xt|x0) 边缘与 DDPM 相同。因训练只依赖这些边缘的加噪形式，同一个 εθ 可以复用而无需重新训练。

以下用 ᾱ 表示 DDPM 的累积系数；DDIM 原论文把同类累积量写作 α。给定当前步 t 与前一步 s（完整链中 s=t−1，跳步时 s=τi−1），先计算 x̂0，再定义：

x̂0=(xt−√(1−ᾱt)εθ(xt,t))/√ᾱt,　σt,s(η)=η√[(1−ᾱs)/(1−ᾱt)]√(1−ᾱt/ᾱs)(11)
xs = √ᾱsx̂0 + √(1−ᾱs−σt,s²)εθ(xt,t) + σt,sz,　z∼N(0,I)(12)

η=1 时得到 DDPM 对应的马尔可夫随机生成过程；η=0 时随机项消失，得到 DDIM 的确定映射。固定初始 xT 后，确定映射使插值和重建更可控，但不意味着网络误差消失。可在递增子序列 τ⊂{1,…,T} 上采样，从 τ 的末端逆向走到起点，从而减少网络调用；跳步改变了近似与更新，不应承诺任意少步都保持同样质量。

教学伪代码 · 非 DDPM/DDIM 官方源码
# 仅说明 DDIM 论文式 (12)；不是 hojonathanho/diffusion 中的函数。
# tau 为递增的一基论文时间索引；abar 是零基数组，abar[k-1] 对应 ᾱ_k。
# x 已在 tau[-1] 处初始化为标准高斯。
for i in reversed(range(1, len(tau))):
    t, s = tau[i], tau[i - 1]
    a_t = abar[t - 1]
    a_s = abar[s - 1] if s > 0 else 1.0  # 约定 ᾱ_0=1
    eps = denoise(x, t - 1)               # 网络与数组均使用零基索引
    x0 = (x - sqrt(1 - a_t) * eps) / sqrt(a_t)
    sigma = eta * sqrt((1 - a_s) / (1 - a_t) * (1 - a_t / a_s))
    direction = sqrt(1 - a_s - sigma**2) * eps
    x = sqrt(a_s) * x0 + direction + sigma * randn_like(x)
return x

这段伪代码已显式转换一基论文时间与零基数组索引，但刻意不处理框架特有的图构建、clip、batch 广播和 τ 终点之后的最后一步，不能直接当作上游复现脚本。要接入已训练 DDPM，应使用训练时同一份 β/ᾱ、时间索引和 [−1,1] 数据约定，并分别记录 η、轨迹长度和初始种子。DDIM 不是通过“把 DDPM 的 σ 随便设零”就自动得到所有性质的通用最优采样器。

九、成本、实验结论与真实边界

训练每张图只需随机一个 t 和一次去噪器前向，避免完整 T 步反向链；但采样默认要 T 次串行 U-Net。论文在 TPU v3-8 上报告：CIFAR batch 128、800k steps 约 10.6 小时，256 张采样 17 秒；256×256 模型 batch 64，128 张采样 300 秒。这是原文特定硬件与实现的观测，不是本地测量，也不能直接换算到任意 GPU。

显存来自多尺度激活、残差中间值、上采样 skip concat 与注意力矩阵。16×16 自注意力的单样本权重已是 256×256 项；空间 HW 增大时平方增长，这是高分辨率成本的重要来源。训练还要保留反向传播激活，而采样 back_prop=False 不构造反向图，两者显存不可直接比较。论文训练时 EMA 还维护一份滑动平均参数。

原论文报告 CIFAR 的 Lsimple 配置 FID 3.17、IS 9.46，同时承认对数似然不具竞争力；固定方差真实 VLB 的码长略好但样本质量较差。这说明 MSE、FID 与 NLL 是不同目标，不能互相替代。原模型是无条件图像模型，没有文本编码器、classifier-free guidance、latent VAE、级联超分辨率或视频时间维。把后续 Stable Diffusion 的组件投射到这份代码上会得到错误架构图。

与 VAE 的关系也应准确表述：DDPM 可视为潜变量与数据同维、层级很长的变分模型，但其 q 固定；它没有 VAE 那种可学习且低维的摊销编码器。DDIM 改变生成过程而非训练网络；跳步是速度/质量权衡，不是 DDPM 官方默认循环的原有选项。

十、复现清单与单元测试建议

  • 固定 SHA 1e0dceb3b3495bbe19116a5e1b3596cd0706c543，区分 CIFAR 的 GaussianDiffusion2 与大图的 GaussianDiffusion，记录 model_mean_type/model_var_type/loss_type。
  • 用纯 NumPy 对照 β→α→ᾱ、两个 posterior mean 系数和 β̃；检查 β̃1=0，且 log 方差首项不会产生 NaN。
  • 固定 x0、t、ε，手算式 (3)，与 q_sample 比较；用同一 ε 计算 _predict_xstart_from_eps，应还原 x0，再检查裁剪仅在采样路径发生。
  • 从 q(xt−1|x0) 和 q(xt|xt−1) 的指数配方法独立推导 μ̃、β̃，与小 T 的数值高斯积分或已知公式比较。
  • 令 denoise_fn 返回零，检查训练目标在 eps 模式等于 ε² 的空间均值；检查每个样本可拥有不同 t，且系数广播为 [B,1,1,1]。
  • 构造小的 NHWC 张量，验证 32→16→8→4 的下采样、skip 栈最终为空、输出通道与输入通道一致；对注意力单独验证每个位置权重和为 1。
  • DDPM 采样用固定 RNG，验证调用 t 的顺序为 T−1…0、最后不加噪；比较 μ̃(xt,x̂0) 与式 (10) 的代数一致性。
  • 对 DDIM 教学实现，验证 η=0 时相同初始状态及种子产生完全相同轨迹；η=1 且完整相邻时间步时，核对与所选 DDPM 方差约定的代数关系，而非只比较图像。
  • 检查数据严格映射到 [−1,1]，FID 使用论文规定的样本数/参考集；不将 MSE 当作 bits/dim，不省略 EMA 后声称复现表格。
