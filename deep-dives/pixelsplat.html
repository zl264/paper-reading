1. 任务与范式：从逐场景拟合到跨场景前馈重建

pixelSplat 的输入是一对参考图像、各自相机内外参与近远平面，输出是两视图预测的像素对齐高斯之并集；给定目标相机，输出新视角 RGB，也可输出深度。它通过在 RealEstate10k、ACID 等大量场景上训练一个共享网络，学习从稀疏观测推断三维辐射场。推理一个新场景时只做一次编码器前向，不做原始 3DGS 那种数万步逐场景优化。

原始 3DGS 的高斯参数本身就是优化变量，可借非可微的克隆、分裂、修剪改变基元布局。pixelSplat 的参数由编码器预测，训练梯度必须穿过高斯集合回到共享网络；直接移动一个局部支撑的椭球容易卡在错误位置，又不能用不可微操作任意生成或删除它。论文因此把“高斯在哪里”重写为“每条射线上各深度的概率是多少”，再让采样位置和概率耦合。

图 1：pixelSplat 将多视图预测与概率深度结合。依据论文机制与公开代码重新绘制；模块形状用于说明数据流，而非照搬论文插图。

另一障碍是 SfM 位姿只有任意尺度：同一张室内照片无法单独决定物体究竟是一米还是十米，输出却必须与该场景重建的相机平移尺度一致。pixelSplat 不是先估计一个全局尺度标量再相乘，而是在极线采样点上注入由两相机三角化得到的深度编码，让注意力通过对应关系取得尺度相容的几何线索。这里的“解决尺度歧义”是多视图条件推断，并非从无约束单目图像恢复真实米制。

2. 网络结构与数据流：主干、两轮极线注意力、逐像素头

EncoderEpipolar 接收 context[image]，形状为 B×V×3×H×W；主实验 V=2。DINO 主干由 DINO 预训练 ResNet-50 和 ViT-B/8 组成，将 ResNet 特征、ViT 局部 token 重排到原分辨率后的特征、ViT 全局 token 广播特征相加。之后 ReLU+Linear 投影为 d_feature=128。与仅把低分辨率 ViT token 直接解码相比，这种像素对齐特征保留了预测每个像素高斯的接口。

极线 Transformer 先用 stride=kernel=4 的卷积降采样，因此 256×256 特征变成 64×64；注意力 query 为每个视图像素位置，key/value 来自其他视图沿极线的样本。配置 num_layers=2、num_heads=4、d_dot=128，深度编码有 10 个 octave。每层之后的 feed-forward 位置被 ImageSelfAttentionWrapper 替换为逐图自注意力，在单张图像内部传播信息，而不是执行普通全局 MLP。结束后用转置卷积升回 4 倍，再经两层 7×7 卷积细化并加残差。

特征回到 H×W 后，再叠加一个由原 RGB 经 7×7 卷积得到的高分辨率 skip。逐像素 DepthPredictorMonocular 输出 2×Z×S 个数，Z=32 是深度桶，S=1 是表面数；softmax 得到深度概率，sigmoid 得到桶内 offset。另一个 to_gaussians 头输出 S×(2+7+3DSH)，前两个是像素内位置偏移，其余是 3 个 scale、4 个四元数和三通道 SH。默认 SH 阶数 4，所以 DSH=25。

训练每像素独立采样三次，故 H=W=256、V=2、S=1 时，一个场景产生 2×256×256×3=393,216 个高斯。deterministic=True 时采样数强制为 1，走 top-k 等价的最大概率桶，产生 131,072 个高斯。最终把 B×V×R×S×M 合并为 B×G，再被目标视图共享使用。网络不会先对两个视角重合的高斯去重，重复覆盖是其显式设计局限。

3. 极线 Transformer：把候选对应和对应深度一起编码

对于参考图 I 的像素 u，其射线由相机内参 K 和 camera-to-world 外参 T 确定。将该射线在另一视图 Ĩ 中投影，近、远平面交点定义有效极线区段 ℓ。官方 EpipolarSampler 在该区段均匀取 S=32 个归一化图像坐标，grid_sample 双线性抽取另一视图的特征。若视锥区段不与图像相交，使用 overlaps_image 将采样特征置零。

每个候选点 ũl 不只提供外观特征，还和原射线三角化，得到该对应若成立时在原相机中的深度 d̃l。深度先裁剪到 near/far，再转换为 relative disparity，经过频率位置编码 γ 与线性投影，和采样特征相加。论文用拼接符号描述“特征加深度编码”，固定提交实现是相加，两者通道都投影到 128：

sl = F̃[ũl] + P(γ(disparity(d̃l))),　q = QF[u],　kl = Ksl,　vl = Vsl(1)
F[u] ← F[u] + softmaxl(q·kl/√d) vl,　F ← F + SelfAttention(F)(2)

当外观匹配选中正确极线位置时，value 也携带该位置的深度编码，因此 query 特征能获得与当前 SfM 尺度一致的深度线索。没有可靠跨视图对应的区域，由逐图 self-attention 传播邻近信息填补，但这只是先验推断，不是真实观测恢复。

4. 概率深度：用离散分布替代单点深度回归

直接回归 d，然后 μ=o+d·r，会让均值只能从一个局部起点连续移动。高斯在错误位置几乎没有响应时，梯度很弱；即使移向真值，途中也可能先遮挡背景导致损失升高。pixelSplat 沿每条像素射线设置 Z 个深度桶。在视差空间均匀采样，z=0…Z−1：

bz = [(1−z/Z)(1/dnear−1/dfar) + 1/dfar]−1(3)

视差均布意味着近处深度划分更密、远处更稀，符合透视下近处像素运动更敏感的特点。网络输出 φ=softmax(a)，作为桶的归一化概率，并对每个桶输出 δ=sigmoid(b)。采样索引 z 后，用 (z+δz)/Z 表示相对视差，再转换为深度，而不是简单把 δ 当作一个世界坐标单位加到 bz。这与代码的 relative_disparity_to_depth 一致，也比文字公式的简写更明确。

ρ = (z+δz)/Z,　d = [1/dnear + ρ(1/dfar−1/dnear)]−1,　μ = o + d·ru(4)

sample_discrete_distribution 先再次归一化 pdf，累加为 CDF，以均匀随机数和 searchsorted 反演采样；gather 同时取回 φz 和 δz。训练时同一分布独立采样 M=3 次，使一次前向能让多个候选深度收到图像监督。deterministic 分支不是取期望深度，而是 top-k；当样本数被 EncoderEpipolar 固定为 1 时，就是概率最大的桶。

5. 可微采样的关键：把被抽中桶的概率作为不透明度

离散索引 z 的采样本身不可微，但取回的 φz 是普通可微张量。pixelSplat 将抽中高斯的不透明度设为该概率（训练再除以 M）：

z ~ pφ(z),　α = φz/M,　∂L/∂az 经由 α=softmax(a)z 回传(5)

若某次抽样的高斯改善渲染，梯度通常推动其 opacity 增大，softmax 相应提高以后再次采到该桶的概率；若它造成错误遮挡，梯度可压低 opacity 和该桶概率。网络于是能以连续概率变化实现软性的“生成/淘汰”，无需把不可分割的 clone/prune 操作插入编码器计算图。训练时 M=3 条样本共享同一条射线，除以 3 避免总 opacity 因样本数直接翻三倍。

不要把它误写成普通连续 VAE 重参数化。这里没有 z=μ+σ·ε 的连续位置变换，也没有直接用 ∇φμ 穿过离散采样；可微通道是 gather 回来的概率到 opacity 的恒等映射。它能提供有用学习信号，但不是无偏的路径导数估计，也不保证离散索引采样方差消失。

固定提交的 map_pdf_to_opacity 还支持幂次 warm-up，一般公式为 0.5[1−(1−p)e+p1/e]，e 随 global_step 变化。然而默认 initial=final=0、warm_up=1，即 e=1，映射退化为 p。use_transmittance 默认 false；若开启，会先计算 p/(1−cumsum_previous+ε) 再 gather，以桶间剩余透过率修改概率。这些分支不能省略成“实现永远 α=φ/3”的绝对规则。

可选 predict_opacity 还会增加独立 sigmoid 乘子，但默认 false。因而官方默认主路径仍是 PDF 概率控制不透明度；独立颜色、尺度和旋转头则正常通过可微回归监督。概率采样解决的是位置的局部极小与学习信号问题，不意味着模型能自动发现完全不可见区域的真实几何。

6. 从像素头到世界高斯：尺度、协方差与 SH 旋转

GaussianAdapter 将原始输出切为 scale(3)、rotation(4)、SH(3DSH)。scale 经 sigmoid 映射到 [0.5, 15]，再乘深度和由归一化内参、像素尺寸得到的 0.1 倍尺度因子。因此高斯的物理范围会随射线上深度和相机焦距变化，而不是固定为若干世界单位。四元数除以自身范数，DSH 各阶在初始化乘衰减 mask：一阶起乘 0.1×0.25ℓ，使高阶方向分量初始更小。

Σcam = R(q) diag(s2) R(q)T,　Σworld = Rc2w Σcam Rc2wT,　μworld = o + d·r(6)

由于编码器预测的是相机空间的高斯，外参不仅平移均值，还必须旋转协方差。方向相关 SH 也不能原样搬运：官方 rotate_sh 使用 e3nn 约定的 Wigner D 矩阵把 SH 从相机坐标旋到世界坐标。opacity 在旋转中保持不变。若仅将 μ 乘外参、却忘记 Σ 和 SH，目标视角中会出现椭圆朝向或反光方向错误。

7. 可微渲染与训练损失：同一高斯场渲染多个目标视图

ModelWrapper.training_step 先编码 context，再把输出高斯与 target 相机交给 DecoderSplattingCUDA。decoder 将 B 个场景、V 个目标视图展开成 B·V 次渲染任务，每视图 repeat 同一份场景高斯。render_cuda 默认按 1/near 将相机平移、均值、协方差和 near/far 一起缩放，以改善数值范围；协方差乘 scale²，均值和相机平移乘 scale，保证几何相似而不改变渲染。

投影矩阵使用 OpenCV 风格 camera-to-world 外参的逆，并采用 z 映射到 [0,1] 的形式；归一化内参转 FoV。循环中构造 GaussianRasterizer，以 cov3D_precomp 的上三角六个数输入，SH 从 B×G×3×D 转成 B×G×D×3。最终颜色堆叠回 B×V×3×H×W。深度渲染不是另一套几何积分，而是把高斯相机空间 z（或 disparity 等变换）作为固定 RGB，再用同一 α 混合渲染并平均三通道。

深度正则不是主模型必需项。对应配置使用 50,000 步 fine-tune，并启用 log-depth 归一化的邻域差分、二阶差分与图像边缘衰减；固定代码采用 exp(−σimage·颜色差) 和绝对值均值。论文附录公式出现正指数的排版，但实现应以此处代码为准并说明版本边界。主实验默认 train.depth_mode=null，不应无故给每次训练都加深度损失。

8. 仓库结构与真实调用链：Hydra 配置如何落到模块

9. 推理步骤、成本与真实局限

完整推理顺序是：准备固定数量的带位姿参考图；执行 patch/bounds 数据变换；提取 DINO 双主干特征；执行两轮极线交叉与逐图自注意力；预测深度 PDF、offset、像素偏移、scale、rotation 和 SH；随机采样或选最大概率桶；转换到世界高斯；最后对任意多个目标相机重复 splatting。编码成本按场景支付一次，渲染成本按视图支付，这比每条新射线重新跑光场解码更有利于多帧输出。

可调的 deterministic 会改变高斯数和位置分布：验证 deterministic=True 只取每桶最大概率，并非取 3 个 top-k，因为编码器将样本数参数强制为 1。若在其他调用路径直接设置 num_samples>1，则 DistributionSampler 可返回 top-k。随机推理可产生视图间不稳定性；要求可重复输出时应固定随机种子或使用确定性路径，并明确它与论文主测试设置的差异。

主要限制有四点。第一，需要准确相机与适当 near/far，宽基线遮挡或无纹理区域仍只能靠先验。第二，两视角高斯简单求并，不做融合去重；第三，未观测区域没有生成式补全，不能把 plausible 颜色当真实几何。第四，更多参考视图会增加极线注意力 key/value 和显存。论文还观察到反光表面可能变透明、从分布外视角看高斯像 billboard，这些问题继承自显式 splat 表示与训练分布。

成本不能只引用“渲染快”：256² 双图训练样本就产生近 40 万个高斯，编码器还需在 64×64 特征、每线 32 个样本上做多视图注意力。论文报告在其设置下比对比光场 Transformer 大幅降低编码加多帧渲染时间和训练内存，但场景目标视图数、图像分辨率和 GPU 都会改变结论。与 3DGS 的关系应是“共享显式表示和光栅器、不同参数获得方式”，而不是前者无条件取代后者。

10. 复现与单元测试清单：先验证几何，再验证学习

  • 相机与极线：用已知的平移双目相机验证同一三维点落在对应极线上，near/far 端点顺序正确；测试视锥不相交时 overlaps_image 和特征置零，检查 grid_sample 的 [0,1] 到 [−1,1] 转换。
  • 三角化与尺度：将整套世界坐标、相机平移、near/far 同乘 s，三角化深度应相应乘 s，relative disparity 保持一致。验证深度编码的 batch/view/other_view 轴没有转置错误。
  • 注意力形状：在 B=1、V=2、小 H/W 下手算 query 与 kv 数量；确保 key/value 的 sample 轴合并的是 S×(V−1)，图像 self-attention 不跨场景、不跨视图。
  • 深度桶：测试 z=0、Z−1 和 offset=0/1 的端点，验证 disparity 线性而 depth 非线性；PDF 每射线归一化到 1，gather 的索引和 offset 属于同一个桶。
  • 随机/确定采样：固定随机种子时 CDF 反演应可复现；单峰分布总命中正确桶。deterministic=True 配合编码器只返回一个最大概率桶，不要误断言返回三个。
  • 梯度通道：对单像素合成渲染的 opacity 求导，检查梯度经 gather、softmax 回到所有 logits；确认离散 index 没有伪梯度，训练 M=3 时 opacity 有 /3。
  • 高斯几何：检查 Σ 对称半正定，四元数归一化，scale 随深度和内参变化；将相机旋转后，均值、协方差和 SH 应一致变换，而非仅移动均值。
  • 尺度不变渲染：对 means、extrinsic translation、covariance、near/far 按代码同时缩放，在数值容差内输出应一致；协方差必须乘 s² 而不是 s。
  • 损失与课程：149,999 步 LPIPS 应为零，150,000 步后权重为 0.05；验证参考视图 gap 的课程、每场景 4 个 target、batch=7、Adam warm-up 与梯度裁剪。
  • 版本与评价：锁定提交和匹配 checkpoint，使用官方 evaluation index，分别记录随机和确定性输出、编码与解码耗时及峰值显存，不把不同版本数字拼接比较。

推荐实现顺序为：独立几何函数与简单两像素 splat 参考实现；不接注意力的单视图概率深度；接入极线采样与深度编码；最后接完整 DINO 主干和多目标训练。这样可以在显存和训练时间大幅增加之前定位坐标轴、采样轴和梯度路径错误。
