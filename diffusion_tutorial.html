01什么是扩散模型

1.1 生成模型：让 AI 学会「无中生有」

所谓生成模型（Generative Model），就是从海量数据中学习到数据的分布 pdata(x)，然后能从这个分布里采样新样本的模型——给它看一亿张猫的照片，它就能画出一亿零一张「新的猫」。

过去十年里，学界主要沿着四条路线攀登这座山：

路线核心思想优点缺点代表
GAN生成器与判别器对抗博弈生成快（单次前向）训练不稳定、模式坍塌、难以扩展StyleGAN
VAE编码到隐空间再解码，最大化 ELBO训练稳定、有隐空间结构生成结果偏模糊VQ-VAE
自回归逐像素 / 逐 token 预测「下一个」概率建模清晰、可扩展性极好采样必须串行、速度慢GPT、PixelRNN
扩散模型逐步加噪破坏数据，再学习逐步去噪还原训练稳定（纯 MSE 回归）、质量极高、可控性强采样需多步迭代（可加速到 20~50 步）DDPM、Stable Diffusion、Sora

扩散模型把「生成」这个困难问题，拆解成了几千个极其简单的「去掉一点点噪声」的小问题——每个小问题都是一个普通回归任务，神经网络学得又稳又好。这正是它在 2020 年后迅速统治图像生成领域的根本原因。

1.2 一句话核心思想

核心思想

训练时：往真实图像里一步步加高斯噪声，直到它变成纯随机噪声（这个过程是固定的、不需要学习的），同时训练一个神经网络，在任意噪声程度上预测图像里混入了多少噪声。

生成时：从纯高斯噪声出发，反复调用这个网络「减去一点点噪声」，迭代几百步（或加速到几十步），噪声就逐渐「结晶」成一张清晰的图像。

—— 扩散模型本质上就是一个学出来的去噪器（Denoiser）。

1.3 发展史：从冷门物理概念到 Sora 的基石

  • 2015扩散模型的思想起源 —— Sohl-Dickstein 等人在《Deep Unsupervised Learning using Nonequilibrium Thermodynamics》中借用非平衡热力学的扩散概念，首次提出用「逐步加噪 / 逐步去噪」做生成建模，但当时效果平平。
  • 2020.06DDPM（划时代） —— Ho 等人发现：只要把训练目标简化成「预测噪声的 MSE」，再配上一个 U-Net，扩散模型就能达到与 GAN 相当的图像质量。现代扩散模型框架就此奠定。
  • 2020.10DDIM —— Song 等人提出非马尔可夫采样，把采样从 1000 步加速到 20~50 步，且支持确定性生成（同一噪声 → 同一张图）。
  • 2021.02Improved DDPM —— cosine 噪声调度 + 学习方差，首次在 ImageNet 上全面超越 GAN。
  • 2021.12Latent Diffusion（SD 前身） —— Rombach 等人把扩散搬到 VAE 的潜空间，并用交叉注意力注入文本条件，训练成本骤降一个数量级。
  • 2022.08Stable Diffusion 开源 —— AI 绘画全民化的起点，「文生图」成为消费级应用。
  • 2023DiT —— Peebles & Xie 用纯 Transformer（而非 U-Net）做扩散主干，成为 Sora 视频生成模型的基础架构。
  • 2024+Flow Matching / 视频扩散 —— SD3 采用整流流匹配（Flow Matching）统一框架；Sora 把扩散扩展到时空 patch，生成 60 秒视频。

1.4 为什么扩散模型最终胜出

  1. 训练极其稳定 —— 损失就是一个均方误差（MSE），像拟合回归一样平稳收敛；没有 GAN 的对抗博弈、模式坍塌、梯度爆炸。
  2. 生成质量天花板高 —— 多步迭代天然适合精细修正，细节与全局结构兼得，在 FID 等指标上全面领先。
  3. 可控性无与伦比 —— 文本条件（cross-attention）、类别条件、图像条件（ControlNet）、引导强度（CFG）都能精细操控生成结果。
  4. 与 Transformer / Scale Law 天然契合 —— 去噪网络可换成任意大模型（DiT、Sora），数据越多、模型越大，效果越好，没有对抗训练的扩展瓶颈。
  5. 采样慢的短板正被补齐 —— DDIM、DPM-Solver、蒸馏（LCM）、一致性模型把采样压到几步甚至一步。

02核心直觉：加噪与去噪

2.1 一个比喻：一滴墨水

想象往一杯清水里滴一滴墨水：

  • 最初几秒，墨迹的形状还能看清 —— 「图像」的信息尚存；
  • 随着分子扩散，墨色越来越均匀 —— 图像被逐步「抹掉」；
  • 最终整杯水变成均匀的浅灰 —— 你再也无法从水中恢复那一滴墨的形状，就像纯噪声里看不出任何图像。

把过程拍成电影再倒放：墨水从均匀状态自发聚拢回一滴 —— 这在物理上不可能（熵增不可逆），但如果我们能学会倒放的规律，就能「从混乱中恢复秩序」。

扩散模型干的正是这件事：把「图像 → 噪声」设计成一条已知的加噪链，再训练神经网络拟合「噪声 → 图像」的逆过程。

2.2 前向过程：破坏是免费的

前向 Forward 给图像 x0（下标 0 表示原始干净图像）规定一条固定的马尔可夫链：每一步只做一件事 —— 乘一个略小于 1 的系数，再叠加一点点高斯噪声：

xt = √1−βt · xt−1 + √βt · εt,   εt ∼ 𝒩(0, I) βt（beta）是一个很小的数（如 0.0001 ~ 0.02），控制第 t 步加入的噪声量，整条 β1…βT 称为「噪声调度」

重复 T = 1000 步后，√(1−β) 的连乘趋近于 0，噪声的累积方差趋近于 1 —— xT 变成完全的标准高斯噪声，与原始图像再无关系。这个过程没有任何可学习参数，就是确定的数据破坏流程（噪声本身随机，但「加噪规则」固定）。

2.3 反向过程：学习「逆流而上」

反向 Reverse 理论上，如果已知整条前向链，那么每一步的逆分布 q(xt−1 | xt) 是可解的 —— 但它依赖整个数据分布，无法直接计算。

幸运的是数学上可以证明：当每一步的 βt 足够小时，反向的每一步也近似是一个高斯分布。于是我们用一个神经网络 εθ(xt, t) 来参数化这个反向高斯 —— 网络输入「当前带噪图像 + 当前时间步」，输出「对混入噪声的预测」，由此计算出 xt−1，一步步走回 x0。

2.5 关键洞察：把难题拆成一万个简单题

为什么这样做就行？

让网络直接从噪声一步生成图像，等价于学一个极其复杂的多模态分布 —— 这正是 GAN 难以稳定训练的原因。

而「在 xt 上去掉一点点噪声」是一个条件充分的回归问题：输入里有 99% 的答案（图像自己），网络只需回答「里面混了多少噪声」。把一个难题拆成一万个简单题，每一题网络都能拿高分 —— 这就是扩散模型的全部秘密。

与 Transformer 的关系

扩散模型（一种生成范式）与 Transformer（一种网络结构）并不冲突，而是强强联手：去噪主干既可以是 U-Net（Stable Diffusion 1.x/2.x），也可以是纯 Transformer（DiT、Sora）。而且你会看到，正弦时间步嵌入、交叉注意力这些零件都是直接从 Transformer 搬过来的 —— 建议配合阅读《Transformer 详解》食用，效果更佳。

03DDPM 数学原理

这一章是全文的「硬核」部分，但请别慌 —— 所有公式都只围绕一个问题：怎么把「学习去噪」变成一个普通的回归任务。我们先固定符号：

符号含义备注
x0原始干净图像归一化到 [−1, 1]
xt加了 t 步噪声后的图像t 越大越接近纯噪声
βt第 t 步的噪声量预先设定的常数，很小（10⁻⁴ ~ 0.02）
αt = 1 − βt第 t 步的信号保留系数习惯定义，纯粹为了书写简洁

3.1 前向过程：一条固定的马尔可夫加噪链

Forward 给定图像 x0，定义 T = 1000 步的加噪过程，每一步只依赖上一步（马尔可夫性）：

前向过程定义（DDPM Eq. 2） q(x1:T | x0) = ∏s=1…T q(xs | xs−1),    q(xt | xt−1) = 𝒩( xt ; √1−βt · xt−1,   βt · I )

直观拆解这个高斯：均值是 √(1−βt) · xt−1（原图稍微缩一点，信号略损），方差是 βt（叠加一个很小的噪声）。每一步都「温和地破坏」一点点，1000 步下来累计破坏就足够彻底。

3.2 关键一步：任意时刻的闭式解

按定义，要得到 xt 得迭代 t 次 —— 训练岂不是太慢？不是的。高斯分布有个好性质：高斯 + 高斯 = 高斯。每一步「乘系数 + 加小噪声」叠加起来仍是高斯，可以直接一步写出 xt（详细推导见下方折叠框）：

前向过程的闭式解（DDPM Eq. 4，训练时直接用它，一步到位） q(xt | x0) = 𝒩( xt ; √αt · x0,   (1−αt) · I )

xt = √αt · x0 + √1−αt · ε,    ε ∼ 𝒩(0, I)
推导思路：为什么「跳步」是允许的？（点开查看 3 行推导）

把两步展开：x2 = √(α1α2)·x0 + √(α2(1−α1))·ε1 + √(1−α2)·ε2。两个独立高斯相加仍是高斯，方差相加：α2(1−α1) + (1−α2) = 1 − α1α2。于是 x2 = √(α1α2)·x0 + √(1−α1α2)·ε′，ε′ 仍是标准高斯 —— 信号系数连乘、方差余项相加，归纳可得任意 t。

工程意义

训练时我们随机抽一个 t，用闭式解一步合成 xt，完全不需要迭代 t 次。这就是「重参数化技巧」的威力 —— 也是你在第 2 章交互动画里看到的那个公式：信号系数 √ᾱt 与噪声系数 √(1−ᾱt) 此消彼长，且平方和恒等于 1。

3.3 反向过程：贝叶斯公式给出「标准答案」

Reverse 我们想学反向链 pθ(xt−1 | xt)。真正的反向分布 q(xt−1 | xt) 需要对整个数据分布积分，无法直接求 —— 但数学上可以证明：只要 βt 足够小，q(xt−1 | xt) 就近似高斯。更妙的是，如果我们还知道 x0，那它的解析式可以直接用贝叶斯公式算出来：

「已知标准答案」的后验分布（由贝叶斯公式 + 前向闭式解联立得到） q(xt−1 | xt, x0) = 𝒩( xt−1 ; μ̃t(xt, x0),   β̃t · I )

μ̃t = √αt−1 · βt · x0  +  √αt · (1−αt−1) · xt1 − αt      β̃t = 1 − αt−11 − αt · βt

把 μ̃t 里的 x0 用 3.2 节闭式解反解出来（x0 = (xt − √(1−ᾱt)·ε) / √ᾱt），代入整理后，反向均值可以改写成只依赖 xt 和噪声 ε 的形式 —— 而噪声恰好是网络能预测的量！于是反向过程被参数化为：

反向过程的神经网络参数化 —— 「预测噪声」与「预测均值」完全等价 pθ(xt−1 | xt) = 𝒩( xt−1 ; μθ(xt, t), σt² · I )

μθ(xt, t) = 1√αt · ( xt − βt√1−αt · εθ(xt, t) )

解读这个式子：反向每一步 = 从 xt 里「按网络估计的比例」减去一点噪声。网络 εθ 预测得越准，减掉的噪声就越接近真实混入量。

3.4 训练目标：一切归为一个 MSE

完整推导需要对 p(x0) 极大化证据下界（ELBO），把联合分布展开后，T 步的贡献都是「反向高斯逼近真实后验」的 KL 散度 —— 而两个高斯之间的 KL 有解析解。把 μ̃t 与 μθ 代入相减，KL 里的常数项全部消掉，只剩下预测噪声与真实噪声的距离。DDPM 论文的妙笔是：进一步丢掉权重系数，得到简化损失：

Lsimple —— DDPM 实际训练的目标函数，一个再普通不过的均方误差 Lsimple(θ) = 𝔼t, x₀, ε [ ‖ ε − εθ( √αt · x0 + √1−αt · ε,  t ) ‖² ] 期望下标：t 从 {1,…,T} 均匀采样，x₀ 从数据集采样，ε 从标准高斯采样 —— 这就是整个训练循环
一句话总结 DDPM

把图像加噪到随机的第 t 步，让网络猜「我加的是哪个噪声」，用 MSE 打分。没有对抗、没有复杂的变分下界技巧、没有多网络协调 —— 和训练一个图像去噪器、甚至和训练一个房价回归模型没有本质区别。这正是扩散模型训练如此皮实的原因。

进阶：完整 ELBO 的形式，以及 DDPM 丢了什么？

完整的目标（VLB）为 L = LT + Σ Lt + L0，其中 LT 是 xT 与标准高斯的 KL（无参数，为常数），L0 是最后一步重构项。每个 Lt = DKL( q(xt−1|xt,x0) ‖ pθ(xt−1|xt) )。用「预测 ε」参数化后每项 ∝ (βt²/2σt²αt(1−ᾱt))·‖ε−εθ‖² —— DDPM 把括号里的权重扔掉，实验发现反而更稳（对中等 t 的步骤加强了监督）。理论上等价的目标还有「预测 x̂0」「预测 v」（SD 的 v-prediction），它们之间可以互相转换。

04噪声调度与采样加速

4.1 噪声调度 βt：破坏的「火候」

整条 β1…βT 决定了每一步加多少噪声，也决定了反向去噪的难度曲线。实践中的关键指标是信号保留率 ᾱt：它衰减太快，训练早期（t 小）就要学「几乎纯噪声」的难题；衰减太慢，t 大时图像还没坏透、反向过程学不到「从混乱开始」。

4.3 DDIM：把 1000 步压到 20~50 步

DDPM 采样的痛点是必须完整走完 1000 步（每步一次网络前向）。DDIM 的观察是：前向链不必是马尔可夫的 —— 只要保证各时刻的边缘分布 q(xt|x0) 不变（即还是 √ᾱtx0+√(1−ᾱt)ε），中间怎么跳是自由的。于是可以只在时间轴上取一个稀疏子序列 τ1 < τ2 < … < τS（例如 S = 50），按 DDIM 更新式跳步采样：

DDIM 采样（η = 0 时完全确定性；η = 1 退化为 DDPM 行为） x̂0 = xt − √1−αt · εθ(xt, t)√αt   ⟶   xt−1 = √αt−1 · x̂0 + √1−αt−1 · εθ(xt, t)  (+ η 项可选随机)
  1. 先显式估计干净图 x̂0：把网络预测的噪声从 xt 里「扣干净」；
  2. 直接缩放到上一个时间步：用 xt−1 的调度系数重新「染」上适量的噪声 —— 一跳就是几十个时间步；
  3. 整个过程不再注入新随机噪声（η=0）→ 同一个初始噪声永远生成同一张图（图像到图像编辑、 img2img 的基础）；
  4. 50 步质量 ≈ DDPM 1000 步，采样加速 20 倍 —— Stable Diffusion 默认 50 步正源于此。

05去噪网络：U-Net 详解

第 3 章里的 εθ(xt, t) 是一个「输入图像、输出同尺寸图像」的网络 —— 输入带噪图像，输出对噪声的预测。DDPM 选择的主干是 U-Net：一个医学图像分割领域的老将（2015 年发明），因为它恰好是「同分辨率进、同分辨率出」结构里的最强设计之一。

5.1 为什么是 U-Net

  1. 输入输出形状一致 —— 预测的噪声 ε 必须和 xt 逐像素对齐，U-Net 天然满足；
  2. 多分辨率层次结构 —— 编码器把 64×64 逐步压缩到 8×8，高分辨率层管细节、低分辨率层管全局结构，与「先构图、后精修」的去噪逻辑完美契合；
  3. 跳跃连接（Skip Connection） —— 解码器每一层都能拿到编码器同级别的特征，细节信息不必穿过整个瓶颈，去噪时「原样还原图像纹理」变得容易；
  4. 卷积的归纳偏置 —— 图像去噪天然需要局部感受野与平移等变性，卷积网络对此最擅长（后来 DiT 证明了数据够大时 Transformer 也行）。

5.3 时间步嵌入：让网络知道自己「去到哪一步了」

同一个网络要处理 1000 个噪声等级完全不同的输入 —— t=10 时几乎是干净图、t=999 时是纯噪声，去噪策略截然不同。所以必须把 t 编码后「喂」给网络，而且不同噪声等级要有截然不同的编码。DDPM 的做法直接照搬 Transformer 的正弦位置编码（只是把「位置」换成「时间步」）：

时间步的 sinusoidal 编码（与 Transformer 位置编码完全同构） t-emb2k = sin( t / 100002k/d ),    t-emb2k+1 = cos( t / 100002k/d ) 
time_embedding.py · 正弦时间步嵌入 + 两层 MLP
class SinusoidalTimeEmbedding(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, t):                              # t: (B,) 整数时间步
        device, half = t.device, self.dim // 2
        freqs = torch.exp(
            -math.log(10000) * torch.arange(half, device=device) / half
        )                                              # 不同频率的正弦基
        args = t[:, None].float() * freqs[None, :]     # (B, 1) x (1, d/2) -> (B, d/2)
        return torch.cat([torch.sin(args), torch.cos(args)], dim=-1)  # (B, d)

class TimeMLP(nn.Module):
    """正弦编码 -> Linear -> SiLU -> Linear，得到每个 ResBlock 使用的时间向量"""
    def __init__(self, embed_dim, out_dim):
        super().__init__()
        self.mlp = nn.Sequential(
            SinusoidalTimeEmbedding(embed_dim),
            nn.Linear(embed_dim, out_dim),
            nn.SiLU(),
            nn.Linear(out_dim, out_dim),
        )
    def forward(self, t):
        return self.mlp(t)                             # (B, out_dim)
呼应 Transformer

这段代码与 Transformer 的位置编码几乎一字不差 —— 频率从高到低的正余弦「条形码」让每个 t 都有独一无二的指纹，且邻近的 t 编码也相近（网络能平滑泛化到没见过的噪声等级）。详见《Transformer 详解》第 3 章。

5.4 ResBlock：时间信息在这里注入

U-Net 的基本积木是带时间条件的残差块。相比普通的 ResNet 块，它多了两个 diffusion 特有的设计：① GroupNorm 归一化（不用 BatchNorm）；② 时间嵌入经过一层线性层后加进特征图（广播到每个空间位置）：

两个细节

为什么用 GroupNorm？ BatchNorm 的统计量随 batch 内容波动，而扩散训练中每个 batch 的噪声等级、t 分布都不同，统计量极不稳定；GroupNorm 按通道分组归一，与 batch 无关，更稳。为什么时间加在中间？ 加在两个 Conv 之间，相当于给「第二次卷积」下达条件指令：不同 t 触发不同的卷积行为（t 大 → 大刀阔斧改结构；t 小 → 精修细节）。

5.5 自注意力：让全图「互相对话」

卷积的视野有限（3×3），而去噪常常需要全局决策（「左边的深色块是影子还是头发？」）。DDPM 在低分辨率层（16×16、8×8）插入标准的多头自注意力 —— 又是 Transformer 的直接移植：

自注意力（每个像素位置是一个 token） Attention(Q, K, V) = softmax( Q · KT√dk ) · V,    Q = x·WQ,  K = x·WK,  V = x·WV

实现上有个 diffusion 特色：注意力只在通道维做投影，然后把空间维 (H×W) 拆成序列 —— 每个空间位置是一个 token。16×16 只有 256 个 token，注意力开销完全可接受；64×64 有 4096 个 token，太贵，所以只在低分辨率层开（SD 系列同理，并在 64×64 用线性注意力或分组注意力等变体省算力）。

5.6 交叉注意力：文本条件的「接口」

如果要按文字生成图像（如 Stable Diffusion），还需要交叉注意力（Cross-Attention）：Q 来自图像 token，K、V 来自文本 token —— 这样每个空间位置都能「查询」文本里与自己相关的词（画到天空的位置会强烈关注「sunset」这个词）：

直观理解

交叉注意力就像图像拿着一张清单（Q）去文本里查资料（K→V）：画到「天空」区域的 token 会重点取「sunset」的值，画到「地面」的 token 会重点取「grass」的值。Stable Diffusion 的可视化研究证实：把「sunset」这个词的注意力图涂色，高亮区域恰好就是生成图的天空 —— 语义与像素在这里完成了对接。

6.2 Classifier-Free Guidance：推理时质量的「免费午餐」

直接按条件采样（w=1）往往「不够听话」：模型常忽略 prompt 的细节。CFG 的技巧：训练时以 10%~20% 的概率随机丢弃条件（用空条件 ∅ 代替），让同一个网络既能 εθ(xt, t, c) 又能 εθ(xt, t, ∅)；推理时每次去噪做两次前向，然后沿「条件方向」外推：

CFG 引导更新（w = 1 退化为条件采样；w > 1 沿条件方向外推） ε̃t = εθ(xt, t, ∅) + w · ( εθ(xt, t, c) − εθ(xt, t, ∅) )
  1. 无条件预测 ε(xt, ∅)：网络「啥也没被告知」时的平均去噪方向；
  2. 条件预测 ε(xt, c)：被告知 prompt 后的修正方向；
  3. 差向量（条件 − 无条件）正是「prompt 想要把图像推往的方向」；
  4. 外推系数 w（guidance scale，典型 5~8）：把这个方向放大 w 倍 —— 图像更贴合 prompt、对比更强烈、细节更锐利，但过大（>10）会过饱和、多样性崩塌（千人一面）。

7.1 噪声调度：预先算好所有系数

训练与采样中用到的系数全部只依赖 t，所以开工前一次算好缓存成张量（这是所有扩散框架的标准做法）：

schedule.py · 线性 / 余弦调度与系数预计算
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class DiffusionSchedule:
    """噪声调度：预计算 DDPM 需要的全部系数（每个形状都是 (T,)）"""
    def __init__(self, T=1000, schedule="linear", device="cpu"):
        self.T = T
        if schedule == "linear":                       # DDPM 原论文调度
            betas = torch.linspace(1e-4, 0.02, T)
        else:                                          # cosine 调度（Improved DDPM）
            steps = torch.arange(T + 1, dtype=torch.float64)
            f = torch.cos(((steps / T) + 0.008) / 1.008 * math.pi / 2) ** 2
            f = f / f[0]                               # ᾱ_t，从 1 缓降到 0
            betas = torch.clip(1 - f[1:] / f[:-1], 1e-4, 0.999)

        self.betas  = betas.to(device)                 # β_t
        self.alphas = 1.0 - self.betas                # α_t = 1 - β_t
        self.alphas_cumprod = torch.cumprod(self.alphas, dim=0)   # ᾱ_t = ∏α_s
        self.alphas_cumprod_prev = F.pad(self.alphas_cumprod, (1, 0), value=1.0)[:-1]

        self.sqrt_acp    = torch.sqrt(self.alphas_cumprod)        # √ᾱ_t      （信号）
        self.sqrt_1m_acp = torch.sqrt(1 - self.alphas_cumprod)    # √(1-ᾱ_t)   （噪声）
        self.sqrt_recip_at = torch.sqrt(1.0 / self.alphas)        # 1/√α_t
        # 反向后验方差 β̃_t = (1-ᾱ_{t-1})/(1-ᾱ_t) · β_t   （第 3.3 节）
        self.posterior_var = self.betas * (1 - self.alphas_cumprod_prev) \
                                             / (1 - self.alphas_cumprod)

7.2 扩散引擎：数学公式 → 代码

这个类就是第 3 章的全部内容。四行核心公式：加噪（闭式解）、训练损失（MSE）、反向一步（Algorithm 2）、DDIM 跳步 —— 每行都注明了出处：

diffusion.py · 加噪 / 损失 / 逐步采样 / DDIM
class GaussianDiffusion:
    """把 DDPM 的数学公式写成代码：训练损失 + 三种采样"""

    def __init__(self, schedule):
        self.sch = schedule

    # ---------- 前向：一步加噪 ----------
    def q_sample(self, x0, t, noise):
        # x_t = √ᾱ_t·x0 + √(1-ᾱ_t)·ε     （第 3.2 节闭式解）
        s1 = self.sch.sqrt_acp[t][:, None, None, None]
        s2 = self.sch.sqrt_1m_acp[t][:, None, None, None]
        return s1 * x0 + s2 * noise

    # ---------- 训练损失 ----------
    def training_loss(self, model, x0, y=None):
        # L_simple = MSE(ε, ε_θ(x_t, t))  （第 3.4 节）
        B = x0.shape[0]
        t = torch.randint(1, self.sch.T, (B,), device=x0.device)
        noise = torch.randn_like(x0)
        x_t = self.q_sample(x0, t, noise)
        return F.mse_loss(model(x_t, t, y), noise)

    # ---------- 网络预测（含 CFG 外推） ----------
    def _eps(self, model, x_t, t, y, w):
        eps = model(x_t, t, y)
        if w != 1.0 and y is not None:                  # CFG（第 6.2 节）
            eps_u = model(x_t, t, None)                 # 无条件分支
            eps = eps_u + w * (eps - eps_u)             # 沿条件方向外推
        return eps

    # ---------- 反向走一步（DDPM 祖先采样） ----------
    @torch.no_grad()
    def p_sample(self, model, x_t, t, y=None, w=1.0):
        # x_{t-1} = 1/√α_t · (x_t - β_t/√(1-ᾱ_t)·ε_θ) + σ_t·z   （Algorithm 2）
        sch = self.sch
        eps = self._eps(model, x_t, t, y, w)
        b  = sch.betas[t][:, None, None, None]
        s  = sch.sqrt_1m_acp[t][:, None, None, None]
        ra = sch.sqrt_recip_at[t][:, None, None, None]
        mean = ra * (x_t - b / s * eps)
        if int(t[0]) > 0:                             # 最后一步不加随机噪声
            var = sch.posterior_var[t][:, None, None, None]
            return mean + torch.sqrt(var) * torch.randn_like(x_t)
        return mean

    @torch.no_grad()
    def ancestral_sample(self, model, n, y=None, w=1.0, size=32):
        """完整 1000 步祖先采样（Algorithm 2）"""
        device = next(model.parameters()).device
        x = torch.randn(n, 1, size, size, device=device)   # 从纯噪声出发
        for t in reversed(range(self.sch.T)):
            t_b = torch.full((n,), t, device=device, dtype=torch.long)
            x = self.p_sample(model, x, t_b, y, w)
        return x

    # ---------- DDIM 跳步采样 ----------
    @torch.no_grad()
    def ddim_sample(self, model, n, steps=50, y=None, w=1.0, size=32, eta=0.0):
        """DDIM：steps 步搞定（第 4.3 节，eta=0 时完全确定性）"""
        sch = self.sch
        device = next(model.parameters()).device
        ts = torch.linspace(sch.T - 1, 0, steps, device=device).long()  # 稀疏时间表
        x = torch.randn(n, 1, size, size, device=device)
        for i in range(len(ts) - 1):
            t, t_next = ts[i], ts[i + 1]
            t_b = torch.full((n,), int(t), device=device, dtype=torch.long)
            eps = self._eps(model, x, t_b, y, w)
            # 先估计干净图 x̂0 = (x_t - √(1-ᾱ_t)·ε) / √ᾱ_t
            s0 = sch.sqrt_acp[t_b][:, None, None, None]
            s1 = sch.sqrt_1m_acp[t_b][:, None, None, None]
            x0_hat = (x - s1 * eps) / s0
            # 再「染」上下一个时间步的噪声量：x_{t-1} = √ᾱ_{t-1}·x̂0 + √(1-ᾱ_{t-1})·ε
            x = sch.sqrt_acp[t_next] * x0_hat + sch.sqrt_1m_acp[t_next] * eps
        return x

# ---------- ResBlock：图 5-2 的实现 ----------
class ResBlock(nn.Module):
    def __init__(self, in_ch, out_ch, time_dim):
        super().__init__()
        self.norm1 = nn.GroupNorm(8, in_ch)
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3, padding=1)
        self.time_proj = nn.Linear(time_dim, out_ch)    # t-emb 投影到通道维
        self.norm2 = nn.GroupNorm(8, out_ch)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3, padding=1)
        self.act = nn.SiLU()
        self.skip = nn.Conv2d(in_ch, out_ch, 1) if in_ch != out_ch else nn.Identity()

    def forward(self, x, t_emb):
        h = self.conv1(self.act(self.norm1(x)))
        h = h + self.time_proj(t_emb)[:, :, None, None] # 时间注入：广播相加
        h = self.conv2(self.act(self.norm2(h)))
        return h + self.skip(x)                         # 残差连接

    def forward(self, x):
        B, C, H, W = x.shape
        h = self.norm(x).flatten(2).transpose(1, 2)     # (B,C,H,W) -> (B, HW, C)
        h, _ = self.attn(h, h, h)                       # Q=K=V，标准自注意力
        h = h.transpose(1, 2).reshape(B, C, H, W)
        return x + h                                    # 残差：只学增量

# ---------- 组合块与上下采样 ----------
class Block(nn.Module):
    """ResBlock x2 + 可选注意力（对应图 5-1 里的每个色块）"""
    def __init__(self, in_ch, out_ch, time_dim, attn=False):
        super().__init__()
        self.res1 = ResBlock(in_ch, out_ch, time_dim)
        self.res2 = ResBlock(out_ch, out_ch, time_dim)
        self.attn = SelfAttention(out_ch) if attn else nn.Identity()

    def forward(self, x, t_emb):
        return self.attn(self.res2(self.res1(x, t_emb), t_emb))

class Down(nn.Module):
    def __init__(self, in_ch, out_ch, time_dim, attn=False):
        super().__init__()
        self.block = Block(in_ch, out_ch, time_dim, attn)
        self.pool = nn.Conv2d(out_ch, out_ch, 3, stride=2, padding=1)  # 学习式下采样

    def forward(self, x, t_emb):
        h = self.block(x, t_emb)
        return self.pool(h), h                          # 返回（下采样结果, skip）

class Up(nn.Module):
    def __init__(self, in_ch, skip_ch, out_ch, time_dim, attn=False):
        super().__init__()
        self.block = Block(in_ch + skip_ch, out_ch, time_dim, attn)

    def forward(self, x, skip, t_emb):
        x = F.interpolate(x, size=skip.shape[-2:], mode="nearest")    # 上采样 x2
        x = torch.cat([x, skip], dim=1)                 # 拼接跳跃连接
        return self.block(x, t_emb)

# ---------- U-Net 主体：图 5-1 的实现 ----------
class UNet(nn.Module):
    def __init__(self, base=64, time_dim=256, num_classes=10):
        super().__init__()
        self.time_mlp = TimeMLP(128, time_dim)          # 第 5.3 节
        self.class_emb = nn.Embedding(num_classes, time_dim)  # 类别条件
        self.conv_in = nn.Conv2d(1, base, 3, padding=1)

        self.d1  = Down(base,   base,   time_dim, attn=False)   # 32x32 -> 16
        self.d2  = Down(base,   base*2, time_dim, attn=False)   # 16x16 -> 8
        self.d3  = Down(base*2, base*4, time_dim, attn=True)    #  8x8 -> 4
        self.mid = Block(base*4, base*4, time_dim, attn=True)   # 瓶颈 4x4
        self.u3  = Up(base*4, base*4, base*2, time_dim, attn=True)
        self.u2  = Up(base*2, base*2, base,   time_dim, attn=False)
        self.u1  = Up(base,   base,   base,   time_dim, attn=False)

        self.norm_out = nn.GroupNorm(8, base)
        self.act_out = nn.SiLU()
        self.conv_out = nn.Conv2d(base, 1, 3, padding=1)       # 输出与输入同形状

    def forward(self, x, t, y=None):
        t_emb = self.time_mlp(t)
        if y is not None:
            t_emb = t_emb + self.class_emb(y)          # 类别与时间嵌入相加（第 6.1 节）
        h0 = self.conv_in(x)
        h1, s1 = self.d1(h0, t_emb)
        h2, s2 = self.d2(h1, t_emb)
        h3, s3 = self.d3(h2, t_emb)
        h = self.mid(h3, t_emb)
        h = self.u3(h, s3, t_emb)
        h = self.u2(h, s2, t_emb)
        h = self.u1(h, s1, t_emb)
        return self.conv_out(self.act_out(self.norm_out(h)))

7.4 训练循环：短得令人感动

万事俱备。训练循环就是「取 batch → 算 Lsimple → 梯度下降」，外加两个扩散模型的标配技巧：EMA 权重平均与CFG 条件丢弃：

train.py · 完整训练脚本（MNIST）
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import random

device = "cuda" if torch.cuda.is_available() else "cpu"

# ---------- 数据：务必归一化到 [-1, 1] ----------
tf = transforms.Compose([
    transforms.Pad(2),                       # 28x28 -> 32x32（2 的幂，方便上下采样）
    transforms.ToTensor(),
    transforms.Normalize([0.5], [0.5]),
])
ds = datasets.MNIST("./data", train=True, download=True, transform=tf)
loader = DataLoader(ds, batch_size=128, shuffle=True, num_workers=2, drop_last=True)

# ---------- EMA：指数滑动平均，扩散模型质量提升的关键 ----------
class EMA:
    def __init__(self, model, decay=0.9999):
        self.decay = decay
        self.shadow = {k: v.clone() for k, v in model.state_dict().items()}

    @torch.no_grad()
    def update(self, model):
        for k, v in model.state_dict().items():
            if v.dtype.is_floating_point:
                self.shadow[k].mul_(self.decay).add_(v, alpha=1 - self.decay)
            else:
                self.shadow[k].copy_(v)

# ---------- 组装 ----------
diffusion = GaussianDiffusion(DiffusionSchedule(T=1000, device=device))
model = UNet().to(device)                   # 约 6M 参数
opt = torch.optim.AdamW(model.parameters(), lr=2e-4)
ema = EMA(model)

# ---------- 训练 ----------
for epoch in range(10):
    for i, (x0, y) in enumerate(loader):
        x0, y = x0.to(device), y.to(device)
        if random.random() < 0.1:
            y = None                        # CFG：10% 概率丢弃条件（第 6.2 节）
        loss = diffusion.training_loss(model, x0, y)
        opt.zero_grad()
        loss.backward()
        opt.step()
        ema.update(model)
        if i % 200 == 0:
            print(f"epoch {epoch}  step {i:4d}  loss {loss.item():.4f}")

08从 DDPM 到 Stable Diffusion / DiT

8.1 Latent Diffusion：把扩散搬进「潜空间」

第 7 章的模型在 32×32 上很愉快，但真实需求是 512×512：像素量暴涨 256 倍，U-Net 的注意力在 64×64 层要处理 4096 个 token，训练成本高到离谱。Latent Diffusion（LDM，Stable Diffusion 的前身）的天才一步是：先训练一个 VAE 把图像压进潜空间，再在潜空间里做扩散：

  1. 训练 VAE 自编码器：Encoder 把 512×512×3 压缩到 64×64×4（约 48 倍信息压缩，视觉质量几乎无损保留在潜码里）；Decoder 负责还原；
  2. 扩散只在 64×64×4 的潜码上进行：U-Net、加噪、去噪、采样全部照旧，只是「图像」换成了「潜码」—— 计算量骤降 48 倍；
  3. 文本条件走交叉注意力：CLIP 文本编码器把 prompt 变成 77×768 的嵌入序列，注入 U-Net 每层的交叉注意力（第 5.6 节）；
  4. 生成完的干净潜码再经 VAE Decoder 解码成像素图像。
组件SD 1.5 配置状态
VAEEncoder / Decoder，8× 空间压缩（512³ → 64×64×4）预训练后冻结
文本编码器CLIP ViT-L/14，输出 77×768冻结
U-Net约 860M 参数，交叉注意力注入文本唯一训练的部分
调度器训练 1000 步；推理 DDIM/DPM++ 50 步无需训练
为什么这样省钱？

扩散 99% 的训练算力花在反复对同一批数据加噪去噪上；而这些数据里大部分比特是人眼察觉不到的高频压缩冗余。把扩散搬到「信息密度高」的潜空间，把「像素级重建」外包给一次性的 VAE —— 各司其职，训练成本直接砍到 GAN 时代的水平，还能享用扩散的稳定性。这就是 SD 能在消费级显卡上训练与运行的根本原因。

8.3 DiT：Transformer 全面接管

2022 年底，Peebles & Xie 提出 DiT（Diffusion Transformer）：既然注意力才是核心，为什么主干还要卷积？DiT 把 U-Net 整个换成标准 Transformer：

  1. Patchify：把潜码 64×64×4 按 2×2 切块成 32×32 = 1024 个 token（和 ViT 完全同款）；
  2. DiT Block：标准「多头自注意力 + MLP」，但条件注入用 adaLN-Zero —— 时间 t 与类别 c 拼接后经 SiLU-MLP，输出缩放与平移系数 γ、β 同时调制注意力与 MLP 的归一化层，并且每个残差分支末端的 Linear 初始化为全零（零初始化 = 训练开始时网络恒等，超级稳定）；
  3. 结尾 Unpatchify 回潜码形状，输出预测的噪声。

关键实验结论：算力给足时，DiT 的 FID 全面超越 U-Net 版本，且缩放规律干净漂亮（模型从 S 到 XL 一路平滑涨点）。Sora 就是「视频版 DiT」：时空 patch 化 + 3D VAE 压缩 + 大规模视频-文本联合训练 —— 一脉相承的配方。

9.1 全文脉络

9.2 十条核心要点

  1. 扩散模型 = 学出来的去噪器：把「一步生成」的难题拆成 1000 个「去掉一点噪声」的简单回归题；
  2. 前向加噪是固定的，且有闭式解 —— 训练时一步合成任意噪声等级，无需迭代；
  3. 训练目标就是预测噪声的 MSE —— 无对抗、无坍塌，像训练回归模型一样稳；
  4. 噪声调度（线性 / 余弦）决定 ᾱt 的衰减曲线，是效果与步数的第一决定因素；
  5. U-Net 靠跳连 + 多分辨率同时管细节与结构，自注意力放低分辨率层管全局；
  6. 正弦时间嵌入（照抄 Transformer 位置编码）让一个网络服务 1000 个噪声等级；
  7. 文本条件经交叉注意力注入 —— 语义与像素在这里对接；
  8. CFG 用「条件 − 无条件」差向量外推，是文生图听话程度的总旋钮；
  9. DDIM / DPM-Solver 把 1000 步压到 20~50 步，蒸馏进一步压到 1~4 步；
  10. Stable Diffusion = VAE 潜空间 + U-Net + CLIP 文本编码器；DiT 换成纯 Transformer 后路线一路通向 Sora。
