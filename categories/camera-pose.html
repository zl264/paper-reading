相机可控视频生成的关键不是是否出现“camera”一词，而是用户给的几何条件经过什么变换后影响像素。下面按输入表示、注入位置、显式几何、视频重渲染与长时记忆整理，包含本站尚未逐篇解读的工作。

01

文本与离散动作运镜

运镜 prompt / 离散动作 token / 动作原语

最易交互但精度有限；离散动作提升可控性，却难表达任意连续轨迹与内参变化。

代表工作 / 原文：MotionCtrl ↗ · DisCo ↗
02

外参与射线条件

RT / Plücker / ray map / 像素对齐几何

将帧级外参变为逐像素射线；注意 c2w/w2c、K、尺度、像素中心和 VAE 时间压缩。

代表工作 / 原文：CameraCtrl ↗ · CamCo ↗ · CamViG ↗
03

DiT 注入与几何位置编码

QKV/ControlNet / cross-attention / RoPE / PRoPE / UCPE

控制强度不只取决于 Plücker：条件通道比、注入层位、去噪时刻与相对几何编码同等重要。

代表工作 / 原文：VD3D ↗ · AC3D ↗ · PRoPE ↗ · UCPE ↗
04

免训练与测试时控制

latent 重排 / warp / guidance / reward / 粒子滤波

不改主干参数，把相机轨迹转成 latent 位移或采样引导；代价是额外优化、几何近似或采样不稳定。

代表工作 / 原文：CamTrol ↗ · Latent-Reframe ↗ · LightMotion ↗ · PartiCam ↗
05

显式几何与新视角生成

RGB-D / 点云 / 3DGS / 可见性 mask / 几何记忆

位姿先驱动确定性投影，扩散模型负责修复与补洞；控制精度更强，但受深度、尺度和遮挡误差限制。

代表工作 / 原文：ViewCrafter ↗ · GEN3C ↗ · Wonderland ↗ · WorldWarp ↗
06

已有视频的相机重定向

V2V 重渲染 / 源视频 token / 动态点云参考

除换机位外，还要保留外观与动作同步；需要同步多机位训练数据或双重投影监督。

代表工作 / 原文：ReCapture ↗ · ReCamMaster ↗ · TrajectoryCrafter ↗ · EX-4D ↗
07

长程探索与持久记忆

历史 latent / SLAM / 3D cache / 几何寻址注意力

回到旧位置时仍需一致；关键是外部记忆、统一世界参考系、检索与误差更新，而非逐段重置首帧。

代表工作 / 原文：CameraCtrl II ↗ · Spatia ↗ · MemCam ↗ · SPARC ↗
08

电影级与自动运镜

轨迹生成 / 分镜规划 / 视觉偏好优化 / 多镜头

从手动给位姿扩展到文本到轨迹、主体相对构图和导演式规划，关注“镜头是否有意义”。

代表工作 / 原文：CineMaster ↗ · TKCAM ↗ · CamPilot ↗ · VERTIGO ↗
09

全景、镜头与统一模型

360° / 鱼眼 / 重力参考 / metric RoPE / 数据评测

突破针孔假设、处理尺度与全景球面；同时需要公开轨迹数据、质量评价与几何基准。

代表工作 / 原文：CamPVG ↗ · GimbalDiffusion ↗ · MeRoPE ↗ · WorldScore ↗
