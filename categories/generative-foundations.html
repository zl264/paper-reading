生成模型不能只按模型名称记忆。更稳定的划分是：数据如何表示、如何构造生成分布、如何采样，以及条件与效率如何实现。下面覆盖概率生成、离散/连续 token、自回归、扩散、流匹配与加速的统一技术地图。

如何使用这张图：这里按技术问题划分，而非按模型名称罗列。链接指向代表论文、综述或官方项目；标注“本站”的入口可阅读中文详解。覆盖范围为代表性路线，不声称穷尽所有论文。
01

表示学习与压缩

VAE / VQ-VAE / 连续与离散视觉 tokenizer

先把像素压到 latent 或离散 code，再在其上生成；码本量化误差、时间压缩与重建质量构成下游模型上限。

代表工作 / 原文：VAE ↗ · VQ-VAE ↗ · MAR / 无向量量化 AR ↗
02

自回归与离散生成

next-token / next-scale / masked parallel decoding

按像素、token、尺度或频率顺序分解联合分布；核心是视觉序列顺序、并行解码和误差传播。

代表工作 / 原文：VQGAN ↗ · VAR ↗ · FlowAR ↗
03

分数扩散与概率流

SDE / DDPM / score matching / probability-flow ODE

通过逐步加噪学习分数或去噪器，再反向采样；需要区分 epsilon、x₀、v 预测与不同时间方向。

代表工作 / 原文：Score SDE ↗ · DDPM ↗ · 扩散综述 ↗
04

确定性流与少步生成

Flow Matching / Rectified Flow / Consistency / Distillation

用速度场、流映射或一致性约束替代长链迭代；少步模型还要处理离散化误差和教师—学生分布偏移。

代表工作 / 原文：Flow Matching ↗ · Rectified Flow ↗ · Consistency Models ↗ · 蒸馏综述 ↗
05

网络骨干

U-Net / DiT / MMDiT / 状态空间模型

卷积归纳偏置、token 全局交互、文本—图像双流或多模态统一注意力决定扩展方式；位置编码与条件注入同样关键。

代表工作 / 原文：DiT ↗ · SD3 / MMDiT ↗ · 高效扩散综述 ↗
06

条件控制与对齐

cross-attention / ControlNet / adapters / RLHF / preference optimization

文本条件只是起点；空间条件、参考图、主体一致性、可验证奖励与偏好优化决定“是否按意图生成”。

代表工作 / 原文：ControlNet ↗ · T2I-Adapter ↗ · DDPO ↗
07

效率与部署

latent 压缩 / 稀疏注意力 / KV cache / 量化 / 蒸馏

训练 FLOPs 不等于推理延迟；采样步数、token 数、显存、KV 管理和编译共同决定实际成本。

代表工作 / 原文：高效扩散综述 ↗ · FlashAttention ↗
08

可靠性与治理

水印 / 概念擦除 / 对抗鲁棒性 / 数据与许可

开放部署还需处理内容来源、身份滥用、模型编辑与安全评估，不能把质量指标当作唯一目标。
