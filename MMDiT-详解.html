MMDiT 详解:多模态扩散 Transformer 的原理、结构与代码

从扩散模型与 Rectified Flow 出发,逐层拆解 Stable Diffusion 3 的核心架构 MMDiT(Multimodal Diffusion Transformer),并用教学版 PyTorch 代码完整复现其双流联合注意力机制。

难度:进阶 论文:arXiv 2403.03206 配套代码:PyTorch 教学实现

1什么是 MMDiT

一句话:MMDiT 是把"文本"和"图像"两种模态放进同一个 Transformer 里做联合注意力、但保留两套独立权重的扩散骨干网络。

MMDiT(Multimodal Diffusion Transformer,多模态扩散 Transformer)是 Stability AI 在 2024 年 3 月发表的论文 《Scaling Rectified Flow Transformers for High-Resolution Image Synthesis》(arXiv:2403.03206)中提出的架构, 它是 Stable Diffusion 3 / 3.5 的核心生成骨干,也以混合形式影响了 FLUX 系列模型。

要理解它解决了什么问题,先看它的两个"前任":

架构代表模型条件注入方式局限
U-Net + Cross-Attention SD 1.5 / SDXL 文本通过 cross-attention 单向注入图像特征;图像侧永远看不到文本内部的推理过程,文本也看不到图像 卷积归纳偏置强、长距离建模弱;文本与图像的交互是"被动条件化",不充分
DiT DiT (ImageNet)、PixArt 等 类别标签 / 文本全局向量通过 AdaLN-Zero 调制注入 只处理单一视觉 token 序列;文本被压成一个向量,逐词细节丢失
MMDiT SD3 / SD3.5 文本 token 与图像 token 在每个 block 内做一次联合自注意力,双向交换信息;两种模态各持一套权重 计算量随序列长度平方增长,需要 QK-Norm 等稳定化设计

MMDiT 的核心思想可以浓缩为三点:

  1. 两种模态,两套权重。文本和图像的分布差异极大,用同一组 Q/K/V 投影和 FFN 去处理是次优的。MMDiT 让文本流和图像流各自拥有独立的 LayerNorm、调制参数、Q/K/V 投影与 FFN。
  2. 一次联合注意力。在每个 block 里,把两种模态的 Q、K、V 沿 token 维拼接成一个序列做自注意力,使每个文本 token 都能直接"看见"每个图像 patch,反之亦然——信息是双向流动的。
  3. Rectified Flow 训练目标。抛弃 DDPM 的噪声预测参数化,改用直线路径上的速度场(v-prediction 的连续时间推广),采样路径更直、所需步数更少。
阅读本文前你需要知道
本文假设你了解 Transformer 自注意力与 LayerNorm 的基本概念。扩散模型和 Rectified Flow 会在第 2 章从直觉到公式完整讲解,不需要事先掌握。

2预备知识:扩散、DiT 与 Rectified Flow

MMDiT 的三个支柱:在潜空间里做扩散、用 Transformer 做骨干、用 Rectified Flow 定义前向过程与训练目标。

2.1 潜空间扩散模型回顾

扩散模型的前向过程,是逐步向数据中加入高斯噪声,直到数据变成纯噪声。传统 DDPM 定义一个马尔可夫链,每一步加一点点噪声;经过足够多步后,数据分布退化为标准正态分布。

生成过程则是其逆过程:从纯噪声出发,逐步"去噪"还原出数据。由于真实逆向转移概率不可求,我们训练一个神经网络来近似它——这就是扩散模型中唯一需要学习的部分。

直接在像素空间做扩散代价高昂。SD 系列的通用做法是先用一个预训练 VAE 的编码器把图像压缩到低维潜空间(latent space),扩散过程全部发生在潜空间,最后由 VAE 解码器还原成像素。SD3 沿用这一范式,其 VAE latent 有 16 个通道(SD 1.5/SDXL 是 4 通道,信息密度更高)。

像素图像 x→ VAE Encoder→ 潜空间 z→ 扩散/去噪(MMDiT 在这里工作)→ VAE Decoder→ 生成图像

2.2 从 U-Net 到 DiT

2022 年底的 DiT(Diffusion Transformer)论文证明:把扩散骨干从 U-Net 换成标准 ViT,不仅可行,而且可扩展性(scalability)显著更好——模型越大,FID 越低,且计算效率更高。

DiT 的做法非常直接:

  1. 把带噪 latent 切成不重叠的 patch(如 2×2),展平成 token 序列;
  2. 每个 token 线性投影到 hidden dim,加上位置编码;
  3. 送进 N 个标准 Transformer block;
  4. 最后的线性层把每个 token 解码回 patch 形状的预测结果(噪声或速度场)。

条件信息(类别标签、时间步 t)通过 AdaLN-Zero 注入:用一个 MLP 从条件向量回归出 LayerNorm 之后的 scale / shift(以及残差分支的 gate),对主干特征做逐通道仿射变换。这套"调制"机制被 MMDiT 完整继承,并在第 5.2 节详细展开。

关键认知
DiT 证明了"Transformer 主干 + AdaLN 条件注入"在扩散模型上的有效性;MMDiT 要解决的,是 DiT 没有回答的问题:如何让变长的、语义丰富的文本 token 序列与图像 token 进行细粒度、双向的交互?

2.3 Rectified Flow / Flow Matching

SD3 抛弃 DDPM 的噪声调度,采用 Rectified Flow(整流流)训练目标,它属于 Flow Matching 框架的一个特例。理解它只需要一个核心图像:用直线连接数据点与噪声点,网络学习这条直线上的速度。

先统一本文的记号(与 SD3 论文一致):

  • x₀:真实数据(VAE latent),t = 0 时刻;
  • ε ~ N(0, I):纯噪声,t = 1 时刻;
  • 时间 t ∈ [0, 1],t 越大越接近纯噪声。

前向过程就是数据与噪声之间的线性插值(一条直线):

zt = (1 − t)·x0 + t·ε 前向过程:t=0 是纯数据,t=1 是纯噪声

沿这条直线对 t 求导,得到样本从数据流向噪声的瞬时速度:

ut = dzt/dt = ε − x0 条件速度:给定 (x₀, ε) 对,目标速度是一个不依赖 t 的常量

训练一个网络 v_θ(z_t, t, c)(c 是文本条件)去回归这个速度,就是 Conditional Flow Matching 损失:

LCFM = Et, x₀, ε [ wt · ‖ vθ(zt, t, c) − (ε − x0) ‖² ] 训练目标:让网络预测的速度场逼近直线插值的速度

生成(采样)是这个 ODE 的反向积分:从 t=1 的纯噪声出发,沿学习到的速度场逐步"流"回 t=0 的数据:

dzt/dt = vθ(zt, t, c),    从 t=1 积分到 t=0 采样:对学到的 ODE 做数值积分(如 Euler 法)

为什么不把所有 t 一视同仁?直觉上,t 接近 0.5 时,zt 是"一半数据一半噪声",预测速度最难;t 接近两端时任务很容易。SD3 论文采用 logit-normal 时间步采样,让训练样本更多落在中间难度区域,其时间步权重满足:

wtπ = ( t / (1 − t) ) · π(t) 加权形式:π(t) 是时间步的采样密度(如 logit-normal)
记号约定提醒
不同资料的记号可能相反(有的论文令 x₀=噪声、x₁=数据)。本文统一采用 SD3 论文约定:x₀ = 数据,ε = 噪声,t=0 是干净数据,t=1 是纯噪声。阅读其他教程时注意换算。

3SD3 的整体数据流

在钻进 MMDiT block 之前,先看清楚数据从提示词和噪声出发、经过哪些模块、最终如何变成图像。

SD3 的完整推理管线包含五个部分,其中只有 MMDiT 是训练出来的去噪骨干,其余都是冻结的预训练模块:

  1. 三个文本编码器(冻结):CLIP-L、OpenCLIP-bigG、T5-XXL。前两个 CLIP 各产出 token 序列和一个池化向量;T5-XXL 产出语义更强的长 token 序列。
  2. 文本序列拼接:三个编码器的 token 序列被投影到统一维度后沿序列维拼接,形成 MMDiT 的文本流输入。
  3. VAE 编码器(仅训练 VAE 时使用;推理生图时用不到):把真实图像压成 16 通道 latent。
  4. MMDiT 主干:在带噪 latent 上做速度场预测,这是本文的主角。
  5. VAE 解码器(冻结):把去噪完成的 latent 还原成像素图像。
两种"文本条件"不要混淆
SD3 中其实有两路文本信息:① 池化全局向量(CLIP 池化输出拼接后与时间步嵌入相加)——它进入 调制(AdaLN) 通路,控制每个 block 的整体风格/尺度;② token 序列(CLIP + T5 的逐 token 输出拼接)——它作为文本流进入 联合注意力,提供逐词的细粒度语义。后文第 5 章会分别看到它们的落点。

4Token 化与张量形状

MMDiT 里最容易出错的不是数学,而是形状。本节把每个张量的形状从头到尾固定下来,后文代码严格沿用。

设定一组贯穿全文的符号:

符号含义示例取值(SD3 风格)
Bbatch size任意
DTransformer 隐藏维度(hidden size)1536(SD3 Medium)
H, Wlatent 的空间尺寸64×64(对应 512×512 图像)
ppatch 边长2
N图像 token 数 = (H/p)·(W/p)32×32 = 1024
M文本 token 数(三编码器拼接后)例如 77+77+256 ≈ 410(具体随实现)
h注意力头数24(head_dim = D/h = 64)

图像侧:带噪 latent zₜ ∈ [B, 16, H, W] 被切成 p×p 的 patch,展平后经线性投影:

[B, 16, H, W] → unpatch → [B, N, 16·p²] → Linear → x_img ∈ [B, N, D] 再加 2D 位置编码(论文使用预计算频率位置编码 / RoPE 风格处理)

文本侧:各文本编码器输出维数不同(CLIP-L 768、bigG 1280、T5-XXL 4096),先各自线性投影到统一维度再拼接:

concat(proj_L, proj_G, proj_T5) → x_txt ∈ [B, M, D] 文本流 token;不同模态使用不同位置编码策略,文本通常不加 2D 位置编码

联合注意力时,两流沿 token 维拼接成一个序列:

[x_img ; x_txt] ∈ [B, N+M, D] 注意力结束后必须按 (N, M) 拆分回两个分支——这是 MMDiT 代码的关键操作
为什么形状拆分如此重要
联合注意力输出 [B, N+M, D] 的前 N 行属于图像、后 M 行属于文本。拆错(或忘记拆)会让图像特征被文本 FFN 处理,模型完全学不动。教学代码中我们会显式写出 img_out, txt_out = out.split([N, M], dim=1)。

模型缩放规律(论文 Table 8 / 附录给出):用深度 d(双分支 block 数)表示规模,则

  • hidden size = 64d,注意力头数 = d,每头维度固定 64;
  • FFN 扩展倍数为 4;
  • 论文研究 d = 15(~0.45B 参数)、18、24、30、38(~8B)等规模;
  • SD3 Medium: d = 24(D=1536);SD3.5 Large: d = 38(约 8.1B 参数)。

5MMDiT Block:双流结构逐层拆解

这是全文的核心章节:一个 MMDiT block 内部,数据按"调制 → 归一化 → QK-Norm → 联合注意力 → 残差 → 调制 → 归一化 → FFN → 残差"的顺序流动,且文本与图像各走各的参数。

5.1 双分支权重:两套参数

一个 MMDiT block 里,几乎所有可学习参数都成对出现:

组件图像流文本流
调制 MLP(AdaLN)mod_img(独立参数)mod_txt(独立参数)
Q/K/V 投影Wq_img, Wk_img, Wv_imgWq_txt, Wk_txt, Wv_txt
QK-RMSNormnorm_q_img, norm_k_imgnorm_q_txt, norm_k_txt
注意力输出投影Wo_imgWo_txt
FFNffn_img(4D 扩展)ffn_txt(4D 扩展)
注意力本身共享:拼接后的单次 softmax 注意力,无额外参数

为什么这样设计?文本 token 来自语言模型空间、图像 token 来自 VAE patch 空间,两者统计性质完全不同。共享投影会强迫同一组权重去对齐两种分布;而独立参数 + 联合注意力相当于:每种模态用自己的"语言"把内容编码到同一个注意力空间里,再在注意力层中自由对话。论文的消融实验表明,这种双流设计优于单流(完全共享)与纯 cross-attention 方案。

5.2 调制(Modulation / AdaLN)

条件向量 c = t_emb + pooled_text_emb ∈ [B, D](时间步嵌入 + CLIP 池化文本向量相加)。每个分支用一个 SiLU+Linear 的小 MLP,从 c 回归出 6 个调制参数:

(shift₁, scale₁, gate₁, shift₂, scale₂, gate₂) = MLPmod(c) ①作用于注意力分支;②作用于 FFN 分支;gate 控制残差贡献强度

对归一化后的特征做逐通道仿射(广播到每个 token):

modulate(x, shift, scale) = x · (1 + scale) + shift x: [B, N, D];shift/scale: [B, D] → 广播为 [B, 1, D]

注意力输出乘上 gate₁ 再加回残差;FFN 输出乘 gate₂ 再加回残差。DiT 论文发现把 gate 初始化为 0(AdaLN-Zero)对训练早期稳定性至关重要——模型初始等价于恒等映射,条件信号从零开始逐渐学会注入。

5.3 QK-RMSNorm 与训练稳定性

当 MMDiT 扩展到数十亿参数时,论文观察到严重的训练不稳定:注意力 logit 持续增长、注意力熵塌陷(entropy collapse,注意力集中到极少数 token 上)、最终发散。解决方法是 QK-Norm:在计算注意力之前,对 Q 和 K 的每个 head 维度向量做带可学习缩放的 RMSNorm:

QK-RMSNorm(q) = q / RMS(q) · g,    RMS(q) = sqrt( mean(q²) + ε ) 对 head_dim 维做归一化;g 是可学习的逐通道缩放;文本流与图像流各自独立应用

这样 Q·K 点积的量级被约束住,logit 不再随训练爆炸,注意力熵保持在健康范围。这一技巧后来被 FLUX 及众多大模型沿用。

一个容易忽略的细节
SD3 的调制向量 c 由"时间步嵌入 + CLIP 池化文本"组成,因此时间信息同时通过两条路径影响模型:一路是这里的 AdaLN 调制(全局控制),另一路是文本 token 在联合注意力里的交互(细粒度)。这与 U-Net 时代"时间嵌入加在特征图上、文本走 cross-attention"的分工在思想上一致,但实现完全 Transformer 化。

6联合注意力:四种信息流

联合注意力是 MMDiT 的灵魂。把拼接序列的注意力矩阵按模态切开,会得到四个语义清晰的区域。

联合注意力的计算在数学上就是一次普通的多头自注意力,只是输入序列由两种模态拼接而成:

Attn = softmax( [Qimg; Qtxt] · [Kimg; Ktxt]T / √dh ) · [Vimg; Vtxt] Q/K/V 由两条流各自独立投影产生;dh = 64 为每头维度

把注意力矩阵 A ∈ [B, h, (N+M), (N+M)] 按查询/键的模态切分成四块:

  • T2I(图像查询 × 文本键):图像 token 从文本中取语义——这正是传统 U-Net 里 cross-attention 做的事,例如让"猫"这个词的表征流向画面左侧的某个 patch。
  • I2T(文本查询 × 图像键):文本 token 从图像中取视觉信息——这是 MMDiT 相对 U-Net 的新增方向。文本表征不再静止,而是随着画面内容逐层演化,后续层中"猫"的 token 已经包含了"画面里那只猫长什么样"的信息,从而让图像侧读到更精确的条件。
  • I2I / T2T:模态内部的自注意力,负责图像的空间连贯与文本的句法一致。

这种双向结构带来了一些可观测的性质,也成为后续研究(如 prompt-based 编辑)的抓手:

  • 提示词跟随能力更强:文本 token 被图像内容"校准"后,再反过来指导图像,多轮往返逐层精炼;
  • 注意力图可直接可视化:取出 T2I 区域(图像查询对文本键的注意力),reshape 回 H/p × W/p,就是"每个词作用于画面哪里"的热力图;
  • 编辑的入口:在 T2I 区域替换某个词的注意力分布,可实现仅修改指定物体而不动背景的局部编辑。
计算代价
联合注意力的序列长度是 N+M。1024×1024 图像(p=2,16 通道 latent 为 128×128)对应 N=4096,加上 M≈400,注意力矩阵约 (4500)² 每头——这就是为什么 SD3 需要 QK-Norm 稳定训练、以及实际部署需要 FlashAttention 等内存高效实现。

7.1 基础组件:调制、RMSNorm、时间嵌入、Patchify

import math
import torch
import torch.nn as nn
import torch.nn.functional as F


def modulate(x, shift, scale):
    """AdaLN 调制: x * (1 + scale) + shift
    x:     [B, L, D]   归一化后的 token 特征
    shift: [B, D]      由条件向量回归
    scale: [B, D]
    """
    return x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)


class RMSNorm(nn.Module):
    """对最后一维做 RMSNorm,带可学习缩放 g。
    用于 QK-Norm:约束注意力 logit 量级,防止熵塌陷。"""

    def __init__(self, dim, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))  # 可学习缩放 g

    def forward(self, x):
        # x: [..., head_dim]
        rms = x.pow(2).mean(dim=-1, keepdim=True).add(self.eps).sqrt()
        return x / rms * self.weight

    def __init__(self, dim, freq_dim=256):
        super().__init__()
        self.freq_dim = freq_dim
        self.mlp = nn.Sequential(
            nn.Linear(freq_dim, dim), nn.SiLU(), nn.Linear(dim, dim)
        )

    def forward(self, t):
        # t: [B],取值 0~1
        half = self.freq_dim // 2
        freqs = torch.exp(
            -math.log(10000.0) * torch.arange(half, device=t.device) / half
        )
        args = t[:, None] * freqs[None, :] * 1000.0     # [B, half]
        emb = torch.cat([args.sin(), args.cos()], dim=-1)  # [B, freq_dim]
        return self.mlp(emb)                            # [B, D]


class PatchEmbed(nn.Module):
    """latent [B, C, H, W] -> token [B, N, D],用 2D 正弦位置编码。"""

    def __init__(self, in_ch=16, patch=2, dim=768, img_size=64):
        super().__init__()
        self.patch = patch
        self.grid = img_size // patch
        self.proj = nn.Linear(in_ch * patch * patch, dim)
        # 预计算 2D 正弦位置编码 [1, N, D]
        self.register_buffer("pos", self._build_2d_sincos(dim), persistent=False)

    def _build_2d_sincos(self, dim):
        gh, gw = self.grid, self.grid
        assert dim % 4 == 0
        omega = torch.exp(-math.log(10000.0) * torch.arange(dim // 4) / (dim // 4))
        ys = torch.arange(gh)[:, None].expand(gh, gw).reshape(-1).float()
        xs = torch.arange(gw)[None, :].expand(gh, gw).reshape(-1).float()
        pe = torch.cat([
            (ys[:, None] / gh * omega[None, :]).sin(),
            (ys[:, None] / gh * omega[None, :]).cos(),
            (xs[:, None] / gw * omega[None, :]).sin(),
            (xs[:, None] / gw * omega[None, :]).cos(),
        ], dim=-1)                                       # [N, D]
        return pe[None]                                  # [1, N, D]

    def forward(self, z):
        # z: [B, C, H, W]
        B, C, H, W = z.shape
        p = self.patch
        z = z.reshape(B, C, H // p, p, W // p, p)
        z = z.permute(0, 2, 4, 1, 3, 5)                  # [B, H/p, W/p, C, p, p]
        z = z.reshape(B, -1, C * p * p)                  # [B, N, C·p²]
        return self.proj(z) + self.pos                   # [B, N, D]

7.2 JointAttention:拼接、注意力、拆分

这是整个架构最关键的一段代码。注意三件事:① 两流各自独立投影 Q/K/V;② 沿 token 维拼接后做一次注意力;③ 输出按 (N, M) 拆开,各自过独立的输出投影。

mmdit/joint_attention.pyPython
class JointAttention(nn.Module):
    """MMDiT 联合注意力:双模态共享一次 softmax,参数各自独立。"""

    def __init__(self, dim, heads):
        super().__init__()
        self.heads = heads
        self.head_dim = dim // heads          # SD3 固定为 64

        # ---- 图像流投影 ----
        self.qkv_img = nn.Linear(dim, dim * 3, bias=False)
        self.out_img = nn.Linear(dim, dim, bias=False)
        self.q_norm_img = RMSNorm(self.head_dim)   # QK-RMSNorm
        self.k_norm_img = RMSNorm(self.head_dim)

        # ---- 文本流投影 ----
        self.qkv_txt = nn.Linear(dim, dim * 3, bias=False)
        self.out_txt = nn.Linear(dim, dim, bias=False)
        self.q_norm_txt = RMSNorm(self.head_dim)
        self.k_norm_txt = RMSNorm(self.head_dim)

    def _split_heads(self, x):
        # [B, L, D] -> [B, h, L, head_dim]
        B, L, D = x.shape
        return x.view(B, L, self.heads, self.head_dim).transpose(1, 2)

    def forward(self, x_img, x_txt):
        """
        x_img: [B, N, D]   图像 token(已经过调制)
        x_txt: [B, M, D]   文本 token(已经过调制)
        返回: (img_out [B,N,D], txt_out [B,M,D])
        """
        B, N, D = x_img.shape
        M = x_txt.shape[1]

        # 1) 各自独立投影 Q/K/V
        q_i, k_i, v_i = self.qkv_img(x_img).chunk(3, dim=-1)
        q_t, k_t, v_t = self.qkv_txt(x_txt).chunk(3, dim=-1)

        # 2) 分头 + QK-RMSNorm(两流各自的 norm 参数)
        q_i = self.q_norm_img(self._split_heads(q_i))
        k_i = self.k_norm_img(self._split_heads(k_i))
        q_t = self.q_norm_txt(self._split_heads(q_t))
        k_t = self.k_norm_txt(self._split_heads(k_t))
        v_i = self._split_heads(v_i)
        v_t = self._split_heads(v_t)

        # 3) 沿 token 维拼接 -> [B, h, N+M, head_dim]
        q = torch.cat([q_i, q_t], dim=2)
        k = torch.cat([k_i, k_t], dim=2)
        v = torch.cat([v_i, v_t], dim=2)

        # 4) 一次联合注意力(I2I/T2T/T2I/I2T 同时发生)
        o = F.scaled_dot_product_attention(q, k, v)   # [B, h, N+M, d_h]
        o = o.transpose(1, 2).reshape(B, N + M, D)    # [B, N+M, D]

        # 5) 关键步骤:按模态拆分,各自过输出投影
        img_o, txt_o = o.split([N, M], dim=1)
        return self.out_img(img_o), self.out_txt(txt_o)

7.3 MMDiTBlock:调制 → 注意力 → FFN 双残差

mmdit/block.pyPython
class MMDiTBlock(nn.Module):
    """一个双分支 MMDiT block(结构对应图 5-1)。"""

    def __init__(self, dim, heads, mlp_ratio=4.0):
        super().__init__()
        hidden = int(dim * mlp_ratio)

        def make_ffn():
            return nn.Sequential(
                nn.Linear(dim, hidden), nn.GELU(approximate="tanh"),
                nn.Linear(hidden, dim),
            )

        # 每条流:无仿射 LN(仿射由调制提供)+ 注意力 + FFN + 调制 MLP
        self.norm1_img = nn.LayerNorm(dim, elementwise_affine=False)
        self.norm2_img = nn.LayerNorm(dim, elementwise_affine=False)
        self.ffn_img = make_ffn()
        self.norm1_txt = nn.LayerNorm(dim, elementwise_affine=False)
        self.norm2_txt = nn.LayerNorm(dim, elementwise_affine=False)
        self.ffn_txt = make_ffn()

        self.attn = JointAttention(dim, heads)

        # 调制:从条件向量 c [B,D] 回归 6 个参数,输出初始化为 0(AdaLN-Zero)
        self.mod_img = nn.Sequential(nn.SiLU(), nn.Linear(dim, dim * 6))
        self.mod_txt = nn.Sequential(nn.SiLU(), nn.Linear(dim, dim * 6))
        for m in (self.mod_img, self.mod_txt):
            nn.init.zeros_(m[-1].weight)
            nn.init.zeros_(m[-1].bias)

    def forward(self, x_img, x_txt, c):
        """
        x_img: [B, N, D];x_txt: [B, M, D];c: [B, D](t_emb + 池化文本)
        """
        s1_i, sc1_i, g1_i, s2_i, sc2_i, g2_i = self.mod_img(c).chunk(6, dim=-1)
        s1_t, sc1_t, g1_t, s2_t, sc2_t, g2_t = self.mod_txt(c).chunk(6, dim=-1)

        # ---- 注意力分支 ----
        h_img = modulate(self.norm1_img(x_img), s1_i, sc1_i)
        h_txt = modulate(self.norm1_txt(x_txt), s1_t, sc1_t)
        a_img, a_txt = self.attn(h_img, h_txt)
        x_img = x_img + g1_i.unsqueeze(1) * a_img     # 残差 × gate₁
        x_txt = x_txt + g1_t.unsqueeze(1) * a_txt

        # ---- FFN 分支 ----
        x_img = x_img + g2_i.unsqueeze(1) * self.ffn_img(
            modulate(self.norm2_img(x_img), s2_i, sc2_i))
        x_txt = x_txt + g2_t.unsqueeze(1) * self.ffn_txt(
            modulate(self.norm2_txt(x_txt), s2_t, sc2_t))
        return x_img, x_txt

7.4 完整模型:从带噪 latent 到速度预测

mmdit/model.pyPython
class MMDiT(nn.Module):
    """教学版 MMDiT。默认 depth=8, dim=512,仅为可运行演示;
    SD3 Medium 对应 depth=24, dim=1536;SD3.5 Large 对应 depth=38, dim=2432。"""

    def __init__(self, depth=8, dim=512, heads=8,
                 in_ch=16, patch=2, img_size=64, txt_len=256):
        super().__init__()
        self.patch = patch
        self.in_ch = in_ch
        self.patch_embed = PatchEmbed(in_ch, patch, dim, img_size)
        self.txt_proj = nn.Linear(dim, dim)   # 教学简化:假设文本编码器输出已是 dim
        self.t_embed = TimestepEmbedder(dim)
        # 教学简化:池化文本向量用一个可学习投影代替 CLIP 池化拼接
        self.pool_proj = nn.Linear(dim, dim)

        self.blocks = nn.ModuleList(
            [MMDiTBlock(dim, heads) for _ in range(depth)]
        )
        # 最终输出层:仅图像流需要解码回 patch
        self.final_norm = nn.LayerNorm(dim, elementwise_affine=False)
        self.final_mod = nn.Sequential(nn.SiLU(), nn.Linear(dim, dim * 2))
        self.final_proj = nn.Linear(dim, in_ch * patch * patch)

    def unpatchify(self, x, H, W):
        # x: [B, N, C·p²] -> [B, C, H, W]
        B = x.shape[0]
        p, C = self.patch, self.in_ch
        h, w = H // p, W // p
        x = x.reshape(B, h, w, C, p, p).permute(0, 3, 1, 4, 2, 5)
        return x.reshape(B, C, H, W)

    def forward(self, z_t, t, txt_tokens, txt_pooled):
        """
        z_t:        [B, 16, H, W]  带噪 latent
        t:          [B]            时间步 ∈ (0, 1)
        txt_tokens: [B, M, dim]    文本 token 序列(已投影)
        txt_pooled: [B, dim]       池化文本全局向量
        返回: 预测速度 v, [B, 16, H, W]
        """
        H, W = z_t.shape[-2:]
        x_img = self.patch_embed(z_t)                 # [B, N, D]
        x_txt = self.txt_proj(txt_tokens)             # [B, M, D]
        c = self.t_embed(t) + self.pool_proj(txt_pooled)  # [B, D]

        for blk in self.blocks:
            x_img, x_txt = blk(x_img, x_txt, c)

        # 最终调制 + 线性解码(文本流到此丢弃)
        shift, scale = self.final_mod(c).chunk(2, dim=-1)
        x_img = modulate(self.final_norm(x_img), shift, scale)
        v = self.final_proj(x_img)                    # [B, N, C·p²]
        return self.unpatchify(v, H, W)               # [B, 16, H, W]

8训练目标与采样

把第 2 章的 Rectified Flow 公式翻译成代码:训练是一次回归,采样是一次 ODE 积分。

8.1 训练损失:logit-normal 时间步 + 速度回归

mmdit/train_step.pyPython
def sample_t_logit_normal(bsz, device, mean=0.0, std=1.0):
    """logit-normal 时间步采样:u ~ N(mean, std),t = sigmoid(u)。
    密度集中在 t ≈ 0.5 附近的中间难度区域(论文的 ln(std=1) 变体)。"""
    u = torch.randn(bsz, device=device) * std + mean
    return torch.sigmoid(u)


def train_step(model, x0_latent, txt_tokens, txt_pooled):
    """
    x0_latent:  [B, 16, H, W]  VAE 编码出的干净 latent(数据,x₀)
    返回: 标量损失
    """
    B = x0_latent.shape[0]
    device = x0_latent.device

    # 1) 采样噪声与时间步
    eps = torch.randn_like(x0_latent)              # ε ~ N(0, I)
    t = sample_t_logit_normal(B, device)           # t ∈ (0, 1)

    # 2) 前向过程:直线插值得到带噪样本
    #    z_t = (1 - t) · x0 + t · ε
    t_b = t[:, None, None, None]                   # 广播到 [B,1,1,1]
    z_t = (1 - t_b) * x0_latent + t_b * eps

    # 3) 目标速度:u_t = ε - x0(常量,不依赖 t)
    target_v = eps - x0_latent

    # 4) 网络预测速度,CFM 损失
    v_pred = model(z_t, t, txt_tokens, txt_pooled)
    loss = F.mse_loss(v_pred, target_v)
    return loss
Classifier-Free Guidance(CFG)的训练侧
与所有文生图模型一样,训练时以约 10% 概率把文本条件替换为空字符串(或空嵌入),让模型同时学会条件与无条件速度场;推理时再用 CFG 放大条件方向。教学代码为简洁略去,工程实现只需在文本嵌入处做 dropout。

8.2 Euler 采样循环:从噪声积分回数据

训练完成后,生成图像就是从 t=1 的纯噪声出发,用数值方法反向求解 ODE dz/dt = v_θ(z, t)。最简单的一阶 Euler 求解器:

zt−Δt = zt − Δt · vθ(zt, t, c) 注意方向:从 t=1(噪声)走向 t=0(数据),所以是减去速度 × 步长
mmdit/sample.pyPython
@torch.no_grad()
def sample(model, txt_tokens, txt_pooled, uncond_tokens, uncond_pooled,
           H=64, W=64, steps=28, guidance=5.0, device="cuda"):
    """Euler 采样 + Classifier-Free Guidance。"""
    B = txt_tokens.shape[0]
    # t=1 是纯噪声(对应本文记号约定)
    z = torch.randn(B, 16, H, W, device=device)

    # 时间网格:1.0 -> 0.0,共 steps 步
    ts = torch.linspace(1.0, 0.0, steps + 1, device=device)

    for i in range(steps):
        t_cur = ts[i]
        dt = ts[i] - ts[i + 1]                      # 正的步长
        t_batch = torch.full((B,), t_cur, device=device)

        # CFG:同一步预测条件/无条件速度,外推放大条件方向
        v_cond = model(z, t_batch, txt_tokens, txt_pooled)
        v_uncond = model(z, t_batch, uncond_tokens, uncond_pooled)
        v = v_uncond + guidance * (v_cond - v_uncond)

        # Euler 更新:沿速度反方向走 dt(向 t 减小的方向积分)
        z = z - dt * v

    return z   # [B, 16, H, W],交给 VAE Decoder 解码成图像

Rectified Flow 的一个漂亮性质:如果速度场学得完美且数据-噪声对是直线插值,理论上一两步就能走到终点。实际中模型学到的是所有数据-噪声对的边缘平均速度场,路径仍有曲率,但比 DDPM 直得多——这就是 SD3 用 28 步左右即可出图的原因,也是蒸馏版(Turbo 类)能把步数压到 1~4 步的理论基础。

9SD3 / SD3.5 / FLUX 的架构差异

MMDiT 是一个家族而非单一模型。理解各成员的异同,才能看懂它们的权重结构和源码目录。

模型深度 dhidden size参数量结构特点
SD3 Medium241536~2B(MMDiT 部分) 纯双流 MMDiT;CLIP-L + bigG + T5-XXL 三文本编码器;16 通道 VAE
SD3.5 Large382432~8.1B 同样的纯双流结构,按 64d 缩放规律放大;训练数据与调度改进;引入 QK-Norm 等稳定化(论文实验部分)
SD3.5 Medium241536~2.5B 在 SD3 Medium 基础上改进;部分配置移除了 T5,降低显存门槛
FLUX.119 + 383072~12B 混合结构:前 19 层为双流 MMDiT block,后 38 层把两流合并为单流(共享参数的单序列注意力);文本编码器为 CLIP-L + T5-XXL;使用 RoPE 旋转位置编码

FLUX 的"双流 → 单流"混合设计是一个重要信号:经过若干层充分交互后,文本信息已经"写入"图像 token,后续层不必再维持两套参数,合并成单流可以省参数、提效率。这启发我们理解 MMDiT 的本质——双流权重是为了让模态对齐发生在注意力空间,而不是为了永远分开。

读源码时的定位技巧
在 Diffusers 中,SD3 的 block 叫 JointTransformerBlock(models/transformers/transformer_sd3.py),联合注意力在 JointAttnProcessor 系列中;FLUX 对应 FluxTransformerBlock(双流)与 FluxSingleTransformerBlock(单流)。认准"是否拆分 q/k/v 投影"这一特征即可快速区分。

10总结

把全文浓缩成一张心智地图。

  1. 问题定义:在 VAE 潜空间里学习数据分布,用 Rectified Flow 定义前向直线插值 z_t = (1−t)x₀ + tε 与训练目标——回归速度 u_t = ε − x₀。
  2. 架构动机:U-Net 的 cross-attention 是单向条件注入,DiT 只接受全局条件;MMDiT 让文本与图像 token 在每一层做双向联合注意力。
  3. 结构三件套:① 双分支独立参数(调制、QKV、FFN);② 一次拼接式联合注意力(输出必须按 [N, M] 拆分);③ AdaLN 调制(时间步 + 池化文本,6 参数,gate 零初始化)。
  4. 稳定性:QK-RMSNorm 约束注意力 logit,是大规模 MMDiT 可训练的关键。
  5. 缩放规律:深度 d → hidden 64d → 头数 d → 每头 64 维;d=24 是 SD3/3.5 Medium,d=38 是 SD3.5 Large。
  6. 演化方向:FLUX 证明"先双流交互、后单流处理"是参数效率更高的后继形态。
建议的动手路径
1. 先跑通第 7、8 章的教学代码(随机数据上验证形状与损失下降);2. 在 Diffusers 里加载 stabilityai/stable-diffusion-3-medium,对照 JointTransformerBlock 读官方实现;3. 取出某层 T2I 注意力画热力图,直观感受"词→区域"的对齐;4. 有余力再读 FLUX 的混合结构,思考为什么单流阶段可行。
