01DDPM 是什么

一句话：DDPM（Denoising Diffusion Probabilistic Models，去噪扩散概率模型）是 2020 年 Jonathan Ho、Ajay Jain、Pieter Abbeel 提出的生成模型。它做两件事——把一个干净样本「一步步加噪」直到变成纯高斯噪声，再训练一个网络把这条路径反过来走。学会走后一条路，就能从随机噪声生成全新样本。

1.1 基本事实

  • 论文：Denoising Diffusion Probabilistic Models，NeurIPS 2020。它不是「扩散模型」的发明者（Sohl-Dickstein 2015 就有），而是第一个把它做到图像质量超过 GAN 的工作。
  • 成绩：CIFAR-10 上 FID 3.17、Inception Score 9.46，无条件生成首次达到当时 SOTA。LSUN 256×256 上也大幅领先同期方法。
  • 核心贡献有三个：① 用 ε-预测（噪声预测）重参数化训练目标，把复杂的变分下界化简成一条加权 MSE；② 证明可以去掉权重项直接优化简化目标，效果反而更好；③ 给出一个与时间步条件化的 U-Net 架构，作为事实标准沿用至今。
  • 代价：采样慢。生成一张图要跑 T=1000 次网络前向（对比 GAN 1 次）。这也是后续 DDIM、Consistency Models 等工作的出发点。

1.2 与其他生成模型对比

为什么 DDPM 训练这么稳？因为它的训练目标本质上就是「给图加已知噪声，让网络猜噪声」——一个监督回归任务，没有对抗、没有不可导的采样、也没有 ELBO 里的近似后验塌缩。这是它取代 GAN 成为主流的关键。

1.3 三个关键词

  • 扩散（Diffusion）：借自热力学——墨水滴进水里会自发扩散均匀，这个过程不可逆但每一步都很简单。
  • 马尔可夫链（Markov Chain）：前向和反向都被建模成马尔可夫链，即每步只依赖上一步。这让数学可以逐项分解。
  • 变分下界（ELBO）：与 VAE 同源的训练目标。DDPM 最漂亮的一步，就是把这个看起来吓人的下界，化简成一行能直接写进代码的 MSE。

02直觉：先毁掉，再学着造回来

在写任何公式之前，先把整件事在脑子里过一遍。DDPM 只包含两条链：一条把数据变成噪声（前向，不需要学），一条把噪声变回数据（反向，需要学）。

2.1 前向过程：一个不需要学习的「破坏器」

取一张真实图片 x0，连续 T 次（论文取 T=1000）往上面加一点点高斯噪声。每次只加很少一点，少到肉眼几乎看不出变化；但加 1000 次之后，图像信息被彻底淹没，最终 xT 就是一张标准正态噪声图。

关键在于：这条路是人为定义的，完全不需要训练。我们规定了每一步加多少噪声（由 βt 控制），因此「x0 怎么变成 xt」有精确的解析公式。

2.2 反向过程：要学的那个「修复器」

真正难的是反方向：给你一张噪声图 xt，能不能猜出「上一步 xt−1 长什么样」？这个条件分布 q(xt−1 | xt) 在数学上没有闭式解——要知道它，得知道整个数据分布。

于是我们用一个神经网络 pθ 去逼近它。网络的学习材料是现成的：前向过程已经给了我们「xt 是由哪个 x0 加噪来的」这个监督信号。也就是说——

一句话抓住 DDPM

训练 = 拿真实图加噪，让网络看图猜「我加了什么噪声」；采样 = 从纯噪声出发，每一步都猜一次噪声、减掉它，重复 1000 次就得到一张图。

2.4 为什么这样能生成新图？

一个自然的疑问：既然反向过程是「猜上一步」，为什么生成出来的不是训练集的复制品？

因为起点 xT 每次采样都不同——它是从 N(0, I) 随机抽的。而反向链每一步都在做「在给定当前噪声图的前提下，最可能的上一张更干净的图」这件事。模型学到的是「什么样的局部纹理、结构配得上什么样的上下文」，而不是某张具体的图。从不同的随机起点出发，网络会收敛到数据分布的不同模式上，因此能产出从未存在过的新样本。

换个角度：反向过程本质上是在学数据分布的对数梯度（score）的方向。第 3 章的闭式解会告诉我们，预测噪声等价于预测 score——这一点在第 4.4 节会正式点明。

03前向过程：把图一点点变成噪声

这一章只有一个目标：搞明白 xt 到底长什么样。会得到一个极其重要的结论——不需要真的走 t 步，一步就能直接从 x0 采样出 xt。这个「一次到位的闭式解」是整个 DDPM 高效训练的基础。

3.2 单步定义

前向过程的每一步都是「先衰减信号，再加入固定方差的高斯噪声」：

q(xt | xt−1) = N( xt ; √(1 − βt) · xt−1 , βt · I ) 等价于 xt = √αt · xt−1 + √βt · ε，其中 αt = 1 − βt

为什么要乘 √(1−βt)？这是一个精心设计的保方差操作。若 xt−1 的方差为 1，那么 xt 的方差是 (1−βt)·1 + βt·1 = 1。整个过程方差不膨胀也不收缩，始终维持在 1 附近——这是让最终分布收敛到标准正态、而不是某个未知尺度的正态的前提。（真正重要的原因见 3.5 节的 callout。）

3.3 两步合并：闭式解的萌芽

现在做一件看起来平凡、但极关键的事：把两步展开。

xt = √αt · xt−1 + √βt · ε1

xt = √αt · ( √αt−1 · xt−2 + √βt−1 · ε2 ) + √βt · ε1

    = √(αtαt−1) · xt−2  +  ( √(αtβt−1) · ε2 + √βt · ε1 ) 两个独立高斯相加仍是高斯：N(0, σ₁²I) + N(0, σ₂²I) = N(0, (σ₁²+σ₂²)I)

后两项是两个独立零均值高斯，方差相加：

αtβt−1 + βt = αt(1 − αt−1) + (1 − αt) = 1 − αtαt−1 所以 xt = √(ᾱt) · xt−2 + √(1 − ᾱt) · ε，噪声可以直接合并成一个

这就是归纳法的第一步：两步可以合成一步，且形式完全不变，只是 ᾱ 变成了 αtαt−1。同样的推导可以一路归纳到 x0。

3.4 闭式解（最重要的公式）

q(xt | x0) = N( xt ; √ᾱt · x0 , (1 − ᾱt) · I )

⟺   xt = √ᾱt · x0 + √(1 − ᾱt) · ε ，  ε ~ N(0, I) ᾱt = ∏s=1..t αs。注意它是单调递减的：t 越大，ᾱt 越小，信号越弱

这个公式的意义怎么强调都不过分：训练时任意 t 的 xt 都可以一步采样得到，不需要真的循环 t 次。这让训练可以完全并行——一个 batch 里每张图随机抽一个 t，各自一步加噪，然后统一前向。如果没有这个闭式解，DDPM 的训练成本会高的多得多。

为什么必须用 √(1−β) 而不是别的系数

假设定义成 xt = xt−1 + √βt·ε（不加 √α 衰减）。那么展开后 xt = x0 + √(Σβt)·ε，x0 的信号永不衰减——不管加多少步噪声，原图信息都还在，最终分布不是 N(0,I) 而是「原图 + 大噪声」，采样时无法从纯噪声开始。√(1−β) 衰减项保证了 ᾱt → 0，信号才会被彻底淹没。

3.5 噪声调度：β 怎么选

论文用的是线性调度：β1 = 10−4 线性增长到 βT = 0.02。

βt = β1 + (t − 1) · (βT − β1) / (T − 1) T = 1000 时，每步 β 增加约 2×10−5

为什么要递增？早期 β 小，图像几乎不变，模型可以学到精细的去噪；后期 β 大，快速破坏剩余结构直到纯噪声。反过来（先大后小）会导致早期信息损失太快，训练信号不足。

3.6 x_T 真的接近 N(0, I) 吗

由上表，t=1000 时 √ᾱT ≈ 0.0063，意味着 xT = 0.0063·x0 + 0.99998·ε。x0 的贡献只剩下千分之六，可以忽略。所以 xT ≈ N(0, I)——这就是采样时可以从标准正态直接起步的理论依据。

必须把图像归一化到 [−1, 1]

上面的推导假设「信号和噪声的方差都是 1」。如果你的数据是 [0, 1] 取值（均值 0.5、方差约 0.08），那么 xT ≈ 0.0063·0.5 + ε 仍然接近 N(0,I)，但采样时网络输出的是 [−1,1] 区间的图，你直接 clip(0,1) 会看到严重偏灰、对比度崩塌的样本。正确做法：训练时用 Normalize((0.5,), (0.5,)) 把数据映射到 [−1,1]，采样完成后用 (x+1)/2 转回 [0,1]。

换个调度会怎样

线性调度在 256×256 以下表现良好，但高分辨率图像「有效信号」衰减太快，后期白耗步数。改进方案 cosine 调度（Nichol & Dhariwal 2021）令 ᾱt = cos²((t/T + s)/(1+s) · π/2)，让 √ᾱ 下降更平滑，在 512/1024 分辨率与低步数采样时显著更好。代码上只需换一行 β 生成函数，其余全不变。

04反向过程：从噪声里长回图像

前向是「已知的破坏」，反向是「要学的修复」。这一章做三件事：写出那个真正的目标分布 q(xt−1|xt, x0)（注意多了 x0 这个条件），把它整理成网络能直接实现的形式，最后解释为什么「预测噪声」是这个形式的最佳选择。

4.1 要学的分布

真实的反向分布 q(xt−1 | xt) 没有闭式解——它需要对整个数据分布积分。但我们有一步之遥的替代品：如果已知 x0，反向分布就有精确的闭式解。因此用网络 pθ 去拟合它，并假设反向过程也是各向同性高斯：

pθ(xt−1 | xt) = N( xt−1 ; μθ(xt, t) , Σθ(xt, t) ) 网络只需要预测均值 μθ；方差 Σθ 在 DDPM 中被固定为常数（见 4.5）

整个 DDPM 的网络结构、损失函数、采样公式，全部围绕这个假设展开。下面先求出「理想的均值应该是什么」，再让网络去逼近它。

4.2 真后验的推导

我们的目标形式是 q(xt−1 | xt, x0)。用贝叶斯公式展开：

q(xt−1 | xt, x0) = q(xt | xt−1, x0) · q(xt−1 | x0) / q(xt | x0) 分子三项全是已知高斯（因为马尔可夫性，q(xt|xt−1,x0) = q(xt|xt−1)）

三项分别是：

q(xt | xt−1) = N( √αt·xt−1 , βt·I )
q(xt−1 | x0) = N( √ᾱt−1·x0 , (1−ᾱt−1)·I )
q(xt | x0) = N( √ᾱt·x0 , (1−ᾱt)·I )

高斯分布的乘积仍是高斯，因此结果必然是 N(μ̃t, β̃tI)。按标准做法展开指数项、对 xt−1 配方（把二次项凑成完全平方），可以分离出均值和方差。过程略去代数细节，结论是：

β̃t = βt · (1 − ᾱt−1) / (1 − ᾱt)

μ̃t(xt, x0) = √ᾱt−1 · βt
1 − ᾱt · x0  +  √αt · (1 − ᾱt−1)
1 − ᾱt · xt 注意两个系数之和恒为 1：这是权重插值的形式，所以 μ̃t 一定落在 x0 与 xt 之间

β̃t 的数值很小（t=500 时约 0.0100，t=1000 时为 0.02），且与 t 几乎同步于 βt。

4.3 ε 参数化：把 x0 换成噪声

4.2 的结论有个问题：它需要 x0，可采样时我们只有 xt，没有 x0。解法是把 x0 用闭式解反表示出来：

xt = √ᾱt·x0 + √(1−ᾱt)·ε   ⟹   x0 = ( xt − √(1−ᾱt)·ε ) / √ᾱt

代回 μ̃t 的表达式，x0 就消失了，只剩 xt 和 ε：

μ̃t = 1
√αt · ( xt − βt
√(1−ᾱt) · ε ) 推导要点：把 x0 的系数与 √ᾱt−1βt/(1−ᾱt) 相乘后，xt 的总系数恰好化简为 √αt(1−ᾱt−1)/(1−ᾱt) + βt/√αt = 1/√αt（用到 βt + αt = 1 与 ᾱt = αtᾱt−1）

这一步是全篇最关键的一次视角转换：「预测 xt−1 的均值」等价于「预测 xt 里混进了什么噪声」。于是网络的任务从「生成一张图」变成了「估计一个噪声张量」——这是一个标准的回归问题，MSE 就能训练，稳定性极好。

为什么采样必须加随机噪声

如果去掉 σtz 项，采样就变成了确定性映射（这正是 DDIM 的做法，见第 10 章）。保留随机性有两个作用：一是让 pθ 真正对应一个「各向同性高斯」的概率模型，理论上保证它拟合的是 q；二是多次采样会产生不同细节，提高多样性。代价是 Steps 无法减少——必须老老实实走 1000 步。

4.4 换个视角：预测噪声 = 估计 score

这个等价关系能解释 DDPM 为什么「有效」，也是它通往 score-based 模型与 SDE 框架的桥。定义 xt 的对数密度梯度（score）：

∇xt log q(xt) = − E[ ε | xt ] / √(1 − ᾱt) 由 Tweedie 公式可得：给定 xt，最优的 MSE 回归目标就是条件期望 E[ε|xt]

也就是说，网络输出的 εθ 实际上是数据分布 score 的一个缩放版本。这在数学上把 DDPM 与「噪声条件 score 匹配」统一了起来，也解释了为什么每一步的预测都可以写得如此简洁。对实现没有直接影响，但理解这一点会让后面读 DDIM / Flow Matching / SDE 类论文轻松很多。

4.5 方差 σt 怎么定

DDPM 的一个简化是：不学方差，直接用固定的常数。论文对比了三种选择：

posterior_variance = betas * (1.0 - alphas_cumprod_prev) / (1.0 - alphas_cumprod)
为什么 DDPM 选择不学方差

学方差会让损失变成「变分下界各部分加权求和」，训练时梯度噪声大、需要精心调权重。固定方差后，损失退化成纯 MSE，一个 F.mse_loss 搞定，且实测质量更好。后来 Improved DDPM 用「混合目标」（固定方差 + 一个学出来的插值系数，且用 stop-gradient 隔离）才把学方差做稳，属于进阶内容。

05训练目标：从 ELBO 到一条 MSE

这一章是全篇数学密度最高的部分，但结论极简：最终损失就是「预测噪声与真实噪声的均方误差」。我们一步步从最大似然走下来，让你知道那条 MSE 不是拍脑袋定的。

5.1 出发点：让模型的对数似然最大

生成模型的本质目标是最大化训练数据在模型下的概率 log pθ(x0)。但 pθ(x0) 需要对所有可能的中间路径积分，无法直接计算（intractable）。标准解法与 VAE 一样：用变分推断，构造一个下界。

log pθ(x0) ≥ Eq[ log pθ(x0:T) − log q(x1:T | x0) ] = −L 即 ELBO（证据下界）。最大化 ELBO ⟺ 最小化 L。这一步由 Jensen 不等式得到

5.2 关键一步：把 L 拆成三项

利用马尔可夫性展开联合分布，再按 t 分组，L 会分解成三个结构清晰的部分：

L = LT  +  Σt=2..T Lt−1  +  L0 三项分别是「终结项」「中间项」「重建项」，物理含义完全不同
项形式含义是否含参数怎么处理
LTKL( q(xT|x0) ‖ p(xT) )前向终点与先验的差距不含 θ常数，可直接扔掉（且已设计为接近 0）
Lt−1KL( q(xt−1|xt,x0) ‖ pθ(xt−1|xt) )每一步「真后验 vs 模型预测」的差距含 θ主战场，下面重点化简
L0− log pθ(x0|x1)最后一步的似然含 θ论文并入 Lt−1 一起处理

LT 与 θ 无关，可以直接删。L0 在实现中通常用同一套公式近似（把 t=1 也当中间步处理），不必单独设计离散解码器。所以真正要优化的是中间那 T−1 个 KL 项。

5.3 高斯 KL 的闭式解

Lt−1 是两个高斯的 KL。对于同方差的对角高斯，KL 有闭式解：

KL( N(μ1, σ²I) ‖ N(μ2, σ²I) ) = ‖μ1 − μ2‖² / (2σ²) 因为两者方差被固定为同一个值，KL 简化为均值之差的平方距离（差一个常数系数）

于是问题变成：让网络预测的均值 μθ 逼近真均值 μ̃t。把 4.3 的 ε 参数化代入两边，取差值：

μ̃t − μθ = βt
√αt·√(1−ᾱt) · ( εθ − ε ) 两个均值共享同样的 xt 项，相减后只剩 ε 的差，前面的常数系数原样提出来

再代回 KL 并整理常数，就得到每一项的最终形式：

Lt−1 = Eq[ λt · ‖ ε − εθ(xt, t) ‖² ] + C，   λt = βt
2αt(1−ᾱt) C 是与 θ 无关的常数。λ_t 是每步损失的权重——这一步从「KL 最小化」彻底变成了「噪声回归」

5.4 最漂亮的一步：扔掉权重

λt 在 t 小时很大（因为 1−ᾱt 很小），意味着小 t 步的损失被赋予极高权重。直觉上这是合理的——早期去噪更「确定」。但论文作者做了一个实验性的决定：直接令 λt = 1，得到简化目标：

Lsimple = Et~U[1,T] Ex0, ε [ ‖ ε − εθ( √ᾱt·x0 + √(1−ᾱt)·ε , t ) ‖² ] 这就是 DDPM 论文 Algorithm 1 的第 5 行，也是你实现里唯一需要的损失函数

去掉权重相当于降低了对小 t 步的重视程度、相对提升了大 t 步的权重——而大 t 步（高噪声）正对应「结构生成」这种最难也最重要的任务。实验结果是：Lsimple 训练出的样本质量明显优于完整的加权 ELBO。

损失为什么能这么简单——从「生成」到「去噪」

至此整篇论文最核心的洞察落地了：与其直接学「怎么生成数据」，不如学「怎么去掉噪声」。后者是一个有监督的回归任务，标签（加了什么噪声）是我们自己造的，永远准确、永远现成、永远不需要判别器。这就是 DDPM 训练稳定性的根源。

5.6 训练目标的三种等价参数化

既然 x0、ε、v（速度）之间可以互相换算，网络也可以选择预测其中任意一个。三种形式在数学上等价，但梯度尺度与实际效果不同：

06两个算法与最小骨架代码

论文只有两页伪代码，却包含了 DDPM 的全部。这一章逐行翻译这两个算法，并把它们压缩成 20 行可运行的骨架——先看清骨架，第 7、8 章再往里填结构。

6.1 Algorithm 1：训练

Algorithm 1　Training
  1. repeat（每个 batch）
  2.   x0 ~ q(x0)　← 从数据集抽一批真实图像
  3.   t ~ Uniform({1, …, T})　← 每张图独立抽一个时间步
  4.   ε ~ N(0, I)　← 抽标准高斯噪声
  5.   梯度下降 ∇θ ‖ ε − εθ( √ᾱt·x0 + √(1−ᾱt)·ε , t ) ‖²
  6. until converged

两个容易忽略的细节：

  • t 是均匀抽的，不是顺序遍历。一个 batch 里可能同时有 t=5 和 t=998 的样本，这天然构成了「简单任务与困难任务」的混合课程，也是训练稳定的重要原因。
  • t 每步重抽，同一个 x0 在不同 epoch 会遇到完全不同的 t 和 ε，等价于无限的数据增强。

6.2 Algorithm 2：采样

Algorithm 2　Sampling
  1. xT ~ N(0, I)　← 从纯噪声起步
  2. for t = T, …, 1 do
  3.   z ~ N(0, I) if t > 1, else z = 0
  4.   xt−1 = (1/√αt) · ( xt − (βt/√(1−ᾱt)) · εθ(xt, t) ) + σt·z
  5. end for
  6. return x0

采样必须串行——第 t 步的输出是第 t−1 步的输入。这是 DDPM 慢的根本原因：一次生成 = 1000 次完整前向，无法并行。

6.3 训练流程的完整数据流

把 Algorithm 1 展开成流水线，你会看到每一步的张量操作。注意第 4 步「构造 xt」是整个训练的核心——它把任意 t 的加噪压缩成一次运算。

07U-Net 结构逐层精讲

前面所有章节都假设有一个能用的 εθ(xt, t)。这一章就把它拆开：为什么必须是 U 形、时间步怎么注入、注意力放在哪、张量在每个阶段是什么形状。

7.1 为什么是 U-Net

噪声预测任务对网络有三个硬性要求，恰好对应 U-Net 的三个设计：

  • 输入输出同形状。εθ 要和 xt 逐元素相减算 MSE，输出必须与输入完全同尺寸、同通道。这排除了分类网络式的全局池化结构。
  • 需要多尺度感受野。去噪既要看局部纹理（这个像素周围是不是噪点），也要看全局结构（这一块该是数字的哪一笔）。U-Net 的下采样路径正是为此存在：分辨率减半、感受野翻倍。
  • 需要精确定位。下采样会丢失位置细节，而图像生成对「哪个位置该有什么」极度敏感。跳跃连接把编码器的浅层高分辨率特征直接送到解码器，解决了这个问题。

此外 DDPM 还有一个额外要求：网络必须知道当前是第几步。t 小时任务是「去掉一层薄雾」，t 大时任务是「从随机噪声里凭空构想结构」，两者天差地别。这个信息通过时间嵌入（7.3）注入每一个残差块。

7.3 ResBlock：时间步怎么进网络

每个残差块有两个卷积和一个「额外输入通道」——时间嵌入。它的注入方式极其朴素：把 t_emb 投影成与特征通道数相同的向量，然后直接加在特征图上（广播到每个空间位置）。

图 7-2 ResBlock 内部。主干是「GN → SiLU → Conv」两遍，时间嵌入经线性层投影成 C 维向量后广播相加，最后与入口做残差相加。注意第二个卷积输出通道是 C_out，所以当 C ≠ C_out 时捷径也要用 1×1 卷积改变通道。

时间嵌入为什么要用正弦函数

与 Transformer 的位置编码同源。整数 t 直接输入网络有两个问题：数值范围差异巨大（1 到 1000），且「相邻时刻相似」这一先验无法被普通全连接层捕获。正弦嵌入把这些信息编码成一组不同频率的波：

PE(t, 2i) = sin( t / 100002i/d )，   PE(t, 2i+1) = cos( t / 100002i/d ) d 是嵌入维度；低频分量编码「大致在第几个阶段」，高频分量编码「精确是哪一步」

随后的两层 MLP（Linear → GELU → Linear）负责把这些波变换成对每个通道有意义的调制信号。实现上非常短：

time_embeddingPython
class SinusoidalEmbedding(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, t):                              # t: [B]，整数步
        half = self.dim // 2
        freqs = torch.exp(-math.log(10000) * torch.arange(half, device=t.device) / half)
        args = t[:, None].float() * freqs[None]        # [B, half]
        return torch.cat([args.sin(), args.cos()], dim=-1)   # [B, dim]

7.4 注意力为什么只放在低分辨率

每一层都做自注意力的话，32×32 特征图有 1024 个 token，注意力矩阵是 1024×1024，显存与计算量都不可接受，而收益甚微。DDPM 的做法是只在低分辨率层（16×16、8×8，以及瓶颈 4×4）插入注意力：

分辨率token 数注意力矩阵是否使用
32×3210241024² ≈ 1.0M不用（太贵，且此处靠卷积足够）
16×16256256² ≈ 65K用
8×86464² ≈ 4K用
4×4（瓶颈）1616² = 256用

为什么低分辨率处需要注意力？因为此时每个 token 已经浓缩了一大块区域的语义信息，注意力负责建模「这些区域之间该有什么样的全局关系」——比如数字的笔画是否闭合、整体是否左右对称。这种长程依赖卷积要多层才能建立，注意力一步到位。

自注意力本身是标准的 Transformer 结构（含残差与 LayerNorm），只是把空间维展平成序列：

def forward(self, x):                       # [B, C, H, W]
    B, C, H, W = x.shape
    h = self.norm(x).view(B, C, H * W).transpose(1, 2)   # [B, N, C]
    q, k, v = self.qkv(h).chunk(3, dim=-1)               # 各 [B, N, C]
    q = q.view(B, H * W, self.heads, -1).transpose(1, 2) # [B, heads, N, d]
    k = k.view(B, H * W, self.heads, -1).transpose(1, 2)
    v = v.view(B, H * W, self.heads, -1).transpose(1, 2)
    out = F.scaled_dot_product_attention(q, k, v)        # [B, heads, N, d]
    out = out.transpose(1, 2).reshape(B, H * W, C)       # [B, N, C]
    return x + self.proj(out).transpose(1, 2).view(B, C, H, W)

7.5 上下采样为什么这样选

  • 下采样用 MaxPool2d(2)，不用 stride=2 卷积。池化无参数、无额外计算，且在去噪任务中「取局部最大值」有助于保留显著结构。代价是完全丢弃了部分位置信息，所以必须靠跳跃连接补偿。
  • 上采样用最近邻插值，不用转置卷积。转置卷积容易在生成图像上产生棋盘格伪影（checkerboard artifact），而最近邻 + 后续 3×3 卷积的组合更平滑稳定，这也是现代扩散模型的主流做法。
  • 先上采样再 concat：把 x 放大到目标分辨率，再与同分辨率的 skip 特征在通道维拼接，这样空间对齐、无需插值 skip。
DDPM 原始 U-Net 与本档实现的差异

论文用的是 128×128 输入、4 个分辨率层级、每层 2 个 ResBlock，并额外有「缩放后的自注意力块」。本档为了让代码能在 MNIST + 单卡上几分钟训完，裁剪成了 3 个层级、每层 1 个 ResBlock、32×32 输入（约 8M 参数）。所有设计原则完全一致，把这几个数字调大就是论文配置。

def linear_beta_schedule(T=1000, beta_start=1e-4, beta_end=0.02, device="cpu"):
    """论文的线性调度：β 从 1e-4 均匀增长到 0.02"""
    return torch.linspace(beta_start, beta_end, T, device=device)


def extract(arr, t, shape):
    """按 batch 取出每个样本自己的系数，并 reshape 成可广播的形状。

    arr: 长度 T 的一维张量；t: [B] 的 long 张量；shape: x 的形状
    -> [B, 1, 1, 1]（与 [B, C, H, W] 广播）
    """
    return arr.gather(0, t).reshape(t.shape[0], *((1,) * (len(shape) - 1)))


class DDPM:
    """把前向闭式解、训练损失、采样循环打包在一起"""

    def __init__(self, T=1000, device="cuda"):
        self.T = T
        self.device = device

        betas = linear_beta_schedule(T, device=device)
        alphas = 1.0 - betas
        alphas_cumprod = torch.cumprod(alphas, dim=0)                 # ᾱ_t
        alphas_cumprod_prev = F.pad(alphas_cumprod[:-1], (1, 0), value=1.0)  # ᾱ_{t-1}

        # ---- 前向 q(x_t | x_0) ----
        self.sqrt_ac = torch.sqrt(alphas_cumprod)                     # √ᾱ_t
        self.sqrt_1m_ac = torch.sqrt(1.0 - alphas_cumprod)            # √(1-ᾱ_t)

        # ---- 反向 p(x_{t-1} | x_t) ----
        self.sqrt_recip_alpha = torch.sqrt(1.0 / alphas)              # 1/√α_t
        self.coef_eps = betas / self.sqrt_1m_ac                       # β_t/√(1-ᾱ_t)
        self.posterior_var = betas * (1.0 - alphas_cumprod_prev) / (1.0 - alphas_cumprod)

    def q_sample(self, x0, t, noise):
        """闭式解：一步得到任意 t 的加噪图（训练用）"""
        return (extract(self.sqrt_ac, t, x0.shape) * x0
                + extract(self.sqrt_1m_ac, t, x0.shape) * noise)

    def p_losses(self, model, x0):
        """L_simple：预测噪声 vs 真实噪声"""
        B = x0.shape[0]
        t = torch.randint(0, self.T, (B,), device=self.device).long()
        noise = torch.randn_like(x0)
        x_t = self.q_sample(x0, t, noise)
        eps_hat = model(x_t, t)
        return F.mse_loss(eps_hat, noise)

    @torch.no_grad()
    def sample(self, model, shape):
        """Algorithm 2：从纯噪声逐步去噪"""
        x = torch.randn(shape, device=self.device)
        for i in reversed(range(self.T)):
            tb = torch.full((shape[0],), i, device=self.device, dtype=torch.long)
            eps_hat = model(x, tb)
            # 去噪 + 缩放：x ← (1/√α_t)(x_t − β_t/√(1−ᾱ_t)·ε_θ)
            x = extract(self.sqrt_recip_alpha, tb, x.shape) * (
                x - extract(self.coef_eps, tb, x.shape) * eps_hat)
            # 最后一步（i == 0）不加噪声
            if i > 0:
                x = x + torch.sqrt(extract(self.posterior_var, tb, x.shape)) * torch.randn_like(x)
        return x
为什么 sample 里用 reversed(range(T))

T=1000 时索引是 0..999，代表「已加噪 1..1000 次」。从 999 开始递减到 0，对应论文的 t = T..1。当 i == 0 时，算出的 x 就是 x0，此时不能再加噪声——所以判断写的是 i > 0。

class SinusoidalEmbedding(nn.Module):
    """把整数 t 编码成一组不同频率的正余弦波"""

    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, t):                                  # t: [B]
        half = self.dim // 2
        freqs = torch.exp(-math.log(10000) * torch.arange(half, device=t.device) / half)
        args = t[:, None].float() * freqs[None]            # [B, half]
        return torch.cat([args.sin(), args.cos()], dim=-1)  # [B, dim]

ResBlockPython
class ResBlock(nn.Module):
    """GN → SiLU → Conv，加时间嵌入，再加 GN → SiLU → Conv，最后残差"""

    def __init__(self, in_ch, out_ch, time_dim=256, groups=8):
        super().__init__()
        self.norm1 = nn.GroupNorm(groups, in_ch)
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3, padding=1)
        # 时间嵌入投影：256 → out_ch，两层非线性
        self.time_mlp = nn.Sequential(
            nn.Linear(time_dim, out_ch), nn.SiLU(), nn.Linear(out_ch, out_ch))
        self.norm2 = nn.GroupNorm(groups, out_ch)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3, padding=1)
        # 通道不一致时，捷径也要 1×1 卷积对齐
        self.skip = nn.Conv2d(in_ch, out_ch, 1) if in_ch != out_ch else nn.Identity()

    def forward(self, x, t_emb):
        h = self.conv1(F.silu(self.norm1(x)))
        h = h + self.time_mlp(t_emb)[:, :, None, None]     # 广播到 H×W
        h = self.conv2(F.silu(self.norm2(h)))
        return h + self.skip(x)

（3）自注意力（只用在低分辨率）

SelfAttentionPython
class SelfAttention(nn.Module):
    """空间维展平成序列后做多头自注意力，形状回到 [B, C, H, W]"""

    def __init__(self, ch, heads=4, groups=8):
        super().__init__()
        assert ch % heads == 0
        self.heads = heads
        self.norm = nn.GroupNorm(groups, ch)
        self.qkv = nn.Conv2d(ch, ch * 3, 1)
        self.proj = nn.Conv2d(ch, ch, 1)

    def forward(self, x):                                  # [B, C, H, W]
        B, C, H, W = x.shape
        d = C // self.heads
        q, k, v = self.qkv(self.norm(x)).chunk(3, dim=1)   # 各 [B, C, H, W]
        # [B, C, N] → [B, heads, N, d]（C 拆成 heads × d）
        q = q.reshape(B, self.heads, d, H * W).transpose(2, 3)
        k = k.reshape(B, self.heads, d, H * W).transpose(2, 3)
        v = v.reshape(B, self.heads, d, H * W).transpose(2, 3)
        out = F.scaled_dot_product_attention(q, k, v)      # [B, heads, N, d]
        out = out.transpose(2, 3).reshape(B, C, H, W)
        return x + self.proj(out)

（4）组装成 U-Net

UNet　3 级、mults=(1,2,4)、约 8M 参数Python
class UNet(nn.Module):
    def __init__(self, in_ch=1, base=64, mults=(1, 2, 4), time_dim=256):
        super().__init__()
        # t → 正弦嵌入 → MLP → [B, time_dim]
        self.time_embed = nn.Sequential(
            SinusoidalEmbedding(base),
            nn.Linear(base, time_dim), nn.SiLU(),
            nn.Linear(time_dim, time_dim))

        self.init_conv = nn.Conv2d(in_ch, base, 3, padding=1)

        # ---- 编码器：逐级 ResBlock（+ Attn），然后 MaxPool ----
        self.downs = nn.ModuleList()
        self.down_attn = nn.ModuleList()
        ch = base
        for i, m in enumerate(mults):
            out_ch = base * m
            self.downs.append(ResBlock(ch, out_ch, time_dim))
            self.down_attn.append(SelfAttention(out_ch) if i >= 1 else nn.Identity())
            ch = out_ch
        self.pool = nn.MaxPool2d(2)

        # ---- 瓶颈：Res → Attn → Res，分辨率最低 ----
        self.mid1 = ResBlock(ch, ch, time_dim)
        self.mid_attn = SelfAttention(ch)
        self.mid2 = ResBlock(ch, ch, time_dim)

        # ---- 解码器：上采样 → concat(skip) → ResBlock ----
        self.ups = nn.ModuleList()
        self.up_attn = nn.ModuleList()
        for i, m in reversed(list(enumerate(mults))):
            out_ch = base * m
            # 输入通道 = 上采样来的 ch + 跳跃连接的 out_ch
            self.ups.append(ResBlock(ch + out_ch, out_ch, time_dim))
            self.up_attn.append(SelfAttention(out_ch) if i >= 1 else nn.Identity())
            ch = out_ch

        self.final_norm = nn.GroupNorm(8, base)
        self.final_conv = nn.Conv2d(base, in_ch, 1)

    def forward(self, x, t):
        t_emb = self.time_embed(t)
        x = self.init_conv(x)

        skips = []
        for res, attn in zip(self.downs, self.down_attn):
            x = attn(res(x, t_emb))
            skips.append(x)                    # 先存，再池化
            x = self.pool(x)

        x = self.mid1(x, t_emb)
        x = self.mid_attn(x)
        x = self.mid2(x, t_emb)

        for res, attn, skip in zip(self.ups, self.up_attn, reversed(skips)):
            x = F.interpolate(x, scale_factor=2, mode="nearest")
            x = torch.cat([x, skip], dim=1)    # 通道维拼接
            x = attn(res(x, t_emb))

        return self.final_conv(F.silu(self.final_norm(x)))
两个必须对齐的细节

① skip 要在 pool 之前存。代码里 skips.append(x) 在 self.pool(x) 之前，所以存的是池化前的高分辨率特征（32×32 / 16×16 / 8×8），与解码器的上采样目标分辨率一致。存在 pool 之后会导致形状不匹配。

② 解码器用 reversed(skips)。编码器存的顺序是 [32×32, 16×16, 8×8]，解码器要先处理 8×8，必须倒序取。用 zip 时不会报错但会静默把错误分辨率的特征拼进去——这是最典型的一类 bug。

8.4 EMA：为什么采样要用平滑权重

训练过程中模型参数一直在抖动。直接用最后一个 step 的权重采样，结果往往比「最近若干 step 的平均」差。EMA（指数滑动平均）维护一份参数影子副本，采样时临时换上：

θ̄ ← decay · θ̄ + (1 − decay) · θ decay = 0.999 时，等效于对最近约 1000 步做平均。几乎所有扩散模型的官方实现都这么做
EMAPython
class EMA:
    """参数滑动平均；copy() 用上下文管理器临时换权重，退出时自动还原"""

    def __init__(self, model, decay=0.999):
        self.decay = decay
        self.shadow = {k: v.clone().detach() for k, v in model.state_dict().items()}

    @torch.no_grad()
    def update(self, model):
        for k, v in model.state_dict().items():
            if v.dtype.is_floating_point:
                self.shadow[k].mul_(self.decay).add_(v.detach(), alpha=1 - self.decay)
            else:
                self.shadow[k].copy_(v)

    @contextmanager
    def copy(self, model):
        backup = {k: v.clone() for k, v in model.state_dict().items()}
        model.load_state_dict(self.shadow)
        try:
            yield
        finally:
            model.load_state_dict(backup)      # 训练权重原样还原

        transforms.Pad(2),                      # 28 → 32，便于 3 次下采样到 4×4

        transforms.Normalize((0.5,), (0.5,)),   # → [-1,1]（关键！）

            opt.step()
            ema.update(model)

        print(f"epoch {epoch:3d}　loss {loss.item():.4f}")

        if epoch % 5 == 4:                      # 每 5 轮采样一次看进展
            model.eval()
            with ema.copy(model):
                samples = diffusion.sample(model, (16, 1, 32, 32))
            save_grid(samples, f"samples_ep{epoch:03d}.png")

09常见疑问十问

这一章收集读 DDPM 时最容易卡住的十个问题，每个答案都尽量回到具体公式或代码行，而不是含糊的类比。

Q1　为什么不直接学 p(x0)，非要绕 1000 步？

因为直接建模一张 32×32×1 的图像分布，等于在一个 1024 维空间里学一个极其复杂的分布——这个分布的支撑集（真实图像所在的流形）只占整个空间极小一部分，网络很难直接命中。DDPM 的做法是把难题拆成 1000 个简单题：每一步只要求「把一点点噪声去掉」。每个子问题都接近高斯、都有闭式解可参考，串起来就完成了整体。这与「一次跳上山顶」和「修 1000 级台阶」的区别相同。

Q2　T 必须是 1000 吗？能不能用 100 步？

不是必须。T 与 β 的调度是联动的：总噪声量必须足够让 xT 接近 N(0,I)。若把 T 降到 100 而保持 β 线性从 1e-4 到 0.02，则 ᾱ100 ≈ 0.37，xT 仍含大量信号，采样起点就错了，效果会很差。正确做法是把 β 调大（例如 1e-3 到 0.1 或更高）以保证 ᾱT ≈ 0。实践中 T=1000 是质量与成本的折中点；要真正减少采样步数，应该换 DDIM 或蒸馏，而不是硬减 T。

Q3　为什么让网络预测噪声 ε，而不是直接预测图像 x0？

数学上两者等价（可以互相换算），但梯度尺度差别很大。由 x0 = (xt − √(1−ᾱt)ε)/√ᾱt 可见，当 t 很小时 √ᾱt ≈ 1，没问题；但预测 x0 的误差在换算成 ε 时会被 √(1−ᾱt) 放大，而 t 大时这一项趋近 1、t 小时趋近 0，导致各时间步的损失权重极度不均。ε 参数化让所有 t 的回归目标都恰好是单位方差的标准高斯，尺度天然一致，这是它更稳的核心原因。

Q4　β 为什么必须很小？取大一点不是收敛更快吗

β 太大意味着单步破坏太剧烈，反向过程「从 xt 猜 xt−1」的不可逆性增强，高斯假设（pθ 是各向同性高斯）就越不成立。极端情况 β=1 时一步就把信号全抹掉，反向完全无从下手。β 小的代价是需要更多步数，收益是每一步的反向分布都近似高斯、KL 项小、训练稳定。「小步多走」是 DDPM 的核心哲学。

Q5　训练没用标签，那它是无监督学习吗

形式上是无监督（数据里只有 x，没有 y），但训练信号是自监督的——标签（噪声 ε 以及时间步 t）是模型自己造的。这也是它比 GAN 好训的原因：不需要判别器提供不稳定的对抗信号，只需要一个永远正确的回归目标。

Q6　为什么采样这么慢？有没有办法只走 50 步

慢是因为必须串行 1000 次完整前向，且每次的输入依赖上一次输出，无法并行。加速的主流三条路：

  • DDIM（第 10 章）：把随机采样改成确定性采样，同一训练好的模型可直接用 50–100 步，质量略降但可用。
  • 蒸馏（Progressive Distillation / Consistency Models）：训练学生模型一次跨多步，可做到 1–4 步，但需要额外训练。
  • 换更快的骨干：用 DiT 或更小的 U-Net，减少单步开销。

Q10　DDPM、VAE、Flow Matching 是什么关系

三者都能写成「从噪声到数据的变换」，但训练路径不同：

  • VAE：一次编码-解码，路径只有一步，靠 KL 正则约束潜空间。重建容易糊。
  • DDPM：一条弯曲的 1000 步随机路径，每步学去噪。质量高但慢。
  • Flow Matching：一条直线路径，直接回归速度场，ODE 积分几十步即可。Wan 2.1、SD3、Flux 都用它。

本质上，DDPM 与 Flow Matching 都在估计同一个东西——数据分布的对数梯度方向（score）。区别只在「用什么路径走过去」：DDPM 用方差调度的曲线，Flow Matching 用直线。这一点在第 10 章会展开。

10.2 DDIM：去掉随机性

把采样公式里的 σtz 设为零，反向过程就变成一条确定性映射：

xt−1 = √ᾱt−1 · x̂0 + √(1 − ᾱt−1) · εθ(xt, t) 其中 x̂0 = (xt − √(1−ᾱt)·εθ) / √ᾱt。对应 DDIM 的 η = 0 情形

这个改写的重要副产品是：公式只依赖 ᾱt，不要求 t 连续。于是可以只取 t 的一个子序列（如 1000 步里挑 50 个），一步跨多格，质量下降可控。这就是「用 DDPM 训的模型，用 DDIM 采样」能直接生效的原因——训练完全不用改。

10.3 CFG：一个公式控制「听不听话」

εcfg = εθ(xt, t, ∅) + w · ( εθ(xt, t, y) − εθ(xt, t, ∅) ) w = 1 时退化为普通条件采样；w 越大越贴合条件，但过大导致过饱和与多样性崩塌

代价是每步要做两次前向（一次带条件、一次不带）。这是所有现代文生图模型推理开销翻倍的原因。

10.4 Latent Diffusion：把扩散搬到潜空间

在 512×512×3 的像素空间做扩散，一次前向的计算量是 32×32 的 768 倍。Stable Diffusion 的做法与第 2 章 Wan 的动机完全一致：先用 VAE 把图像压到 64×64×4 的潜空间，扩散全程在潜空间进行，最后只解码一次。同时把 U-Net 的中间层接上 cross-attention，用文本嵌入作为 K/V——这就是「文生图」的实现方式。

10.5 与 Wan 2.1 / Flow Matching 的对应

如果你读过本地的 Wan2.1-详解.html，会发现两篇文档的骨架高度重合：都是「加噪 → 学去噪 → 反向采样」。差别集中在训练目标上：

维度DDPM（本文）Wan 2.1（Flow Matching）
训练目标预测噪声 ε预测速度 v = x1 − x0
插值路径由 β 调度决定的曲线直线 xt = (1−t)x0 + t·x1
时间采样t ~ U{1..T}t ~ logit-normal
采样步数1000（DDIM 可 50）默认 50（ODE 求解）
主干网络U-Net + 时间嵌入DiT + adaLN + 3D RoPE
数据空间像素Wan-VAE 潜空间（4×8×8 压缩）

一句话总结：DDPM 是理解这一切的地基。把本文第 3–5 章的公式换成线性插值，就得到了 Flow Matching；把 U-Net 换成 Transformer，就得到了 DiT；把像素换成 VAE 潜变量，就得到了 Stable Diffusion 与 Wan。数学换汤不换药，工程各有取舍。

11.2 结语

回看整篇论文，DDPM 的优雅之处在于它把一个生成问题翻译成了一个回归问题：不需要对抗、不需要复杂的变分近似、不需要设计解码器。前向过程是人为规定的、完全已知的；反向过程只需要学一件事——「刚才加了什么噪声」。而整个训练循环短到可以背下来：抽图、抽 t、抽噪声、加噪、算 MSE、反传。

但简单不等于浅。真正难的部分在推导里：为什么闭式解成立、为什么后验是这个形式、为什么 KL 能化成 MSE、为什么扔掉权重反而更好。这四步串起来，才让那条一行 MSE 有了理论依据。建议的下一步是：把第 8 章的代码跑起来，看到第一批数字出现；然后把 DDIM 的采样公式替换进去，观察 50 步与 1000 步的差异；最后去读 Flow Matching，体会「路径从曲线变直线」带来的效率跃迁。

本文档由 AI 辅助整理，公式依据 Denoising Diffusion Probabilistic Models（Ho et al., NeurIPS 2020）推导整理；第 8 章代码为教学目的重新实现，非官方源码，已在设计上对照论文 U-Net 逐层核对。文中噪声调度数值（ᾱt、β̃t 等）均按 T=1000、β ∈ [1e-4, 0.02] 线性调度实际计算。
