01什么是 DiT

DiT = Diffusion Transformer(扩散 Transformer)。它做的事情一句话就能讲完:把潜空间扩散模型里的 U-Net 去噪骨干网络,整个换成 Vision Transformer(ViT)——图像先经 VAE 压缩成潜向量,再切成一个个 patch 组成 token 序列,交给一摞标准 Transformer 块去预测噪声,最后拼回潜向量、解码成图像。

DiT 出自 William Peebles(UC Berkeley,实习于 Meta FAIR)与谢赛宁(NYU)2022 年 12 月的论文 Scalable Diffusion Models with Transformers,并拿下 ICCV 2023 最佳论文。它的价值不在于"又刷了一个 SOTA",而在于回答了一个基础问题:

📌 论文的核心结论 U-Net 的归纳偏置(局部卷积、多尺度下采样、跳跃连接)对扩散模型的性能并不是必需的。换成结构统一、可预测放大的纯 Transformer 之后,模型质量(FID)随前向计算量(Gflops)的增长而稳定、单调地提升——扩散模型第一次拥有了类似 LLM 的"scaling law"体验。

图像 → VAE 压成 32×32×4 潜向量 → 切 patch 成 token 序列 → N 个 Transformer 块预测噪声 → 拼回潜向量 → VAE 解码成图像。

02预备知识:读懂 DiT 需要的三块基石

DiT 不是从零发明的东西,它是三个成熟组件的组合:扩散模型(提供训练目标) + VAE(提供潜空间) + ViT(提供骨干网络)。下面三小节各用最短的篇幅把"够用"的知识补齐。

2.1 扩散模型(DDPM):加噪与去噪的博弈

扩散模型分两个过程。前向过程(固定、不需要学习):对一张干净图像 x₀,按时间步 t = 1…T 逐步叠加微小的方差表 βt 的高斯噪声;反向过程:训练一个神经网络 εθ,学会在任意噪声水平下"去掉一点噪声"。生成时,从纯噪声出发反复调用网络,一步步把图像"雕刻"出来。

前向过程有两条等价的数学描述。逐转移(单步)形式为 q(xt | xt−1) = N(√(1−βt) xt−1, βtI) ;而 DDPM 最优雅的地方在于,任意时刻的 xt 可以从 x₀ 一步采样得到:

xt = √ᾱt · x0 + √(1 − ᾱt) · ε,   ε ~ N(0, I),   ᾱt = ∏s≤t(1 − βs) 训练时不用真的一步步加噪:采样一个随机 t,直接按此式"一步到位"造出带噪样本 x_t

于是整个训练目标简单到令人发指——预测噪声的均方误差:

Lsimple = Ex₀, ε~N(0,I), t [ ‖ ε − εθ(xt, t, c) ‖2 ] c 为条件(类别标签、文本等);DiT 额外沿用 ADM 的做法,同时回归一个对角方差(learn_sigma),见 4.5 节
⚠️ 两个常被追问的点 ① 为什么预测噪声而不是直接预测干净图像?两者数学上可互相换算,但预测 ε 的回归目标分布简单(接近标准高斯)、训练更稳定,这是 DDPM 的经典结论。
② t 怎么编码进网络?不是直接把整数塞进网络,而是先做正弦嵌入再过 MLP(见 4.2 节),与 Transformer 的位置编码思路相同。

2.2 潜空间扩散(LDM):先压缩,再扩散

在原始像素上做扩散非常昂贵:一张 512×512×3 的图有约 78.6 万个数值,采样 250 步意味着网络要对这么大的张量跑 250 次以上。潜空间扩散模型(LDM,即 Stable Diffusion 的方法论)的解法是引入一个冻结的 VAE(自编码器):

  • Encoder:把图像压到低维潜空间,空间分辨率缩小 8 倍,如 256×256×3 → 32×32×4(数值量约 48 倍压缩);
  • 扩散模型只在潜空间训练与采样,去噪对象是 4 通道的潜向量,而不是 RGB 像素;
  • Decoder:生成完成后,只解码一次还原成图像。

DiT 直接复用 Stable Diffusion 的预训练 VAE(sd-vae-ft-ema,下采样系数 8,潜向量缩放系数 0.18215),整个训练过程 VAE 全程冻结、不参与梯度更新——要训练的只有 Transformer。

💡 记住这组数字 DiT 论文的"256×256 模型",实际扩散发生在 32×32×4 的潜空间;"512×512 模型"对应 64×64×4。后面讲 patch 化时,一切 token 数都从 32×32 这个网格出发。

2.3 Transformer 与 ViT:把一切变成序列

Transformer 的核心是自注意力:序列中每个 token 生成 Query、Key、Value 三个向量;用 Query 与所有 Key 的内积(缩放后过 softmax)算出"该看谁"的权重,再加权求和 Value:

Attention(Q, K, V) = softmax( QKT / √dk ) V

多头注意力把 D 维向量拆成 H 个头独立做注意力再拼接,让不同头关注不同类型的关系。标准 Transformer 块(pre-LN 风格)长这样:

x ← x + MultiHeadAttn( LN(x) )    x ← x + MLP( LN(x) ) 残差 + LayerNorm + (注意力 | 前馈网络) —— DiT 块的骨架与之完全一致

ViT(Vision Transformer) 解决了"图像怎么进 Transformer"的问题:把图像切成不重叠的 p×p 小块(patch),每块展平后线性投影成一个 token,加上位置编码,之后就是纯标准 Transformer。DiT 完整继承了这套做法——只是作用对象从图像换成了潜向量。

📌 本章结论(全文最重要的一句话) 一个 DiT 块 ≈ 一个标准 ViT 块,唯一的结构性改动是:LayerNorm 里原本自己学习的仿射参数(缩放 γ、偏移 β),改成由条件信号(时间步 t + 类别 y)通过一个小 MLP 回归生成——这就是 adaLN-Zero,第 4 章的主角。理解了这句话,DiT 就懂了 80%。

3.3 Patchify:把 32×32 的潜空间切成序列

Transformer 只吃序列,不吃网格。DiT 的第一层因此是 ViT 式的 patchify(图块化):把 I×I×4 的潜向量切成 p×p 的不重叠小块,每块展平(得到 p²·4 个数)后经一个线性层投影到模型宽度 D:

T = (I / p)2 个 token   ·   每个 token = Linear( flatten( p × p × 4 ) ) ∈ ℝD + 位置编码

对 256×256 图像(I=32)来说:patch 越小,序列越长、token 数越多,注意力能"看"得越细,但计算量也随之上升——这就是表 3-1 里"最划算的旋钮"。

4.2 输入侧:Patch 嵌入、位置编码与条件嵌入

PatchEmbed:一个卷积搞定

把每个 p×p×4 的 patch 展平后做线性投影,等价于一个 kernel_size = stride = p 的 Conv2d(4, D, p, p)——官方实现就用这个卷积,一行完成"切块 + 展平 + 投影"三件事。

2D 正弦位置编码(默认冻结)

patch 切成序列后需要告诉模型"谁在哪儿"。DiT 默认使用 ViT 的 2D 正弦-余弦位置编码(固定、不参与训练),逐元素加到每个 token 上;代码里也保留了可学习位置编码的选项。因为潜空间只有 16×16 个 patch,位置编码这件事在 DiT 里非常轻量。

两个条件各配一个嵌入器

  • 时间步 t:先做 256 维正弦嵌入(与 Transformer 位置编码同款公式,只是把"位置"换成"时间步"),再过两层 MLP 升到 D 维。这样 0~999 的整数时间步被编码成了语义平滑的向量,相邻时间步的嵌入也相近。
  • 类别 y:一个普通的 nn.Embedding(1001, D)——1000 个 ImageNet 类别 + 1 个"空标签"(为什么多一个,见 5.2 节 CFG)。

两个嵌入直接相加(不是拼接)得到条件向量 c,它会送进每一个 DiT Block 的 adaLN 调制器:

c = MLPt( sin-cos(t) ) + Emb(y)  ∈ ℝD

4.3 条件注入:四种方案与胜负

"条件怎么进入网络"是 DiT 论文最核心的消融实验。四种候选方案:

4.4 adaLN-Zero 详解(全文最重要的一节)

标准 Transformer 的 LayerNorm 自带一对可学习参数(缩放 γ、偏移 β)。adaLN 的想法是:这两个参数不自己学,而是由条件 c 通过一个小 MLP 实时"算"出来。adaLN-Zero 再进一步:每个子层(注意力、MLP)各有独立的 (γ, β, α) 共 6 组参数,其中 α 是乘在残差分支输出上的门控,其回归层初始化为全零。一个完整的 DiT Block 计算如下:

(γ1, β1, α1, γ2, β2, α2) = MLPadaLN(c) ∈ ℝ6D
x ← x + α1 ⊙ Attn( (1 + γ1) ⊙ LN(x) + β1 )
x ← x + α2 ⊙ MLP( (1 + γ2) ⊙ LN(x) + β2 ) ⊙ 为逐元素乘(广播到 token 维度);MLPadaLN = SiLU → Linear(D, 6D),每个 Block 独立一个

三个精妙的设计细节

  • 为什么是 (1 + γ) 而不是 γ?初始化时调制 MLP 输出全零,则 (1+γ)=1、β=0,LayerNorm 退化回标准行为——初始状态就是普通 Transformer,训练从熟悉的起点出发。
  • 为什么 α 零初始化如此关键?α=0 意味着初始时每个子层的贡献被"关掉",整个 DiT Block 等价于恒等映射。深网络在初始时不对输入做任何破坏,梯度通畅、优化极其稳定——这与 ResNet 的零初始化残差分支、ControlNet 的零卷积是同一思想。论文消融显示:去掉零初始化,adaLN 的优势会大幅缩水。
  • 条件每层都注入,且是"乘性 + 加性"双通道。γ 缩放特征、β 平移特征、α 决定"这一层听条件多少"——时间步与类别信息就这样深度参与到每一层的计算中。
🔮 一点前瞻adaLN-Zero 这个设计后来被整个行业继承:SD3、FLUX 全部使用 adaLN 系列条件注入(FLUX 的变体叫 adaLN-single,把 6D 调制参数只算一次、各层复用,进一步省计算)。可以说,图 4-1 这张图是当代所有 DiT 系模型的"公分母"。

4.5 输出头:FinalLayer 与 Unpatchify

最后一个 Block 的输出先经过一个"迷你版 adaLN"(只回归 2 组参数:shift、scale)加 LayerNorm,再接一个线性层,把每个 token 从 D 维投影回 p²·(2C) 维;最后按 patch 网格拼回(unpatchify)潜空间的形状 (B, 2C, 32, 32)。

为什么输出通道是 2C = 8 而不是 4?这沿用了 ADM 的 learn_sigma 设计:DiT 同时预测噪声 ε̂(前 4 通道)与对角方差 Σ̂(后 4 通道)。采样时,预测的方差用于决定每一步去噪的"步幅",让接近干净的低噪声阶段走得更保守,提升细节质量。

输出 = Linear( (1 + γf) ⊙ LN(x) + βf )  →  reshape 回 (B, 2C, 32, 32)

5.2 无分类器引导(CFG):FID 从 9.62 到 2.27 的魔法

类条件模型直接采样往往"不够听话"。CFG 的做法极其简单:同时跑一次有条件和无条件的预测,然后沿"无条件 → 有条件"的方向外推:

ε̃ = ε̂θ(xt, t, ∅) + w · ( ε̂θ(xt, t, y) − ε̂θ(xt, t, ∅) ) w=1 退化为普通条件采样;w>1 放大条件的影响,提升保真度与分类准确率,代价是多样性下降

前提是模型必须"见过"无条件情形——这正是训练时以 10% 概率把标签替换为空标签的原因(对应 LabelEmbedder 里多出来的那一行嵌入)。CFG 是 DiT 战绩里不可缺少的一半:

5.3 采样:DDIM 250 步

官方采样器为 250 步 DDIM(cfg = 1.5)。完整流程:

  1. 从纯噪声出发:xT ~ N(0, I),并给定目标类别 y;
  2. 在均匀间隔的 250 个时间步上,从 t = 999 递减到 0,每步:
    • 跑两次 DiT 得 ε̂y 与 ε̂∅,按 CFG 公式融合为 ε̃;
    • 反推干净潜向量的估计:x̂₀ = ( xt − √(1−ᾱt)·ε̃ ) / √ᾱt;
    • DDIM 确定性更新:xt−1 = √ᾱt−1·x̂₀ + √(1−ᾱt−1)·ε̃;
  3. 循环结束后得到 x̂₀,除以缩放系数 0.18215 后送入 VAE Decoder,输出 RGB 图像。
💡 为什么选 DDIM?DDIM 是确定性采样器,在 250 步内就能达到 DDPM 上千步的质量,且采样轨迹稳定、便于复现与插值。DiT 的采样代码(基于 OpenAI 的 improved-diffusion 库)一行即可切换 DDPM/DDIM。

6.2 时间步嵌入 与 6.3 类别嵌入

两个嵌入器的输出最终会相加成条件向量 c。注意 LabelEmbedder 里那个"多出来的第 1001 行"——它是 CFG 的空标签 ∅,训练时以 10% 概率被使用,采样时用来跑无条件分支:

dit_minimal.py · 1/6 条件嵌入
import math
import torch
import torch.nn as nn
import torch.nn.functional as F


class TimestepEmbedder(nn.Module):
    """把标量时间步 t(如 0~999)映射为 hidden_size 维条件向量"""

    def __init__(self, hidden_size, freq_size=256):
        super().__init__()
        self.freq_size = freq_size
        self.mlp = nn.Sequential(
            nn.Linear(freq_size, hidden_size),   # 256 -> D
            nn.SiLU(),
            nn.Linear(hidden_size, hidden_size), # D -> D
        )

    @staticmethod
    def timestep_embedding(t, dim, max_period=10000):
        # 与 Transformer 位置编码同款:不同频率的 sin/cos 组合
        half = dim // 2
        freqs = torch.exp(
            -math.log(max_period) * torch.arange(half, dtype=torch.float32) / (half - 1)
        ).to(t.device)
        args = t[:, None].float() * freqs[None]                    # (B, half)
        return torch.cat([torch.cos(args), torch.sin(args)], -1)   # (B, dim)

    def forward(self, t):
        return self.mlp(self.timestep_embedding(t, self.freq_size))


class LabelEmbedder(nn.Module):
    """类别标签嵌入;内置 10% 随机丢弃(替换为"空标签"),为 CFG 服务"""

    def __init__(self, num_classes, hidden_size, dropout_prob=0.1):
        super().__init__()
        use_cfg = dropout_prob > 0
        # 额外多一行(第 num_classes 个)= "空标签" ∅,给 CFG 的无条件分支用
        self.embedding_table = nn.Embedding(num_classes + use_cfg, hidden_size)
        self.num_classes = num_classes
        self.dropout_prob = dropout_prob

    def token_drop(self, labels, force_drop_ids=None):
        if force_drop_ids is None:
            drop = torch.rand(labels.shape[0], device=labels.device) < self.dropout_prob
        else:
            drop = force_drop_ids == 1
        return torch.where(drop, self.num_classes, labels)

    def forward(self, labels, train):
        if train and self.dropout_prob > 0:
            labels = self.token_drop(labels)     # 训练时 10% 概率换成 ∅
        return self.embedding_table(labels)      # (B, D)
💡 代码要点 ① timestep_embedding 的公式与 Transformer 正弦位置编码完全一致,只是"位置"换成了"时间步"——所以 t 不是 one-hot,而是一条平滑曲线上的点,相邻 t 的嵌入也相近;
② token_drop 只在 train=True 时生效;采样跑无条件分支时,直接把标签设为 num_classes(即 ∅ 那一行)即可。

6.4 基础组件 与 6.5 DiTBlock(对照图 4-1 逐行读)

先看三个小件:modulate 是 adaLN 的数学本体;Mlp 是标准前馈;Attention 是标准多头自注意力,没有任何魔改:

dit_minimal.py · 2/6 基础组件
def modulate(x, shift, scale):
    """adaLN 本体:x (B,N,D) 逐元素乘 (1+scale)、加 shift;
    shift / scale 形状 (B,D),通过 unsqueeze 广播到所有 token"""
    return x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)


class Mlp(nn.Module):
    """标准前馈网络:Linear -> GELU -> Linear,隐藏层 4D"""
    def __init__(self, dim, hidden):
        super().__init__()
        self.fc1 = nn.Linear(dim, hidden)
        self.act = nn.GELU(approximate="tanh")
        self.fc2 = nn.Linear(hidden, dim)

    def forward(self, x):
        return self.fc2(self.act(self.fc1(x)))


class Attention(nn.Module):
    """缩放点积多头自注意力;用 PyTorch 2.x 内置算子(自动 Flash Attention)"""
    def __init__(self, dim, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.qkv = nn.Linear(dim, dim * 3)     # 一次线性变换同时算出 Q、K、V
        self.proj = nn.Linear(dim, dim)

    def forward(self, x):
        B, N, D = x.shape                      # N 个 token,每个 D 维
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, D // self.num_heads)
        qkv = qkv.permute(2, 0, 3, 1, 4)       # (3, B, heads, N, d_head)
        q, k, v = qkv[0], qkv[1], qkv[2]
        x = F.scaled_dot_product_attention(q, k, v)   # softmax(QK^T/√d)V
        x = x.transpose(1, 2).reshape(B, N, D)
        return self.proj(x)

然后是全文的主角 DiTBlock。对照图 4-1:构造函数里那两行 elementwise_affine=False 的 LayerNorm,加上末尾 15 行的 SiLU + Linear(D, 6D),就是 DiT 与普通 ViT 块的全部区别:

dit_minimal.py · 3/6 DiTBlock(adaLN-Zero)★
class DiTBlock(nn.Module):
    """DiT 块:adaLN-Zero 条件注入(论文最终方案)"""

    def __init__(self, dim, num_heads, mlp_ratio=4.0):
        super().__init__()
        # LayerNorm 关掉自身可学习的仿射参数,交给 adaLN 从条件 c 回归
        self.norm1 = nn.LayerNorm(dim, elementwise_affine=False)
        self.attn = Attention(dim, num_heads)
        self.norm2 = nn.LayerNorm(dim, elementwise_affine=False)
        self.mlp = Mlp(dim, int(dim * mlp_ratio))
        # 调制 MLP:条件 c -> 6 组参数 (shift, scale, gate) x 2
        self.adaLN_modulation = nn.Sequential(
            nn.SiLU(),
            nn.Linear(dim, 6 * dim),
        )

    def forward(self, x, c):
        # c = t_emb + y_emb,形状 (B, D)
        shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp = \
            self.adaLN_modulation(c).chunk(6, dim=-1)

        # --- 子层 1:调制 LN -> 自注意力 -> 门控 -> 残差相加 ---
        x = x + gate_msa.unsqueeze(1) * self.attn(
            modulate(self.norm1(x), shift_msa, scale_msa))

        # --- 子层 2:调制 LN -> MLP -> 门控 -> 残差相加 ---
        x = x + gate_mlp.unsqueeze(1) * self.mlp(
            modulate(self.norm2(x), shift_mlp, scale_mlp))
        return x
📌 与公式的对应关系 modulate(norm1(x), shift, scale) 就是 (1+γ₁) ⊙ LN(x) + β₁;
gate_msa.unsqueeze(1) * attn(...) 就是 α₁ ⊙ Attn(...);
两个子层的结构逐字符对称——MLP 子层只是把 attn 换成 mlp、参数下标换成 2。注意:参数是逐通道(维度级)的,即 α₁、γ₁、β₁ 都是 D 维向量而非标量,条件可以精细控制每一个特征通道。

6.6 输出头、输入头与位置编码

FinalLayer 是一个"迷你版 DiTBlock":只保留一次调制 LN + 一次线性投影,没有门控 α 和残差(它不再需要)。线性层的输出维度是 p² × 2C——每个 token 负责还原自己那个 patch 里所有像素通道;PatchEmbed 则用 kernel = stride = patch_size 的一个卷积,把"切块 + 线性投影"两步合成一步:

dit_minimal.py · 4/8 输入/输出头与位置编码
class FinalLayer(nn.Module):
    """输出头:调制 LN + Linear(D -> p*p*out_chans),无残差无门控"""

    def __init__(self, dim, patch_size, out_chans):
        super().__init__()
        self.norm_final = nn.LayerNorm(dim, elementwise_affine=False)
        self.linear = nn.Linear(dim, patch_size * patch_size * out_chans)
        self.adaLN_modulation = nn.Sequential(
            nn.SiLU(),
            nn.Linear(dim, 2 * dim),       # 只需 shift、scale 两组参数
        )

    def forward(self, x, c):
        shift, scale = self.adaLN_modulation(c).chunk(2, dim=-1)
        x = modulate(self.norm_final(x), shift, scale)
        return self.linear(x)               # (B, N, p*p*out_chans)


class PatchEmbed(nn.Module):
    """输入头:Conv2d(k=p, s=p) 一步完成"切块 + 每块线性投影" """

    def __init__(self, img_size=32, patch_size=2, in_chans=4, dim=1152):
        super().__init__()
        self.num_patches = (img_size // patch_size) ** 2    # 32/2 -> 16*16=256
        # 卷积核不重叠地扫过图像,等价于:每个 p×p 潜像素块
        # 展平成 p*p*in_chans 维向量后过一个共享 Linear
        self.proj = nn.Conv2d(in_chans, dim,
                              kernel_size=patch_size, stride=patch_size)

    def forward(self, x):                    # x: (B, 4, 32, 32)
        x = self.proj(x)                     # (B, D, 16, 16)
        return x.flatten(2).transpose(1, 2)  # (B, 256, D)


def get_1d_sincos_pos_embed(embed_dim, pos):
    """1D 正弦位置编码(与 Transformer 原版同一公式)"""
    omega = np.arange(embed_dim // 2, dtype=np.float64)
    omega /= embed_dim / 2.0
    omega = 1.0 / 10000 ** omega             # 频率从 1 到 1/10000
    out = np.outer(pos.reshape(-1), omega)   # (M, D/2) 弧度
    return np.concatenate([np.sin(out), np.cos(out)], axis=1)  # (M, D)


def get_2d_sincos_pos_embed(embed_dim, grid_size):
    """2D 版:行坐标、列坐标各用一半维度编码,再拼接"""
    grid = np.meshgrid(np.arange(grid_size, dtype=np.float32),   # 行
                       np.arange(grid_size, dtype=np.float32))   # 列
    grid = np.stack(grid, axis=0)            # (2, g, g)
    emb_h = get_1d_sincos_pos_embed(embed_dim // 2, grid[0].flatten())
    emb_w = get_1d_sincos_pos_embed(embed_dim // 2, grid[1].flatten())
    return np.concatenate([emb_h, emb_w], axis=1)   # (g*g, D)
💡 代码要点 ① 位置编码是 2D sincos 且默认冻结(论文中"learnable"为可选项):register_buffer(persistent=False) 表示它不参与梯度更新、也不存进 checkpoint;
② 二维坐标拆成"行 + 列"两个一维编码,各占一半维度——这样每个 token 的位置编码同时知道自己在第几行、第几列;
③ FinalLayer 输出 p²×2C:如果 learn_sigma=True,网络同时预测每个像素的噪声 ε 和方差 Σ(交错模型),采样时用 Σ 给 DDIM 加随机性。

6.7 DiT 主模型:组装与零初始化

主模型把所有零件串起来。重点看 forward 的四步流程和 initialize_weights 里那段置零初始化——它就是"adaLN-Zero"名字里 Zero 的落点:

dit_minimal.py · 5/8 DiT 主模型
class DiT(nn.Module):
    """DiT 主模型:Patchify -> 加位置 -> [DiTBlock] x depth -> FinalLayer"""

    def __init__(self, img_size=32, patch_size=2, in_chans=4,
                 dim=1152, depth=28, num_heads=16,
                 num_classes=1000, learn_sigma=True):
        super().__init__()
        self.learn_sigma = learn_sigma
        self.num_classes = num_classes
        self.patch_size = patch_size
        self.in_chans = in_chans
        # learn_sigma: 输出通道翻倍(前半 ε,后半 Σ)
        out_chans = in_chans * 2 if learn_sigma else in_chans

        # (1) 输入:Patchify + 冻结的 2D sincos 位置编码
        self.x_embedder = PatchEmbed(img_size, patch_size, in_chans, dim)
        pos = torch.tensor(get_2d_sincos_pos_embed(
            dim, img_size // patch_size), dtype=torch.float32)
        self.register_buffer("pos_embed", pos.unsqueeze(0), persistent=False)

        # (2) 条件:t 与 y 两条嵌入支路
        self.t_embedder = TimestepEmbedder(dim)
        self.y_embedder = LabelEmbedder(num_classes, dim)

        # (3) 主体:depth 个 DiTBlock 堆叠
        self.blocks = nn.ModuleList(
            [DiTBlock(dim, num_heads) for _ in range(depth)])

        # (4) 输出:FinalLayer + 零初始化
        self.final_layer = FinalLayer(dim, patch_size, out_chans)
        self.initialize_weights()

    def unpatchify(self, x):
        """(B, N, p*p*out_chans) -> (B, out_chans, H, W)"""
        c = self.in_chans * 2 if self.learn_sigma else self.in_chans
        p, N = self.patch_size, x.shape[1]
        h = w = int(N ** 0.5)                 # 256 个 token 排回 16x16 网格
        assert h * w == N
        x = x.reshape(x.shape[0], h, w, p, p, c)
        x = torch.einsum("nhwpqc->nchpwq", x)   # 通道换到最前
        return x.reshape(x.shape[0], c, h * p, w * p)

    def forward(self, x, t, y):
        """x: (B,4,32,32) 噪声潜图 / t: (B,) 时间步 / y: (B,) 类别标签"""
        x = self.x_embedder(x) + self.pos_embed    # (B, N, D) + 位置
        c = self.t_embedder(t) + self.y_embedder(y, self.training)  # (B, D)
        for block in self.blocks:
            x = block(x, c)                         # (B, N, D)
        x = self.final_layer(x, c)                  # (B, N, p*p*2C)
        return self.unpatchify(x)                   # (B, 2C, 32, 32)

    def initialize_weights(self):
        # ViT 式默认:所有 Linear 用 Xavier 均匀初始化、偏置置零
        def _basic_init(m):
            if isinstance(m, nn.Linear):
                nn.init.xavier_uniform_(m.weight)
                if m.bias is not None:
                    nn.init.constant_(m.bias, 0)
        self.apply(_basic_init)

        # Patchify 卷积:std=0.02 正态(把卷积权重摊平成矩阵看待)
        w = self.x_embedder.proj.weight.data
        nn.init.normal_(w.view(w.shape[0], -1), std=0.02)

        # ★ adaLN-Zero 灵魂所在:所有调制层、输出层全部置零
        #   -> 每个 block 初始都是恒等映射,网络初始输出 0
        for block in self.blocks:
            nn.init.constant_(block.adaLN_modulation[-1].weight, 0)
            nn.init.constant_(block.adaLN_modulation[-1].bias, 0)
        nn.init.constant_(self.final_layer.adaLN_modulation[-1].weight, 0)
        nn.init.constant_(self.final_layer.adaLN_modulation[-1].bias, 0)
        nn.init.constant_(self.final_layer.linear.weight, 0)
        nn.init.constant_(self.final_layer.linear.bias, 0)

📌 为什么要全部置零? adaLN 的调制参数和门控 α 初始为 0 时,每个 block 的前向退化为 x = x + 0×(...) = x——一个 28 层的巨型网络在初始时刻等价于恒等函数,梯度可以毫无阻碍地穿过所有层直达到输入端(与 ResNet 论文"零初始化 BN-γ"同一思想)。配合输出层置零(初始预测 ε=0),整条训练曲线从最温和的起点出发。论文消融显示:去掉零初始化,大 DiT 的损失会明显变差。
💡 unpatchify 的 einsum token 序列先 reshape 回 (B, h, w, p, p, c) 的六维布局(哪个 token 在网格哪个格子、格子里哪行哪列的像素),再用 "nhwpqc->nchpwq" 一步完成"像素移到最后一层、通道提到最前"的重排,最后 flatten 回图像。这就是 Patchify 的精确逆操作。

6.9 极简扩散与训练损失

扩散过程本身不需要任何可学习参数——只是预先算好一串调度系数。q_sample 把第 2 章的前向加噪公式一行写完,training_loss 则是 DiT 的训练目标"预测加进来的噪声 ε":

dit_minimal.py · 6/8 扩散过程与训练损失
class SimpleDiffusion:
    """扩散调度表:预计算 β_t / ᾱ_t,零可学习参数"""

    def __init__(self, T=1000, beta_start=1e-4, beta_end=0.02, device="cuda"):
        self.T = T
        # 线性调度:β 从 1e-4 均匀升到 0.02(DDPM 原版设定)
        self.betas = torch.linspace(beta_start, beta_end, T, device=device)
        self.ac = torch.cumprod(1.0 - self.betas, axis=0)   # ᾱ_t 累乘
        self.device = device

    def q_sample(self, x0, t, noise):
        """前向加噪一步到位:x_t = √ᾱ_t · x0 + √(1-ᾱ_t) · ε"""
        ac_t = self.ac[t].view(-1, 1, 1, 1)          # (B,1,1,1) 便于广播
        return ac_t.sqrt() * x0 + (1 - ac_t).sqrt() * noise

    def training_loss(self, model, x0, y):
        """DiT 训练目标:预测加进来的噪声 ε(L_simple)"""
        t = torch.randint(0, self.T, (x0.shape[0],), device=self.device)
        noise = torch.randn_like(x0)
        x_t = self.q_sample(x0, t, noise)            # 随机加噪

        out = model(x_t, t, y)                       # (B, 2C, 32, 32)
        if model.learn_sigma:                        # learn_sigma:后一半是 Σ,丢掉
            out, _ = out.chunk(2, dim=1)
        return F.mse_loss(out, noise)                # 只监督前一半 ε

6.10 DDIM 采样 + 无分类器引导

采样循环把第 5 章的两张图变成代码:250 步 DDIM 从 t=999 倒着走到 0,每步对模型做两次前向(有条件 / 无条件 ∅),再按 CFG 公式外推:

dit_minimal.py · 7/8 DDIM + CFG 采样
@torch.no_grad()
def ddim_sample(model, diff, y, n_samples=16, steps=250,
                cfg_scale=1.5, img_size=32, device="cuda"):
    """DDIM 采样(eta=0,确定性)+ CFG;y: 想要的类别标签"""
    # 250 个时间步:从 T-1 均匀倒序取到 0
    ts = torch.linspace(diff.T - 1, 0, steps).long().to(device)
    # 无条件标签 ∅ = num_classes(嵌入表里多出来的那一行)
    y_null = torch.full_like(y, model.num_classes)

    x = torch.randn(n_samples, model.in_chans, img_size, img_size,
                    device=device)                    # 纯高斯噪声起步

    for i, t in enumerate(ts):
        tb = t.repeat(n_samples)
        # 每步两次前向:有条件 / 无条件(训练时 10% 标签丢弃为此服务)
        eps_c, _ = model(x, tb, y).chunk(2, dim=1)
        eps_u, _ = model(x, tb, y_null).chunk(2, dim=1)
        eps = eps_u + cfg_scale * (eps_c - eps_u)    # ★ CFG 外推公式

        # DDIM 跳转:x0 = (x_t - √(1-ᾱ_t)·ε) / √ᾱ_t
        ac_t = diff.ac[tb].view(-1, 1, 1, 1)
        x0 = ((x - (1 - ac_t).sqrt() * eps) / ac_t.sqrt()).clamp(-1, 1)

        if i == len(ts) - 1:                          # 最后一步直接给 x0
            return x0
        ac_p = diff.ac[ts[i + 1]].view(-1, 1, 1, 1)  # 上一个时间步的 ᾱ
        x = ac_p.sqrt() * x0 + (1 - ac_p).sqrt() * eps   # 回到 t-1
    return x0
💡 代码要点 ① eps_c - eps_u 就是"条件指向的方向",cfg_scale 沿着它放大——这正是表 5-2 里 1.25→1.5→2.0 时 FID 从 3.22 → 2.27 → 变差的来源:推力越大越忠实类别,但多样性坍缩;
② DDIM 取 eta=0 时整条采样轨迹是确定性的:固定初始噪声 → 固定输出,这也是它能从 1000 步压到 250 步的原因;
③ clamp(-1, 1) 只是对 x0 估计的常规裁剪,防止极端步漂移。

DiT 论文的真正价值不是刷新 ImageNet 分数,而是回答了工业界最关心的问题:"扩散模型的骨干换成标准 Transformer 后,还能继续靠堆规模变强吗?"答案是一个干净的 yes。此后两年,几乎所有主流生成模型都完成了从 U-Net 到 DiT 的迁移,并沿着三个方向持续升级——条件注入、训练目标、位置编码:

2024.01

7.1 PixArt-α:把类别标签换成自然语言(2023.10)

DiT 的条件只有 1000 个类别,离"文生图"还差一步。PixArt-α 在 DiT 骨干上做了三件事:

  • 接入文本:用冻结的 T5-XXL(4.3B)把提示词编码成 token 序列,经交叉注意力注入——正是表 4-2 里的方案 (c):adaLN 继续负责时间步,文本单独走一条注意力旁路;
  • 分解式训练:先沿用 ImageNet 类条件预训练学"像素依赖",再在 SAM 大规模图文数据上学"图文对齐",最后用 LLaVA 生成的密集长标注学"概念组合"——每一步都站在上一步的权重上;
  • 极致省钱:0.6B 参数达到可商用画质,论文称 256×256 模型训练成本约 101 美元,只有同代模型的百分之几。

"DiT + 文本旁路"从此成为文生图的性价比路线,PixArt 系列(α / Σ / 8K)也是国内开源生态的重要起点。

7.2 SiT 与流匹配:换一个训练目标(2024.01)

同期出现的 SiT(Scalable Interpolant Transformers,与 DiT 出自同一实验室)证明了一个反直觉的事实:骨干完全不动,只换训练目标,同样算力下 FID 就能一路走低。SiT 把 DDPM 的 ε-预测放进更一般的"随机插值"框架里统一描述,发现更优的插值路径存在。这条路线与 Flow Matching(Lipman 等)、Rectified Flow(Liu 等)一脉相承:不再逐步预测噪声,而是学习一个速度场,把噪声到数据的路径尽量拉直——路径越直,采样步数越少。此后 SD3、FLUX、混元视频、Wan 全部采用流匹配系目标,DDPM 时代的"1000 步"彻底成为历史。

7.3 MM-DiT:文本不再是旁路,而是同桌(2024.06)★

PixArt 的文本走交叉注意力旁路,但 SD3 论文(Stable Diffusion 3)提出了更强的观点:文本条件本身就是一个几百 token 的序列,凭什么要压缩成一个向量再"旁听"?MM-DiT(Multimodal DiT)为此把 DiT 块拆成两条并行的流,每条流有自己独立的 LayerNorm、Q/K/V 投影和 MLP 权重,但在注意力处拼接 K、V 联合计算:

SD3 的完整配方是:MM-DiT 块 × 多层 + Rectified Flow 目标(logit-normal 时间步加权)+ RoPE 位置编码 + T5-XXL 与双 CLIP 三个文本塔。其中 RoPE 替换 sincos,让任意分辨率、任意长宽比的输入即插即用——这正是视频模型的前提。同一篇论文把这套结构从 2B 一路堆到 8B,FID 持续下降,DiT 式的 scaling law 在文生图上再次应验。

🔮 FLUX.1:MM-DiT 的工程化(2024.08) Black Forest Labs(SD 原班人马)的 FLUX.1(12B)把 MM-DiT 推向实用:前段 双流块 × 38(文本/图像分离)+ 后段 单流块 × 18(两流合并再深化处理);调制升级为 adaLN-single(6D 调制参数只在第一层算一次,各层加可学习偏移直接复用,大幅省算力);并用引导蒸馏把 CFG 强度变成一个标量输入——采样不再需要"有条件 + 无条件"两次前向,速度翻倍。

7.4 视频 DiT:Sora 与开源追随者(2024 →)

在 DiT 的视角里,视频不过是"多了一根时间轴的潜码序列"。Sora 的技术报告披露了三个关键选择,每一条都踩在 DiT 的肩膀上:

  • 时空 patch(spacetime patches):先用视频压缩网络(类 3D VAE)把视频压成时空潜码,再切成"时间 × 空间"的 patch——第 3 章的 Patchify 直接多了一维;
  • 原生多分辨率训练:时长、分辨率、长宽比都不固定,靠 RoPE 兜底任意尺寸——这解释了 7.3 节为什么必须换掉 sincos;
  • 图像与视频统一训练:一个骨干同时吃静态图和视频,生成能力互相迁移。

开源生态随即跟上:Latte 系统对比了"空间/时间注意力分解"与"全 3D 注意力"的四种组合;OpenSora 完整复现了这条路线;腾讯混元视频(13B)采用类 FLUX 的"双流→单流"结构 + 3D 因果 VAE;阿里 Wan 2.1 开源了 1.3B/14B 文生视频与图生视频全家桶;Qwen-Image 则把 MMDiT 路线带回图像。今天,"视频生成模型"几乎就是"视频 DiT"的同义词。

08总结 · FAQ · 学习路线

8.1 五句话带走全文

  1. DiT = LDM 潜空间 + ViT 骨干 + adaLN-Zero 条件注入:它证明了 U-Net 的卷积归纳偏置对扩散模型并非必需,标准 Transformer 骨干反而 scaling 行为更干净、更可预测。
  2. patch 大小 p 是"质量 vs 算力"的主旋钮:token 数 T = (H/p)²,参数量不变、计算量随 T 走高;论文最终选择最"贵"也最好的 p=2(DiT-XL/2)。
  3. adaLN-Zero 是 DiT 相对普通 ViT 的唯一关键改动:6D 调制参数 + 门控 + 零初始化——这个三件套后来被 SD3、FLUX 全盘继承,成了行业标配。
  4. Gflops 与 FID 强相关:堆宽、堆深、减 patch、延长训练全部落在同一条 scaling 曲线上——Transformer 十年攒下的并行与加速基建可以直接平移到生成模型。
  5. 当代生成模型几乎都是 DiT 的直系后代:PixArt(文本旁路)→ MM-DiT(双流同桌)→ 视频 DiT(Sora / 混元 / Wan);变的只是条件注入、训练目标与位置编码三根轴。

8.2 FAQ

DiT 和 Stable Diffusion 是什么关系?
Stable Diffusion 1.x / 2.x 的骨干是 U-Net;从 SD3 开始,骨干换成 DiT 系(MM-DiT)。但 DiT 论文本身只做 ImageNet 类条件生成、不接收文本提示词——"听懂文字"是 PixArt-α 之后的改进。
U-Net 的卷积归纳偏置为什么"不香了"?
卷积的局部性与平移等变是好东西,但在足够大的模型与数据规模下,全注意力能自己学出来,而且 scaling 更可预测(Gflops 与 FID 强相关)、更容易吃到 FlashAttention / 序列并行等 Transformer 基建红利。小模型小数据下 U-Net 仍可能占优——DiT 回答的是"规模化之后谁更强"。
patch 越小越好,那 p=1 行不行?
理论上可以(p=1 时 32×32 潜空间变成 1024 个 token)。论文试过 /1 到 /8:/1 计算量再涨数倍、收益递减,/8 则序列太短、模型连"哪里该有什么"都表达不了;p=2 是质量与算力的甜点。SD3/FLUX 等在更高分辨率潜空间上同样常用 2×2 patch,再靠 RoPE 吃任意长宽比。
adaLN-Zero 和交叉注意力,只能二选一吗?
不冲突,它们注入的是不同"粒度"的条件:adaLN 注入全局量级的信息(时间步、类别、全局风格——每个 token 拿到同一份调制参数),交叉注意力/MM-DiT 注入序列级的信息(几百个文本 token、逐 token 对齐)。PixArt-α 两者都用;SD3 把序列条件升级为双流联合注意力。大模型的共识是:全局条件走 adaLN,序列条件走注意力。
我没有 8 卡 A100,能玩 DiT 吗?
可以。推理:diffusers 的 DiTPipeline 加载官方 DiT-XL/2 权重,单卡(f16 下十几 GB 显存)即可按类别生成 256×256 图像;训练:本文 dit_minimal.py 的 DiT-S/4 在单张消费级显卡上跑几个小时,就能在小数据集上看到雏形——麻雀虽小,五脏俱全。
DiT / SiT / U-ViT / MDT / MM-DiT 都是什么关系?
都是"把 Transformer 用进扩散模型"的家族成员:U-ViT 把 U-Net 式跳连装进 ViT;DiT(本文)用纯 ViT 替换骨干;SiT 换训练目标(随机插值);MDT 加掩码生成式训练,更快更准;MM-DiT 是 SD3 的双流变体。名字看花眼,块结构都是图 4-1 的那三件套。
