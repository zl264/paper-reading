# Paper Reading · 论文精读

公开站点：<https://zl264.github.io/paper-reading/>

## 站点结构

- `index.html`：研究方向分类目录与全站论文搜索。
- `categories/`：各研究方向的独立分类页。
- `camera-pose/`：显式相机位姿可控视频生成专题，含 12 篇独立解读、综合导读与分类综述。
- 根目录其他 HTML：已有论文精读与原论文阅读页，保持原文件路径不变。
