01论文速览

一分钟版本：GAD 是一个「只影响训练、不改推理」的注意力蒸馏框架——把几何基础模型 VGGT-Ω 注意力中的跨帧对应关系，蒸馏进视频扩散模型的注意力里，让模型在长镜头与动态场景中都保持几何一致。

TL;DR

视频扩散模型（Wan 等）生成的短视频很漂亮，但跨帧无法可靠地"认出"同一个场景元素——注意力的响应常常散落在多个区域，即使画面结构已经清晰。GAD 的做法：在训练时用冻结的几何模型 VGGT-Ω 的注意力提取"哪个 token 对应哪一帧的哪个 token"，以带置信度权重的软目标去监督视频模型自己的注意力；由于场景结构在高噪声时于深层形成、低噪声时于浅层形成，蒸馏层随噪声时间步动态路由（L5 / L15 / L25）。训完后推理流程零改动、零额外开销，而跨帧匹配准确率在两个长程基准上至少提升 30%。

1.1 要解决什么问题

视频扩散模型在长时间范围内保持场景几何（视角变化后墙面还直不直、窗户还在不在原处）和运动中保持物体结构（人物转身后帽子还是那顶帽子、四肢不融化和消失）上表现很差。这两类一致性是交互式世界模型、机器人规划、自动驾驶仿真等下游应用的前提——它们要求生成的视频是一个"时间上连贯的环境"，而不是一堆漂亮的单帧。

1.2 核心思路

  • 诊断：对 Wan2.2 5B 的（层 × 去噪时间步）网格做"目标帧特征 PCA + 源查询注意力读出"的联合分析，发现 (a) 注意力即使到结构已清晰时仍然分散；(b) 场景结构形成的"深度"随噪声水平移动——高噪声在深层、低噪声在浅层。
  • 药方：从一个"天生擅长多视角匹配"的几何基础模型（VGGT-Ω）里拿对应关系当监督信号——不是对齐特征、不是投影点云，而是直接监督注意力的对应关系。
  • 三个工程要点：① 教师注意力要"按全部输入帧联合归一化"，这样每个目标帧分到的总注意力质量（attention mass）就能当可靠性权重——被遮挡/出画的对应，质量极低，权重趋零；② 蒸馏层按噪声时间步路由到"结构正在形成"的那一层；③ 成对（pairwise）+ 轨迹（trackwise）两种互补的采样监督，前者管帧内空间判别，后者管跨时间覆盖。

02背景与动机

一致性不是新问题，但以往的方案都在"给模型喂几何信息"上做文章；GAD 指出真正的缺口在"模型自己会不会建立跨帧关联"。

2.1 一致性为什么难

视频扩散模型（如 Wan）以 DiT 为主干，对整段视频的全部 latent token 做全局自注意力。理论上，第 40 帧某个墙面 token 的 query 可以去 attend 第 1 帧同一面墙的 key——这正是"信息跨帧交换"的通道。但注意力是靠数据隐式学出来的：没有任何机制保证 query 会落在"几何上对应"的 key 上。实践中它经常被外观相似（同色墙面、重复纹理）或语义相似（"窗户" attend 到别的窗户）的区域吸引，导致：

  • 几何漂移：镜头推拉后，场景布局逐渐走样——门框倾斜、地板弯曲；
  • 结构退化与物体消失：物体运动或遮挡后重新出现时结构崩坏，甚至凭空消失；
  • 时间越长、视角变化越大，误差累积越严重。

2.3 GAD 的切入角度

与其继续"喂几何"，不如直接监督注意力本身建立正确的对应。这需要回答三个子问题，正好对应方法三组件：

  1. 谁来当老师？——几何基础模型（VGGT-Ω）的注意力天然编码了跨视角/跨时间的对应，且对静态表面与运动物体都有效（第 4.2 节）；但老师的输出也有不可靠的时候，需要置信度过滤（第 6 章）。
  2. 在哪一层教？——结构形成区随噪声移动，蒸馏层必须跟着噪声时间步路由（第 7 章）。
  3. 怎么教？——不是让学生复现老师的完整注意力分布（那会过度约束），而是只教"对应位置应该被匹配到"，用带置信度权重的软目标 + 成对/轨迹两种监督（第 8 章）。
一句话对比

特征对齐类方法（GF、Gen3R）说"你的特征要长得像几何模型的特征"；GAD 说"你的注意力要指对地方，特征随你怎么长"。对应关系被迁移，表示自由度被保留——这是它不伤生成质量（FID/FVD 反而更好）的关键。

03预备知识

四块地基：Wan 的流匹配视频 DiT、多头注意力、几何基础模型 VGGT-Ω、注意力蒸馏。熟悉读者可跳到第 4 章。

3.1 Wan 视频扩散模型：DiT + 流匹配

Wan2.1/2.2 把视频压进 latent 空间后，用 Diffusion Transformer（DiT）去噪。主干组件：3D RoPE（时间 + 空间旋转位置编码）、adaLN（时间步等条件注入 LayerNorm）、以及最重要的——全部帧 token 拼在一起做全局自注意力。GAD 训练的三个底座规格：

训练目标是流匹配（Flow Matching）。记干净 latent 为 z₀，噪声 ε ∼ 𝒩(0, I)，插值系数 s = t/1000 ∈ [0,1]（t ∈ [0,1000] 为模型噪声时间步，越大越噪）：

zt = (1 − s)·z₀ + s·ε，    vθ(zt, t, 𝐜) ≈ ε − z₀ （关于 s 的速度）

模型学的是"从噪声指向数据"的速度场；推理时沿它积分即可还原 z₀。GAD 完整保留该目标（论文 Eq.11，见第 9 章），只在其上叠加注意力蒸馏损失。条件 𝐜 在本文场景中为首帧图像 + 文本 + 目标相机轨迹（相机可控生成）。

3.2 多头注意力：Q、K 与"跨帧关联"在哪产生

某层 ℓ 某头 h 中，token 序列经归一化与 RoPE 后得到 query 𝐪 与 key 𝐤，注意力权重为 softmax(⟨𝐪, 𝐤⟩/√d)。视频 DiT 里 token 按 (帧, 空间位置) 排布，因此帧 i 的空间 token u（记 a=(i,u)）对帧 j 的空间 token v 的注意力分数，就是最原生的"跨帧关联"度量。GAD 的蒸馏不改注意力计算本身，而是让学生在"匹配分布"上与教师对应看齐——学生用的原始材料，正是每头的 ⟨𝐪, 𝐤⟩/√d 分数（Eq.10，第 8 章）。

3.3 几何基础模型：VGGT 与 VGGT-Ω

VGGT 系列是"前馈式几何重建"模型：一次前向同时输出多视角的相机参数、深度图、点图（pointmap）与 2D 轨迹。架构上，图像 patch 化后进入 Transformer，其中全局注意力层（global attention）让所有帧的 patch token 互相看——为了做好重建，这些注意力头必须学会"跨视角找同一块表面/同一个物体部位"。这正是 GAD 想借的先验。

本文用的教师是 VGGT-Ω 1B 的 512 分辨率检查点（facebookresearch/vggt-omega）。论文对其探测后发现一个重要现象：不同头有明显分工——层 13 头 0 只擅长静态 token；层 12 头 12 只擅长动态 token；而层 13 头 10 两者兼顾，最终被选为唯一的标签提取头（零起点编号，详见第 6.4 节）。

3.4 注意力蒸馏与最相近的先行者 CAMEO

知识蒸馏不只能对齐特征，也能对齐注意力图或 token 间关系（relational KD）。在扩散模型里已有特征对齐、token 关系蒸馏等做法。与 GAD 最接近的是 CAMEO：它用静态 3D 点图导出的对应关系去监督一个固定注意力层，改善新视角合成。GAD 与它的三点本质区别：

"用深度 + 相机把源像素反投影到 3D、再投到目标视角"是构造对应标签的经典做法（CAMEO 即如此），但它假设静态场景，运动物体上完全失效；在细结构与邻近表面处，深度误差与 token 离散化还会把不同表面对到一起。论文用这种标签做"选头评估"（第 6.4 节）尚可，做训练标签则不行——而直接读 VGGT-Ω 的注意力，相当于利用模型学到的跨视角一致性，绕开了静态假设。

04关键观察：注意力里的几何歧义

方法的一切设计都能追溯到两个实验观察：① 视频注意力认不出对应点；② 结构形成的深度随噪声移动。本章复现论文第 3 节的分析逻辑。

4.1 实验设计：PCA × 注意力的联合网格

论文用 Wan2.2 5B 在 RealEstate10K 上生成 81 帧、832×480 的视频（50 步采样、CFG=5、shift=5、seed=0），沿完整去噪轨迹收集两类可视化：

  • 目标帧特征 PCA：每个 (层, 去噪步) 组合，取目标帧（latent 帧 10）的 block 输出特征，把空间 token 投影到前 3 个主成分显示成 RGB——它回答"这一层这一步，模型内部是否已经长出可辨认的场景结构"。
  • 注意力读出：固定源查询（首 latent 帧的 (x,y)=(14,8)，26×15 网格），每头的点积分数在全部视频 key 上做 softmax，截取目标帧切片后对头取平均——它回答"这个查询在目标帧里看哪儿"。

两个可视化沿 (层 1–30 × 去噪时间步 1000→0) 排成网格，就得到论文 Fig. 2(a) 的全景图。

4.2 三个区域：结构形成的"移动带"

图 4-1（对应论文 Fig. 2(a) 概念重绘）：横轴为去噪时间步、纵轴为 DiT 层深。红色斜带即"结构形成区"——高噪声时出现在深层，低噪声时出现在浅层。GAD 的蒸馏层沿这条带路由：t≥950 用 L25、850≤t<950 用 L15、t<850 用 L5，始终贴着"结构正在形成"的位置施加对应监督（路由配置见第 7 章）。

网格分析揭示了三个定性区域：

  • 噪声主导区（左上灰区）：PCA 特征里几乎看不出场景结构，注意力响应散落一地——没有结构基础，监督无从谈起。
  • 结构形成区（红带）：可辨认的场景结构开始出现，注意力也开始响应跨帧的对应区域，但竞争响应仍然很多。这是"有结构基础、关联尚未定型"的中间窗口——也是蒸馏最有价值的窗口。
  • 结构建立区（右下绿区）：布局已经清晰，跨帧关联看起来"成立"，但未必几何正确——此时再加指导，能改变的已经不多。
第一个关键观察（歧义性）

即使在结构建立区——PCA 特征已经能看清房间布局——注意力响应依然可能散布在多个区域（相似外观或相似语义的地方）。也就是说："画面成形"≠"注意力找到了对应点"。歧义的关联会把无关区域的信息混进来，正是几何漂移与结构退化的微观机制。

第二个关键观察（深度随噪声移动）

结构形成区的位置不是固定的：高噪声时在深层形成，低噪声时在浅层形成。若把蒸馏钉死在一层（如 CAMEO），那么它只对某个噪声区间"踩在点上"，其余区间要么太早（噪声主导区）要么太晚（结构建立区）。这直接推出 GAD 的核心机制——按噪声时间步路由监督层。

4.3 几何基础模型的注意力：现成的"对应老师"

对 VGGT-Ω 做同样探测（固定首帧查询、观察后续帧响应）：静态例子里，选定头的注意力始终聚焦在同一根栏杆上，跨视角变化不漂移；动态例子里，注意力跟着运动人物头顶的帽子走。说明几何模型的注意力头确实编码了"同一场景元素"的跨帧关联——静态表面与运动物体部位通吃。

但老师也有不可靠的时候：当源 token 代表的内容在目标视角被遮挡或根本不在画面里时，注意力图仍可能出现一个清晰的峰（比如 attend 到外观相似的别处）。单看峰值位置会被骗——这催生了 GAD 的置信度设计：

目标帧注意力质量（target-frame attention mass）

教师注意力是在全部输入帧的全部 token（含特殊 token）上联合归一化的。于是"落到某个目标帧空间 patch token 上的总注意力"就是一个有意义的量：内容可见时质量高，被遮挡/出画时质量极低。峰的位置告诉你"匹配在哪"，质量告诉你"这个匹配可不可信"。（Eq.1 与 Eq.9，第 6 章。）

5.2 三条设计原则

  1. 只教关系，不锁表示：监督对象是"注意力的匹配分布"，而不是中间特征本身——学生特征可以自由演化，只要对应位置被正确关联。这保住了生成质量（实验中 FID/FVD 还变好了）。
  2. 置信度优先：老师的每个对应都带可靠性权重，不可靠的（遮挡、出画、低质量）自动降权甚至置零，避免"错教"。
  3. 训练即插即用、推理零改动：所有附加结构（教师、缓存、门控 MLP）训完即弃，部署侧与原模型完全一致。

06组件一：置信度感知的教师对应

"老师给的每个对应，都要附带一个可信度。"本章覆盖论文 4.1 节与附录 B.1：从 VGGT-Ω 注意力到 (c, m, w, y) 四元组的完整流水线。

6.1 提取：读哪一层哪一头，怎么归一化

教师是冻结的 VGGT-Ω 1B（512 分辨率检查点），吃干净视频帧。提取点固定为全局注意力 层 13 / 头 10（零起点编号；选头过程见 6.4）。关键归一化约定：

  • 教师注意力在所有输入帧的全部 token（含特殊 token）上联合 softmax——这保证了"分配给单个目标帧的总质量"是有意义的量；
  • 源 patch 查询先重采样到学生空间网格再做查询归一化；对每个目标帧，条件 patch 注意力图先空间重采样、再重归一化后取最大值；帧质量单独保留。

论文用 Ā 表示"对齐后的条件图 × 保留质量"。于是对每个源 token a 与目标帧 j，直接缓存两个标量元组而非整张注意力矩阵（省内存的关键）：

ca,j = argmaxv Āa,j(v)，     ma,j = Σv Āa,j(v) Eq. 1 c：候选对应位置（峰在哪）；m：目标帧注意力质量（这一帧总共分到多少注意力）。由于 Ā 的构造方式，对 Ā 求和与求 argmax 恰好还原缓存的质量与对应位置。

6.2 与学生网格的时间 / 空间对齐

时间轴：学生 latent 的时间轴是"每 4 帧取 1 个代表 + 首帧"的结构。对 4n+1 帧的 clip，教师输入帧取时间代表索引 [0, 2, 6, …, 4n−2]（读原视频时加上 clip 的源偏移），得到 n+1 个教师视图，与学生 latent 时间轴一一对齐。举例：81 帧 → 21 个教师视图；241 帧 → 61 个。

空间轴：832×480 分辨率下，学生网格为 30×52（Wan2.1 1.3B / 14B）或 15×26（Wan2.2 5B）。RGB 帧、相机内参与教师目标使用完全一致的裁剪与缩放几何。缓存元数据记录源帧、clip 偏移、网格与教师身份，加载时校验；若从长缓存中读取更短前缀，质量仍取原教师上下文计算的值、不按前缀重归一化。

6.3 置信度：把"质量"映射成"权重"

质量 m 跨越多个数量级，直接用会被极端值主导。论文的做法是——先收集人工可见性标注，再拟合一条 logistic 映射：

  • 标注协议：在 DL3DV 上（81 帧教师上下文）取 55 个场景（48 随机 + 7 个含细结构/遮挡/出画的难例），每页展示 1 个源 token 与来自 7 个时间区间的 7 个目标帧（与注意力质量无关地采样），标注者判断源内容"可见 / 不可见 / 不确定"（标注时看不到注意力统计）。共 803 次判断，剔除 230 个"不确定"，保留 573 对——401 可见 / 172 不可见。
  • 特征选择：比较三种注意力统计量的判别力——log₂质量、1−归一化注意力熵、Top-1 条件响应。按场景分组的 5 折交叉验证下，只用 log 质量的 logistic 回归 ROC-AUC 已达 0.903（30×52 网格）/ 0.932（15×26 网格）；加入熵与 Top-1 仅提升到 0.910 / 0.933。结论：质量单独就够了。
  • 拟合：在全部 573 条确定标注上做类别平衡的 logistic 回归（输入 x = log₂(max(m, ε))），写成 sigmoid((x−μ)/κ) 形式；γ 次幂是经验附加，进一步压低低置信关系。
wa,j = χa,j · [ sigmoid( ( log₂( max(ma,j, ε) ) − μ ) / κ ) ]γ Eq. 9 χ∈{0,1}：缓存中该关系是否有效。ε = 2⁻²⁰（防 log 0）；γ = 2。
网格相关参数 (μ, κ)：30×52 → (−9.86777, 1.81857)；15×26 → (−9.75580, 1.59004)。该映射在静态 DL3DV 上拟合，静态/动态监督共用。

图 6-1：Eq.9 的映射形状。横轴为 log₂ 质量（跨越数量级），纵轴为监督权重。γ=2 的幂次让低质量关系被进一步压低——人工标注拟合的"可见性概率"再平方，等效于对不可信目标更保守。论文的人体实验表明：这条简单的曲线，比"熵 / Top-1 响应"等更复杂的统计量都好用。

6.4 选头：为什么是层 13 头 10

教师层-头对的挑选用参考对应标签做评估（注意：这些标签只用来选头，不进训练）：

  • 静态参考：随机 50 个 DL3DV 场景，用 VGGT-Ω 估计逐视角深度与相机（只保留高置信深度），构造"循环投影"标签——源像素反投影到 3D、投到目标视角落进某 token，再从该 token 中心反投回源视角；仅当双向都在界内、双向深度一致、回投位置足够近时保留（多样本时取循环误差最小者）。
  • 动态参考：TAPVid-DAVIS 30 个动态场景的官方真值点对应。
  • 评估：随机采样输入帧查询 token，遍历每个全局注意力层-头，取每头在各后续视图的最大响应位置与帧质量（Eq.1），与参考标签比对对应误差。

结果：不同头分工显著——层13头0 静态好、动态差；层12头12 动态好、静态差；多数头两者皆差。层 13 头 10 在两类 token 上综合最佳，成为全部实验唯一使用的提取头。这也解释了为什么选头必须静态+动态双集评估：只用其一会被误导。

6.5 软目标：3×3 高斯邻域

老师的 argmax 也只是 token 级离散位置，存在小的定位误差。为容错，目标不做成 one-hot，而是在 ca,j 周围构造 3×3、σ=1（token 单位）的高斯邻域 𝒩(ca,j)：按 token 网格距离算权重，出界位置剔除，剩余归一化到和为 1，帧内其余位置为零：

ya,j(v) ∝ exp( −‖v − ca,j‖² / 2σ² )，v ∈ 𝒩(ca,j)，Σv ya,j(v) = 1；  σ = 1

注意分工：y 说"该匹配到哪"，w 说"这条监督算几分"。y 保留的是教师导出的对应位置本身，而不是复现教师的完整注意力分布——后者会把教师自身的噪声模式也搬进学生。

设计取舍：为什么不直接 KL(教师注意力 ‖ 学生注意力)？

三个理由：① 教师注意力的完整分布包含大量与"对应"无关的模式（比如对特殊 token 的注意力），搬过来是过度约束；② 蒸馏目标是"关系知识"——位置对上即可，形状不必像；③ 分布级匹配会让学生的匹配分布被拉向教师的多峰歧义，而 GAD 实验证明（Table 5）置信度 + 软目标的组合显著优于不加权地全盘接受教师信号（不加权时 Mrate 甚至低于基线）。

07组件二：噪声时间步路由

"在结构正在形成的那一层施加监督。"这是把第 4 章的观察变成机制的一步，也是消融实验中收益最大的单一设计。

7.1 路由规则

设模型噪声时间步 t ∈ [0, 1000]（越大越噪），给定区间边界 0 = b₀ < ⋯ < bK = 1000，按时间步把样本路由到监督层：

ℓ(t) = lk   当   bk−1 ≤ t < bk，k = 1, …, K Eq. 2 K 个噪声区间，每区间指派一个学生层 lk；最后一个区间含 t = 1000。每个训练样本只在一层受监督。

论文在全部三个底座、静态与动态两种设定中用同一张路由表（层编号零起点；边界值归属更高噪声区间）：

噪声区间监督层直觉
t < 850（低噪声）L5（浅层）结构形成区已移到浅层，在那里教
850 ≤ t < 950（中噪声）L15（中层）结构形成区在中层
t ≥ 950（高噪声）L25（深层）结构形成区在深层

注意 t 是网络实际看到的模型噪声时间步（Wan 调度器应用噪声表之后的值），对应归一化插值系数 s = t/1000，而不是训练迭代的整数步号。路由发生在训练采样层面：每个样本抽一个 t，就确定了唯一的监督层。

7.2 为什么必须是"噪声 × 深度"二维对齐

固定层的三种选择（R2–R4：全程 L5 / L15 / L25）都能比基线好——说明对应监督本身有价值；但都显著劣于路由（R8）。更说明问题的是"错配"的三个变体：

  • R5（只在 t≥900 用 L5）：高噪声时结构在深层形成，跑去浅层教 → 几乎白教；
  • R6（只在 t<900 用 L25）：低噪声时结构在浅层形成，在深层教 → 接近无效；
  • R7（低噪声→L25、高噪声→L5，方向反着路由）→ 同样差。

只有"噪声越高、层越深"的正确方向路由（R8）拿到全部收益（Rdist 4.89 vs 固定层最好 6.54，基线 9.57；完整数字见第 11.4 节）。这组消融是"结构形成带随噪声移动"这一观察最硬的证据。

08组件三：学生对应监督

两个子问题：学生拿什么当"匹配分布"（Eq.10 头聚合门控），以及这个分布怎么和软目标比对（Eq.3 逐对应 CE + pairwise/trackwise 两种聚合）。

8.1 学生的匹配分布：多头聚合门控

在路由层 ℓ(t)，取归一化 + RoPE 之后的每头 query/key。第 h 头的原始关系分数为点积：

rha,j(v) = ⟨𝐪ℓ,ha, 𝐤ℓ,hj,v⟩ / √d Eq. 10（上）

哪些头擅长"几何匹配"因层而异，且训练中会漂移，所以不能手工固定头权重。GAD 借鉴 CAMEO，给每个监督层配一个轻量门控 MLP gφ：以 H 维的头分数向量为输入，输出 H 维权重，对 query-key 对逐个计算：

𝜶a,j(v) = softmax( gφ( 𝐫a,j(v) ) )，   sa,j(v) = (1/τ) Σh=1..H 𝜶ha,j(v) · rha,j(v)，   Pa,j(v | 𝒦) = exp sa,j(v) / Σv′∈𝒦 exp sa,j(v′) Eq. 10（下） d：头维；H：头数；τ=1；gφ：H→4H→H 两层 MLP，GELU 激活，末层零初始化（初始时头权重均匀）。每个监督层一个独立门控。辅助 logits 与聚合在 FP32 中计算。门控作用于逐 query-key 分数，不替代生成用的注意力运算。
零初始化的妙处

末层线性零初始化 ⇒ 初始 α = softmax(0) = 均匀分布 ⇒ 初始的聚合分数就是"头平均"。蒸馏信号从头平均出发，让门控自己学着偏向几何能力强的头——一个平滑的、无先验偏置的起点，和 ControlNet 的零卷积、adaLN 的零初始化是同一类工程智慧。

8.2 逐对应交叉熵

对每个源-目标帧关系 (a, j)，候选集合 𝒦 必须包含完整正样本邻域 𝒩(ca,j) ⊆ 𝒦。损失是软目标与学生在候选上的分布的交叉熵：

𝓛corr(a, j; 𝒦) = − Σv∈𝒩(ca,j) ya,j(v) · log Pa,j(v | 𝒦) Eq. 3 聚合多个 (a, j) 的逐对应损失时，用可靠性权重 wa,j 控制每条对应的相对贡献。

8.3 成对监督（Pairwise）：管"帧内空间判别"

采样：不重复地采样有效有向帧对（排除同帧对）；每对内从"有有效缓存对应"的 token 里不重复均匀采样源查询。每个选中的查询与目标帧全部空间 token Ωj 比较——给足完整的空间备选，逼迫学生在整帧里做判别。预算不足时用掩码补齐。

难负样本项：softmax(·|Ωj) 已经隐式对比了全部 token，但论文再加一个显式的难负对比项——用学生自己的 logits 选出正邻域之外得分最高的 Top-Kneg 个负样本：

Z+a,j = Σv∈𝒩(ca,j) ya,j(v) · exp sa,j(v)，    Z−a,j = Σv∈Top-Kneg(Ωj∖𝒩) exp sa,j(v)，    𝓛hard(a, j) = − log ( Z+a,j / (Z+a,j + Z−a,j) ) Eq. 6 Top-Kneg 用学生 logits 选，Kneg = 64；难负系数 η = 0.1。正目标在有效网格邻域内归一化，无效边界位置剔除。

成对损失的聚合（𝒫 为采样的有效关系集合）：

𝓛pair = Σ(a,j)∈𝒫 wa,j · [ 𝓛corr(a, j; Ωj) + η · 𝓛hard(a, j) ]  /  Σ(a,j)∈𝒫 wa,j Eq. 5 置信度加权平均：不可靠对应的损失权重自动被压低。

8.4 轨迹监督（Trackwise）：管"跨时间覆盖"

采样：先采样一个含合格源 token 的源帧；源 token 要求在至少两个其他帧有有效对应（这样才成"轨迹"）。每个源 a 匹配它全部有效目标帧 𝒥a（排除自身帧）。每个 (a, j) 的候选集 𝒦a,j = 正邻域 + 从邻域外不重复均匀采样的随机负样本——不用整帧全部 token，把算力花在时间维度上。

𝓛̄corr,a = Σj∈𝒥a wa,j · 𝓛corr(a, j; 𝒦a,j) / Σj∈𝒥a wa,j，    w̄a = (1/|𝒥a|) Σj∈𝒥a wa,j Eq. 7（上） 源内：先对目标帧做置信度加权平均；源间：以平均置信度 w̄a 为权重再平均（Eq. 7 下：𝓛track = Σ w̄a𝓛̄corr,a / Σ w̄a）。均匀置信度时每个源贡献其目标帧平均损失、与轨迹长短无关；非均匀时，不可靠目标帧在源内降权、平均置信度低的源整体降权。空集产生零辅助损失，实现中对分母做 clamp。

8.5 两支怎么合：系数归一化约定

实现上用总辅助系数 λaux 与两支相对权重 β 来表达 Eq.4 中的 λ₁、λ₂：

λ₁ = λaux · βpair / (βpair + βtrack)，     λ₂ = λaux · βtrack / (βpair + βtrack) Eq. 8 仅一支有效时权重在活跃支上重归一化（该支系数 = λaux）；两支皆无有效监督时辅助损失为零。实验全部使用 λaux = 0.05、βpair = βtrack = 1，即 λ₁ = λ₂ = 0.025。
为什么两支都要

  • R8（完整 GAD）：4.890，比最优固定配置 R4 再降 25.2%，且四项几何指标同时最优——三段路由把不同噪声水平的生成阶段与层级结构正确对齐后，各层在"对的时间做对的事"。

12.2 confidence.py：置信度权重（Eq.9）

回顾公式：w = χ · [sigmoid((log₂(max(m, ε)) − μ) / κ)]γ。输入是教师在目标 patch 上的注意力质量 m（一个 0 到 1 的标量），输出是 0 到 χ 之间的权重。代码里唯一“魔法数字”是标定出的 (μ, κ)，按学生特征网格分辨率二选一：

gad/confidence.pypython
import math
import torch

# 附录 B.3：在 55 个 DL3DV 场景（48 随机 + 7 困难）上
# 以注意力 mass 为特征、可见性为标签的类平衡 logistic 回归标定
CALIB = {
    (30, 52): (-9.86777, 1.81857),   # 832x480 下 1.3B/14B 的 patch 网格
    (15, 26): (-9.75580, 1.59004),   # 480x272 一类的低分辨率网格
}
EPS  = 2.0 ** -20   # 防 log(0)
GAMMA = 2.0         # 陡化系数

def confidence_weight(m: torch.Tensor, grid=(30, 52)) -> torch.Tensor:
    """Eq.9: w = chi * sigmoid((log2(max(m, eps)) - mu) / kappa) ** gamma

    m: 教师在目标 patch token 上的注意力质量，任意形状
    返回同形状的权重，值域 [0, 1]（chi=1）
    """
    mu, kappa = CALIB[grid]
    x = torch.log2(torch.clamp(m, min=EPS))
    w = torch.sigmoid((x - mu) / kappa)
    return w ** GAMMA

三个实现细节：① clamp 在 log 之前（不是之后），保证 max(m, ε)；② γ=2 是幂在 sigmoid 外面，先压平 0.5 附近再保持两端饱和；③ χ（可见性指示）默认为 1，源查询不可见时整个对应直接跳过、根本不会走到加权这一步，所以函数里不出现 χ。

12.3 soft_target.py：高斯软目标（Eq.4）

硬 one-hot 目标会把“对应位置差半个 patch”当作完全错误。GAD 在教师 argmax 位置周围铺一个 3×3、σ=1（token 单位）的离散高斯，出界的邻格剔除后归一化：

gad/soft_target.pypython
import math
import torch

def gaussian_soft_target(c: torch.Tensor, H: int, W: int, sigma: float = 1.0) -> torch.Tensor:
    """Eq.4: 教师对应 argmax 位置 -> 3x3 高斯软目标分布

    c: (N, 2) 教师对应点（学生网格坐标，浮点），取过 argmax 后的位置
    返回 y: (N, H*W) 每行 sum=1（出界邻格剔除后重归一化）
    """
    N = c.shape[0]
    y = torch.zeros(N, H * W, device=c.device)
    cy = torch.clamp(c[:, 0].long(), 0, H - 1)
    cx = torch.clamp(c[:, 1].long(), 0, W - 1)

    for dy in (-1, 0, 1):          # 3x3 邻域，i in {-1,0,1}, j in {-1,0,1}
        for dx in (-1, 0, 1):
            gy, gx = cy + dy, cx + dx
            valid = (gy >= 0) & (gy < H) & (gx >= 0) & (gx < W)   # 出界剔除
            w = math.exp(-(dy * dy + dx * dx) / (2 * sigma * sigma))  # 高斯核
            idx = gy[valid] * W + gx[valid]
            y[valid.nonzero(as_tuple=True)[0], idx] += w

    return y / y.sum(dim=-1, keepdim=True).clamp(min=1e-12)   # 归一化

注意 sigma 以 token 为单位——σ=1 意味着相邻格权重约 0.61、对角格约 0.37、中心格 1.0。如果将来把 patch 化的粒度改细（比如 VAE 下采样 8→4），σ 应该跟着重新考虑，而不是死守 1。

12.4 routing.py：噪声时间步路由（Eq.2）

gad/routing.pypython
import torch

SUPERVISED_LAYERS = (5, 15, 25)   # 零起点层号

def route_layer(t: torch.Tensor) -> torch.Tensor:
    """Eq.2: 三段路由。

    t: 模型噪声时间步 [0, 1000]，不是采样循环的步索引！
       （流匹配下 t 与噪声强度一一对应，见 Eq.11 的 s = t/1000）
    返回与 t 同形状的层号张量（int64），取值 {5, 15, 25}
    """
    t = t.float()
    return torch.where(
        t < 850, torch.full_like(t, SUPERVISED_LAYERS[0]),
        torch.where(
            t < 950, torch.full_like(t, SUPERVISED_LAYERS[1]),
            torch.full_like(t, SUPERVISED_LAYERS[2]),
        ),
    ).long()

最容易写错的两点（也是 Table 4 里 R5–R7 专门惩罚的）：其一，边界归属——t<850 / t<950 的写法让 850 落进 L15、950 落进 L25，即边界归高噪声区间；其二，t 的坐标——是 Wan 调度器里连续的模型噪声时间步，50 步采样时每步的 t 值由调度器算出，与“第几步”不是一回事。训练时每个 batch 会随机采 t，一个 batch 内可能同时命中三个区段——所以返回值是逐元素的张量而不是标量。

12.5 gate.py：头聚合门控（Eq.10）

门控的职责：把 H 个头的内积分数 r 揉成一个聚合分数。结构是两层 MLP（H→4H→H，GELU），末层零初始化——这一步的语义值得反复强调：初始 logits 全 0，softmax(0) 给出均匀头权重，模型从“平均所有头”这个无偏起点出发，由梯度决定最终偏重哪些头：

gad/gate.pypython
import torch
import torch.nn as nn
import math

class HeadAggGate(nn.Module):
    """Eq.10: 逐 (query, key) 对的头聚合门控。每层一份，独立参数。"""

    def __init__(self, num_heads: int, tau: float = 1.0):
        super().__init__()
        self.tau = tau
        H = num_heads
        self.net = nn.Sequential(
            nn.Linear(H, 4 * H), nn.GELU(),
            nn.Linear(4 * H, H),
        )
        # 关键：末层零初始化 -> 初始 logits 全 0 -> softmax(0)=均匀头权重
        nn.init.zeros_(self.net[2].weight)
        nn.init.zeros_(self.net[2].bias)

    def forward(self, q: torch.Tensor, k: torch.Tensor) -> torch.Tensor:
        """q, k: (B, L, H, d)  各头的 query / key
        返回聚合分数: (B, L, L)  —— 与普通单头注意力的分数同形状，
        可直接替换 attn 计算，且推理时可整体丢弃
        """
        q, k = q.float(), k.float()                      # 全程 FP32
        # 逐对头内积: r[b, i, j, h] = <q[b,i,h,:], k[b,j,h,:]>
        r = torch.einsum("bihd,bjhd->bijh", q, k) / math.sqrt(q.shape[-1])
        alpha = torch.softmax(self.net(r), dim=-1)       # (B, L, L, H) 头权重
        return (alpha * r).sum(dim=-1) / self.tau        # 加权求和 -> (B, L, L)

两个容易被忽略的点：① 输入是逐对的 H 维向量（einsum 出来的 bijh），门控看的是“这对 query-key 在每个头上的分数模式”，而不是每头各自的某个全局统计量——这让门控能学到“这对 token 在头 3 和头 7 上都强才可信”这类交叉头的证据组合；② 零初始化的是末层，第一层仍是正常初始化，梯度才能从第一步就流进特征变换。tau=1 只是把温度留在接口里，论文并未调节它。

12.6 losses.py：三种对应损失（Eq.3 / Eq.5-6 / Eq.7）

三个函数分别对应第 6 章的三种监督。先看最基础的逐对应交叉熵（Eq.3）：

gad/losses.py（1/3：对应交叉熵）python
import torch
import torch.nn.functional as F

def corr_ce(s: torch.Tensor, y: torch.Tensor) -> torch.Tensor:
    """Eq.3: 逐对应交叉熵 L = -sum_y y * log softmax(s)

    s: (N, K) 聚合门控输出的对应 logits（N 个源查询 × K 个候选 key）
    y: (N, K) 高斯软目标，每行 sum=1
    """
    return -(y * F.log_softmax(s, dim=-1)).sum(dim=-1)   # (N,) 逐对应损失

pairwise 间隔损失（Eq.5-6）——正例从软目标加权平均得分，难负从学生自己的 logits 里挑 Top-64：

gad/losses.py（2/3：pairwise 间隔）python
def pairwise_loss(s: torch.Tensor, y: torch.Tensor,
                  eta: float = 0.1, k_neg: int = 64) -> torch.Tensor:
    """Eq.5-6: 间隔损失 L = -log Z+ / (Z+ + Z- + eta)

    s: (N, K)  N 个源查询对某目标帧全部 token 的 logits
    y: (N, K)  软目标（正例位置权重高，其余近似 0）
    难负例：按【学生自己的 logits】挑 Top-64 —— 模型觉得最像的位置
    """
    logp = F.log_softmax(s, dim=-1)
    # Z+ : 正例加权几何平均（soft 版正例得分）
    z_pos = (y * logp.exp()).sum(dim=-1)                       # (N,)
    # Z- : 难负例的 log-softmax，排除正例格后取 Top-64
    neg_mask = y <= 1e-8
    hard_neg = logp.masked_fill(~neg_mask, float("-inf"))
    z_neg = hard_neg.topk(k_neg, dim=-1).values.exp().sum(-1)   # (N,)
    # 难负里也可能混着教师认为低置信的位置，不精确排除是刻意的：
    # 论文按学生 logits 排序取 Top-64 作为候选难负集合
    return -torch.log(z_pos / (z_pos + z_neg + 1e-12))

trackwise 集合级 InfoNCE（Eq.7）——每个源帧对齐它的正例集与负例集，置信度 w 双重加权：

gad/losses.py（3/3：trackwise）python
def trackwise_loss(per_frame: list, per_w: list):
    """Eq.7: 轨迹级 InfoNCE 的批内实现。

    per_frame[i]: 源帧 i 的 (n_i,) 逐对应损失（已含对齐损失）
    per_w[i]:     源帧 i 的 (n_i,) 置信度权重 w
    返回 (L_track, w_bar)：w_bar 是帧平均置信度，
    供总损失里给两支做置信度再平衡（Eq.8 的 w-bar 项）。
    空轨迹（<2 个有效目标帧）整条剔除，不参与均值。
    """
    frame_means = []
    for l, w in zip(per_frame, per_w):
        if l.numel() < 2:          # 不足两个目标帧：跳过该源帧
            continue
        frame_means.append((w * l).sum() / w.sum().clamp(min=1e-12))
    if not frame_means:
        return None, None
    L_bar = torch.stack(frame_means).mean()
    w_bar = torch.stack([w.mean() for w in per_w]).mean()
    return L_bar, w_bar

提醒一个容易混淆的点：Eq.7 在论文里是集合级公式（分母 clamp、对负例集求和），上面的实现把它拆成了"逐源帧的加权平均 + 帧间平均"两级——数学上等价于论文附录 A 对 Eq.7 的展开形式，但如果你要严格逐项对齐论文符号，注意 Z+/Z− 的求和范围是该源帧的全部有效目标（正例 + 采样负例），不是全 batch。

12.7 teacher.py：教师注意力提取与缓存（附录 B.1）

这一块是"标签生产线"，也是复现时工作量最大的部分。三个关键动作：选帧（4n+1 学生帧 → n+1 教师视图）、取注意力（第 13 层第 10 头，全 token 联合 softmax 后截 patch 块）、对齐回学生网格（重采样 + 重归一化 + argmax）：

gad/teacher.pypython
import torch

LAYER, HEAD = 13, 10      # VGGT-Omega 全局注意力：第 13 层、第 10 头（零起点）

def representative_indices(n_frames: int) -> list:
    """4n+1 个学生帧 -> n+1 个教师视图: [0, 2, 6, 10, ..., 4n-2]
    例: 241 帧 -> [0, 2, 6, ..., 238]，共 61 个视图
    """
    return [0] + list(range(2, n_frames - 1, 4))

@torch.no_grad()
def extract_teacher_cache(model, frames, src_view, grid) -> dict:
    """跑一次教师前向，抽出 src_view 对所有教师视图的注意力标签。

    frames: (V, 3, H, W) 教师输入（V 个代表视图，512 分辨率）
    src_view: 源视图索引（学生侧对应某个源帧）
    grid: 学生 patch 网格 (h, w)，如 (30, 52)
    返回: {"c": 对应点, "m": 质量分数, "meta": 元数据}
    """
    out = model(frames)                       # VGGT-Omega 前向
    attn = out["global_attn"][LAYER][:, HEAD]  # (V_s, V_t, N_t, N_s) 全局注意力
    # 全部 token（含相机/注册特殊 token）已经联合 softmax 过；
    # 现在按教师 patch 网格截出 patch 块：
    ps = model.patch_slice                    # patch token 的下标切片
    A = attn[:, :, ps, :]                     # (V_s, V_t, P_t, N_s)

    # 质量分数 m：目标 patch token 上、对源视图整行的注意力总和
    m = A.sum(dim=-1)                         # (V_s, V_t, P_t) —— 归一化前单独留一份！

    # 条件分布 c = A / m：重采样到学生网格、重新归一化后取 argmax
    c = A / m.clamp(min=1e-12).unsqueeze(-1)
    c = resample_grid(c, to=grid)             # 双线性重采样到 (h, w)
    c = c / c.sum(dim=-1, keepdim=True).clamp(min=1e-12)   # 重归一化
    corr = c.argmax(dim=-2)                   # (V_s, V_t, h*w) 对应点

    return {"c": corr, "m": m, "meta": {
        "src_view": src_view, "grid": grid, "layer": LAYER, "head": HEAD,
    }}

三处细节直接决定标签质量：① 联合 softmax 的顺序——教师注意力在含特殊 token 的全部输入上联合归一化，截取 patch 块之后行和 m≤1，这个 m 才是第 4 章的"质量"（剩下的质量去了特殊 token，说明对应本身不可靠）；② m 与 c 分开存，缓存里只有 (c, m) 和元数据，没有教师激活——61 个视图 × 每视图一张注意力图的存储量远小于激活本身；③ 短前缀读缓存时 m 不重算（10.1 表格最后一行），保持标签与提取时上下文的一致性。

12.8 trainer.py：组装一切（Eq.8 / Eq.11）

训练器做四件事：给三个监督层挂前向钩子拿 q/k；按 Eq.11 做流匹配插值与主损失；按路由结果选层、采对应样本算两支辅助损失；合成 Eq.8 总损失。为控制篇幅，下面是骨架级但可读的实现：

gad/trainer.pypython
import torch, torch.nn as nn, torch.nn.functional as F

L_AUX = 0.05                      # lambda_aux（附录 C.1）
LAM   = L_AUX / 2                 # beta_pair = beta_track = 1 -> 两支均分
SUPERVISED_LAYERS = (5, 15, 25)

class GADTrainer(nn.Module):
    def __init__(self, dit, teacher_cache, gates):
        super().__init__()
        self.dit, self.cache, self.gates = dit, teacher_cache, gates
        self._hooks = []
        self._qk = {}
        for L in SUPERVISED_LAYERS:        # 只挂三个监督层，别的层零开销
            self._hooks.append(
                self.dit.blocks[L].attn.register_forward_hook(self._mk_hook(L))
            )

    def _mk_hook(self, layer_id):
        """捕获该层注意力的 q_rot / k_rot（RoPE 旋转后的，用于门控）"""
        def hook(mod, inp, out):
            self._qk[layer_id] = (mod.q_rot, mod.k_rot)
        return hook

    def training_step(self, batch):
        z0, cond = batch["latents"], batch["cond"]
        B = z0.shape[0]
        # ---- Eq.11: 流匹配插值 ----
        t = torch.randint(1, 1000, (B,), device=z0.device)
        s = (t / 1000).view(B, 1, 1, 1)
        eps = torch.randn_like(z0)
        z_t = (1 - s) * z0 + s * eps
        pred = self.dit(z_t, t, cond)
        l_fm = F.mse_loss(pred, eps - z0)          # 方向场：预测 eps - z0

        # ---- 对应监督：路由选层 ----
        L = route_layer(t).item()                  # Eq.2
        q, k = self._qk[L]                         # (B, Lq, H, d), (B, Lk, H, d)
        gate = self.gates[L]

        l_pw = self._pairwise(q, k, gate, self.cache, n_pairs=32, n_query=256)
        l_tr, w_bar = self._trackwise(q, k, gate, self.cache,
                                      n_src=256, n_neg=128)

        # ---- Eq.8: 总损失 ----
        if l_pw is not None and l_tr is not None:
            l_aux = LAM * l_pw + LAM * l_tr        # 0.025 + 0.025
        elif l_pw is not None:
            l_aux = L_AUX * l_pw                   # 单支：0.05（重归一化）
        elif l_tr is not None:
            l_aux = L_AUX * l_tr
        else:
            return l_fm                            # 无有效对应：纯底座损失
        return l_fm + l_aux

    def _pairwise(self, q, k, gate, cache, n_pairs, n_query):
        """联合采样: <=32 有向帧对 x 256 查询（覆盖目标帧全部空间 token）"""
        s = sample_pairwise(q, k, gate, cache, n_pairs, n_query)   # (N, K) logits
        y = build_targets(cache)                                   # (N, K) 软目标
        w = confidence_weight(cache["m"])                          # (N,)
        return (pairwise_loss(s, y, eta=0.1, k_neg=64) * w).mean()

    def _trackwise(self, q, k, gate, cache, n_src, n_neg):
        """联合采样: <=256 源帧 x 128 随机负帧；源须 >=2 个有效目标"""
        per_l, per_w = sample_trackwise(q, k, gate, cache, n_src, n_neg)
        return trackwise_loss(per_l, per_w)

几个工程决策值得展开：

  • 钩子只挂三层（L5/L15/L25），其余层的训练路径与底座逐位一致——这是"推理零改动"的训练侧对偶：训练时对非监督层也几乎零侵入。
  • 捕获的是 RoPE 旋转后的 q/k（q_rot/k_rot），门控分数与学生真实注意力的几何量一致；如果捕获旋转前的 q/k，位置编码信息就丢了。
  • 单支重归一化：消融时不是把 λ₁/λ₂ 其中一项清零，而是活动支拿满 0.05——保证消融实验中辅助损失的总量级可比，这是论文对照实验的严谨之处（也是 10.3 表格里"单支消融"列的来源）。
  • l_fm 永远在：对应监督是 λ_aux=0.05 的辅助项，流匹配主损失才是主体——这个比例远小于常见蒸馏工作的 1:1，对应信号是"轻微塑形"而非"主导优化"。

13局限性与未来方向

论文附录 F 坦率列出了三个开放问题——它们同时也是后续研究的三个入口：

13.1 对应目标的天花板在教师

GAD 的监督信号完全来自 VGGT-Ω 的跨帧注意力，因此教师匹配不准的地方，学生不可能学得更好：歧义外观（重复纹理、对称结构）、遮挡边界、运动物体表面——这些区域教师自己的对应就不可靠。论文用置信度权重 w 把这类低质量标签的梯度压到很小（不放大错误），但"压小"不等于"解决"。

两个自然的延伸：其一，换更强或互补的对应证据——比如用多个几何估计器交叉验证、或把光流/深度/多视角跟踪作为第三证据源融合进标签生产；其二，置信度标定流程（55 场景 → mass-only logistic，10.3 节）本身可以在线化，让 w 随教师升级而自适应。

13.2 路由表是手工固定的

三段路由 850/950 的边界与 L5/L15/L25 的指派是训练前写死的，只依赖噪声时间步 t 这一个变量。它没有参与端到端学习，也没有随训练进程调整——Table 4 证明了"方向对就够好"，但也留下了空间：边界可以由训练课程联合学习（比如按重建误差自适应换层），或把离散路由松弛为可微的软路由。风险同样明显：可微化会引入新的超参与不稳定性，GAD 当前的简洁性（一个 if-else）本身是工程优点。

13.3 自回归长视频生成

本文的"长程"是在单次全注意力窗口内的 241 帧；当视频生成走向分钟级、采用滑动窗口自回归（Wan2.2 的时序维度 / 开源社区的 chunk 式续写）时，因果注意力只允许看到前面的 chunk，新内容与更早前置帧之间不存在直接注意力通路——蒸馏出来的对应结构无法跨 chunk 传递。如何让 GAD 的几何一致性在 chunk 之间"接力"（缓存对应图？跨 chunk 蒸馏？），是把它推向真正长视频的关键一步。

14.4 结语：四条带走的话

  • 几何一致性可以是"白来的"。GAD 把跨帧对应作为训练时的辅助监督蒸馏进注意力权重，推理时一行代码不改、一毫秒不加、一字节显存不占——峰值显存逐位相同的实验数据（Table 2）是这类"蒸馏式"方法最漂亮的证明。对比之下，显式几何条件路线（Gen3C/Voyager）在推理时间上付出 4.8×/14.9× 的代价。
  • 监督"什么时候给、给到哪"比"给不给"更重要。路由消融是全文最有信息量的实验：同样的对应标签，监督错层（R5/R6/R7）收益几乎归零，监督对层（R8）比最优固定层再降 25.2%。扩散模型不同噪声水平对应不同的生成阶段，监督信号必须与阶段匹配。
  • 三个损失不是三份保险，是三段频谱。CAT 塑形（哪个 key 该被注意）、PWS 拉开（正负对应要分得开）、TWS 稳轨（长程要稳）；去掉 CAT 后 M_rate 掉到比底座还低——只学"排序"不学"落点"，一致性反而受损。
  • 置信度是蒸馏的前提。教师注意力天然携带质量信号（patch token 上分到的总质量 m），把它显式标定成权重去过滤不可靠标签，比任何"事后清洗"都便宜。任何"从估计器蒸馏"的工作都值得先问一句：你的教师知道自己什么时候在瞎猜吗？

最后回到整体视角：GAD 的贡献不在某个单点技术——交叉熵、InfoNCE、课程式路由都是旧零件——而在于把"几何模型的注意力 = 对应"这个观察，完整地走通了从教师选择、标签生产、时间步-层级对齐、到零开销推理的端到端工程闭环，并用消融实验把每个决策的必要性单独证明了一遍。对想做"一致性增强"或"知识蒸馏进扩散模型"的人来说，这篇论文的实验设计本身就值得精读。
